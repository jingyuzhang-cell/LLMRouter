## 4. 机制证据（这是本轮真正的科学收获）

**4.1 传递丢失被精确回收，且不多不少。**
B 臂 5 块全部命中同一 14 条：D01–D06、A01、A03、A05、A06、A07、A09、A10、E01。
这正是"n1 已提取且落在 4000 字符窗口内"的全部事实——即预注册 §2.3 推导的天花板。
A03、A09、A01 在 A 臂 0/5 到达终端（死于 `[:3000]` 截断），B 臂 5/5 到达；
E01 从 A 臂 1/5 提升到 5/5。**回收量与截断处预测完全吻合，没有额外"凭空增益"。**

**4.2 A 臂的损失根源是容量截断，不是模型能力。**
A 臂 n2 在 **5/5 块**被 768 截断，n9 在 **5/5 块**被 2000 截断（B1 还额外 n7、n8 截断）。
B 臂中间节点输出为 ID 列表，n2/n3/n4/n6/n9 几乎不截断（仅 n8 在 3/5 块截断）。
同一 n1 输出，A 臂在每一块都把中间通道塞满。

**4.3 结构化传递同时降低了成本（反直觉但可解释）。**
C_B/C_A = 0.742。原因：A 臂把 768/2000 的预算花在**截断后重新输出的值**上（且被截断浪费），
B 臂的中间节点只传 `fact_id` 与状态，值由代码从事实库原样注入 n10。
**"更多信息 + 更少 token"在本例中同时成立**——因为信息不再由模型逐节点重抄。

**4.4 零幻觉。** B 臂 5 块 FP 全为 0；A 臂出现 9 条无据数值
（如 `12,100万`、`1.3亿元`、`2016-01-01`、`8,600万元`、`3,800万元`、`2021-05-11`、`2023-07-07`）,
全部来自模型记忆/编造而非本轮窗口证据。

## 5. 必须披露的偏离与缺陷

| 编号 | 内容 | 影响 |
|---|---|---|
| **D1** | A 臂 n3/n4 接线修正（原 V7 因 DEPS/模板键名不匹配，二者恒收空串——已字节验证） | 使 A 臂成为真正可用的"字符截断"对照。A 臂本轮 TP 10–11，高于历史 V7 的 10–11 区间上沿，符合预期；**因此本轮不可与历史 V7 直接比绝对值** |
| **D2** | 模型 glm53flash → **glm-5.3**（coding-plan 配额耗尽；资源包仅覆盖 glm-5.3），标准端点，**思考强制开启（low）** | 两臂同模型，单变量设计不受影响；但与历史基线不同协议，且思考 token 抬高了绝对消耗 |
| **D3** | token 上限 250K → 400K | 实际仅用 176,581，上限未触及 |
| **D4** | B1:B:n10 重复调用 1 次（1,545+985 tok） | 根因：`fed` 由 set 迭代构造，提示词字节顺序不稳定。**已记录为可复现性缺陷**，后续必须改为有序 |
| **D5** | B2 的 n9 输出解析失败（状态词表不符），回退为"全部事实喂给 n10" | 该块 B TP 仍为 14，结论不变；但说明 n9 输出契约仍需规范化 |
| **D6** | A 臂 B2/B3 的 P03（市场禁入）被 v3 计为 TP | **语义误报**：该词在窗口内三次出现全在当事人申辩语。**它抬高的是 A 臂**，方向对 B 有利；剔除 P03 后 A TP 变 [10,10,10,10,11]、配对差变 [+4,+4,+4,+4,+3]，**结论更稳** |

## 6. 结论的边界

1. **单案例**（泽达易盛）；**单模型族**（GLM-5.3，强制思考）。
2. **天花板效应**：B 已达 14/22 的通道上限，本实验无法区分"刚好达上限"与"更高能力"；
   要突破 14 需改 n1 契约或扩大输入窗口——均为另立自变量。
3. B 臂 14 条 TP 稳定复现 5/5，说明收益来自**机制**而非采样运气；
   但 5 块样本量仍不足以做显著性检验，只能陈述配对方向。
4. 未使用人工 Gold（P1 门禁仍 CLOSED）；Silver 为既有 22 条有效事实。
5. **本实验证明的是传递架构，不是 JSON 格式**：B 臂 = 结构化事实库 + 确定性溯源 + ID 引用消费 + n9 核验 + n10 仅组织已核验事实，整体生效；不能拆出"schema 单独贡献"。

## 7. 对研究主线的意义

本轮给出的是**机制层面的因果证据**：
在模型能力、DAG 结构、输入文档全部不变的条件下，**仅改变节点间的信息表示**，
终端质量提升 3 条事实、Precision 提升 14.5pp、成本下降 26%。

这直接支撑后续研究的前提假设——**异构模型分配（V9）与反馈驱动动态调度（V10）的收益，
受制于节点间信息通道的质量**；若通道本身会截断事实，则模型升级与调度优化的收益都会被吞掉。
本轮已把这条通道修好并量化，V9/V10 可以在此之上开展，不必再回到管道修补。
