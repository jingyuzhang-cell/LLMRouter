# STAGE_C_AUDIT — 零调用执行审计（2026-10-30）

> 审计范围：Stage-C 144 run 最终批次 + 3 次失败启动。零新模型调用。
> 结论依据：144 份 trace.json、652 条最终账本、50 条失败账本、运行器源码分析。

---

## 核心发现（必须最优先报告）

### 发现 1：六臂实际执行完全相同的代码路径——**未测试不同策略**

**证据**：
- 144 个 run 的 trace 中，24 个配对组内六臂的节点序列**全部完全一致**（0/24 组有行为分化）
- 运行器源码 `stage_c_v2.py` 中，`run_single` 函数**没有任何基于 arm 参数的分支逻辑**
- 六个臂名称仅在 ARMS 列表定义中出现各 1 次，用于循环标签
- 所有臂使用相同模型（glm53）、相同提示词、相同异常处理

**结论**：Stage-C 实际上执行的是**同一策略重复 144 次**（标注不同臂名），Q 差异完全来自模型输出随机性，不反映算法差异。

### 发现 2：Transport 异常 = 全臂硬中断，无恢复行为

**证据**：
- n3（timeline）被注入 transport 异常后，`obj` 设为 `None`，状态标记 `ANOMALY_TRANSPORT`
- 运行器在 `obj is None` 时直接 `break`，**没有恢复/重试逻辑**
- 没有节点尝试重试 n3 或调整后续节点的模型分配
- 下游节点（n4-n6）全部未执行

**结论**：transport 异常下所有策略 INCOMPLETE 是因为**运行器不支持恢复**，不是因为恢复策略无效。六个臂都没有实现恢复行为。

### 发现 3：tasks_frozen.jsonl 被清空（0 条有效记录）

**证据**：清理过程中写回了空列表（0 valid entries），但 Stage-C v2 运行器不依赖此文件（自足设计）。

**影响**：不影响 Stage-C 结果，但 bench 原有 8 个任务的定义文件已损坏，需从冻结清单恢复。

### 二、六臂动作归因

**六臂完全未产生不同的物理动作。**所有 24 个配对组内：
- 节点序列：一致
- 模型分配：一致（全部 glm53）
- 异常响应：一致（无恢复）
- 唯一差异：模型输出的随机性

### 三、Transport 异常根因

| 分类 | 结果 |
|---|---|
| 异常注入 | ✅ 正确（n3 输出替换为垃圾） |
| 故障检测 | ✅ 正确（parse_status = ANOMALY_TRANSPORT） |
| 恢复触发 | ❌ **无恢复代码** |
| 下游处理 | ❌ 直接 break，无闭包重算 |

**根因**：运行器将 transport 异常视为**不可恢复的终止条件**，而非可恢复的节点失效。六臂均未实现任何恢复行为（无重试、无模型切换、无结构变更）。

### 四、终端评分与合同

- 评分基于 Silver 事实覆盖（简化版），非全维度 Q_eff
- evidence_fail 异常下 Q 非零（0.29-0.71），说明管道在数据降级时仍能产出可评内容
- transport 异常下 Q 非零（0.29-0.50），说明部分 Silver 事实在 n1-n2 的上游输出中已被覆盖

## 当前证据能/不能支持的结论

### 能支持：
1. 修复后的基础设施可以完成 144 个 run 的端到端执行
2. 两种异常类型的行为分化真实（transport=中断，evidence_fail=降级完成）
3. 事件难度差异（E1<E2<E3<E4）远大于策略标签间差异
4. Silver 评分器在非截断条件下可区分质量

### 不能支持：
1. ❌ 动态联合调度优于静态分配（六臂代码路径相同）
2. ❌ R/π/Z 各自的增量贡献（未实现差异化行为）
3. ❌ 异常恢复有效（transport 下无恢复代码）
4. ❌ 并行调度与截止期优化（未测量 makespan/资源）

## 修复要求（下一轮 Stage-C 真正实验的前置条件）

1. **必须为六臂实现真正不同的异常响应逻辑**：
   - Static: 异常→相同模型重试1次→继续原 π
   - SimpleDyn: 异常→换强模型重试1次
   - R_only: 异常→计算恢复闭包→按原 π 重执行闭包
   - π_only: 异常→重试失败节点→对剩余节点重优化 π
   - Joint(R,π): 异常→枚举恢复闭包×π 重优化→选最优组合→执行
   - Joint(Z,R,π): 异常→枚举 Z 操作×R×π→语义守卫过滤→选最优→执行

2. **必须实现 makespan 测量与并行执行**（至少逻辑并行）

3. **必须使用异构模型池**（当前全部 GLM-5.3，Flash 从未被调用）

4. **必须恢复 tasks_frozen.jsonl**
