## 一、假设与统计判定（修正 #1，v1.1 收紧版）

**主指标统一为 Q_F1。最小有意义效应量统一为 ΔQ_F1 ≥ 0.05。**

| 假设 | 内容 | 正向判定 | 负向判定 |
|---|---|---|---|
| H1 | Joint Q_F1 > Static Q_F1 | ≥4/5 种子差值为正 **且** 中位差 ≥ +0.05 | ≥4/5 种子差值为负 **且** 中位差 ≤ −0.05 |
| H2 | Joint Q_F1 > π-only Q_F1 | 同上 | 同上 |
| H3 | Joint Q_F1 > R-only Q_F1 | 同上 | 同上 |
| — | 不满足正向也不满足负向 | — | **不确定** |

**比较优先级**: H2（Joint vs π-only）> H3（Joint vs R-only）> H1（Joint vs Static）。
H2+H3 同时正向且可重复 = **联合调度增量价值成立**（核心科学结论）。
仅 H1 正向 = 联合调度优于静态但不优于单机制（需进一步分析）。

**种子身份**: 5 组独立重复实验（API 的 temperature=0.7 提供随机性，不保证可控种子复现；不冒充可控种子实验）。

## 三、Joint 动作选择机制（修正 #2：归一化 + 覆盖度改契约满足率）

### 3.1 动作空间（不变）

Z: NONE / FALLBACK / MERGE
R: EMPTY / FAILED / DOWNSTREAM
π: KEEP / SWAP_FAILED / SWAP_REMAINING

### 3.2 语义守卫（修正 #4：Z 操作边界）

**Z_FALLBACK 语义边界**:
- 输出契约：降级输出 = 上游原始数据的直接引用（不经模型加工）
- **必须携带 `DEGRADED` 标记**，下游节点收到的提示词中明示"该输入为降级数据，未经模型处理"
- Q_F1 评价中：降级节点产出的内容不计入 Silver 事实覆盖分子，但计入分母（防降级刷覆盖率）
- 缺少必要信息时标记 `UNKNOWN`（不编造）

**Z_MERGE 语义边界**:
- 仅允许向**直接下游**节点合并（一步合并，不递归）
- 下游节点提示词追加原节点任务描述 + 输出契约要求（新字段需在下游输出 JSON 中保留）
- **不改变**终端节点 n10 的输出契约要求（Silver 事实清单不变）
- Q_F1 评价使用**同一套 Silver 事实清单**——结构操作不能通过降低任务要求获得表面成功率

**排除规则**（不变）：Z_MERGE 不适用于终端节点；R_EMPTY 不适用于终端直接上游；PI_SWAP_REMAINING 不适用于已执行 >70% 时。

### 3.3 选择公式（修正 #2：归一化 + 契约满足率）

```
Score = 0.5 × C_norm + 0.3 × K_norm + 0.2 × L_norm

C_norm（终端输入契约满足率）:
  = 终端节点 n10 的全部必需输入端口中，
    在该动作执行后能被有效（非 DEGRADED）数据填充的比例
  值域 [0, 1]（n10 有 3 个必需输入端口：timeline_deep、amounts_checked、verified_facts）

K_norm（成本效用）:
  = 1 − (该动作剩余需执行节点数 × 每节点平均 token 成本) / 全部节点总预算 token
  值域 [0, 1]

L_norm（时延效用）:
  = 1 − (该动作预期 makespan) / 截止期(120s)
  值域 [0, 1]

权重 w = (0.5, 0.3, 0.2)，预冻结
tie_breaker: Z_NONE > Z_FALLBACK > Z_MERGE; R_EMPTY > R_FAILED > R_DOWNSTREAM; PI_KEEP > PI_SWAP_FAILED > PI_SWAP_REMAINING
```

**信息边界**: 选择公式输入 = 图拓扑结构 + 节点执行状态 + 已消耗 token / 已用时间（全部可观测信号）。**不使用**异常注入标签、模型输出质量评分或 Silver 评价结果作为调度输入。

## 四、双异常联合恢复协议（修正 #3）

**统一重规划、节点去重、顺序处理、状态更新。**

```
协议:
1. n3 transport 异常触发第一次重规划
   → Joint 臂枚举动作组合 → 语义守卫 → 选择公式 → 执行
   → 恢复闭包可能包含 {n3, n6, n9, n10} 的子集
   → 已完成且不受影响的节点（n1, n2, n4, n7）禁止重复执行

2. n5 evidence_fail 异常触发第二次重规划
   → 使用第一次重规划后的最新 DAG 状态 + 资源状态
   → 恢复闭包可能包含 {n5, n8, n9, n10} 的子集
   → 与第一次闭包的重叠节点（n9, n10）合并为一次重新执行（去重）

3. 每个异常的恢复动作和成本分别记录（归因独立）
   但重叠节点的执行只发生一次，token/latency 只计一次

4. 控制器只看到节点执行失败/截断的信号（超时、空输出、解析失败）
   不获得异常注入器注入的故障类型标签（防止诊断信息泄漏）
```

## 五、终端指标与两层判定（修正 #5）

### 第一层：质量增量验证

主指标 Q_F1（v1.1 定义不变），判定标准见第一节。

### 第二层：Q/C/L 综合评价

| 维度 | 容忍阈值（预冻结） | 超出阈值含义 |
|---|---|---|
| Cost | Joint 总成本 ≤ π-only 总成本 × 1.5 | 超出 → 报告"质量收益伴随不可接受成本" |
| Makespan | Joint makespan ≤ max(π-only, R-only) makespan × 1.3 | 超出 → 报告"质量收益伴随不可接受时延" |
| Pareto | Joint 在 (Q_F1, Cost, Makespan) 三维中不劣于全部对照臂 | 部分 Pareto 占优 / 完全 Pareto 占优 |

**两层关系**: 第一层正向 + 第二层在容忍范围内 = **联合调度增量价值成立**。第一层正向 + 第二层超出容忍 = **联合调度有质量收益但 Q/C/L 综合不成立**（报告为条件性正向）。

### Silver 代理声明

Q_F1 基于 Silver 事实清单计算，是 Silver 代理指标。正向结果不等于 Gold 质量收益，不用于 P3 冻结。
