## §4 指标族与终端效用（G2）

### 4.1–4.4 五指标族（F4 沿用）：故障节点成功率 / 下游事实恢复率 / 下游事实条件传递率
（仅机制解释，条件化有选择偏差）/ Q_adj（失败计 0 主分析）/ Token / Makespan / 报告率 /
按期正确率；全部按 task/run/fact 保留完整分子分母；因果主张仅限配对臂差分。

### 4.5 终端效用 U（**预登记：方案 A 约束优化**，不拼凑权重）

**主判定（预登记）**：`max Q_adj  s.t.  C ≤ B 且 L ≤ D`（B=该臂分模型与全局预算硬顶；
D=任务截止期）。
- **臂 X 优于臂 Y** ⟺ Q_adj(X) > Q_adj(Y) **且** X 双约束满足（C_X≤B, L_X≤D）。
- 违反任一约束的臂不得凭质量宣称优势（质量优势在约束破坏下不成立）。
- **ΔU(Joint−π) > 0** ⟺ Q_adj(Joint) > Q_adj(π) 且 Joint 双约束满足；等值或约束内不可比
  → 判"无联合增量"。
- **不设综合加权分**（无充分依据的权重不临时拼凑）。
- **辅助描述（预登记）**：五指标配对差 + Pareto 优劣分类（支配/被支配/不可比），只作描述，
  不宣称综合效用提升。

### 4.6 双臂约束可行性与效用比较三态规则（TGV-F8，预登记）

**可行性定义**：臂 X 可行 ⟺ C_X ≤ B（分模型与全局硬顶，按结算 Token）**且** L_X ≤ D（任务截止期）。

| 情形 | 效用比较规则 | 结果字段 |
|---|---|---|
| 两臂均可行 | 比较 Q_adj，更高者占优 | `quality_dominance`（质量占优） |
| 仅一臂可行 | **约束可行性占优**（feasibility_dominance）——不论另一臂 Q 高低；可行臂自身 Q 可能为 0，故**这是"唯一满足约束的候选"，不是正向质量收益** | `feasibility_dominance` |
| 两臂均不可行 | **均不构成有效优势**，仅描述性报告 | 两者皆无 |

- **双维结果字段**：每对比较必须分开报告 `feasibility_dominance` 与 `quality_dominance`，
  不得以可行性占优冒充质量收益。
- ΔU(Joint−π) > 0 的**质量性主张**仅产生于情形 1（两臂均可行且 Q_adj(Joint) > Q_adj(π)）；
  情形 2 只能报告为 Joint 的可行性占优。
- **联合可行性判定（逐模型核验）**：可行 ⟺ `C_total ≤ B_global` **且** `C_m ≤ B_m, ∀m`
  （逐模型独立配额同时满足——只查总量而某模型配额已触顶不算可行）。
- **失败/中止 run**：Q_adj = 0（冻结口径），其实测 C/L 计入约束判定；但**不得解释为成功完成任务**。

## §5 实验组成与统计定位

- **A 档 20 runs 组成（显式）**：**MCF = 2 任务 × 4 臂 × 2 rep = 16 runs**；
  **S3 = 预登记第一任务（按任务 ID 序）× 4 臂 × 1 rep = 4 runs**；合计 20。
  S3 四臂采用**同任务、同前缀配对**：无故障语义下，共享前缀为 π0 正常执行至预登记切点
  （extracts 层完成后），四臂同态分叉。
### 5.2 统计口径（TGV-F7 修正：本轮配对数如实核算，明确探索性定位）

- **本轮（A 档 20 runs）任一两臂比较的配对数上限**：MCF 主实验内 = 2 任务 × 2 rep = **4 对**；
  S3 的配对属无故障条件，**只进 S3 描述性分析，不并入 MCF 主分析**。
- **Joint−π 的有效配对数**：n_eff = （有合法 Z 候选的任务数 × 2 rep）− 缺失配对剔除——若仅
  1/2 任务有 Z 空间，n_eff = 2。**结果报告中必须给出实际 n_eff 的推导**。
- 双侧精确符号检验最小 p 值表（全部非零且同向时）：n=4 → **0.125**；n=5 → 0.0625；n=6 →
  0.03125。**本轮 n_eff ≤ 4 < 达到 α=0.10 的可能**——故本轮定位为**探索性机制验证**，
  不设显著性预登记条款、不作显著性主张、不为缩小 p 值扩大规模。
- 确认性实验为**独立设计**（≥6 非零同向配对、另立预算与授权），不得通过追加本轮 run 数凑配对。
- 零差异限定：p_min=2/2^n_eff 仅在全部配对差非零同向时可达；零差异使 n_eff 下降，如实报告。
- **统计单位与任务簇独立性（收口）**：同一任务的多次重复**不构成独立样本**（受相同任务难度、
  文书结构、依赖与事实分布影响）。报告须分层：
  1. **run-level**：保留全部 4 个配对差，逐次完整报告（n_pair_valid）；
  2. **task-level**：按任务聚合两 rep 形成任务簇配对效果（n_independent_task_clusters ≤ 2）；
  3. 明确三量：`n_pair_valid`（有效配对）/ `n_nonzero`（非零配对）/ `n_independent_task_clusters`
     （独立任务簇数）。
  4/n_nonzero 的 run-level 同向**不等于** n=4 的独立任务证据；簇数 ≤2 时**不作总体推断主张**，
  本轮定位探索性机制验证（一切结论限定于所测任务）。
- 预登记双侧 α=0.10（仅未来确认档适用，且确认档须独立任务簇数 ≥ 所需配对数）；无中期适应；
  缺失配对成对剔除并披露。
