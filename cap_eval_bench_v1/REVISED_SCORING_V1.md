## 3. 操作员四问的直接回答

**Q1：V7 的 16 条 TP（B4）中哪些有文档证据支持？**
**11 条**：D01–D06（6 日期）+ A05/A06/A07/A10（4 金额）+ E01（实体）。
V7 各块支持集稳定为 10–11 条，全部是 D/A/E 类。**所有 P 类处罚事实（P01–P04）与 A02 在任何
臂、任何块中都没有一条是文档证据支持的。**

**Q2：P01 是否键名匹配伪影？是，且是三类伪影的合集：**
- 键名/类别标签伪影：V7-B3 命中于 `"项目": "罚款金额", "金额": "UNKNOWN"`（ctx：`项目罚款金额金额UNKNOWN`）；
- UNKNOWN 状态伪影：V7-B1 命中于处罚类型列表 `"罚款"|UNKNOWN、"警告"|UNKNOWN`——模型在披露**无法核验**，评分器记为命中；
- 否定语境伪影：V7-B4 的 P03/P04 命中于"市场禁入责令改正等**处罚类型未在核验事实中出现**"——模型披露**缺失**，评分器记为存在。
"罚款"在源文档中首次出现于偏移 7244（处罚决定节），超出一切输入窗口——P01 在任何臂都不可能文档提取。

**Q3：A02、P02、P04 是否训练记忆污染？是。**
文档偏移 7657 / 7438 / 7431，全部 >6000 窗口；两臂 n1 均未提取；在 V7-B4 中由 n5/n10 首次产生，
而这两个节点从不接触源文档（字节级证明，见 V8_2_CONTRACT_ATTRIBUTION_ZERO_CALL.md §5）。

**Q4：修正后 V7 的真实质量？**
**Recall_v2 = 0.455–0.500（中位 0.500）；Precision_v2 = 0.769–1.000；F1_v2 中位 0.6268。**
原始 0.748 中约 **0.12 由无据命中贡献**。

## 4. 科学结论

1. **V6→V7 相对结论存活，但效应量缩水 61%**：配对差 4/4 正（不变），
   中位差 **+0.202 → +0.0784**。原增益中约 0.124 来自 V7 更活跃的中间管道放大了
   记忆/伪影命中（n5/n10 的 P 类与 A02 输出），而非文档分析能力。
   n9+n10 容量共扩的真实文档收益仍在（+3~4 条支持 TP/块），但幅度需按 0.078 口径引用。
2. **V8-2 方向性反转（n=1，仅报告方向）**：v2.2 下 V8-2（0.6667）**高于** V7 修订中位
   （0.6268）。原始评分中 V8-2 的"终端为负"部分源于它失去了 V7 所享有的污染通道
   （n2 契约反转→n5/n10 断粮→无参数记忆输出）。GLM53 升级在文档支持口径下**不是负贡献**。
   该结论受 n=1 限制，不作为重开 V8-2 的依据，仅登记。
3. **测量效度的层级教训**：原始求值器的子串匹配在三类语境（键名/UNKNOWN 状态/否定）
   均可产生假阳；加上参数记忆通道，绝对 Q_F1 不可再按面值引用。跨案例（非公开案例）
   验证前，所有管道质量结论按 v2.2 口径引用。
