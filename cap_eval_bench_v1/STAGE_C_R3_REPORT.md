## 1. 可重评分性裁定：材料充足

144 条响应全文（LEDGER_responses.jsonl）+ 逐调用目的标签（run:node:version）足以重建每个 run 的全部节点输出与终端报告；silver（E1 7 条 / E3 6 条）与证据原文在位。**48 run 中 24 个可评分**（有终端报告）；另 24 个为 INCOMPLETE（无报告节点输出）——已逐条记录 `scorable: false, reason: no_terminal_report`，不臆造评分。

## 2. 独立评分器（五维，确定性）

| 维度 | 定义 | 口径 |
|---|---|---|
| C1 完整性 | silver 事实被**报告文本本身**覆盖的比例 | 报告级（非累计端口——这是对 R1 饱和 Q 的修正口径） |
| C2 正确性 | 报告中的日期/金额原子断言对照证据原文：supported / unsupported / contradicted | 矛盾=与同型 silver 事实近邻失配 |

| C5 UNKNOWN 边界 | 任务声明的未知项被标注 UNRESOLVED 而非捏造 | — |

**对照 R1 的饱和 Q（同 cell 全臂 0.542–0.667 且无差异）**：报告级 C1 均值仅 0.167–0.387，且**臂间出现真实排序**。归因分析：覆盖事实全部由后缀节点供应（35 条）或分裂分支供应（5 条），无一来自前缀节点的逐字输出——终端报告的事实经由 verification/分裂节点传递。

## 4. 区分度检验（操作员第 4 项）——部分成立，如实分层

- **能区分**：报告级 C1 把饱和 Q 下的"全同"分解为有序差异；Simple-Dynamic 在 SC-E1 上两重复均 C1=0.000，是**唯一稳健的落后臂**（其"升级强模型重试"未转化为报告质量）。
- **不能稳健区分**：π-only / Joint(R,π) / R-only / Joint(Z,π) 的 C1 差异在 n=2×2 下与任务难度混杂（E1 更难：全臂偏低），无法宣称联合搜索的报告质量优势——与 R1 的探索性阴性结论一致，现在有了**报告级证据**而非仅完成率。
- **Z 贡献（操作员第 6 项）**：S2 下 Joint(Z,R,π) 以 +162 tokens（+3.7%）/+3.9s 换得**唯一存在的终端报告**（C1=0.202、C2=0.250、无矛盾），其余臂无报告。质量收益的诚实表述为"从无报告到有部分经验证事实的报告"，不是高质量交付。

## 5. 必须如实报告的评分器局限

1. C2 的 unsupported 计数偏保守：少量合法派生值（如汇总金额）会被计入 unsupported；本批报告断言极少（每报告 0–4 条），比例波动大。
2. C5 全部为 None：报告**完全未提及**任务声明的 UNKNOWN 项（既未标注也未捏造）——边界处理缺失本身是发现，但无法区分"谨慎回避"与"信息丢失"。
3. 归因按归一化逐字匹配，改写后的事实会漏配。
4. C4 的内部矛盾检测是长度类+前两位近邻的确定性代理，仅捕捉明显捏造模式。

## 6. 核心诊断：终端信息瓶颈（跨臂共性，非策略差异）

所有报告短小（71–486 字符）、大量字段为 UNRESOLVED、C3 可追溯=0、C1≤0.5。机制：冻结的节点 SYS 提示词强制"每字段≤50字"且每节点仅见父节点输出（≤2000 字符/父）——五级链式摘要（idx→extracts→reasoning/timeline→verification→report）逐层丢弃事实与 doc_id 引用。**完成率恢复机制有效，但交付物质量被管道设计压顶**。这不是本批调度的失败，而是下一轮（若获授权）应检验的管道假设：报告节点应可访问多级上游或证据原文（受 Token 预算约束），且 SYS 的 50 字上限需放宽——属未来工作，本轮未做任何修改。

## 7. 结论

1. 历史可重评分性：**成立**（材料充足，24/48 可评分，其余如实标记）。
2. R1 的"Q 失效"诊断被独立证据确认并细化：累计端口 Q 饱和 + 报告级信息瓶颈两层叠加。
3. 报告级评价下：SimpleDyn 稳健落后；π-only/Joint(R,π)/R-only/JointZ 无稳健质量差异（探索性）；JointZ 的 S2 价值=完成率与"有报告"，非报告质量。
4. 对研究方向：SPLIT_VERIFY 的研究信号（结构恢复改变完成结局）依然成立且值得深入，但其**质量**收益的检验需先解决终端信息瓶颈——否则任何调度策略的质量比较都被管道上限压制。
