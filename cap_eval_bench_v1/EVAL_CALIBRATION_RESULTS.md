## 二、原评分器天花板效应分析

### 原评分机制
原评分 = **文档关键词覆盖率**（`hits / len(docs)`）。任务 E04 有 2 份文档、E07 有 3 份——
只要输出提到任一文档中的常见词组即计为"命中"，命中 2/2 或 3/3 即 Q=1.0。

### 天花板证据

| 统计 | 值 |
|---|---|
| 中位 Q | **1.000**（61/89 run 达满分） |
| 零分 run | 25/89（Q=0.0，为 JSON 格式失败或完全偏题，非"质量差"） |
| 有效区分区间 | 3/89（Q 在 (0,1) 开区间内仅 3 个 run） |

**天花板确认：原评分在六策略间中位数全部 1.000，零区分度。**61 个满分 run 中质量差异
被完全掩盖——包括实体幻觉数 0-6 个/运行、日期幻觉、金额幻觉等维度。

## 五、四层结论

### 层 1：评分器本身的有效性

**判定：原评分器（文档关键词覆盖）不可用于策略比较——天花板效应严重。**

- 61/89 run 满分，中位数全 1.000，零区分度
- 遗漏了主体幻觉（205 个不支持实体/89 run）、金额幻觉（32 个）、日期幻觉（4 个）
- 仅 3 个 run 落在有效区分区间 (0,1)

### 层 2：89 个 run 支持的观察

1. **fjc-v1 机制验证成功**：18/36 对模型分配不同（从 0/96 到 18/36 是决定性进步）
2. **质量效果方向不一致**：dQ 均值 −0.046（微降），反馈改变输出后有升有降
3. **策略幻觉差异存在**：R_only 幻觉最少（中位 1.0），SimpleDyn/Joint_R_pi 最多（3.0）
4. **但样本仅覆盖 2 个事件（1 完整 + 1 部分 25%），不可外推**

### 层 3：反馈控制器的真实收益是否可识别

**判定：当前数据不可识别。**

- 原评分天花板使 Q 差异不可测
- 事实级维度（幻觉）方向不一致（R_only 幻觉最少但 Q_mean 最低）
- 89/432 目标 run（20.6%），事件覆盖不足
- 冻结 Silver 参考缺失，无法进行事实覆盖/正确性评估

### 层 4：后续确认性实验的评分前置条件

1. **必须替换评分器**：从文档关键词覆盖升级为事实级评分（覆盖+正确性+幻觉惩罚+UNKNOWN 合规）
2. **必须冻结 Silver 参考**：当前 89 run 无冻结 Silver，需在下一批实验前构建并通过人工裁决
3. **必须测量引用准确性**：终端输出须携带 doc_id 引用（当前无）
4. **必须定义 UNKNOWN 边界**：每个任务需声明不可确认事项（当前未定义）
5. **样本量**：≥4 独立事件 × 6 策略 × ≥3 重复（当前 2 事件远不够）
