## §1 故障模型（F1：两层，严格区分）

**第一层：Real-MCF（真实能力断层）——唯一进入真实实验的处理条件。**
- 节点执行契约从严（R8 式推导合同：双侧来源+显式计算；delta 输出合同）。
- 节点成败**完全由真实模型输出对照契约判定**；适配器不得覆盖、不得注入任何模型条件化结果。
- 模型/节点类型组合按冻结 Stage-B 能力表选定（大差距组合，如 reasoning: flash 0.58 vs
  glm53 0.80），**选择规则与任务提前冻结，不按结果反调**。
- 失败是**随机实现**而非保证：预登记"断层未显现"分支——若弱模型在该节点类型上未持续失败，
  该 cell 如实按 S3 类结局报告，不得事后加严契约或换节点类型。

**第二层：模型条件化契约失败注入（命名如实；仅合成环境）。**
- 用于验证四臂决策逻辑与恢复路径（Static/R/π/Joint 的分化矩阵），**零真实调用**。
- 合成层通过 ≠ 真实能力断层成立；真实层结论只以第一层为准。

## §2 任务结构（F2：终端事实依赖证明，逐任务验收后冻结）

每个候选任务须提交并通过**五项依赖证明**，任何一项不满足即降级或弃用：
1. **独立来源文书清单**（≥2 份，互不为衍生物）；
2. **分书抽取事实清单**（哪些事实必须从不同文书分别抽取，逐一标注出处）；
3. **多上游推导清单**（哪些推导消费≥2 个上游结果，标注消费边）；
4. **故障-下游事实映射**（关键节点失败 → 哪些终端事实必然无法产生，逐一列举）；
5. **恢复/结构空间证明**（是否存在真实替代路径或合法结构重构；若无，**诚实标记该任务
   仅可验证 π 收益，不得用于主张 Z 贡献**）。
禁止以形式层数/节点数充数：上述映射必须落在具体 fact_id 与 node_id 上。候选簇
（E04/E06/E07/E08 等）全部过此验收；任务与映射冻结后方可进入参考构建。

## §3 四臂自主性与 Z 决策空间（F3）

- **决策器自主性**：四臂全部使用冻结决策器；**禁止任何配置级模型提示**（如"故障后切
  glm53"）；π-only 的选择由其冻结规则（能力画像×剩余资源）自主作出，决策轨迹全量落档
  （rounds rationale）。实验若证明的是"指定模型有效"而非"调度器会选模"，即判无效。
- **Joint 的 Z 空间**：任务冻结时逐任务枚举**合法结构候选集**（按冻结 z_candidates 规则：
  SPLIT_VERIFY 需 kind∈{verification, timeline, factcheck_full} 且≥2 个异类健康父节点；
  MERGE 需同 kind 同父集健康兄弟；ADJUST_DEP 需冗余边）。结构变化必须保持终端参考事实
  语义不变（合法性的一部分），其新增执行成本（拆分多付的节点调用）**计入该臂成本**。
  无合法 Z 候选的任务标记 π-only-verifiable，ΔU(Joint−π) 仅对有 Z 空间的任务报告。

## §4 指标族（F4：命名与解释收紧）

| 指标 | 定义 | 解释边界 |
|---|---|---|
| 故障节点成功率 | 分子/分母按 run×node 全量保留 | 局部恢复度量 |
| 下游事实恢复率 | 按 fact 全量分母 | 终端传递度量 |
| **下游事实条件传递率**（Conditional Downstream Propagation Rate） | P(下游事实恢复 \| 故障节点成功)，按 task/run/fact 保留完整分子分母 | **仅作机制解释指标**；节点成功是处理后结果，条件化存在选择偏差 |
| Q_adj（裁决参考覆盖） | 失败 run 计 0 为主分析 | 终端质量 |
| Token / Makespan / 报告率 / 按期正确率 | 结算值 | 资源代价 |

**因果规则**：任何"动态调度带来收益"的因果表述**只能**来自同任务、同故障、同资源下的
配对臂间差分；条件传递率不得单独用作因果证据。

## §5 统计定位（F5：分层，诚实功效）

- **A 档（2 任务 × 4 臂 × 2 rep = 20 runs + S3 描述性 1 cell）**：每对两两比较 n=4 配对，
  双侧精确符号检验最小 p=0.125 > α=0.10 —— **定位为探索性机制验证**，不作显著性主张，
  不设显著性预登记条款。
- **S3 无故障对照**：仅 1 cell → **明确定位为描述性检查**（误触发代价的量级观察），
  不做任何显著性判断。
- **确认性实验（若需）**：≥6 配对（如 3 rep × 2 任务或 3 任务 × 2 rep；n=6 时 p_min=0.03125
  ≤0.10），须单独授权与单独预算表（约 28 runs / ~108 次 / ~200K，超出本次范围）。
- 预登记双侧 α=0.10（仅确认档适用）；无中期适应；缺失配对成对剔除并披露。

## §6 独立裁决流程与分模型预算（F6）

**裁决流程（冻结）**：
1. 参考制备（确定性抽取流水线）与最终裁决**分人**——制备者不得担任裁决者；
2. 裁决者在任何真实 run 之前完成裁决（时序保证**对实验臂结果盲**）；
3. 每条事实记录：原文证据（含位置）、来源文书、计算过程；
4. 分歧处理：第二裁决者复核 → 操作员终裁；
5. 若最终仅能 AI 裁决：永久标注 AI-adjudicated（OPERATOR_DESIGNATED_AI 溯源链），
   不得称独立人类 Gold。

**分模型预算表（A 档；T1 实测均值推算：glm53 ~11.6K/run，flash ~1.9K/run）**：

| 预算项 | 预计 | 硬上限 | 安全余量 |
|---|---|---|---|
| GLM-53 | ~55 次 / ~88K | 75 次 / 110K | ≥22K |
| Flash | ~17 次 / ~10K | 20 次 / 20K | ≥10K |
| 总计 | ~72 次 / ~135K | 100 次 / 150K | ≥15K |
| **停止规则** | **任一单模型配额触顶 → 立即 BUDGET_STOP**（沿用；T1 教训：glm53 曾触 97%） | | |

## §7 推进路线（四阶段，验收条件按本版收紧）

1. **曝光审计**：候选簇文档/事实/派生结果的历史曝光核查 → 冻结候选任务（零调用）。
2. **任务与参考构建**：五项依赖证明验收（§2）→ 参考构建 → **独立裁决**（§6 流程）→
   冻结任务难度与评价标准（零调用）。
3. **机制与合成验证**：冻结 Real-MCF 选择规则 → 合成层模型条件化注入验证四臂分化矩阵、
   缓存/配额/模型身份/fork 三保证、Z 合法候选集（零模型调用）。
4. **GO/HOLD**：统计定位核对（§5）、分模型预算核对（§6）、裁决完成度核对 →
   重新提交完整授权矩阵 → **等待操作员单独授权**。

## §8 明确不做

不修改冻结算法/评分器；不重跑历史；真实层禁止适配器覆盖模型真实输出；不因中途结果调整
故障规则/任务/契约；不把节点级改善包装为终端收益；A 档不作确认性主张；论文暂停。
