# 下一阶段实验设计：终端收益验证（Terminal-Gain Verification, TGV）

**日期**: 2026-10-30 | **状态**: 设计稿（零调用，未启动任何执行；待操作员审定后按预登记流程推进）
**研究问题（操作员原话）**: 「当复杂 DAG 中出现执行异常时，系统能否根据反馈，合理调整恢复范围和
异构模型分配，从而以更低的综合代价获得更高的终端任务质量？」
**设计原则（操作员原话）**: 设计能够发挥动态调度优势的**合理**实验条件，而不是人为制造正向结果。

---

## 一、断点与本设计的对应

| 本轮暴露的断点 | 本设计的解法 |
|---|---|
| 节点级收益出现（S1：glm53 2/2 vs flash 0/2）但未传递到终端 | 任务结构使被治理节点**位于推导链上游**，其产物直接决定终端事实（传递可测） |
| T1 瞬态故障下双方均可恢复 → π 无优势空间 | 新处理条件 **MCF**（模型相关型持续失效）：弱模型在该节点类型持续失败、强模型具备能力——π 的优势前提成为受控实验变量而非臆设 |
| 单因素 π 对照无法回答联合问题 | 四臂阶梯（Static / R-only / π-only / Joint(Z,R,π)），同 fork 配对归因 |

## 二、处理条件（提前冻结；三层情景）

| 情景 | 定义 | 度量目标 |
|---|---|---|
| **S3 无故障对照** | 不注入任何故障 | 动态机制的**误触发代价**（若 π/Joint 在无故障时乱换模型，成本自证） |
| **MCF 持续能力断层** | 指定节点类型上，弱模型（按冻结 Stage-B 能力表选定）每次尝试确定性失败（契约型）；强模型正常 | π 的**必要性场景**：R-only 同模型重试注定耗尽，π-only 换模型可活，Joint 另有 R/Z 自由度 |
| T1 瞬态（已测，归档） | 单次 transport | 作为既有边界参照，不重跑 |

**反作弊保障**：MCF 的"弱模型/节点类型"组合取自**已冻结的实测能力表**（Stage-B 124 次标定，
如 flash 在 reasoning/report 的 Q=0.58-0.60 vs glm53 的 0.80-0.85），不按结果反向调节；
故障位置按"位于关键路径且下游有≥2个推导事实"的**结构规则**自动选定，不人工挑软柿子；
S3 对照强制同场。MCF 实现在**驱动器适配器包装层**（修正案 B 同款模式，冻结文件零改动，
SHA 于授权时冻结）。**外部效度边界如实声明**：确定性断层是能力差异的极端化操作化
（现实对应：上下文上限/严格格式失败等），结论限定于此断层模型。

## 三、任务结构（传递性的来源：真实文书推导链，非人为堆叠）

新任务取自**未曝光**多文档事件簇（候选：E04-zhuoran×3 / E06-huanrui×3 / E07-xiwang×3 /
E08-zhongtie×3；主证据库 31 文档中 22 份未被任何冻结任务使用——预处理第 1 步做全账本
曝光审计确认）。任务 DAG 要求：

1. **深层结构**（≥7 节点、≥4 层）：index → 双 extracts → 推导节点（temporal/cross-doc）→
   verification → report——被治理的节点类型置于推导节点层。
2. **终端事实 = 推导链产物**：参考事实集以跨文档推导为主（间隔天数、双文书数值比较），
   使"节点修好→下游事实恢复"成为直接可测的传递指标（E2-DD-1 型 272 天推导即此类）。
3. 参考构建走已验证流水线：确定性抽取 → 八项式裁决底稿 → **独立裁决**（不再由制备方裁决；
   AI 裁决仅作缺省选项并保留溯源披露）→ 新文件落档。

## 四、四臂与归因阶梯（全部为冻结决策器，零新算法）

| 臂 | 冻结实现 | MCF 下预期 | 归因 |
|---|---|---|---|
| Static | decide_StaticParallel | 死于故障 | 基线 |
| R-only | decide_R_only | 同模型重试注定耗尽 | 恢复范围无模型维时的极限 |
| π-only | decide_pi_only | 换模型后存活 | **π 的净贡献** |
| Joint(Z,R,π) | decide_Joint_Z_R_pi | 存活 ± 结构重构溢价 | **联合增量**（相对 π-only 的差分） |

同 fork 配对（共享前缀至故障触发，四臂同态分叉，前缀去重 + 模型后缀 purpose——本轮已验证的
三项保证沿用）。**预登记判定框架**：若 π-only≈Joint 且均优于 Static/R-only → 收益来自 π；
若 Joint 显著优于 π-only → 结构自适应有独立增量；若 S3 中动态臂成本显著高于 Static →
误触发代价成立，须写入调度器的启用条件。

## 五、指标（五项核心 + 传递分析）

- 五项核心：Q_adj（裁决参考覆盖，失败 run 计 0 为主分析）/ Token / Makespan / 报告生成率 /
  按期正确率。
- **传递分析（新增）**：以"故障节点下游的推导事实恢复率"为条件指标——
  传递系数 = P(下游事实恢复 | 故障节点成功)。本轮断点（节点好≠终端好）由此直接量化。
- 模型使用剖面（每臂切换次数×收益矩阵）；统计：配对差 + 符号检验，预登记 α、无中期适应。
