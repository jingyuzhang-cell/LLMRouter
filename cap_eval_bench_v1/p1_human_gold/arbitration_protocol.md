# P1 分歧仲裁流程

## 触发条件
当两名评审者对同一样本的任一维度评分差距 ≥ 3 分，或对"是否存在致命错误"判断不一致时，触发仲裁。

## 仲裁流程
1. **仲裁者身份**: 第三方（非原评审者、非系统开发者）
2. **仲裁者可见信息**: 
   - 两份匿名评审表（含具体错误列表）
   - 原始终端输出
   - 原始文书文本
   - 密封信封（含系统元数据，仅用于理解上下文，不用于评判）
3. **仲裁规则**:
   a. 仲裁者独立对争议维度给出自己的评分
   b. 取三方中位数作为最终 Gold 分数
   c. 仲裁者记录分歧原因（评分标准理解差异 / 信息遗漏 / 系统输出歧义）
4. **仲裁结果**: 最终 Gold 标签 = 中位数评分 + 仲裁备注

## Gold 标签合成规则
| 条件 | Gold 标签 |
|---|---|
| 双方一致（差距 < 3）且均无致命错误 | GOLD（可信） |
| 双方一致但存在致命错误 | GOLD_NEGATIVE（可信负面） |
| 经仲裁后达成一致 | GOLD_ADJUDICATED |
| 仲裁后仍有分歧 | UNKNOWN（从 Gold 集合中剔除） |
| 样本因执行失败无输出 | 不进入 Gold 集合（记录为 R_delivery 而非 Q_terminal） |

## 质量控制
- 评审者间一致性 (Cohen's κ) ≥ 0.6 方可进入 P2
- 若 κ < 0.6，需要增加评审者培训或修订评分标准
- 每个 Gold 标签附带完整评审轨迹（两份原始表 + 仲裁记录）
