## 一、最终检验规范（正式分析与功效模拟同一程序）

**主终点**：`D_i = TP_Proposed,i − TP_Simple,i`，i = 16 个配对（S3 8 + S4 8）。

**精确符号翻转置换**（`exact_perm.exact_paired_perm`）：
1. 按预登记规则剔除零差值（`m` = 非零配对数）；
2. 非零差值的 `|D|` 计算平均秩（并列取平均）；
3. 枚举全部 `2^m` 种正负号组合：本设计配对总数 16，故 `m ≤ 16`（`2^16 = 65536`）；代码对 `m > 16` **拒绝计算**（严格按预登记边界，不进入 17–20 的近似区），**确认性分析不做近似**；
4. 统计量 `W+` = 正号组秩和；
5. 单侧精确 `p = #{W+ ≥ W_obs} / 2^m`（备择方向：Proposed > Simple）。

**族非伤害门禁（定义）**：分别计算 S3-only 与 S4-only 各 8 对差值的中位数；**任一族中位数 < 0 → 主检验判负**，即使合并 16 对的 p<0.05。门禁与主检验同表报告，不得只报合并 p。

**强制条款**：终局分析入口 `stage_d_final_analysis.py` 是**唯一**的正式分析程序，必须 `from exact_perm import exact_paired_perm`；**禁止** scipy.wilcoxon 作正式 p 值（ties/zeros 下不保证精确）。该脚本的 SHA-256 入清单，执行后、分析前各校验一次。

**H0 对称性（符号翻转精确性的前提，与设计的匹配）**：精确符号翻转检验要求，在 H0 下配对差 `D_i` 的分布**关于 0 对称**；**仅有配对间独立并不充分**。本设计以同源配对使两臂共享同一冻结上游、同一故障时刻表、同一预算与资源约束，差异仅来自策略，从而在分析单位上与对称性假设对齐；但对称性本身不可由数据直接检验，故预登记 **Hodges–Lehmann 配对位置差 + 固定种子 bootstrap 95% CI** 作为旁证，并报告**逐对删除（leave-one-out）敏感性**（结论是否依赖少数极端对）。若数据强烈偏离对称性，主检验结论降级为方向性并如实报告。其余假设：置换单位=一个配对；配对间独立性=分块随机化；跨族合并=设计假设（逐族敏感性优先）；但 Bootstrap CI 与 leave-one-out **不能证明对称性成立**，只能识别结果对少数极端配对的脆弱性；最终报告不得写成“对称性已验证”。**已知残余风险如实登记，不伪造聚类稳健结果。**

**实现验证（可复现）**：
- D2 真实数据反演：S3 `[2,1,0,2,0]` → p=0.125（m=3，8 枚举）；S4 `[7,4,5,7,5]` → p=0.03125（m=5，32 枚举）——与 D2 报告一致；
- 压力测试：8 个相同 +1 → 0.00390625；正负交替 → 0.63671875；全零差 → 1.0；
- 一致性自检：300 个随机并列/零差案例，向量化枚举 == 暴力枚举（逐例精确相等）；
- 交叉验证：无并列连续数据 2000 例，本实现 vs scipy exact **0 不一致**。

**条件性界定（必须随数字一起报告，不得省略）**：

## 五、最终判定措辞（锁定，三分支）

**前提**：主检验（S3+S4 合并精确置换）p<0.05 **且**族非伤害门禁通过。在此前提下，按保护集倒退数分别限定结论：

| 保护集倒退数 | 最终允许的结论 | 明令禁止 |
|---|---|---|
| **0** | "确认性质量证据成立，保护集通过"；可报告机制/安全性验证 | — |
| **1** | "主检验获得确认性质量证据，但保护集呈现混合结果" | **不得**概括为"安全性验证通过"或"全部确认条件通过" |
