## 2. 区间怎样成立

沿用已冻结的F1，不新增权重：

`Q = 2TP / (2TP + FP + FN)`，必要项数R=22，唯一匹配TP至多为`M+U`，其中M是确认匹配、U是UNKNOWN要求数。已确定遗漏、完整组的部分表达、明确不满足均不能凭猜测变成TP。于是：

`Q <= 2(M+U) / (R+M+U)`，因为`FN=R-TP`且`FP>=0`。

该界限**以旧裁决正确、冻结分组及评分范围成立为条件**，不是统计置信区间、世界真值或成功概率。下界0刻意宽松，因为全部输出精度/FP裁决尚未闭合；这不是最紧识别区间，也不表示确认匹配不存在。尤其不能把UNKNOWN替换成正确来计算一个所谓乐观模型得分；这里只推导所有容许情况之外不应越过的外界。

所有12个方向的成对区间比较都不能认证某个模型质量更好。外界上界的大小排序不是Q排序，也不能用来证明动态路由优势或通过Qmin。
