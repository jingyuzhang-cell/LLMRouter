# 文档②：完整联合调度确认性实验协议

## 1. 核心假设

**H1**：反馈驱动的 (Z, R, π) 联合调度相对于强化静态基线，在真实
复杂 DAG 任务上取得稳定的质量-成本-时延净收益。

- Z：恢复范围（不恢复 / 局部恢复 / 更大范围恢复）
- R：合法重执行节点集合
- π：恢复节点及剩余节点的异构模型分配

## 2. 对照组设计

### 2.1 强化静态基线（不是弱基线）

静态基线必须：
- 使用与联合调度**完全相同**的模型池
- 使用相同的模型能力画像（基于独立校准数据）
- 使用相同的初始 DAG 和资源约束
- 在执行前**充分优化**节点分配（基于先验信息的最优静态方案）
- 执行过程中**不做任何**反馈驱动的联合调整

### 2.2 消融策略

| 策略 | Z | R | π | 检验目的 |
|---|---|---|---|---|
| 强化静态 | 固定 | 固定 | 固定 | 基线 |
| Z-动态 | 动态 | 联动 | 固定 | 恢复范围选择的独立贡献 |
| π-动态 | 固定 | 联动 | 动态 | 模型重分配的独立贡献 |
| 全联合 | 动态 | 联动 | 动态 | 完整联合决策的额外贡献 |

### 2.3 公平性要求

- 所有策略从**相同**的任务输入、初始 DAG、缓存版本及模型配置开始
- 使用**相同**的预算、截止时间和终端评分规则（文档①）
- 共享初始执行结果（共同初始输出设计）
- 各策略独立缓存空间，禁止跨策略泄漏

## 3. 任务要求

- 必须包含**真实分叉、跨源汇合和多层依赖**的任务
- 不能将简单任务人为拆分成多节点后声称验证了复杂 DAG
- 至少覆盖 3 种 DAG 结构（链式、钻石、多路径）
- 至少 10 个独立事件（非同源文档）
- 故障类型至少覆盖：截断、格式异常、延迟检测

## 4. 评价框架

### 4.1 主要终点

终端任务效用 U = f(Q, C, L)，其中：
- Q：独立终端评分（文档①的六维度综合）
- C：实际 Token 和现金费用
- L：端到端时延

### 4.2 次要终点

- 逐维度质量得分
- 按期完成率
- 恢复成功率
- 约束违反率
- 逐任务配对效用差 ΔU

### 4.3 Pareto 分析

不只报告加权效用——同时呈现 Q/C/L 三维 Pareto 前沿，展示不同
策略的支配关系。

## 5. 统计方法

### 5.1 样本量

- 以独立事件为统计单位
- 基于先验方差估算：假设效应量 ΔU ≈ 0.05-0.15，方差来自试点
  数据，需要 ≥10-15 个独立事件达到 80% 功效
- 样本量在实验前确定，不因结果方向调整

### 5.2 检验方法

- 逐事件配对差值 ΔU 的符号检验（非参数）
- Wilcoxon 符号秩检验（如果差值分布近似对称）
- 报告效应大小（中位数差值及置信区间），不只报告 p 值

### 5.3 多重比较

如果同时比较多个消融策略，使用 Holm 校正。

## 6. 停止规则

| 条件 | 动作 |
|---|---|
| 任一硬预算上限触发 | 停止，保留部分结果 |
| 联合调度在 >70% 事件上劣于静态 | 提前停止（无效假设成立） |
| 全部事件完成 | 正常结束 |
| 执行缺陷影响公平性 | 停止，标记受影响事件 |

## 7. 成功门槛（预注册）

| 结果 | 解释 |
|---|---|
| ΔU(联合-静态) > 0 且 ≥70% 事件方向一致 | 支持联合调度优势 |
| ΔU ≈ 0 或方向不一致 | 不支持，如实报告 |
| ΔU < 0 | 联合调度劣于静态，报告边界条件 |

**不允许**：实验后修改效用权重、调整任务子集或放宽评分标准。

## 8. 与 H2/H3 的关系

- H1 的结果不替代 H2（D2 机制可靠性）和 H3（图森林增量）
- 三个假设需分别提供证据
- H1 的消融策略可为 H2/H3 提供部分数据，但需独立分析
