# SCORING_AUDIT_FINAL — 独立评分核查（2026-10-30，零调用，operator 裁决 C 交付）

> 基于 89 个冻结终端输出的独立审计。未修改评分代码、未重新执行模型、
> 未调整原始结果——这是**零调用**的评分质量核查。

## 一、原始 Q=1.0 为什么饱和

原始评分 = 文档关键词覆盖率（命中 2/2 或 3/3 文档的关键词即满分）。
89 run 中中位数 1.000——**只要输出提到任何一份文档中的常见词组，
就计为覆盖**，完全无法区分质量。

## 二、新审计指标：原评分遗漏了什么

对每个终端输出独立测量三个维度（零调用，纯正则锚定）：

| 维度 | 测量方法 | 总量 |
|---|---|---|
| 日期幻觉 | 输出中的日期不在任何证据文档中 | 4 个（89 run 合计） |
| 金额幻觉 | 输出中的金额不在证据文档中 | 32 个 |
| 主体幻觉 | 输出中的公司/机构名不在证据文档中 | 169 个 |

**主体幻觉是最大的被遗漏质量问题**——模型在输出中提到了证据文档
中不存在的公司名（可能是常识推断、也可能是虚构）。

## 三、策略间幻觉率差异（原评分完全掩盖）

| 策略 | 原Q_med | 日期幻觉 | 金额幻觉 | **主体幻觉中位** |
|---|---|---|---|---|
| Joint_R_pi | 1.000 | 0 | 0 | **1.0** |
| R_only | 1.000 | 0 | 0 | **1.0** |
| Static | 1.000 | 0 | 0 | **2.0** |
| pi_only | 1.000 | 0 | 1.0 | **2.0** |
| Joint_Z_R_pi | 1.000 | 0 | 0 | **2.5** |
| SimpleDyn | 1.000 | 0 | 0 | **3.0** |

**关键发现**：原评分全部 1.000 的六个策略，在新指标上拉开了差距：
- Joint(R,π) 和 R_only 主体幻觉最少（中位 1.0）
- SimpleDyn 和 Joint(Z,R,π) 主体幻觉最多（中位 3.0/2.5）
- 这提示**联合调度策略在减少无依据主体提及方面可能确有优势**——
  但仅 n=14-15/run，需完整数据确认

## 四、结论

1. **原评分天花板确认**：关键词覆盖在 2-3 文档任务上快速饱和，
   不可用于策略比较；
2. **主体幻觉是被遗漏的最大质量维度**（169 个幻觉实体 / 89 run）；
3. **策略间幻觉率差异存在**——联合策略（Joint_R_pi）幻觉最少，
   但差异的统计可靠性需完整数据；
4. **日期幻觉极少**（4 个 / 89 run）——模型在日期方面较可靠。
