**Bug 精确定位**：`build_prompt()` 中 n3 查找 `ud.get("doc_extracts")`
但 upstream dict 存储的键是 `upstream['extraction']`（角色名）——
**键名不匹配** → n3 的输入为空字符串 → 模型正确报告"无输入" → 
下游全部级联失败。

```python
# 存储时（runner line ~30）:
upstream[roles[nid]] = text    # → upstream['extraction'] = n1_text

# 查找时（build_prompt for n3）:
ud.get("doc_extracts", "")     # → 找 'doc_extracts'，但 dict 里是 'extraction'
# 结果：空字符串传给 n3 的提示词
```
