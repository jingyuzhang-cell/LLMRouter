# 评分参考构建方案（方案 B：双模型交叉核验 + 规则检查 + 分歧审计）

已获操作员批准。当前冻结方案，不启动模型调用。

## 流程

1. **冻结现有材料**：10 任务 / 7 事件 / 原始文档 / 六维评分规范。
   不修改任务，不用调度器输出构造参考。

2. **两个模型独立核验**（需付费授权后执行）：
   - 不同模型家族（如 GLM-5.3 + DeepSeek）
   - 各自获得相同原始材料 + 评分规则
   - 互相不可见对方结果
   - 各自输出：关键事实清单、19 个冲突项判定、不可核验主张
   - 每项判断须附原文证据及位置（可追溯）

3. **规则检查**（零调用，程序化）：
   - 日期/金额/文号/主体/版本逐项核对
   - 两个模型的判断必须能追溯到源文档
   - 模型一致 ≠ 正确——必须有原文支持

4. **分歧处理**：
   | 情况 | 处理 |
   |---|---|
   | 两模型一致 + 原文支持 | 候选参考 |
   | 两模型不一致 / 证据不足 | 标记未决，不强判 |
   | 复杂矛盾/归属/语义 | 降级证据等级，必要时缩小评分范围 |

5. **稳健性检查**：
   - 对未决项采用不同合理判定方式
   - 检查调度策略比较结论是否因判定变化而改变

## 限制（必须标注）

- **双模型一致 ≠ 独立金标准**：共同偏差仍可能同时判断错误
- **7 个事件均曾参与先前实验**：可用于评分流程验证，不构成全新
  独立测试集
- 最终标记为"机器辅助构建、来源证据约束的评分参考"，不声称完成
  双人独立盲评
