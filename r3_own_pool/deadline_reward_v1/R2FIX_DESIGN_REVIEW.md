## 〇、硬预算数学上界核验（操作者 2026-10-25 唯一待确认门槛）

### 结论

**18 次计划调用的最坏费用总和 = ¥0.2824 ≤ ¥0.30（余量 ¥0.0176）。**
运行器在**任何调用之前**断言此总和，超限拒绝启动。逐次最坏费用：

| 调用 | 角色 | 字符界(构造) | 输出上限 | 最坏费用 |
|-----|------|------------|---------|---------|
| 1 | extraction | 3,197 | 2,048 | ¥0.0228 |
| 2–7 | section ×6 | 3,192 | 768 | ¥0.0119/次 |
| 8 | synthesis | 12,365 | 1,280 | ¥0.0309 |
| 9–10 | section ×2 (D2) | 3,192 | 768 | ¥0.0119/次 |
| 11 | synthesis (D2) | 12,365 | 1,280 | ¥0.0309 |

| 18 | synthesis (C) | 12,365 | 1,280 | ¥0.0309 |
| | | | **总和** | **¥0.2824** |

### 为什么必须调低输出上限（操作者判断正确）

统一 2048 输出上限下：**仅输出费用底线 = 18×2048×¥8.52/M = ¥0.3141，
已经超过 ¥0.30**——无论输入如何，原配置数学上不可能硬保证。故按指令
调整为按角色输出上限：extraction 2,048（保持，实测 3,723–4,000 字符
完整输出需此量级）/ section 768（角色聚焦清单，远小于同质全量克隆的
2,981 字符）/ synthesis 1,280（结构化四字段，≈观测到的 2,455 字符
综合）。**截断风险如实冻结**：若某次输出触顶（finish_reason=length），
如实记录并照常评估，不重试。

### 三项核验（对应操作者要求 1–3）

1. **输入界（要求 1）**：HF 不可达（沙箱）→ 采用验证保守界。5 次真实
  交付的 deepseek 调用（fe_recovery 台账，提示词 2,061–9,832 字符，
   从 V2 样本精确重建）实测 **max prompt_tokens/字符 = 0.6259**，
   ×1.15 余量 = **0.7198 ≤ 0.75**（取 0.75 为界）。计费 prompt_tokens
   已含消息封装开销，另加 +128 token 缓冲。字符上界由**构造保证**：
   文档仅入 root 且截断 [:3000]，每个上游答案入提示词前截断 [:3000]，
   模板文本固定（对抗探针：所有上游输出恰 3,000 字符时实测
   root 3,197 / section 3,192 / sink 12,365）。
2. **逐次最坏（要求 2）**：上表——每次调用按其字符界×0.75+128 输入
   token 与其角色输出上限计价。
3. **总和 ≤ 上限 + 机制保留（要求 3）**：¥0.2824 ≤ ¥0.30；派发前
   `spent + worst_next ≤ cap` 逐调用检查保留；计费异常检测保留
   （任何一次实际计费 > 该次准入最坏界 → fail-stop，因数学保证已破）；
   任何 API/解析错误 → INCOMPLETE 停止。正常成本路径无误停验证：
   18 次现实成本走查（¥0.2353）零异常。

**¥0.28 的裁决**：计划级最坏总和 ¥0.2824 > ¥0.28 → 在 ¥0.28 下运行器
会在启动前拒绝（宁可不开跑，不把硬预算降格为估算）。维持 **¥0.30**。

## 一、R2 暴露问题的处置（v1 内容，继续有效）

### 1. 预算护栏（已修正 + 测试）

新模块 `budget_guard.py`：**结算不是安全机制**——每次派发前按实际
提示词长度与该角色输出上限计算最坏单次费用，`spent + worst ≤ cap`
才放行；计划级总和断言先于一切调用；计费异常（实际>准入最坏）即停。

### 2. 分支异质性（真实任务依据）

四分支角色映射到操作者四类节点分类（`capital_event_screening.py`）：

| 节点 | 角色 | 提示词要求 | 专属评分类 |
|------|------|-----------|----------|
| n0 | extraction（=fact_extraction） | 唯一信息入口，输出原子事实 | — |
| b0/x0 | timeline / timeline_deep | 按日期整理事件序列；深化只复核不新增日期 | 日期 d: ×4 |
| b1/x1 | amounts / amounts_check | 汇总涉案金额；复核只核对不新增金额 | 金额 a: ×3 |
| b2 | penalties | 处罚类型/对象/依据 | 处罚 p: ×3 |
| b3 | entity_relations | 主体及角色关系 | 主体 e: ×3 |
| sink | synthesis | 四字段结论；key_dates 取自 x0；缺失如实注明 | — |

异质性来自**输出契约不同**，无人为抑制条款；兄弟输出自然携带的日期
算真实任务属性，判据按此诚实预注册。
