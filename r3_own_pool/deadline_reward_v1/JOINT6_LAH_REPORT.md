# JOINT6_LAH_REPORT — 双阶段 EVSI 前瞻：核验→后验更新→联合重规划（2026-10-28，零调用）

> 本轮唯一任务（operator 指定）：实现并验证"核验—后验更新—联合重规划"。
> 假设（operator 固定措辞）：在预算和截止期受限、异常严重度不确定且核验会
> 改变最优恢复计划的状态下，将 VERIFY 作为信息分支纳入 (Z,R,π) 联合前瞻，
> 能否提高期望终端净效用？——**Tier-1 全部零 API 调用。**

## 算法（LA1，joint6_lookahead.py）

- **EVSI 而非 EVPI**（吸收 operator 指正）：核验观测 y = sev + N(0, σ_v=0.05)
  （不完美）；期望按观测的预测分布加权；每步核验的现金与时延机会成本
  通过缩减后续规划的 (C_cap, D) 显式入账。
- 贪心序贯：每轮对每个未核验故障计算 myopic EVSI（期望重规划值 − 当前
  规划值），核验 argmax 且仅当 EVSI>0；核验后贝叶斯合并、联合重规划。
- 规划器 (R,π)：R-扫描 + π 贪心，与全部基线共享（公平）。
- **信息泄漏审计**：规划只见后验均值；真实 sev 仅用于终值评分。

## 三项验收结果

### 1. LA1 相对强 PJ 的净收益：校准域为零（且这是正确答案），廉价核验域为正

主网格（4 状态域 × σ_s∈{0.17,0.35} × 30 种子，标准核验价 ¥0.004/2.5s）：
**LA1 ≡ PJ（0/30/0 全格），平均核验 0-0.03 次**。EVSI 估计正确判定信息
不值其价——同期所有花钱核验的方法全部更差（ALL −0.15~−9，COSTH 最差
−2.9，RANDV −0.02~−0.05，MEVPI −0.11~−0.17）。**LA1 的价值在该域表现为
"与其他核验策略可区分地不浪费预算"。**

存在域扫描（核验价 ¥0.001/1.0s × σ_s∈{0.35,0.5} × 故障数 3/5）：
LA1 平均核验 0.33-0.77 次，对 PJ **3-4 胜/0-11 负/多数平**，均值 +0.002~
+0.003（如 0.5896 vs 0.5868；0.5260 vs 0.5236）。收益小但方向正确、无系统
性损失（负格 −0.000x 量级）。

### 2. 收益源于计划改变，非信息泄漏或算力不公平（机制证据）

**核验后计划确实改变的种子上，LA1−PJ = +0.021~+0.043；计划未改变的种子上
= −0.001~0.000。** 收益 100% 集中在 (R,π) 被核验观测翻转的情形——正是
operator 要求检验的机制："核验之后系统改变了恢复集合/结构/模型分配，且
调整收益超过核验成本"。PJ_MS（同算力多起点）无法复现这些收益（信息而非
算力驱动）。

### 3. 有收益/无收益的条件域（全报告，含否定域）

| 条件 | LA1 vs PJ | 判定 |
|---|---|---|
| 标准核验价（¥0.004/2.5s），任何 σ_s、故障数 | 0/30/0 平 | **EVSI≤0：不核验即最优** |
| 廉价核验（¥0.001/1.0s）× 高噪声（σ_s≥0.35） | 3-4 胜/16-23 平 | 小而正，机制归因成立 |
| 宽松状态域（全修复可行） | 平（计划对信息不敏感） | 无收益区 |
| 极紧现金（ALL 直接不可行 −9） | LA1 = PJ > ALL | 前瞻避免灾难性信息购买 |

## 诚实边界

1. 全部 Tier-1 合成；σ_s 虽取 H1V8 实测波动，但**严重度分布、观测模型、
   核验价均为构造**——仿真机制成立 ≠ 真实执行有效（operator 提醒吸收）。
   真实验证需把 LA1 接入真实配对运行（需另行授权）。
2. LA1 是 myopic 序贯 EVSI；多节点联合观测的精确前瞻未实现（指数观测
   空间），小故障数下可枚举——留作扩展。
3. PJ 在个别紧域因多起点规划（PJ_MS）+0.02——LA1 的终规划器未用多起点，
   公平起见两者可叠加；不影响核验维度的结论。
4. 收益量级诚实：+0.002~0.003 均值（廉价域），非戏剧性优势。
