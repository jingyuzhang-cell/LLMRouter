# DD_V51_MULTIPONT_ANALYSIS — 多时点反馈重规划分析（2026-10-27，零调用）

## 一、从 CASH30 真实日志构建的两个决策点

### 决策点 1（t=26.5s）：双故障初始规划

| 状态 | 值 |
|---|---|
| 已完成 | n_main（Flash，缓存有效） |
| 失效 | n_sup1（GARBAGE）+ n_sup2（GARBAGE） |
| 未执行 | verify, sink |
| 剩余时间 | 33.5s |
| 剩余现金 | ¥0.030 |

**所有强策略（JOINT/π-only/Alternating）选择相同动作**：repair_both + Flash(n_sup1,verify) + DS(n_sup2,sink)

### 决策点 2（t=49.6s）：verify 完成后的执行偏差

| 状态 | 值 |
|---|---|
| 已完成 | n_main + n_sup1(Flash 7.6s) + n_sup2(DS 3.0s) + verify(Flash 12.5s) |
| 偏差 | verify 实际 12.5s vs 预测 12.1s（+3%，较小） |
| 剩余时间 | 10.4s |
| 已花现金 | ¥0.007（n_sup2 DS） |
| 剩余现金 | ¥0.023 |

**原始计划仍可行**：DS sink（2.4s, ¥0.013）→ 总计 52.0s ≤ 60s, ¥0.020 ≤ ¥0.030。

**→ 本轮偏差不够大，不触发重规划。** 所有策略继续执行 DS sink，结果一致。

## 二、策略在 DP2 的行为分析

| 策略 | DP2 行为 | 结果 |
|---|---|---|
| STATIC/SD-FC | 不重规划 → DS sink | 合规（偏差小） |
| R-only | 不重规划模型 → DS sink | 同上 |
| π-only | 重新优化剩余节点 π | DS sink（无更优选项） |
| SEQ/Alt | 重新运行决策序列 | DS sink（同上） |
| **JOINT** | 重新枚举 (Z,R,π) | DS sink（同上） |

**结论：在本轮实际偏差（+3%）下，重规划不改变任何策略的动作——JOINT ≡ 所有重规划策略。**

## 三、什么条件下重规划会产生策略分化？

### 需要的偏差幅度

| 偏差类型 | 触发重规划的阈值 | 对策略的影响 |
|---|---|---|
| verify 时延 +39% | >+30% 时 Flash verify 逼近截止期 | Flash→DS 切换可能 |
| DS sink 成本 +47% | >+70% 时现金超限 | DS→Flash 降级 |
| **两者同时发生** | verify +39% + sink +47% | **原计划不可行，必须重规划** |

### 双偏差场景下的重规划选项

原计划：Flash(verify 12.1s) + DS(sink ¥0.017) → 偏差后：16.8s + ¥0.025

| 选项 | verify | sink | 时延 | 现金 | 可行？ |
|---|---|---|---|---|---|
| A | Flash | Flash | 22.3s | ¥0 | ✗超时 |
| B | DS | DS | 4.1s | ¥0.027 | ✓（但质量低） |
| C | Flash | DS | 14.5s | ¥0.025 | ✗超时+超现 |
| **D** | **DS** | **Flash** | **11.9s** | **¥0.010** | **✓** |

**选项 D（DS verify + Flash sink）** 是唯一同时满足时间和现金约束的方案——
但它是"反直觉"的（把快的 DS 用在 verify、把慢的 Flash 用在 sink）。

**π-only 可能不会考虑 D**：它的规则是"Flash→DS fallback"（从便宜到贵），不会做
"DS→Flash 升级"（为了省钱而降质量）。

**只有联合枚举（JOINT）会系统性地尝试所有 2^n 组合**——包括"用 DS 替换 Flash
以节省时间，同时用 Flash 替换 DS 以节省现金"这种交叉替换。

### 但：两个节点 × 两个模型 = 只有 4 种组合

即使穷举也很快。**真正的联合搜索优势需要 ≥3 个剩余节点**（8+ 组合），使得贪心
或交替策略可能陷入局部最优。

## 四、JOINT 独有优势的必要条件（汇总）

| 条件 | 当前状态 | 说明 |
|---|---|---|
| ≥3 个剩余节点 | ✗ 仅 1-2 个 | 需要更长的下游链 |
| 非单调质量模型 | ✗ DS≥Flash 全维度 | 需要某维度 Flash>DS |
| **真实资源偏差** | ✓ 已有 | verify +3-39%, sink +47% |
| **交叉替换最优** | △ 可能 | DS verify+Flash sink 组合 |
| 顺序策略无法到达 | △ 待验证 | 需证明 greedy/alt 陷入局部最优 |

## 五、对论文的诚实定位

**已证明的**：
- 混合 π 在现金约束下最优（Flash 免费 + DS 关键）
- 反馈恢复必要性（repair >> no-repair）
- 信息架构 > 模型选择（+400% vs +13%）
- JOINT > SEQ-π→R（+0.13，来自 R 选择）

**未证明的**：
- JOINT > π-only/Alternating（始终等价）
- 多时点重规划中 JOINT 的独有优势
- 反馈驱动的质量估计改善

**下一步最小真实验证**：设计一个 3+ 节点剩余链 + 资源偏差场景（如 verify 和
sink 同时偏差），验证 JOINT 的交叉重规划是否优于 π-only 的单向 fallback。
