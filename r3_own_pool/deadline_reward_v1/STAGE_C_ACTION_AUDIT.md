## 结论

**两臂在全部 4 个配对中执行了完全相同的恢复计划**（相同 R、相同 π、
相同节点序列）。Q 差异（−0.379 至 +0.266）**完全来自模型输出采样
随机性**（temperature>0 的 LLM 在相同提示词下产生不同输出）。

**含义**：
1. Joint(Z,R,π) 在传输级异常下**正确选择了 Z=IDENTITY**——与
   Joint(R,π) 行为一致；
2. Stage-C v2 报告中"Z 无增量"的正确表述应为：**在无结构替代条件的
   异常类型下，Joint(Z,R,π) 与 Joint(R,π) 行为完全一致；观察到的 Q
   差异为输出方差，不构成算法层差异**；
3. Stage-C v2 的 Q 中位排名（Joint_R_pi 0.382 > Joint_Z_R_pi 0.216）
   **是采样伪影，不是算法结论**——校正后两者应视为等价。

## 修正后的 Stage-C v2 结论

| 修正前（错误归因） | 修正后（正确归因） |
|---|---|
| Joint(R,π) 优于 Joint(Z,R,π) | **两者行为等价**（Z=IDENTITY 正确选择），Q 差为输出方差 |
| Z 无增量 | **Z 在此异常类型下正确选择不干预**——不能推广为 Z 无效 |
| π 是主要贡献（保持） | 保持——π 重分配与 R-only/Static 的差异远大于输出方差 |
