# 评分参考审计发现（事实 ID 验证 + 争议裁决）

## 路径 (a) 结果：事实 ID 验证率从 37% 提升至 60%

| 方法 | 验证率 | 改善 |
|---|---|---|
| 证据文本字符串匹配（旧） | 13/35 = 37% | — |
| **事实 ID + 源文档查找（新）** | **21/35 = 60%** | +23pp |

## 关键发现：13 个"一致但不可验证"项

21/35 项完全验证。但 **13 项的事实 ID 在源文档中不存在**：

### CT03（7 个大额金额）
274,749,679.09元 / 264,503,773.76元 / 307,178,200.95元 等大额数字
**不在源文档中**（即使整数部分也找不到）。

**可能原因**：
1. **模型计算值**：两个模型可能从文档中的多个金额计算出总和/差值
2. **幻觉**：不同家族的两个模型独立幻觉出相同数字的概率极低
3. **格式问题**：数字可能以中文大写或其他格式存在

**无论原因如何：这些金额不应纳入评分参考**——它们不是文档中的
直接可验证事实。

### CT06（5 个万元金额）
12,500.00万元 / 2,187.21万元 / 19,804.88万元 等

**同样不在源文档中**。可能来自模型对文档内容的算术推导。

### 处理方式
- 21 个验证通过项：**纳入评分参考**（事实 ID 在源文档中确认存在）
- 13 个未验证项：**排除或标记为 UNVERIFIED**（事实 ID 不在源文档中）
- 1 个部分验证项（CT04 处罚+虚假，"虚假"找到但"处罚"未找到）：标记为
  PARTIALLY_VERIFIED

## CT05 争议裁决

"处罚"关键词**在 CT05 源文档中存在**（上下文：《行政处罚法》…决定对
公司立案）。

- DS=CONFIRMED：正确——"处罚"作为关键词确实在文档中
- QW=REJECTED：可能因"处罚"仅出现在法律引用语境（"行政处罚法"），
  qwen 可能认为这不是一个独立的处罚事实主张

**裁决：DS 判定更准确**。"处罚"作为关键词存在是可验证的；qwen 的
拒绝理由（语境过于泛化）有道理但不影响关键词的存在性。

**纳入评分参考，标注 CT05 处罚词为 CONFIRMED。**
