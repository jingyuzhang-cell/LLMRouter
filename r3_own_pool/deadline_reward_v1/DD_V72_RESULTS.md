> 3 分支，未参与算法开发）上独立验证。零模型调用。

## 跨 DAG 验证结论

### 发现 1：B_r3 上全部算法达到 Oracle（100%）

与 D_r1 不同（π-only/Alternating 在 n5/n6 失败），**B_r3 上没有任何
算法产生 regret**——问题在 B_r3 的结构上仍然是可分的，坐标搜索
足够。

### 发现 2：交互感知的评估效率优势在 B_r3 上减弱

| 指标 | D_r1（开发） | B_r3（验证） |
|---|---|---|
| IB avg evals | 42 | 52 |
| EB avg evals | 74 | 59 |
| **IB/EB 效率比** | **57%（IB 少 43%）** | **89%（IB 少 11%）** |

**D_r1 上的 43% 评估节省在 B_r3 上缩减为 11%**——交互感知效率优势
**未跨 DAG 稳定复现**。

### 发现 3：B_r3 的 DAG 结构差异导致结果差异

| | D_r1 | B_r3 |
|---|---|---|
| 分支结构 | n1→4子节点（大扇出） | n1→3子节点（中等扇出） |
| 关键差异 | n5 和 n6 有**跨源**依赖（n1+n2） | n6 有 3 输入但主要依赖 n1 |
| 资源竞争强度 | 更强（更多节点共享模型槽） | 较弱 |
| 结果 | 坐标搜索在 n5/n6 失败 | 坐标搜索全达 Oracle |

**含义**：联合块优化的优势**依赖于 DAG 的具体交互结构强度**——
D_r1 的跨源多输入节点产生了足够的资源-质量耦合使坐标搜索失败，
B_r3 的结构虽然复杂但耦合不足以区分算法。

## 诚实结论

| 问题 | 答案 |
|---|---|
| Interaction Block 在 B_r3 上达到 Oracle？ | **是（6/6）** |
| 交互感知比 Exact Block 更高效？ | **不稳定**——D_r1 少 43%，B_r3 仅少 11% |
| 联合块搜索优于坐标搜索？ | **条件性**——D_r1 是（6/6 vs 4/6），B_r3 否（均 6/6） |
| 跨 DAG 稳定算法优势？ | **未证明** |

### 按 operator 停止条件

> "如果没有复现，冻结负面结果，不继续针对 B_r3 调参。"

**交互感知的评估效率优势（D_r1 的 43% 缩减到 B_r3 的 11%）未稳定
复现。** 联合块搜索相对坐标搜索的优势也是条件性的（取决于 DAG 的
资源-质量耦合强度）。

**冻结此结论，不在 B_r3 上调参。**

3. R 和 Z 维度从未被激活
4. 代理能力参数未校准
