# 文档①：独立终端评分参考规范

## 1. 目的

定义"什么才算正确、高质量且有证据支持的终端答案"的独立评价标准。
此评价独立于调度器、预测器、恢复机制和完整性护栏——调度策略的
内部质量估计（如 D0/D2 的 Wilson-LB 先验、传播模型预测）不得作为
评分依据。

## 2. 六个评分维度

### 2.1 事实正确性（Fact Correctness）

**定义**：终端报告中的关键事实主张是否与证据文档一致。

**评分标准**：
| 分值 | 含义 |
|---|---|
| 1.0 | 所有关键事实（日期、金额、主体、行为）与文档一致 |
| 0.5 | 大部分正确但有个别非关键错误 |
| 0.0 | 存在关键事实错误（错误金额、错误日期、错误主体归因） |

**同义表达**：允许"任职"="担任职务"等语义等价表达，不要求字面
匹配。评分者需判断语义是否等价，而非仅检查字符串重叠。

### 2.2 证据支持（Evidence Support）

**定义**：主张是否有指定材料的支持，来源是否明确。

| 分值 | 含义 |
|---|---|
| 1.0 | 每个关键主张都有明确来源引用且引用真实存在 |
| 0.5 | 部分主张有来源，部分无来源但内容可能正确 |
| 0.0 | 关键主张无来源支持，或引用了不存在的来源 |

### 2.3 必要完整性（Necessary Completeness）

**定义**：是否保留任务要求的关键事实、日期、金额和主体关系。

**操作化**：在实验协议中为每个任务预定义"必要事实清单"（来源、
主体、时间、数值、关系），评分时逐项检查。

| 分值 | 含义 |
|---|---|
| 1.0 | 必要事实清单全部保留 |
| 0.5 | 缺失 ≤30% 的必要事实 |
| 0.0 | 缺失 >30% 的必要事实 |

### 2.4 矛盾处理（Contradiction Handling）

**定义**：当证据来源之间存在差异时，是否正确呈现差异，而不是
擅自择一或忽略。

| 分值 | 含义 |
|---|---|
| 1.0 | 明确呈现差异并注明各来源说法 |
| 0.5 | 提及差异但处理不够清晰 |
| 0.0 | 忽略差异或擅自选择一方而不说明 |

### 2.5 不可核验拒判（Unverifiable Refusal）

**定义**：当证据材料没有提供依据时，是否明确说明无法核验。

| 分值 | 含义 |
|---|---|
| 1.0 | 对无依据的主张明确标注"无法核验"或"证据不足" |
| 0.5 | 对部分无依据主张做了标注 |
| 0.0 | 将不可核验的内容当作事实呈现 |

### 2.6 问题相关性（Question Relevance）

**定义**：是否真正回答当前问题，而不是复用一份内容看似正确的
旧报告。

| 分值 | 含义 |
|---|---|
| 1.0 | 直接回答当前问题的核心 |
| 0.5 | 与问题相关但未完全回答 |
| 0.0 | 答非所问或复用了不相关的旧内容 |

## 3. 综合评分

终端质量总分 = 六维度加权平均。默认权重相等（各 1/6），可按任务
类型调整但须在实验前冻结。

## 4. 评分流程

### 4.1 冻结时点

评分标准、参考答案、文档版本和判定规则必须在比较实验**前**冻结。
不允许实验后修改评分标准。

### 4.2 双人独立评审

关键样本（至少 20%）采用双人独立评审：
- 评分者不知道输出来自哪种调度策略
- 评分者独立打分
- 计算评分者间一致性（Cohen's κ 或 Krippendorff's α）
- 争议项由第三方复核

### 4.3 与 doc-atom 的关系

doc-atom 覆盖率/精确率可作为**辅助诊断指标**，但不得替代人工评分
作为主要质量依据。已知局限：
- 无法检测实体归属错误
- 无法判断结论语义正确性
- 覆盖率高不等于答案正确

## 5. 参考答案构建

每个任务须在实验前构建参考答案，包含：
1. 必要事实清单（从证据文档中提取）
2. 正确答案要点（每个要点对应文档中的可验证内容）
3. 已知歧义/不可核验项（明确标注）
4. 文档版本变更时的事实更新（如 v1→v2 的数值更正）

## 6. 已知局限

- 本规范定义的是评分框架，具体任务的参考答案需逐任务构建
- 人工评分成本高，适合小规模确认性实验，不适合大规模筛选
- 语义等价判断仍有主观性，通过双人评审和争议复核缓解
- 无法完全排除评分者偏差，通过盲评（不知策略来源）缓解
