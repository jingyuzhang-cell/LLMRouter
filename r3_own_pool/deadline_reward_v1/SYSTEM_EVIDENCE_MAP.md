将研究主线的每个模块映射到：已实现什么、已有何种证据、还缺什么验证。
区分三个层次：**模块存在** ≠ **机制正确** ≠ **性能收益**。

## 证据等级汇总

| 等级 | 含义 | 模块 |
|---|---|---|
| **A：有真实模型证据支持性能收益** | 真实执行+独立评价+配对对照 | 跨轮语义复用（P22-D/E） |
| **B：有真实模型正向发现，需复现** | 真实执行但 n=1，未控制所有变量 | D2 定向修复（EXP4C） |
| **C：有机制级证据，无性能证明** | 零调用验证或模拟确认机制正确 | 质量传播、学习通道、闭包枚举 |
| **D：已实现，无证据** | 代码存在但未验证 | 初始 DAG 优化、Pareto 决策 |
| **E：有负面结果** | 实验显示无效或劣于基线 | 依赖管理额外增量（=0）、全闭包修复（劣于不修复） |

## 关键负面结果（必须保留）

1. **全闭包修复劣于不修复**：C 臂 coverage=0.000 vs D0=0.667（EXP4C）
2. **依赖感知额外增量 = 0**：当前匹配器下 D ≡ C+（P22-D 零调用+真实）
3. **早期异构分配落后单模型**：分解有损失（早期 DAG 实验）
4. **90s 截止层全臂迟到**：截止时间-奖励校准问题（多轮实验一致）
