## 2. 核心发现：画像更新**未改变任何调度决策**

对全部 96 个节点级模型选择逐对审计（48 run × f3-f6 各 2 节点）：

| 审计项 | 结果 |
|---|---|
| frozen 与 feedback 模型选择不同的节点 | **0 / 96** |
| frozen 与 feedback 模型选择相同的节点 | **96 / 96** |

**原因**（从 runner 代码可证）：`predict_pi` 的决策规则是
"选 GLM 若 glm_q > flash_q 且预算内"——两个画像中 GLM 的质量估计均
高于 Flash（未变），GLM 的成本估计也未变。反馈仅下调了 Flash 的
质量/成本估计，但 Flash 本来就不被选中，**不影响任何决策**。

**这意味着**：
- Q1 的"反馈更新使质量下降 0.164"**不能归因于画像更新**——调度器
  在两种画像下做出了**完全相同的模型分配**，Q 差异 100% 来自 LLM
  输出随机性；
- **正确的结论是：当前的反馈更新方法（仅调 Flash 参数）过于保守，
  未能改变任何调度决策**——不是"反馈方向错误"，而是"反馈无效"。

## 5. 对论文的影响

**反馈学习的正确研究问题重述**：
- 不是"反馈更新是否改善调度"（本次更新没有改变决策，无法回答）
- 而是"**怎样的反馈更新才能真正改变调度决策**"——需要更积极的
  更新策略（如同时调整 GLM 参数、改变决策规则、收紧预算使 Flash
  被强制选择于某些节点）

**方差主导问题**：
- 48 run 中 6 个 Q=0（12.5%）、同条件重复间 Q 差最大 0.6——
  **单任务 n=2 重复完全不足以区分策略效果**
- 后续实验需要：更多重复（n≥5-10）或更多任务（利用任务间方差
  而非任务内方差）
