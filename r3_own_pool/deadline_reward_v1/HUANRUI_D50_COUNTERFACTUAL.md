# HUANRUI_D50_COUNTERFACTUAL — 零调用截止期反事实回放（2026-10-27）

方法：用 D=50s 运行的**实测每臂时延**（从账本逐调用修正）和**实测 Silver 质量**，
在 D=50-100s 区间做反事实 eU 回放。这是回放（非新执行），数字代表"如果 D 设为 X，
本轮已执行的臂会得到什么效用"——不改变已花费用，也不预测新抽样的时延。

**翻转点**：D=52s——JOINT 时钟 51.6s 首次按期，eU 从 −2.10 跳到 +0.44，从最差之一

**J−π = 0 恒成立**（同动作共享执行）——本轮仍未证明联合搜索优于最强独立优化。

## Flash 时延漂移敏感性（±15%，仅影响前缀时钟）

|---|---|---|---|---|

| 标称 | 51.6s ✓ eU=+0.44 | 43.8s ✓ eU=+0.17 | 51.6s ✓ +0.44 | 43.8s ✓ +0.17 |
| **+15%** | **56.4s ✗ eU=−2.09** | 48.6s ✓ +0.17 | **56.4s ✓ +0.44** | 48.6s ✓ +0.17 |

**D=55 的漂移风险**：+15% 漂移下 JOINT 超期 1.4s（56.4>55）→ 再次被摧毁。
**D=60 在全漂移带内稳健**：+15% 后 56.4s 仍 ≤60 → JOINT 稳定胜出。

## 结论

1. **D=50s 的 1.6 秒边际迟到是唯一的失败原因**——D≥52 时 JOINT 的质量优势
   （0.500 vs 0.200）使其稳定最优
2. **D=60s 是安全的重跑选择**：±15% 前缀漂移带内 JOINT 均按期；D=55s 在 +15%
   漂移下仍有 1.4s 风险
3. **J−π=0 结构性问题依旧**：本轮 JOINT 与 π-only 同动作——联合搜索的独有增量
   仍待在 JOINT≠π-only 的状态上验证
4. **不需要新模型调用即可得到本结论**——反事实回放零成本完成

## 建议

- **最小验证**：D=60s 重跑欢瑞（预算同前 ~18 次/¥0.12），验证反事实预测（JOINT
  应按期且 eU≈+0.44）；如果时延漂移使预测失效，如实报告
- **结构改进**（零调用）：修改 π-only 的 R 规则使其不再恰好与 JOINT 同动作——
  例如 π-only 使用 Flash 可行性检查而非联合可行性，在 targeted+Flash 不可行时
  降级为 accept+DS（而非升级为 targeted+DS）——这将使 JOINT(targeted+DS) ≠
  π-only(accept+DS)，真正测试联合搜索的独有价值
