## 第二轮收束附录（operator 裁决吸收，2026-10-28 晚）

### 固化的四项原则

1. **逐项关键事实至上**：多数锚点覆盖（0.596）只是辅助条件；任务不可
   缺失的关键事实（处罚金额/对象/决定日期等）须**逐项满足**，不得被
   整体覆盖率抵消。
2. **单模型边界标注**：本实验 API 池 Flash-only——**π 维度固定，未测试
   异构模型重分配收益**；报告不更改冻结策略名，但必须注明此边界。
3. **动作空间差异≠纯算法优势**：非 Z 策略无替代动作是定义差异；结果
   不得解释为"排除动作空间差异后的纯搜索优势"。
4. **两道门序列**：窗口3独立参考对齐 → 140 次真实请求单独授权；
   113 次干跑≠真实成本测量。
