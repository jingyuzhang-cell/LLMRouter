## 第一步：决策模型可靠性审计（完成，12 个真实故障决策点）

**先修一处数据错误**：H1V7 行的 fault 字段此前缺失（v7 结果 JSON 未含），
按冻结协议补齐 S1→b0、S2→b2。修正后各决策模型排序：

| 决策模型 | 错误 | 平均遗憾 | 判定 |
|---|---|---|---|
| **FLR（位置先验：{b0,x0}→修，其余→受）** | **2/12** | **0.0077** | **真实数据最强** |
| THRESH（cov<0.318 硬阈值） | 4/12 | 0.0261 | |
| ER（幅值加权后验规则） | 6/12 | 0.0377 | 精度降但遗憾降 |
| PJ（LOO 贝叶斯通道） | 8/12 | 0.0555 | |
| COSTH/ALL（购买信息） | 7/12 | 0.077-0.087 | 成本吞没 |

**PJ 的 8 次错误逐点归因**（可多因）：
- **6/8 特征选择错误**：位置先验单独即可答对的点，cov-only 通道把它们
  判错——决策模型丢弃了最强预测特征（故障位置/角色）；
- **5/8 中频带信号歧义**：cov∈[0.25,0.55] 处两类条件分布近完全重叠
  （修 0.34 vs 受 0.39），任何 cov 估计器在此带都接近抛硬币；
- **3/8 薄样本过度自信**：如 Z-b1_r1 通道输出 p=0.99 却错（n=11 的 LOO
  高斯在尾部外推失真）；
- **0/8 优化器错误；0/8 约束判断错误**：同样的 argmax 机制配上更好的
  后验就会答对。

**审计结论（回应 operator 的"根本问题"怀疑——成立）**：
瓶颈在**决策模型的特征与后验层**（用什么观测、怎么校准），不在联合搜索层。
真实数据上最强的是最简单的位置先验；cov 作为附加特征在此样本上无增量
信息。这意味着 DD-V5.2 及后续任何搜索算法创新的收益上限，受制于决策模型
可靠性——与 operator 警示"优化器无法修复不准确的 Q/C/L 预测"一致。

## 第二~四步：增量联合重规划平台（建成、测量、停止条件触发）

**平台**（`dd_v52_incremental.py`）：真实 r2fix diamond-8 DAG；反馈
(时延,token) 逐调用 bootstrap 自冻结账本（v7 92 + v8 111 次真实调用）；
故障事件（即时检测/迟检测，位置取自真实协议 {b0,x0,b1,b2}）；预测层
评估器（token 计价 eU=真实形状，现金=硬约束，层级并行时延预测——三次
实现修正均有记录：¥计价惩罚→token 计价、平串→层级并行、缓存 key
→限制语义）。修复语义=闭包；已执行节点锁定、仅 R 可重执行。

**对比表**（3 事件集 × 4 种子 × 2 约束域，预测层；可行率 0=全部超期

**停止条件触发（如实报告，不调参翻案）**：
1. **规模不足**：n=8 的真实 DAG 上，冷启贪心以 ~100 次评估即达穷举质量
   （本平台第三次独立确认"小规模=搜索无瓶颈"）。增量维护可省的评估，
   相对一个本来 100 次就够的基线，**没有可测的收益空间**。
2. **实现边界**：真正的 O(1) 缓存补丁要求**按层级分量存储**（当前实现
   在限制后无法从聚合量精确重构层级时延，导致预检路径全部跳过、命中为
   0）——精确增量维护的算法设计已明确（per-level max 分量、限制时仅对
   最大值被删除的层级重算），但即便完美实现，在当前规模也不改变结论 1。
3. 增量优势若要可测，需要 **≥15-20 节点、每事件候选空间 ≥3^10** 的任务
   族——现有真实任务不满足；人工扩节点制造优势被 operator 规则禁止。

## GO/HOLD 结论

- **HOLD（真实调用）**：无任何新实验获授权建议；增量重规划在现有真实
  规模下无可测收益，不进入真实配对。
- 决策模型层的教训进入主线：后续任何调度算法工作必须先过"决策模型
  可靠性"关（特征选择 + 后验校准），位置先验是当前最强基线，新观测
  特征须证明对位置先验有**增量**信息（T2 已证 cov 无）。
- 论文继续暂停；付费 HOLD 保持。
