## 0. 研究问题与收益三分解(不变,自 V1)

**问题**:DAG 执行出现故障时,联合优化恢复范围与后续节点模型分配
a=(Z,R,π),能否比固定恢复策略更有效地实现按时、正确、低成本完成?

以四臂平均任务奖励 μ_SS, μ_DS, μ_SD, μ_DD 定义:

| 量 | 定义 | 回答的问题 |
|---|---|---|
| B-REC | μ_DS − μ_SS | 动态恢复决策本身的收益 |
| B-REA | μ_SD − μ_SS | 节点级模型重分配本身的收益 |
| B-JOINT | μ_DD − μ_DS − μ_SD + μ_SS | 两机制的**交互效应**(可为负) |

## 1. 确认性与次级统计假设(V2 修订 1:两个问题分开回答)

**四个确认性主检验(Holm 校正族,单侧,方向预注册):**

| # | 假设 | 统计量 |
|---|---|---|
| H1 | B-REC > 0 | μ_DS − μ_SS |
| H2 | B-REA > 0 | μ_SD − μ_SS |
| H3 | **B-JOINT > 0(正交互效应)** | μ_DD − μ_DS − μ_SD + μ_SS |
| H4 | 完整方法优于静态 | μ_DD − μ_SS |

**关键次级优势检验(预注册,独立于 H3,不得混用;V2 勘误:交并法):**

| # | 假设 | 统计量 |
|---|---|---|
| S1 | μ_DD > μ_DS **且** μ_DD > μ_SD(同时优于两个单独方法) | 两个单侧配对检验构成**交并检验(IUT)** |

**S1 的完整判定规则(冻结)**:
- S1 = min( 单侧配对检验(μ_DD > μ_DS), 单侧配对检验(μ_DD > μ_SD) );
  **两个都显著才判 S1 成立**。
- IUT 的整体 α:每个分量在 **α = 0.05** 下单侧配对检验(交并法下
  两分量各取 α=0.05 的 IUT 整体第一类错误 ≤ 0.05,无需再合并)。
- p 值产生方法:任务级配对置换检验(符号翻转,≥10⁴ 次重抽样,与
  H1–H4 的 p 值方法一致,见下)。
- 与 Holm 族的关系:S1 **不进入 H1–H4 的 Holm 校正族**(它是次级
  假设,IUT 已自带多重性控制);论文同时报告 H3 与 S1 时,表述规则
  如下,不得混用。

**声明规则(V2 明确)**:交互效应显著(H3)不得被表述为"完整方法
最好";完整方法最好(S1)不得被表述为"存在正交互"。二者是不同的
科学命题,论文分别报告。(反例已内化:μ=0.40/0.55/0.50/0.62 时
B-JOINT=−0.03 而 D/D 最强——该情形下只能宣称 S1 不能宣称 H3。)

## 2. 对照臂(2×2 因子 + NONE 地板;自 V1 不变)

| 臂 | 恢复 | 分配 | 隔离 |
|---|---|---|---|
| S/S | 固定(见 §3 选择规则) | 计划模型 | 参照 |
| D/S | 动态(Z,R 奖惩决策) | 计划模型 | B-REC |
| S/D | 固定配方(同 S/S) | 动态 π | B-REA |
| D/D | 动态 | 动态 | B-JOINT / S1 / H4 |
| NONE | 不恢复 | 计划 | 地板(语义检查,不入主检验) |

配对原则:同一冻结故障面板(同种子/任务/故障节点),任务级配对;
全部估计为任务内差分。D/S、S/D 为已实现代码的**消融配置**——
**实现开关状态:待代码与测试证据独立核验**(见 §9)。

## 3. S/S 静态参照选择规则(V2 修订 3:操作者裁决 1)

在**独立校准数据**上(Calibration GO 阶段产出,与试点/确认面板
不相交),按**预先规定的任务奖励准则**选择唯一固定静态臂:对每个
候选静态臂(NONE/C/D/E),用校准画像 + 冻结任务面板做**零真实调用
的先验推演**(与 Stub 相同的引擎,画像换为校准值),取推演平均
R_task 最高者。规则、候选集、推演方法在推演前冻结;**试点与确认
数据不得参与选择**。

## 4. 截止时间三档(V2 修订 4:操作者裁决 2 + 重要限制)

D 规则:**独立参照分布**(校准阶段的 S/S 推演完成时延分布)的
**P40/P60/P80** 分位点,逐任务生成三档(紧/中/宽),写入冻结面板。

**限制(按操作者裁决原文)**:P40/P60/P80 是**生成规则**,不保证
静态参照实际获得 40/60/80% 按时率;实际按时率作为**实验结果报告**,
**不得事后调整 D 追求目标比例**。D 的分布、每任务取值在试点前
冻结,确认期间不可变。

**三档 D 的任务分配、分层与配对规则(V2 勘误,冻结)**:
- **每任务只分配一个档位**(不跨档重复执行同一任务),避免任务
  难度与档位混淆;150 个任务 = 3 档 × 50。
- **分层随机分配**:先按校准阶段可得的先验难度代理(静态推演的
  S/S 完成时延分位)将任务池分层,层内用冻结种子的置换随机把任务
  均匀分配到紧/中/宽三档;分配表在试点前冻结。
- **五臂严格配对**:同一任务在五个策略臂中执行时共享同任务、同
  故障注入、同 D 档;档位只随任务变,不随臂变——B-REC/B-REA/
  B-JOINT 全部是同任务同档内的臂间差分,难度与档位效应被配对
  消除。档位间的比较(如机制收益是否随紧度变化)作为**探索性
  分析**报告,不进入确认性族。

## 5. 试点与确认(V2 修订 5+9:两段设计与时间顺序修正)

**试点**(操作者裁决 3):每档 50 个**不同任务**,三档共 150 任务,
五臂配对执行 → 750 个任务—臂执行单元。(注:执行单元 ≠ 模型请求
数;恢复重试、切换、失败调用、校准均另计,见 §7。)

**时间顺序(V2 修订,消除 V1 矛盾)**:
- **试点前冻结**:任务来源与清单、D 生成规则、故障面板种子、奖励
  公式与权重(校准后冻结的正式值)、臂定义、S/S 选择规则、分析
  方法、功效计算方法、最大资源上限。
- **试点后、确认前冻结**:按**预注册的功效计算方法**由试点效应量
  与方差确定确认样本量(目标 power ≥0.8,α=0.05,Holm 校正后),
  生成确认实验冻结文件(独立哈希)。试点数据**不得**混入确认分析。
- **确认开始后**:不得依据结果调整样本量、终点、D、面板或权重;
  预算硬帽触发即停对应臂(StopRun 语义)。

**主终点**(操作者裁决 4):任务级 **R_task**(冻结公式,真实
q/C_full/T/D);**按时正确率为关键次级终点**(McNemar 配对)。

**H1–H4 的 p 值与 Holm 流程(V2 勘误,冻结)**:
- 每个假设 Hk 的统计量为任务级配对差 d_i(臂 A 的 R_task 减臂 B
  的 R_task,按假设方向定 A/B)。
- **单侧配对 p 值:符号翻转置换检验**——p = (#{|T_perm| ≥ |T_obs|
  且方向一致} + 1) / (2^n + 1) 的精确/蒙特卡洛形式,n = 任务数,
  ≥10⁴ 次随机符号翻转;同时报告 BCa 配对 Bootstrap CI(≥10⁴)作为
  效应量区间,但**假设检验以置换 p 值为准**。
- **Holm 流程**:将 H1–H4 的四个单侧 p 值升序排列 p(1)≤…≤p(4);
  逐个与 α/(4−k+1) 比较(k 为名次),首个不显著即停;全部通过才
  可宣称族级 α=0.05 下的确认性结论。H4 的结论表述以 H1–H3 的
  通过情况为条件语境(联合机制贡献需 H3)。
- 方向全部预注册为正(见 §1);单侧若在试点中发现方向为负,确认
  段照原方向执行并如实报告(不得翻转)。

## 7. 资源与硬预算上限(V2 修订 10:不提前宣称量级)

**计算方法(冻结于 Calibration GO 前)**:
- 校准:Σ over (节点×模型×家族) 目标次数 ×(单次请求 P95 token +
  预留)× 安全系数;GPU/墙钟按每格测量批的启动/切换上限计。
- 试点:750 执行单元 ×(单元请求数 P95:含计划调用+恢复事件上界+切
  换不增加请求)+ 校准总量;token 同法。
- 确认:样本量 N(功效计算产出)× 五臂 × 单元 P95 + 全部试点量。
- 全部量以**预算包络审计文件**为准(预留-结算硬帽,campaign 级
  reserve/settle);**在包络审计完成前,不宣称总量低于 Formal
  campaign**(V1 的那句估算作废)。

## 8. B4/T1 的真实实验落地(自 V1 精化)

- **B4**:校准阶段对每(节点×模型)时延做分布族拟合检验(正态/
  对数正态/经验;KS/AD,显著性预注册)。通过检验的格用解析 E1;
  未通过的格用**经验分位/Bootstrap 按时概率**。估计器选择随
  PRIORS_REAL_V1 冻结,确认期不可换。
- **T1**:校准与验证阶段(确认实验开始前)实测共居任务等待,校准
  contention 估计;**估计器选择与降级判定(如 P90 覆盖率 < 90% 的
  预注册阈值时切换保守上界模式)只允许使用独立校准/验证数据,并
  在确认实验前冻结**(V2 勘误)。确认实验期间逐任务报告预测
  μ_E2E/p90 对实际 E2E 的误差与覆盖率,**如实验中覆盖率不足,如实
  报告,不得据此临时切换估计器或任何冻结方法**——确认开始后无
  方法变更。
