## 第二阶段：D≈C 根因分析

### D/C 动作重合率：50%（9/18 相同）
不同动作集中在 V03（er 延迟故障）：
- C 选择 DS 修复→qwen 回退；D 选择 TERMINATE→本地修复
- V04（xc 延迟故障）D≡C 完全重合
- 截断故障各臂全选本地修复（一致正确）

### 三个根因（按重要性排序）
1. **机会缺失（主因）**：Z/R 无选择→联合动作退化为模型选择→模型间质量差距小→选择趋同
2. **模型质量差距不足**：Wilson-LB 乘积 0.08-0.13，相对成本/时延差距不够大
3. **关键路径太短**：3 个串行节点，无路径间权衡空间

## 第三阶段：优化机会审计（复杂 DAG）

| 结构 | 4 节点 | 8 节点 | 12 节点 | 16 节点 |
|---|---|---|---|---|
| chain | 38% / 4 闭包 / 58 组合 | 44% / 8 / 138 | 46% / 12 / 218 | 47% / 16 / 298 |
| diamond | 38% / 5 / 76 | 44% / 37 / 712 | 46% / 145 / 2872 | 47% / 401 / 7992 |
| wide | 38% / 5 / 76 | 44% / 65 / 1268 | 46% / 1025 / 20460 | 47% / 16385 / 327652 |
| multipath | 38% / 5 / 76 | 44% / 17 / 316 | 46% / 65 / 1274 | 46% / 257 / 5112 |
| deep | 38% / 4 / 58 | 44% / 9 / 158 | 42% / 17 / 312 | 47% / 20 / 376 |

（百分比 = 有优化机会的故障位置比例；闭包数 = 最大合法闭包选择数；组合数 = 闭包×模型分配的最大联合动作数）

**关键发现**：
- **4 节点钻石（当前实验）：仅 38% 位置有优化机会，最大 5 个闭包选择、76 个联合动作**——这解释了 D≈C：决策空间太小。
- **8 节点钻石：44% 机会率，37 个闭包、712 个联合动作**——动态调度开始有实质空间。
- **12+ 节点：145-16385 个闭包选择，2872-327652 个联合动作**——联合优化的空间巨大，简单规则无法穷举。
- **宽结构（wide）产生最多闭包选择**（大量独立节点=大量子集选择）。
- 链式结构即使很长也较少闭包选择（下游总是全部依赖）。

## 第四阶段：下一阶段实验清单（按优先级）

### 实验 1：联合动作 vs 简单规则（P0）
- **任务**：8 节点钻石 + 8 节点多路径（有 37+ 闭包选择、700+ 联合动作的结构）
- **臂**：简单门控 C / 联合动作 D（枚举+约束过滤+Oracle 指导） / Oracle 上界
- **核心问题**：当合法闭包>5 且联合动作>100 时，动态联合调度能否找到简单规则找不到的方案？
- **预计调用**：2 结构 × 3 重复 × (8 计划 + ~3 恢复) × 3 臂 ≈ 200
- **停止条件**：若 D 仍与 C 重合或劣于 C，说明当前任务模型本身不产生足够的优化机会梯度

### 实验 2：截止时间扫描（P0）
- **任务**：8 节点钻石，截止时间从宽松到不可行（6 层）
- **核心问题**：在哪个截止时间区间，动态调度的止损+闭包选择才产生净收益？
- **预计调用**：1 结构 × 6 层 × 2 重复 × 3 臂 × ~8 调用 ≈ 290

### 实验 3：故障类型异质性（P1）
- **任务**：12 节点多路径，混合故障（截断+延迟+超时+依赖污染）
- **核心问题**：故障类型异质性增大时，动态分类+差异化恢复是否优于统一规则？
- **预计调用**：~350

### 实验 4：在线学习隔离验证（P1）
- **前提**：实验 1-3 中存在 D>C 的条件
- **方法**：共同初始输出 + 保证学习样本存在（至少 2 个 repair/fallback）
- **预计调用**：~150
