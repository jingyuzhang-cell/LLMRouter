## 关键发现

### 1. 所有臂终端质量为零（q=0.000 全部）

**根因**：合成 DAG 节点的提示词不包含实际文档内容（只有节点类型标签
如 "Node n0 type=extraction doc=E07-xiwang"），模型无法从中学到
任何可验证事实。独立评价器（doc-atom 匹配）正确测量到输出不含任何
文档原子。

**这不是评价器的问题——是实验设计缺陷**：合成 DAG 结构验证了调度
决策机制，但节点提示词缺少真实任务内容，使质量维度退化为零。

### 2. 三臂决策差异（真实的）

| 臂 | 恢复闭包 | 决策 |
|---|---|---|
| C | R=0（不修复） | 接受故障 |
| D0 | R=0-1（有时修复） | 取决于成本估计 |
| D2 | R=1（总是修复） | 传播模型认为修复有质量收益 |

D2 在所有完成的任务上都选择修复 1 个节点（因传播模型预测质量改善），
但真实质量为零（文档内容不在提示词中）→ 修复的成本纯粹浪费。

### 3. 配对效用差（真实数据）

| 任务/重复 | ΔU(D2−D0) | ΔU(D2−C) |
|---|---|---|
| E4T01 r0 | −0.006 | −0.006 |
| E4T01 r1 | −0.003 | −0.017 |
| E4T02 r0 | −0.003 | −0.017 |
| E4T02 r1 | −0.002 | −0.015 |
| E4T03 r0 | +0.008 | −0.010 |

**ΔU(D2−D0) 均值 = −0.001（4 负 1 正）——D2 略差于 D0。**
**ΔU(D2−C) 均值 = −0.013（全负）——C 最好（零成本）。**

### 4. 诚实解释

在当前设定下（合成 DAG + 无文档提示词 + 零质量基线）：
- **C 获胜因为不花钱**：接受故障零成本，eU 仅含已有的成本惩罚
- **D2 修复但因质量=0 所以纯浪费**：传播模型预测有质量收益但
  真实无收益（文档内容不在提示词中）
- **D0 介于两者之间**：有时选择不修复（正确），有时修复

**这不是"D2 质量传播无用"的证据——是"D2 在质量不可测量时仍选择
修复"的证据。**传播模型需要真实质量差异才能展现价值。

## 需要修正才能得到有效结论

1. **节点提示词必须包含实际文档内容**（同 full_dag_tasks.py 的
   完整提示词，不是合成标签）
2. **故障节点的真实输出必须有可测量的质量差异**（好的修复
   应该能提取出文档原子）
3. **重复 2 次不足以判断方向**——至少需要 3 次以覆盖服务随机性
