## 一、等价性根因的形式化（为什么此前 JOINT ≡ π-only ≡ SEQ-π→R ≡ Alt）

**命题（顺序充分性条件）**：若
(a) 动作空间可分解且 |R 选项|、|π 选项| 均为小常数（4 节点 × 3 模型）；
(b) 每个基线在自身维度上做**完备搜索**（π-only(FULL) 遍历全部 π；
   SEQ-π→R 的第一步遍历全部 π）；
(c) 效用函数对 π 分支可加（除可行性耦合外无其他交叉项）；
则任何完备维基线都能碰到联合最优 → 等价是**结构性必然**，不是算法失败。

**已有 4 项结构发现正是 (a)(b)(c) 的实例化**：Z 恒 LOCAL、R 恒闭包（|R|小）、
质量单调（交叉项弱）、规模小（完备搜索可行）。

**推论（取胜的三个充分机制）**——任一成立即可打破等价：
- **M1 规模机制**：节点数 × 模型数 × R 子集数使完备搜索不可行 → 在**共享
  评估预算** N_eval 下，基线被迫贪心/采样，JOINT 用支配剪枝保优 →
  同预算更优 + 同质量更低开销。
- **M2 耦合机制**：资源竞争（模型并发上限 κ）使有效时延**非可加、非单调**
  （把节点 i 加到 R、或给 i 换 Flash，会延迟同模型其他节点）→ 坐标交替
  存在局部最优，需要 R 与 π **同时移动**才能逃出 → SEQ/Alt 结构性卡死。
- **M3 信息机制**：连续异常（部分退化，非二值故障）下 Z=VERIFY 是信息
  购买决策；H1V8 证明硬阈值门控被观测方差摧毁（同情境 cov 0.188↔0.562
  翻转）→ 用**贝叶斯后验 + VOI 自适应核验**替代硬阈值——这是对我们自己
  负结果的算法回应。反馈驱动 = 显式不确定性处理。

## 二、算法：JOINT-v6 = 联合 (Z,R,π) + 支配剪枝 + 耦合传播 + 自适应核验

1. **支配剪枝**（Z 恒 LOCAL 定理的推广）：节点级 Pareto 支配（同角色下
   被 (q,c,l) 支配的模型剔除）+ 耦合可行性传播（CashGuard 最坏路径 +
   截止期关键路上界先扩展）→ 搜索开销 O(∏ 剩余分支)。
2. **耦合评估**：R 与 π 在同一棵 best-first 树中展开；分支定界用
   LP-松弛上界（忽略整数性的可加上界）+ 容量感知时延界。
3. **自适应核验（Z 维）**：对可疑节点可选择 VERIFY（付费、无副作用、
   观测 q̃ = q + ε, ε~N(0,σ)——σ 来自 H1V8 实测 cov 波动）→ 后验更新
   → VOI = E[后续决策值提升]。决策规则：VERIFY 当且仅当 VOI ≥ 其成本。
   对照：硬阈值门控（H1V8 失败法）、不核验、全核验。
