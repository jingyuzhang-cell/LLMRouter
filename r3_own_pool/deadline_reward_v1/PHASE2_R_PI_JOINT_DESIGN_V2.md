# PHASE2_R_PI_JOINT_DESIGN_V2 — 修订版（2026-10-26，零调用，四个关键问题已处理）

依据裁决修订 V1；V1 保留存档。新增实测证据：`PHASE2_ROOTCOV_RECALIB.json`（ROOT 期覆盖度
重校准）、H1v7 逐调用时延（LEDGER 92 次）。

## 修订 1：在线决策时点与状态快照（统一口径）

**时点**：故障节点执行实例失败之后、受影响后继执行之前。决策状态 S 快照：

| 字段 | 内容 | 来源 |
|---|---|---|
| DONE | 已成功节点（合法缓存：输入指纹未变） | 执行器 |
| FAILED | 实例失效节点（输出=显式占位符） | 故障注入/契约检查 |
| PENDING | 故障闭包内未执行后继 + 未执行兄弟 + sink | 拓扑 |
| 资源 | 剩余硬 Token 预算 B_tok、剩余现金、剩余截止期 D−elapsed | 计量器 |
| 观测 | 检测信号、ROOT 期覆盖度、故障节点部分输出、模型先验 | 本设计修订 2/3 |

## 修订 2：覆盖度门控不可继承 → ROOT 期替代（含重校准证据）

**V1 缺陷（裁决确认）**：v7 门控 cov(probes, **sink 输出**) 在新时点不可观测，θ=0.318 禁止直接继承。

**替代（决策时可观测）**：cov(probes, **ROOT 抽取输出**)——ROOT 在决策时已执行。
**零调用重校准**（v7 存档 6 状态，同一探针函数）：

| 状态 | ROOT-cov | sink-cov（v7 口径复算） |
|---|---|---|
| S1_r1/r2（修有益） | 0.337 / 0.327 | 0.276 / 0.235 |
| S2_r1/r2（修有害） | **0.582 / 0.510** | 0.408 / 0.367 |
| S3_r1/r2（无故障） | 0.602 / 0.347 | 0.520 / 0.235 |

**分离成立**（S1 上界 0.337 < S2 下界 0.510）。θ′ 取中点 **0.42**（区间内）。
**边界如实**：n=4 拟合点、开发样本；S3_r2（0.347）落入 S1 区间但 S3 下检测不触发、门控
不参与；θ′ 必须在主实验中以出样文档验证（预注册：门控决策仍记录，判据不依赖其单点正确）。

## 修订 3：ACCEPT 合法性（显式占位降级契约）

H1 实现中故障输出即 `GARBAGE=[{"fact":"占位","evidence_doc_id":"?"}]`（显式占位、非编造）。
**合法性规则（冻结）**：分支节点失败 → ACCEPT = 下游消费显式占位符（合法降级，承担质量损失）；
**必需节点**（ROOT/sink 本身）失败 → 必须修复或拒答，ACCEPT 非法。禁止以跳过必需节点制造
效用优势（判据审计项）。

## 修订 4：六策略对照（增 SEQ 顺序基线）

| 策略 | R | π | 说明 |
|---|---|---|---|
| STATIC | 预固定闭包 | 预固定 Flash | 静态基线 |
| SD-FC | 故障位置规则（b0→targeted、b2→accept） | Flash | 强规则基线 |
| R-only | 动态（accept/targeted/full，θ′=0.42 门控） | Flash | 恢复决策贡献 |
| π-only | 固定 targeted（事前冻结） | PENDING 逐节点 Q/C/L | 重分派贡献 |
| **SEQ（新）** | 先独立选 R（同 R-only 规则），再在选定 R 上选 π | 同 π-only 规则 | **顺序优化强基线** |
| JOINT | (R,π) 联合枚举 | 同上 | 联合贡献 |

六策略同 S、同故障、同检测、同预算/截止期、同评分器（evaluator sha 冻结）。

## 修订 5：资源可行性（实测时延）与"归一化≠预算"修正

**实测串行 Flash 路径**（H1v7 中位）：n0 28.8 + (b0 10.6+x0 8.1) + (b1 13.7+x1 19.5) +
b2 6.8 + b3 8.6 + sink 25.6 ≈ **122s**；targeted 修复（b0 闭包：b0+x0+sink）≈ +44s。

- **D=100**：Flash-only 基线即不可行 → **π 压力真实存在**（DS 中位时延约为 Flash 1/3，
  全 DS 路径估计 ~45–55s）；修复可行性同时受 R 影响——交互轴成立。
- **D=160**：Flash 基线可行、Flash 修复贴线（166s）→ 半绑定。
- **C0 修正**：eU 的 token 归一化常数**固定 60K**（跨轮可比）；**硬 Token 预算独立分档**
  B_tok ∈ {24K（绑定：接受臂实测 ~19.7K，修复臂 24.5K 贴线）, 60K（宽松）}，超限=fail-stop
  截断并按 INCOMPLETE 规则计。
- 现金与 Token 分账：GLM 订阅 ¥0 边际（配额占用记录）与 DS 按量（¥）分别列报。

## 修订 6：JOINT 验收条件（强化）

1. **净收益（主）**：绑定档下 JOINT 平均 eU > max(SD-FC, R-only, π-only, **SEQ**)，且逐情境
   不劣（−0.05 容差）；
2. **交互证据（机制）**：≥2 状态出现"最优 R 随 π 可用性翻转"或"最优 π 随 R 翻转"
  （逐决策分歧表）；
3. **消融**：JOINT 胜出时分解 R 项 / π 项 / 交互项（vs SEQ 的差=交互净贡献）；
4. 质量：探索期沿用冻结 t_q 代理；确认期独立核验（边界如实记录）。
**明确**：仅有动作翻转无净收益 ≠ 联合更优；仅胜 R-only/π-only 不胜 SEQ ≠ 联合搜索独有。

## 修订 7：预算核验（估算 vs 最坏，修正口径）

DS 单次最坏（3072 上限契约，in≤10K tok）：高峰 ¥0.048 / 非高峰 ¥0.024。
- 16 次校准：典型 ¥0.02–0.04；**最坏 ¥0.77 高峰 / ¥0.38 非高峰** → 校准须非高峰 + 现金硬顶 ¥0.40
- 主实验（40 臂 ×6 策略…修正矩阵：2 情境×2 资源档×6 策略×2 重复=48 臂 ≈ 312 次调用
  +8 前缀 ≈ 320）：π 活跃臂（π-only/SEQ/JOINT=24 臂）DS 调用**每臂限 3 次**（预注册）→
  最坏 72+修复 ≈ 90 次 DS → **最坏 ¥4.3 高峰 / ¥2.2 非高峰** —— 超原 ¥0.40 上限。
  **处置**：主实验强制非高峰 + 总现金硬顶 **¥1.20**（fail-stop）+ DS 每臂限 3 次 +
  典型预期 ≈ ¥0.3–0.5。诚实结论：**V1 的 ¥0.13 是典型估计非最坏**，V2 按最坏重核。
- 上限汇总：调用 340 / token 依 B_tok 档 / 现金 ¥1.20 硬顶 / 墙钟 7200s。

## 修订 8：速率控制与 fail-stop（跨实验共享，零探测）

共享限速器（全局，两研究线）：≤1 请求/秒、每 5 分钟 ≤20 次；429 = **退避后 HALT**
（禁自动重试，HOLD 等裁决）；连续 2 次 429 → 批次终止；HTTP 错误头**必须持久化**
（CapitalEvent 429 事故的整改项，transport 层统一实现）；跨线日历协调（当日另一线已用
92 次订阅调用时降速至 0.5 请求/秒）。
