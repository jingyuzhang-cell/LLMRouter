## 诚实结论

**在共同初始输出+全新事件+受控随机性下，D 的状态条件化恢复决策相对 C
的简单截止门控没有净效用优势。** 截断型近乎平局（+0.006）；延迟型
D 略差（−0.02，因 D 的门控在 V03 的 er 修复中选择了不同模型，导致
质量略低但 token 更少）；V04 完全一致（D 的门控在此场景与 C 重合）。

试点中 D 的 +1.44 优势**完全来自非决策因素**：
1. 随机输出分岔（不同首次输出→不同故障轨迹）；
2. 执行缺陷（TERMINATE-后-重执行、REPAIR→ACCEPT 映射）；
3. 截止违约差异放大（试点多任务超截止→D 的止损突出）。

**这些因素都不属于"更好的恢复决策"。**

## 对论文的最终含义

试点证明的是：包含止损+零调用修复+便宜优先的**策略组合**在混合故障
+随机输出+紧截止的真实环境中，比固定规则有资源/时延优势。
独立验证证明的是：在控制这些混淆后，**动态状态条件化选择本身没有
超过简单截止门控的独立收益**（至少在当前四节点钻石任务+两种故障类型
+两个截止层上）。

这是一个真实的边界结果：**动态调度决策的价值可能不在于"选择不同的
恢复动作"，而在于"在随机故障环境中更稳健地执行止损和成本控制"。**
后者是否需要复杂的状态条件化（vs 简单规则），取决于故障异质性
和截止时间的多样性是否足够大。
