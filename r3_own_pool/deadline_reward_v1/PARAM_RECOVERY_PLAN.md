## 成功判据（现在冻结，防事后挪门柱）

1. **格式修复**：严格 JSON（去围栏）∧ 非空 ∧（finish_reason=stop，GLM 无此字段时
   以 completion < 0.98×cap 替代）。
2. **质量修复（关键，防"JSON 合法即胜利"）**：Silver 召回（FE3 n=17 / FE4 n=4）必须
   **超过截断文本的诊断性下界**（GLM-5.3：FE3 41.2% / FE4 50.0%）才算质量收益；
   仅格式过而召回不超下界 → 记"格式修复、无质量收益"。同时对照 qwen 已观测值
   （FE3 35.3% / FE4 50.0%）。
3. **成本/时延**：逐细胞真实 token/现金/延迟入账；修复效用 = 质量收益 − 增量成本。
4. **失败判据**：细胞 finish 仍顶格或 JSON 仍无效 → 该 θ 修复标记 REFUTED，写入
   机制注册表（负结果同样入表）。

### 机制结论

1. **参数修复机制成立**：6/8 细胞功能+语义双修复，全部用原失败模型，零换模型。
2. **GLM low@2048 被驳斥**：low effort 下输出+推理仍需 2,617–2,961 token —— 2048 上限本身是约束瓶颈，仅降强度不够；low@8192 完整收束。
3. **deepseek thinking=disabled@2048 成立**：2/2 自然收束（1,612–1,888 < 2048）。
4. 修复后的原模型召回**超过 qwen 参照**（FE3 8-9/17 vs qwen 6/17；FE4 3/4 vs 2/4）——修复优于切换的潜力存在，但见下节信息边界。
5. reasoning_tokens：两家 API 均未在 usage 中返回（全部 None），已如实入账。

### 引用契约（单独记录，按裁决不归责模型）

8/8 细胞引用仍不符台账 doc_id（同原提示词，doc_id 从未出现在输入中——contract_unverifiable 不变）。**格式合法 ≠ 完整节点成功**：引用层修复需 Phase-4b（改提示词声明 doc_id，未授权）。

### 增量 Q/C/L（修复 vs 原失败）
