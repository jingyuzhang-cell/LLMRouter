# 1 引言

## 1.1 背景与问题

大型语言模型工作流将信息抽取、推理、计算和验证组织为具有依赖关系的执行过程。模型在不同阶段具有不同的能力与资源特征，因此系统不仅需要选择由哪个模型完成任务，还需要决定是否拆分、如何分配节点，以及执行失败后采取何种恢复方式。查询路由从完整请求出发选择模型[1,2]，但在多阶段工作流中，候选选择还依赖前驱输出、节点接口与已经发生的失败。

显式有向无环图（Directed Acyclic Graph，DAG）提供阶段分配和依赖追踪的结构基础，同时增加中间接口与执行开销。条件输入下较好的节点质量，不保证实际输出传播后的端到端优势。强模型直接作答可能在无故障条件下同时具有更高质量与更低成本，因此工作流方法需要说明结构化执行何时值得采用，而不能预设任务分解必然改善准确率。

故障引入了另一类执行需求。一个节点的不可解析输出、执行异常或错误中间结果可能影响其后继；整图重跑则可能重复已成功分支，并增加恢复成本。此时，基础求解能力与故障处理能力需要分别评价：强模型在clean条件下表现较好，并不直接回答工作流失败后应在哪里干预、调用什么动作，以及恢复收益是否值得额外资源。

本文关注故障环境中的执行策略选择。其中心问题是：在当前候选能力与资源条件下，如何通过可部署反馈和依赖感知局部恢复减少性能退化，并确定这种执行方式相对于其他候选策略的适用范围。可诊断性、动作可修复性与资源代价共同限制恢复收益；动态调度不能自动创造候选模型和动作中缺失的能力。

## 1.2 方法定位与研究思路

本文提出故障感知动态执行策略（Failure-aware Dynamic Execution）。该策略利用解析失败、表达式不可执行及验证不一致等部署信号触发恢复，保留输入有效且未受影响的分支，仅更新失败节点及其受影响后继。动态性体现为反馈条件化的模型与恢复安排，不要求任意修改图拓扑。实验中的理想检测对照与部署检测实例分别标注，不将标准答案用于部署反馈。

为描述这一策略所处的决策空间，记执行策略为 $\pi=(X,Y,Z)$，其中 $X$ 为节点模型分配，$Y$ 为执行结构，$Z$ 为反馈条件化的恢复策略与重执行范围。Single LLM、Static DAG、Dynamic DAG和Full Replay，以及已实现的分配与恢复配置，构成有限候选集合。该表达是问题形式化，不是本文新增的组合优化算法；Dynamic是其中一种具体策略，已有FLARE-DAG则是有限候选上的局部重优化实例。

评价同时考虑任务质量、故障下的可靠性、token成本与观测时延。可靠性通过跨故障条件的质量保持和恢复率刻画，Q/C/L用于经验非支配分析，预算内正确完成率评价资源限制下的可用性。核心恢复对照的预算统计来自执行后的实际消耗，不被解释为在线硬预算保证。在多目标设置下，候选策略首先形成非支配集合；只有给定偏好或约束，才可讨论特定条件下的优选方案。

研究沿三步展开。首先，以阶段能力、节点路由及严格配对分解实验刻画执行空间，并保留分解可能有害的结果。其次，在同一120题面板上使用三个故障注入种子评价鲁棒性，通过恢复目标匹配和Local Recovery／Full Replay对照区分质量归因与执行效率。最后，结合Pareto、HV、预算及跨任务场景结果分析策略选择的条件依赖性。

核心面板中Single在clean条件下正确率为55%，Dynamic为40%；持续性能力故障从10%增加至30%时，Dynamic均值保持在40.83%—41.39%，而Single由49.72%降至36.39%。这些结果支持所定义故障下的质量保持，不构成对所有故障类型的普遍优势。三个种子改变同一任务集上的故障注入，验证的是注入变化下的稳定性，并不扩大独立任务样本量。数学与代码实验另用于分析接口与反馈条件，不作为统一跨域故障确认。

## 1.3 主要贡献

第一，**故障感知局部执行策略。** 将部署反馈、节点模型恢复与依赖追踪结合，仅重执行失败节点及受影响后继。方法贡献在于故障发生后的干预范围和执行组织，不以提高clean推理能力为前提。

第二，**恢复机制的受控评价。** 通过修正后的恢复目标匹配、理想／部署检测及局部／整图对照区分恢复动作和调度机制。局部恢复相对Full Replay减少约31%的tokens、48%的适配调用和35%的观测服务时延；质量差异未达显著，不被解释为非劣效证明。检测、Verifier与失败归因揭示识别错误仍不足以保证修复，限定了动态机制的收益来源。

第三，**多目标组合执行空间的实证刻画。** 将结构、分配与恢复共同纳入策略描述，展示候选的质量、可靠性、成本与时延权衡。Dynamic在高故障条件下进入经验非支配集，但并非HV最优或紧预算下始终占优；有限候选的FLARE-DAG实例没有额外质量收益。上述结果为未来组合优化求解提供实验基础，不声称已获得全局最优策略。

## 1.4 论文组织

第2章回顾相关工作；第3章给出能力建模、执行与恢复机制，并形式化组合策略选择问题；第4章依次刻画执行策略空间、评价故障感知局部恢复、分析多目标关系与跨任务适用性；第5章讨论机制限制与进一步优化条件；第6章总结全文。
