# 摘要

面向采购分析、财务报表问答等复杂任务，单一大型语言模型在质量、成本与时延上难以同时满足要求，且"把完整问题交给一个模型"的查询级路由无法利用模型在不同子任务上的能力差异。本文提出面向复杂任务的反馈驱动多模型自适应 DAG 执行框架（Feedback-driven Budget-aware Adaptive DAG Execution for Multi-model LLM Collaboration）：以模型能力画像（质量 Q、成本 C、时延 L）支撑节点级控制路由，将复杂任务分解为显式 DAG 并完成初始模型分配；执行层提供 Static 与 Dynamic 两种模式——Static 在节点失败时仅做局部处理、后继计划不变，Dynamic 在真实失败触发下对受影响后继节点执行选择性重调度与预算重分配；失败恢复采用预算感知的分级决策（恢复、升级或终止）；历史执行图以图森林形式版本化保存以支持跨任务复用，最终在单目标、双目标与多目标约束下进行执行策略选择。

在 MultiHiertt 与 TAT-QA 两域数据上的实验表明：（1）节点级协同路由相对查询级路由取得 +6.9pp 的可复现增益（独立确认、两种评分口径一致），类型级互补空间明确（条件口径节点 oracle 相对最佳单模型 +13.59pp），模型能力异质性是节点级调度的经验前提；（2）任务分解的收益呈域依赖与复杂度依赖：MultiHiertt 上分解较单体 +14.0pp，TAT-QA 低复杂度任务单体更优，分解收益随推导步数单调上升；（3）Live 端到端对照中 Static 52.1%、Dynamic v2 54.2%（配对 ΔQ +2.1pp，95% CI 覆盖 0），Dynamic v2 将错误动态调整（harm）降为 0 且预算违规为 0、成本持平；（4）机制诊断揭示**条件能力 ≠ 传播能力**：条件口径下清晰的互补性在真实传播后被共同失败压缩（900 题开发语料中 77.0% 任务全模型皆错，可利用 GAP 收窄至 5pp），跨模型 3×3 组合矩阵进一步证明上游抽取质量是主导因素（E_large→R_medium 20.0% 对 E_medium→R_medium 10.0%）——阶段互补性真实存在，只是被同模型绑定掩盖；（5）残余 GAP 的实例级路由仅在低覆盖率选择性区域安全（5–10% 覆盖率下 GAP 恢复 +7.4–8.6%、harm 接近零），Two-stage 偏好路由在 200 题确认集呈方向性正信号（+22.2%、零 harm）但在 500 题第二确认集未复现，仅作方向性证据；（6）判据纯度审计表明"节点存在缺陷 ≠ 任务已经失败"，116 个判据纯净真失败上四种恢复动作的恢复率均不显著（0–8.7%），动作集 oracle 上界仅 6.9%——**动态调度能够更安全地利用已有模型互补性，但不能突破模型池本身的能力覆盖上限**，当前瓶颈已从路由错误转移为模型池在困难任务上的共同失败。

本文的边界如实声明：节点级路由的独立确认来自审计后的训练留出集而非官方测试集；部分机制证据为基于已采集回答的回放层级；48 个任务的 Live Dynamic 对照为 previously analyzed confirmation set 而非未接触过的留出集；残余 GAP 路由的收益未能在第二个确认集复现，全部按方向性证据报告；恢复覆盖上限的结论限定于当前 3 模型池与冻结 prompt；局部子图重规划经开发实验判定为无额外覆盖收益，仅作为未来工作。

**关键词**：多模型协同；DAG 任务分解；节点级路由；反馈驱动执行；预算感知恢复；图复用；多目标优化
