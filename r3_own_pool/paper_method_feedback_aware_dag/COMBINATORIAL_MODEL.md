# Failure-aware LLM Workflow 的多目标组合优化建模(问题形式化草案)

> 定位:第三章新增内容雏形 + 第四章 4.5/章末伏笔的形式化基础。算法选择(NSGA-II/MILP/精确枚举)
> 延后——先检验模型是否"自然产生"求解必要性。所有量映射到已执行的实验证据;零新调用。
> 主张规则:本文不提出求解器;本文件给出建模与"证据子空间精确求解"结果。

## 1 问题定义:Failure-aware Workflow Execution Planning

给定任务 $T$(问题+上下文)与候选工作流图 $G=(V,E)$:$V=\{v_1,\dots,v_N\}$ 为执行节点
(证据抽取 / 推理 / 验证 / …),$E$ 为依赖(本文面板:$e_1,e_2\to r\to v$,$N=4$)。
执行环境参数:故障率 $p$(能力型故障)、每任务预算 $B$。求执行方案 $\pi$,同时
最大化质量与可靠性、最小化成本与时延。

## 2 决策变量(三族;本文实例取两族半)

**(1) 节点模型分配 $X$**:$x_{ij}=1$ 表示节点 $v_i$ 使用模型 $m_j$;$\sum_{j=1}^{M}x_{ij}=1$。
本文面板 $M=3$(medium/large/coder)。候选集 $A_i$ 由能力异质性实验界定(4.2:池内无全能模型)。

**(2) 执行结构 $Y$**:$y_k,\ k\in\{\text{single},\ \text{dag}\}$,$\sum_k y_k=1$。
single=$T$ 直答单模型(无内部节点分配);dag=按 $G$ 分解执行。

**(3) 恢复策略 $Z$**(仅 dag):失败节点 $v_i$ 的恢复动作 $z_i\in\{\text{none},\ \text{retry},\
\text{switch-model(局部)},\ \text{full-replay}\}$。**信息约束**:$Z$ 只能使用部署可得信号
(解析/执行/一致性;不读 gold)——这是本问题区别于一般调度问题的约束。

一个执行方案 $\pi=(X,Y,Z)$。本文已执行证据覆盖的配置:
$\{\text{single+retry},\ \text{dag+static}(Z{=}\text{none}),\ \text{dag+dynamic}(Z{=}\text{switch-model,
局部}),\ \text{dag+full-replay}\}$,共 4–6 个(含消融臂)。

## 3 目标函数(全部有实测映射)

$$\max\ \big(Q(\pi),\ R(\pi)\big),\qquad \min\ \big(C(\pi),\ L(\pi)\big)$$

- $Q(\pi)$:端到端任务正确率(冻结评分器;120 题全保留分母)。
- $R(\pi)=1-\mathrm{Deg}(\pi)$,$\mathrm{Deg}=\frac{Q_{p=0}(\pi)-Q_{p}(\pi)}{Q_{p=0}(\pi)}$
  (三种子故障场景实测;Dynamic $\mathrm{Deg}\approx-2\%$,Single $+34\%$@$p{=}30\%$)。
- $C(\pi)$:tokens(逐调用 usage 累计;恢复动作计入)。
- $L(\pi)$:观测服务时延(逐调用累计;不含模型加载,声明口径)。

## 4 约束

- **预算**:$C(\pi)\le B$(T2 的 $Q(B)$ 曲线即该约束下的完成率;预算口径=每任务绝对 token 上限)。
- **依赖**:$v_i\to v_j \Rightarrow t_i<t_j$(DAG 顺序不可变;本文不优化拓扑)。
- **资源**:单卡 24GB、串行调用(本文实例不起区分作用;扩池后为真实约束)。
- **信息**:恢复触发仅用部署可得信号(形式化:存在函数族限制 $Z$ 的可实现策略集)。

## 5 搜索空间与"证据子空间"

$$|\Pi| = K\cdot M^{N}\cdot R^{N}\quad(K{=}4,\ M{=}3,\ N{=}4,\ R{=}4)\ \Rightarrow\ \text{指数增长(面板实例}\approx 2\times10^4\text{)}$$

一般问题族包含广义指派类子问题(NP-hard);但**本文面板实例规模小,且关键瓶颈不是搜索而是评估**:
完整空间的每个新配置需真实执行($\sim$120 任务 × 4 节点 × 模型切换)才能得到无偏 $Q$。
已执行证据仅覆盖 4–6 个配置——称**证据子空间** $\Pi_{\text{ev}}$。

**证据子空间可精确求解**:$|\Pi_{\text{ev}}|\le 6$,精确枚举即最优(无需启发式搜索)。
枚举结果 = T1 前沿 + T3 切换边界:clean/10%/20% 由 single 支配,30% 故障 Dynamic 入前沿,
预算约束下 30% 故障 $B\ge 2800$ 处 Dynamic 反超(T2)。

**逐任务选择器天花板(oracle,零调用)**:任意完美逐任务策略选择器在 $\Pi_{\text{ev}}$ 上的上界:
- clean:$0.5917$(最优固定 single $0.5500$ → 余量仅 **+4.2pp**)
- 故障 20%:$0.5667\pm0.014$(最优固定 $0.4389$ → 余量 **+12.8pp**)
- 故障 30%:$0.5389\pm0.024$(最优固定 $0.4083$ → 余量 **+13.1pp**)

**必要性检验结论**:优化收益是故障条件化的——clean 下任何优化器最多 +4.2pp(且需完美逐任务
预测),故障环境下 +13pp。组合优化的价值随 $p$ 增长,与本文主线(failure-aware)一致;
在无故障场景鼓吹优化器没有数据支撑。

## 6 算法层(设计占位,本文不实现)

- **证据子空间**:精确枚举(本文已做)= 最优;启发式搜索无必要(审稿人必问"为何对 6 个点跑 NSGA-II")。
- **全空间 $(X,Y,Z)$**:需先解决**评估瓶颈**——代理模型(能力画像先验 + 温度-0 重放校准)或
  新执行预算;在代理误差未量化前,任何搜索结果不可信。此为下一阶段(方法升级)工作:
  Failure-aware Multi-objective Combinatorial Optimization(FAMO-WE),演化搜索/整数规划,
  对比 Random Search / 人工策略(Dynamic)/ oracle。

## 7 既有实验 ↔ 模型组件映射

| 模型组件 | 既有实验 |
|---|---|
| 候选集 $A_i$ | 4.2 能力异质性(条件节点质量、九组合矩阵) |
| $X$(节点分配) | 节点路由/类型先验(冻结结果) |
| $Y$ 基线 | Single(clean 三策略主表) |
| $Z$ 基线 | Static / Dynamic(局部) / Full-Replay 对照 |
| $R(\pi)$ | 三种子鲁棒性曲线(退化率) |
| $B$ 约束 | T2 预算完成率曲线 $Q(B)$ |
| 证据子空间精确解 | T1 Pareto+超体积、T3 切换边界 |
| 选择器天花板 | 本文件 oracle 上界(clean +4.2pp / 故障 +13pp) |
| $Z$ 信息约束 | Detection F1、Verifier 消融(可诊断性边界) |
| 可修复性(目标可实现性) | Recovery Attribution(固有失败 0–16% vs 偶发 29–100%) |
