## 术语表

| 统一形式 | 含义及限定 |
|---|---|
| 单模型执行 / Single LLM | 端到端执行 |
| 静态DAG执行 / Static DAG | 固定结构及执行计划 |
| 动态DAG执行 / Dynamic DAG | 运行反馈与恢复规则 |
| 局部恢复 / localized recovery | 失败节点及受影响后继重执行 |
| 适配调用 / adaptation calls | 恢复适配调用，不能写成总模型调用 |
| 质量保持率 / quality-retention ratio | 故障质量除以对应无故障参考 |
| 预算内正确完成率 | 轨迹事后指标，不是在线硬预算保障 |
| Pareto感知策略选择 | 给定候选集合上的选择，不是全空间搜索 |
| Selective-DAG | 入口门控，不与状态级Pareto Scheduler混用 |
| 选择性调度oracle | 同种子任务成功并集，不是实际调度性能 |
