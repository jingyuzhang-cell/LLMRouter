## 1.1 两个问题:任务求解与可靠执行

LLM 工作流研究的动机通常表述为:把抽取、推理、验证组织成有向无环图(DAG),应该比单模型直答"更好"。这个表述混淆了两个不同的问题。

**问题 A:任务求解能力。**给定一个任务,哪个模型能给出正确答案?我们以严格配对实验回答了这一问题:同模型拆分本身在 TAT-QA 上显著有害(−21.0 个百分点),异构阶段分工带来 +5.0 个百分点的显著增益但未抵消分解损耗;在本文的四节点面板上,单模型直答以 0.550 的准确率和 603 tokens/题的成本同时优于静态 DAG(0.350,1503)与动态 DAG(0.400,2324),并在无故障的每一个工况下对两种 DAG 构成帕累托支配。结论明确:在无故障、以准确率为唯一尺度的比较中,工作流组织不是单模型的对手,分解引入的协调与接口损耗是结构性的。本文不回避这一结果,也不试图以更多模块逆转它。

**问题 B:可靠工作流执行。**当工作流运行在易失败环境中——节点执行产生不可解析输出、不可执行计划或错误结果——何种执行机制能维持任务质量?这是系统与 Agent 场景中的真实问题:重试是默认动作,但它只对瞬态故障有效;对能力型故障(某模型对该子任务持续失败,贪心解码下同模型重试逐字复现同一输出),单模型策略没有替代动作。本文的贡献在问题 B。

## 1.2 本文思路:故障感知的动态执行

本文提出故障感知的动态执行框架:以部署可得信号进行失败检测(证据节点输出不可解析或为空;推理表达式不可执行;验证值与推理值不一致——运行时不使用标准答案);以依赖感知的局部恢复响应失败(仅重执行失败节点及其后继闭包,并将失败节点切换到恢复模型);恢复动作受剩余预算约束。框架保持既有术语体系:动态执行即反馈条件化的后继适应,不修改图拓扑;选择性调整原则保留强默认分配,仅在运行证据支持且资源允许时覆盖。

证据链按三层组织。**主评估**(120 题 × 注入故障率 10/20/30% × 3 个注入种子):单模型+重试线性退化(0.550 → 0.364±0.026),动态执行持平(0.411±0.004 → 0.408±0.014),相对静态执行配对提升 +7.5±1.4 / +8.9±2.1 / +9.7±3.8 个百分点(p≤0.001,且三种故障率下配对零伤害);30% 故障率下于全部种子反超单模型(+4.4±1.4 个百分点;单种子配对检验为方向一致但未确证,报告跨种子一致性而非单个 p 值);多步任务(≥2 运算符)子集自 20% 故障起全面领先。**恢复效率评估**:与规则完全相同、仅重执行范围不同的整图重执行对照表明,局部恢复无显著质量差异下节省 31% tokens、48% 调用、35% 时延,预算违规 0% 对 45%(整图重执行需约 2.1 倍参考预算方可清零)。**诊断分析**:失败检测评估、恢复归因、验证器消融与入口路由模拟,共同刻画机制边界。

## 1.3 研究问题

- **RQ1(可靠性)**:在注入能力型故障的环境下,反馈驱动的局部恢复能否显著降低执行退化?(对应主评估;对照为单模型+重试与静态 DAG)
- **RQ2(恢复效率)**:依赖感知的局部恢复相对整图重执行节省多少计算,是否伴随质量损失?(对应恢复效率评估;同初始图、同规则、仅范围不同)
- **RQ3(恢复边界)**:恢复收益的边界条件是什么——检测、可修复性与故障来源各自扮演什么角色?(对应诊断分析;含验证器消融与恢复归因)

## 1.4 贡献

第一,**故障感知的动态执行框架**。不以提高无故障准确率为目标,而以部署可得信号、依赖感知局部恢复与预算约束组织可靠执行;主评估给出其有效性条件:故障率 ≥20% 的多步任务与 ≥30% 的整体场景。

第二,**依赖感知的局部恢复策略**。相对整图重执行,在无显著质量差异(−2.5 个百分点,p=0.25,且处于实测会话级非确定性界内)下降低 token、时延与调用开销,并消除预算违规;未受影响分支的重复执行从 217 次降为零。

第三,**LLM 工作流恢复边界的系统刻画**。给出恢复成功的条件关系(合取):可检测、可修复、可执行缺一不可,并逐项量化——执行级失败检测 F1 0.78–1.0;推理级错误对基础信号不可见,跨模型分歧检测将信号精确率提升至 82% 但修复率仅 21%,检测不再是唯一瓶颈;无故障失败的恢复率 0–16% 而偶发故障 29–100%,说明恢复价值集中于故障多发场景而非能力上限。

统一命题(承袭并收窄旧稿):**动态调度能够更安全地利用已有模型互补性,但不能突破模型池本身的能力覆盖上限**;在本文的定位下,前半句的舞台是易失败环境,后半句的量化由恢复边界分析给出。
