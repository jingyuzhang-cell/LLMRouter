## 标题建议

1. **面向复杂任务的反馈感知多模型自适应有向无环图路由**（本稿采用）：保留框架定位，覆盖画像、节点选择、动态执行和复用，不在标题预设显著提升。

| 写作部分 | 采用的组织原则 |
| --- | --- |
| 摘要 | 先问题和约束，再框架，再最有代表性的正结果与限制；不堆全部实验 |
| 引言 | 从任务内部能力差异转向执行状态变化，随后提出研究问题与可验证贡献 |
| 相关工作 | 按模型选择、依赖执行、反馈、资源与记忆分类，每类明确比较对象与本文证据边界 |
| 方法 | 画像→初始图→分配→反馈→选择性动态→复用→多目标；区分一般定义与已有实例 |
| 实验 | 先证明异构与粒度收益，再检验分解、失败判据和动态，最后资源、复用与消融 |
| 讨论 | 解释正负结果为何可以同时成立，限定固定候选输出集合的覆盖上限 |
| 结论 | 只总结已经验证的粒度收益和有限调度证据，保留理想检测与小样本限定 |
