去重命中 clean 输出 → **能力型故障被"治愈"**,Static 列被系统性偏高(偏向 clean)。

`benchmark_run.py`(有正确的故障覆盖)不受影响。修复 = Caller 增加 (任务,节点,规划模型)
三元组故障覆盖并在所有臂的阶段调用传入 uid/node;重跑种子 24/25(~2700 次新真实调用)。
旧输出保留于 `*_BUGGY` 目录。
