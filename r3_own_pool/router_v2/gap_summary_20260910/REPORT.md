# GAP改进实验：正则化、残差、非线性与文本表示

全部使用原训练集2975道客观题，沿用原三折。三个seed控制内层三折划分；所有参数只按内层OOF路由质量选择，再重训评价外折。未读取正式validation/test质量。

| 方法 | 三seed平均质量 | 跨seed SD（pp） | 平均GAP恢复率 |
|---|---:|---:|---:|
| linear | 84.65% | 0.17 | 24.70% |
| rbf | 84.48% | 0.22 | 23.03% |
| dataset_residual_linear | 84.61% | 0.15 | 24.25% |
| dataset_residual_rbf | 84.52% | 0.08 | 23.37% |
| text | 84.63% | 0.21 | 24.47% |
| text_gte | 84.54% | 0.17 | 23.59% |
| 原Ridge / DatasetBest | 84.74% | — | 25.58% |

分母定义：同一经验Oracle（92.27%）减折内选出的固定模型基线（82.15%）。恢复率是经验上界口径，不是去噪稳定gap。

dataset_residual两类使用真实数据集身份，是特权诊断；linear/rbf/text/text_gte仅使用问题文本及其表示。保护阈值在预测优势不足时保留折训练确定的anchor，不使用真实留出正确性。

内层质量并列时保守选择更强正则化和更大切换阈值。TF-IDF词表及IDF在每个内层训练划分重新拟合，避免用留出题塑造文本特征。

注意：这些是在已观察原OOF失败后开展的适应性开发，不是独立确认；相同题目的三个seed不增加独立样本量。不能依据最高单seed数字宣称提高效果。所有六条路线保留，逐seed配对区间见SUMMARY.json。

验证：六项单元测试通过，覆盖Ridge等价性、留出标签隔离、文本词表隔离、保护阈值和参数选择规则；所有已保存预测/选择文件hash核验通过。
