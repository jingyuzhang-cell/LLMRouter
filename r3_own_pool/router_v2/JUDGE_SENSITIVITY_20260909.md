# 训练评分敏感性检查

已实现 `audit_judge_sensitivity.py`，仅分析当前 train arenahard 标签，匹配原题与原响应哈希，保持每响应首次有效主分数。不改已有标签，不调用外部 API，不读取 test 标签。

审计快照：`data/judge_sensitivity_20260909a/AUDIT.json`。531 条有效主评分中，189 条（35.6%）与有效分项之和不同，归一化分数平均绝对差为 0.0663。664 对可比较的同题模型对中，106 对（16.0%）严格排序反转，112 对（16.9%）平局状态改变。67 道四槽均可比较的题中，38 道（56.7%）最优模型集合改变，包括并列集合变化。

这些是尚未完成、非随机到达的训练快照，不能外推全数据比例。分项总和只是敏感性口径，并非真实质量。该结果不能证明主分数错误，也不能证明分项总和正确；它表明当前评分口径足以影响排序监督与 oracle 定义，因此尚不能认证评分可靠性。

执行决策：继续已授权采集与主分数评分；保留原始 judge 返回、分项和尝试历史。正式训练前须对有分歧的训练样本及一致对照进行盲审，审查题目和完整答案，避免只按数值决定真值。若需要额外独立 judge 调用，应先明确其用途、数据范围与预算，不能绕过原响应两次尝试上限。完成可靠性检查后预先固定主口径，在同一数据/划分/资源口径上进行标签敏感性对照，不能选择结果更漂亮的评分口径。

router gap 主线保持：学习条件质量预测与同题排序，在验证集选择偏好及超参数，按相同效用定义比较 router、best single 与 oracle。评分口径不稳时，gap 的变化可能来自标签定义，不能归因为 router 学习进步。成本与独立确认门禁仍未通过。

新的训练覆盖快照：`data/train_matrix_snapshot_20260909b/MANIFEST.json`，11560/14000 标签、2167 道四槽标签完整题，缺1312个原始响应及1128个已采响应标签。审计与矩阵分时读取，judge 数量略有差异是后台追加导致。5000条 GTE 向量再次校验通过。

验证：44项单元测试通过；新增测试覆盖排序反转、平局、最佳集合变化、非法分项不能当零、缺槽不能计入四槽结果。测试日志中的模拟 pilot 指标不是真实研究结果。
