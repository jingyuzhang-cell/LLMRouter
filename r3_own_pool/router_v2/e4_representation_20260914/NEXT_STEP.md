# E4 后续决策

本轮预先固定的 SplitConcat−Original 主比较为 +0.25pp，95%配对区间 [-0.90, 1.40]，四比较 Bonferroni 区间 [-1.20, 1.70]。相对 BestSingle 为 +1.05pp，区间 [-0.20, 2.35]。因此不把 SplitConcat 升级为已验证方法，也不按本轮最高点估计重新定义主比较。

39次学科内联合标签打乱的增益范围为 -1.30 至 +0.95pp，观察到的 +1.05pp 高于全部打乱结果。这说明存在题目级对应信号的迹象，但这种开发面板上的打乱排名与“路由净增益区间跨0”并不矛盾，不能替代100题的新生成负确认结果。

下一项优先实验建议为**独立训练题目数量的学习曲线**。E3 增加重复监督后改善有限，E4 拆分输入亦未明确改善，目前尚未区分独立题目监督不足与模型/表示上限。沿用原始 GTE、Ridge(alpha=1) 和冻结外折，只在每折允许的开发题目内按学科生成嵌套的40/80/120/全量训练子集，预先固定5个采样种子并全部报告；沿用四重复训练、第五重复评估。在同一外折题目上比较各样本量，报告配对收益与跨采样种子变异，避免用多个子样本挑最好结果。

这项后续实验尚未执行，也不能因学习曲线向上就外推大样本收益。若曲线仍平坦或负收益，不扩大 MA/重复采集；如果显示稳定上升，再冻结新的代表性题目采集方案，以检验面板选择偏差与样本规模影响。
