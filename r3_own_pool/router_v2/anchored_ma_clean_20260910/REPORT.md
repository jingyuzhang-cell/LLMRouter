解释与后续优先级：

- 旧MA排序平均质量81.759%；此次AnchoredMA平均87.014%；RidgeGuard平均87.160%；DatasetBest 87.126%。新MA仍未显示超越基线的增量价值。
- 旧模型967425个参数，新模型2800个可训练参数并保留Ridge锚点；这是容量、目标、锚点、内层选参的组合干预，不能把改善单独归因于其中一项，也不是与旧模型等计算预算的比较。
- 2975题中2068题四模型同分，DatasetBest仅170题有严格提升机会。旧MA seed42 alpha=.5救回73题却损失244题；新MA三个seed救回29/30/34题、损失34/34/35题。错误切换已显著减少，增量兼容性信号仍弱。
- 下一个实验应在每个外层训练折内选择重复采样题与稳定阈值，针对large/reasoning的稳定优势训练带回退的成对修正；保留随机分层样本检验选择偏差。对同一客观回答反复打分不能估计生成噪声；重复生成必须与待评部署采样协议一致。
- 对照必须同时包含原始pair标签、repeat均值标签、稳定pair筛选、只加门槛的Ridge。只在同样的折外题上比较净救回题数与净GAP恢复率；独立论文确认仍需要新未暴露测试题。
- 新增3项测试通过：初始预测严格等于Ridge、修正幅度受限、外层标签扰动不改变选择与决策。
