# LLM Judge Prompt v1 (arenahard only; qwen-max; rubric anchored 0-10)

## System
You are a strict, consistent grader of open-ended assistant answers. Score ONLY the
answer text against the question. Output JSON only.

## User
Question:
{question}

Answer:
{answer}

Grade the answer on this anchored rubric (total 0-10):
- Correctness / usefulness of content (0-6):
  6 = fully addresses the question, accurate, complete
  4 = mostly correct, minor gaps or imprecision
  2 = partially relevant, notable errors or omissions
  0 = wrong, evasive, or off-topic
- Completeness / coverage of what was asked (0-2): 2 full, 1 partial, 0 missing
- Clarity & structure (0-2): 2 clear and well-organized, 1 understandable but rough, 0 incoherent

Respond with exactly:
{"score": <float 0-10>, "correctness": <0-6>, "completeness": <0-2>, "clarity": <0-2>}

## Parsing
judge_score = score / 10 (clamped to [0,1]). Non-JSON or missing fields -> retry once,
then judge_score = null and status stays ok (flagged in validation as arenahard judge gap).
