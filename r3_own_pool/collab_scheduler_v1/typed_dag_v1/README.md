# Typed DAG v1 — stages 1–3

Scope: protocol, strict structural/interface validation and Stub-tested execution.
Stage 3 initial graph generation is available through generation.py; neighborhood search, joint optimization and runtime topology patch remain unimplemented. Historical launch entry points are unchanged.

## Protocol and boundary

`Graph` has graph_id/schema_version/graph_version/task_id/nodes/final_outputs/provenance.
`Node` has node_id/node_type/subtask/inputs/output_contract/dependencies/success_contract.
Model assignment is a separate mapping. Types: extraction/transformation/reasoning/verification. Contract IDs resolve to program-owned validators; arbitrary contract code is rejected. Provenance can hold parent graph hashes and change records for future versions. Graph serialization and a full content hash identify immutable execution inputs.

`validate()` checks IDs, references, cycles, types, versions, input/output port types, explicit binding/dependency agreement, required named outputs, terminal outputs, live paths, node/depth/base-LLM-call limits. Graph malformed inputs fail before dispatch. Declared coverage is NOT semantic coverage. Semantic status remains NOT_ASSESSED. Registered empty facts are legal; factual support is not certified by JSON validation.

## Reference adapter

`fixed_financial_graph(task_id)` expresses the existing financial four-node role structure. The old verifier consumes extracted facts in its prompt although its simplified topology lists only r as predecessor. The adapter therefore explicitly connects e1/e2/r to v. This is a faithful DATA dependency expansion, not byte-identical prompt reproduction. Historical entry points and results remain unchanged. The procurement template is not adapted in this minimum.

## Execution

`TypedExecutor(graph, assignment, metered, public_context)` validates/copies a graph, then walks its topological layers. Independent roots are represented but execution is serial in this minimum; no actual parallel latency claim. Task inputs are an allowlist (question/ctx_table/ctx_text); gold and labelled derivation bindings are forbidden. Node outputs are assembled by explicit ports. Transformation uses the existing restricted arithmetic interpreter.

Pass a production-guarded `MeteredExecutor` for future real execution. All LLM calls use its existing cache, Budget reserve/settle and logs; never call the backend directly. Typed cache keys preserve logical node identities and hash task IDs to avoid colon parsing ambiguity. Cache hit deployment usage stays counted while physical spend is zero. Tools have zero model calls and measured tool time. Base call limits are structural estimates; physical Token/request/wall hard limits remain Budget-owned. Runtime resource authorization/GPU locks are NOT provided by this package.

Output-contract failure blocks descendants. `recover_failed(node_id, model, max_attempts)` explicitly reroutes only failed nodes, resets blocked descendants and preserves incurred costs; up to 3 total attempts. Done/consumed output replacement is forbidden. This primitive is NOT an automated recovery policy or DAG structural repair.

`score(scorer, gold)` is isolated final evaluation; tested with the current `score_v21` but does not change its contract. Caller-provided semantic/task graders are not generated by the planner. Missing final output evaluates as failure under score_v21. Log files: TYPED_GRAPH/EVENTS/RECOVERY/RESULTS plus the existing DISPATCH/TRAJECTORY/WORKFLOW journals.

`observed_execution_wall_s` measures one executor's execution lifetime, including explicit retries; it is not generation-inclusive E2E. `serial_service_s` reconstructs logical service plus tool processing. Deployment tokens and physical spend are separate. No dollar-price model is provided.

## Next interfaces (not implemented)

Stage 3 implemented: `InitialDAGGenerator.generate_and_execute()` defaults to LLM generation and uses the existing Graph and TypedExecutor. Public inputs are restricted to context ports, named output requirements, registered types/contracts and task/domain identity. Extra context fields (including gold) are rejected. The planner determines topology; host supplies format, limits and contracts, never a node template. Structural validation is strict; metered LLM coverage review is heuristic and may be wrong. Fenced JSON and duplicate dependencies are deterministically repaired; at most two LLM repairs are permitted. Invalid generations use an explicitly registered domain template (currently financial_arithmetic only); unmatched domains or incompatible fallback are not executed. Quota/transport exceptions abort, without hidden retries or fallback dispatch.

Each graph records graph_version, parent_graph (previous raw candidate hash on repair), public input hash and provenance. GENERATION_EVENTS and GENERATED_GRAPHS log phases, reasons and accounting. Generation physical service excludes cache aliases; generation wall includes preparation. Execution deployment tokens/service and physical search spend remain separate. No monetary conversion is claimed. Tools have zero LLM calls. `real_generation_smoke.py` owns a GPU flock, refuses occupied GPU/port and creates a new output directory; 16 requests/65536 tokens/1800 service-budget seconds, two synthetic public tasks, no research panels.
