## 实际实现调整

- execution.py 抽取prompt附公开原文全部数值字面量和准确位置，不按答案筛选。
- generation_schema.py 要求唯一证据优先不填偏移，禁止猜位置；checker仍严格拒绝错误偏移。
- fact_semantics.py 新source_fact_output_schema，列举当前来源中的全部数值出现位置，约束值/证据/字符位置的绑定。模型选择子集，程序不选最终答案；不把派生值转换成原始事实。
- real_fact_reference_smoke.py 为独立真实诊断适配器，沿用InitialDAGGenerator/TypedExecutor/MeteredExecutor/Budget和GPU锁；固定有限计划/节点修复次数，支持扣除父运行实耗的续跑，以及有来源SHA的已生成图延续。源码/协议每版单独冻结，结构化解码只在此适配器启用，不宣称所有既有服务入口已升级。
- test_fact_semantics.py 增加公开来源候选Schema测试及位置表检查；最终95项回归全部通过，见FACT_REFERENCE_REAL_TEST_RESULT.json。

既有冻结实验、固定48配置入口、评分协议和历史结果未修改；没有git提交/推送。

## 失败归因边界与下一步

真实日志能确认：模型输出了错误偏移/无来源数值，结构化响应发生空白截断，后续选择为空。不能仅凭这些日志断言模型为何选择空集。JSON Schema合法允许空数组；形式合法并不保证必要操作数被选择。既有图的subtask仍写成facts.v1等标签，而非实际抽取目标，语义规划质量也未解决。
