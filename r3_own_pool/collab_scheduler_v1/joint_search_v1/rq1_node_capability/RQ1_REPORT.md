# RQ1：节点能力异质性分析（冻结观测上的描述性诊断）

2026-10-09。零 LLM 调用、不占 GPU、未使用 TEST16、未修改生产代码或活动实验
目录。输入仅为已终止、版本明确的数据副本
（`offline_predictor_audit/copy_inputs/` 四源，WORKFLOW 哈希登记于 JSON）。

## 结论边界（先行声明）

- **分阶段模型表现不同 ≠ 节点级分配优于查询级路由**。后者需要同任务、
  同评分契约的直接对照与路由基线；本报告只描述差异，不做该判定。
- **历史静态/动态轨迹不能自动分离 DAG 分解与恢复的收益**。模型配置、
  Prompt、任务或故障条件不同时只作差异描述，不做因果归因。
- 本报告为机制/能力诊断，不构成算法优势证据。

## 节点正确性判定依据（代理，无 gold 事实标签）

- **e1/e2（抽取）**：`parse_ok` = 产出 ≥1 个可用数值事实（字符串值如
  "$24.7" 容忍转换）；`operand_recall` = gold 派生式非平凡数值字面量
  （排除 0/1/100）被抽取值覆盖的比例。**不存在逐事实 gold 标签**，此为
  代理而非事实正确性。
- **r（推理）**：`expr_ok`（表达式可解析）/ `eval_ok`（在所消费事实上可
  求值）/ `gold_match`（score_v21 契约）。gold_match 与上游抽取质量
  **混杂**；条件化变体（双亲 operand_recall=1.0）样本极小（n=4），登记
  为证据缺口。
- **v（验证）**：`consistency`（与 r 链值 close）/ `gold_match`（v2.1），
  以上游 `eval_ok` 为条件变体。
- 评分契约：**v2.1 统一施加**于全部来源（与各会话历史 gold 版本无关；
  各源历史版本已在 JSON 登记）。

## 主要发现（全部数字见 RQ1_NODE_CAPABILITY.json；图 fig1/fig2）

1. **e1（表抽取）稳定**：两模型 parse_ok 均 1.0；operand_recall
   medium 0.875 (n=168) vs large 0.821 (n=112)。同任务配对 8 任务，
   recall 差均值 +0.062（1 个任务差 0.5，其余 0）。
2. **e2（文抽取）是瓶颈且呈任务×模型互补**（fig2）：整体 parse_ok
   large 0.50 / medium 0.56，但逐任务切割后：
   - 恒空任务 2 个（093e653a、85f0dfad：33/33 空）——**任务属性**
     （文本段落本缺操作数），与模型无关；
   - 混合任务 4 个中 3 个近乎**确定性互补**：4c5cc243 上 large
     17/17 成功、medium 0/16；ab6d7681 与 a3568c44 完全反转
     （medium 16/16，large 0/17）；08fbbc3f 双方 ~50%（9/17 vs 8/16，
     真随机）。**不存在一致的能力排序**——这正是异质性证据本身。
3. **r（推理）**：expr_ok medium 0.957 / large 1.0；eval_ok 双方 0.875；
   gold_match medium 0.239 (n=184) / large 0.250 (n=96)——整体差异小。
   同上游配对（同 e 模型对下 8 任务）：large_large 上游 12/32 vs
   8/32，medium_medium 上游 12/48 vs 16/48——方向相反，样本不足以下
   结论。条件化（干净上游）仅 n=4。
4. **v（验证）**：coder parse_ok 0.943 > large 0.825；gold_match coder
   0.339 (n=192) > large 0.287 (n=80)；同链配对中 coder 在 medium 链上
   优势明显（如 chain_medium_large_medium：14/16 vs 5/16），large 链上
   6/16 vs 3/16。consistency 双方均低（0.34-0.37），受上游失败污染。
5. **缺失与拒答**：e1 无缺失；e2 空 facts 132 条（恒空 66 + 混合 66）、
   拒答 0（"拒答"重分类后均为字符串值事实）；v 缺失 8、不可解析 25；
   无 gold 事实标签是根本缺口。

## 与既有统计的不重复声明

状态敏感性诊断（冻结观测代理）、成本预测器误差审计、gold 污染对账、
战役对账均不含分阶段×分模型能力比较；本报告为首次，节点级口径与最终 Q
口径分开（未用最终 Q 代替节点正确性）。

## 证据缺口登记

- e/r 阶段无 coder 执行数据（配置空间仅将 coder 赋给 v）；
- 抽取无 gold 事实标签，operand_recall 是代理；
- r/v 的 gold_match 与上游混杂，条件化样本不足（n=4）；
- 校准任务（4 个）单一固定配置，无模型对照；
- 混合任务中近确定性成败提示温度 0 下（任务,模型）级近确定性——
  需更多任务验证该模式的普遍性。
