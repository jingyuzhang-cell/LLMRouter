# Formal 战役终局证据包（六方法 × 三种子，18/18 COMPLETE）

2026-10-10。零模型调用。数据：18 个 COMPLETE 会话的账本与评估记录
（碰撞原始失败单元已排除，其补跑为计数轨迹；总账含其消耗与保留额）。
**定位：正式战役完成、终局证据分析。以下全部为描述性结果，主张强度以
本报告边界为准。**

口径要点：每种子初始设计六方法完全相同（已验证），曲线横轴为**共享
初始段之后的额外物理请求**，初始段已达成的目标对每个方法记为零额外。

## 问题一：相同物理预算下，谁更早达到最佳质量？

面板质量上限 0.5，六方法全部达到——**质量差异不可主张**，效率是唯一判据。
到 fault30 首达 0.5 的额外请求（三种子，均值）：

| 方法 | 种子1/2/3 | 均值 |
|---|---|---|
| Proposed（状态+增量成本） | 63 / 36 / 69 | **56** |
| w/o state | 63 / 37 / 67 | **56** |
| w/o incr-cost | 76 / 46 / 73 | 65 |
| qNEHVI（官方） | 76 / 45 / 73 | 65 |
| Scalarized | 67 / 88 / 53 | 69 |
| Random | 107 / 56 / 27 | 63（极差 80）|

配对差（额外请求，负=Proposed 更快，按种子）：
- **对 qNEHVI：−13 / −9 / −4（三种子全胜）**；
- **对 w/o incr-cost：−13 / −10 / −4（三种子全胜）**——增量成本除数是
  本战役中唯一表现出一致收益的机制；
- 对 w/o state：0 / −1 / +2（**状态特征在本面板无可见收益**）；
- 对 scalarized：−4 / −52 / +16（混合）；
- 对 random：−44 / −20 / +42（混合——random 种子 3 极走运，27 即达）。

**结论（受限）**：在 8 题面板、n=3 种子下，Proposed 的效率优势完全由
增量成本感知项贡献（相对官方 qNEHVI 平均少 9 个额外请求、三种子方向
一致），幅度小；状态特征未产生可测收益。不能宣称"全面优于基线"。

## 问题二：谁在三种子间更稳定？

- 请求总量极差：Proposed 9、wo_state 11、qNEHVI/wo_incr_cost 20、
  scalarized 17、**random 32**；
- 首达时间极差：Proposed 33、wo_state 30、qNEHVI 31、scalarized 35、
  **random 80**；
- 曲线 AUC 极差：各 BO 方法 5.2–6.7 相近，random 7.2 最大。

**结论**：稳定性的真实区分在 random 与所有 BO 方法之间；BO 方法内部
（含 Proposed）稳定性相当，不支持"Proposed 显著更稳"。

## 问题三：选中部署配置的成本/时延？

各方法最终收敛到 fault30 Q=0.5 的 LOCAL 恢复配置，但**选中的配置不同**：
- Proposed / wo_state → `medium,large,medium,coder__LOCAL`（部署 C 均值
  约 2,238–2,543，种子 1 偏贵）；
- qNEHVI / wo_incr_cost / scalarized → `medium,medium,large,coder__LOCAL`
  （部署 C 约 2,235–2,271，**更便宜**）。

**结论**：质量相同时，qNEHVI 族找到的部署配置部署成本略低——Proposed
在部署端没有优势，甚至种子 1 略差。论文中如实报告。

## 总量核对（含评审更正）

本轮六方法合计 4,871 请求 = 各方法三种子之和（Proposed 695、wo_state
**663**、wo_incr_cost 837、qNEHVI 707、scalarized 757、random 1,212），
与账本一致，低于 6,901 上限。**wo_state 总量低于 Proposed：不能宣称
Proposed 是请求量最少的方法**（其优势只在共享初始段之外的效率口径成立）。

## 边界与限制

n=3 种子（配对差只报逐种子值与方向计数，不做参数化置信区间）；面板
质量上限 0.5 使质量维度不可区分；两段评分版本（重评零翻转）；random
的高消耗部分来自缓存复用差（真实成本，按实测报告）；TEST16 独立确认
未启动。

**论文可支持的表述**：在固定 DAG 的 48 配置联合搜索中，带增量成本感知
的多目标采集函数以一致更少的额外物理评估达到相同最好质量（相对官方
qNEHVI，三种子方向一致、幅度小），并大幅优于随机搜索的稳定性；状态
特征在本 8 题面板上未显示可测收益——该消融的空结果本身是重要发现，
指向需要更大的状态分化面板（如 TEST16 或更多故障率档位）才能检验
状态条件化假设。
