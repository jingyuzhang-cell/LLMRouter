## §1 精确 DAG 与切换面（从代码重建）

- **MVR-1**（4 文档→10 个 E 页节点→F1–3→SINK）：故障注入于 E2（D2，日期文号类，prefix）；**B 臂切换 = E5/E8（D3 中部页，日期文号类）+ F1–F3 + 无 SINK**。**关键事实：被切换的 E5/E8 所服务的页面不承载任何必需事实的证据**——MVR-1 的抽取层切换面与全部 16 项事实零接触；事实与切换的唯一接触面是 F 聚合层。

## §3 核心结论：终端错误质量中不存在"更强抽取器可修复"类别

34 个错误实例全部分属三类：**(a) 精确匹配/表述变体**（F12 前缀、F16 附加、FB6 词序——两臂同样的模型都"知道"答案，输出口径不合冻结精确匹配）；**(b) 整组采样格式体制**（p4，两臂同犯，温度未固定所致可能性最大）；**(c) 派生算术不稳定**（F7）。**没有任何一例是"值本身错、更强模型会抽对"的抽取能力错误。** 因此 Dynamic-π 的质量收益在此批中不是"传播丢失"，而是**可收益错误类别在该批错误分布中的占比为零**——切换层（无论抽取器还是 F 层）面对的终端错误全部不属于它能修复的类别。

对操作者两种可能性的回答：本批证据支持**可能性 1**（切换只兑现了速度）为主；**可能性 2**（切换经 F 层输出格式造成终端错误）仅 FB6 一例弱证据（词序变体、单实例、与采样混淆），FD1–3 经 F 层的间接影响无法排除但无正向证据。F/E 载荷未持久化 = 两可能性最终区分仍缺数据。

## §4 格式体制分析

后缀率（A 臂/B 臂）：p1–p3 两任务全部 0；**p4：MVR2 A=13/27、B=17/27**（MVR1 全程 0）。整组格式切换是 **run 级**事件（两臂同犯），B 的 +4 恰好等于损害集（FD1–3+FB6）——边缘性、与采样混淆，不足以归因 F 层。

## §6 阶段二（传播感知验证）的准入条件

在已批五项修复（剥 description / temperature=0 / 整句引文 / 节点轨迹持久化 / 方差感知设计）之上，本核查追加**科学层面的任务准入条件**：

1. **终端质量可修复性门禁（repairability gate，操作者提出）**：任务须在独立开发数据上证明——Static 臂在 T\* 类抽取器节点存在**值级错误**（非格式/表述类），且该节点输出确实进入终端事实的依赖路径，且替代模型在校准中对该类节点稳定更强，且下游能消费其输出。本批两任务均不满足（MVR-1 无接触面，MVR-2 有接触面但错误全是格式类）。
2. **错误类别审计**：开发阶段先对 Static 臂错误做 (a)(b)(c) 三分类——只有 (抽取能力类) 占比足够，动态质量收益才有对象。
3. 样本量按 S4 实测方差设计，优先增加独立事件而非同事件重复。

**研究问题（操作者定调，入档）**：DAG 执行中，异构模型的节点级能力优势如何经依赖与信息传播转化为终端质量收益；反馈驱动的动态重分配在何种条件下实现该转化。本批已把它从假设细化为有数据支撑的错误类别分布问题。
