## 二、Token 预算与 J2 挤占问题的解法（三案，pilot 裁决）

### 2.1 预算设计原则

节点预算 = 历史文本输出 P95 × 1.3 + reasoning 配额。文本输出（disabled 时代 P95）：E ≈ 800；J1 ≈ 1400；J2 ≈ 2400；SINK ≈ 2200 tokens。thinking 形态 reasoning 实测：J1 ≈ 3000（=4503−~1500 文本）；J2 ≥ 8192（未观测到上界）。

| **A（推荐 pilot 首选）** | **J2 固定路由 DeepSeek（thinking disabled, max 4000）**；E/J1/SINK 保持 GLM-low@8192 | DS 17/17+2/2+15/15；时延 5–6.5s；成本极低 | SINK 仍无 GLM 完成证据（pilot 补）；**π 的"J2 换模"动作对象改变、S5 场景语义需重定义**（见 §四） | 六臂对照保留，但模型池基线变为异构默认 |

## 三、截止期与 SLO 重推导

### 3.1 串行链模型（真实槽位 K_glm=2 / K_ds=1）

E 相（4 节点 / 2 槽 = 2 波）→ J1 → J2 → SINK → FMT(≈0)。单节点 wall ≈ out/70 + 排队。

| 节点 | 预期 wall（完成路径） |
|---|---|
| E 波 | ≈ 2600/70 ≈ 37s/波 → E 相 ≈ 74s |
| J1 | ≤ 8192/70 ≈ 117s（实测 65s） |
| J2 案 A（DS） | ≈ 6s（实测 5.5–6.5s） |
| SINK | ≤ 117s（待 pilot 实测；估 60–90s） |

- **案 A 端到端（P95 估计）**：74 + 117 + 6 + 117 ≈ **314s**；含重试/动作余量 → **截止期 420s**。
- 案 B/C（GLM J2@8192/16384）：+117s/+234s → 431–661s → 截止期 540–780s，且完成性未证明。

**结论：V2.0 截止期候选 = 420s（案 A）/ 660s（案 B）；180s、90s 体系作废。**

### 3.2 SLO 9.5s 的可行性：**不可行，作废**

任何 GLM-low 节点 wall ≥ 37s（E 波）≫ 9.5s；"GLM 慢→竞速换 DS"的前提（GLM 有时快）在新形态下不存在——GLM 恒慢。S5 处置（案 A 下）：
- S5 原"J2 GLM 持续故障"语义自动退化（J2 已非 GLM）；
- **重定义为 S5′：SINK GLM 持续慢/不可解析故障，race = SINK 双发（GLM vs DS），首个可解析胜出**——保留"持续模型执行形态故障 + 对症换模"的机制考验，时延参数重推导；
- 或降级 S5 为方向性-only（无确认性终点）。二选一由操作者裁定；**默认建议：S5′ 方向性**。
