## P0 三个细节冻结

### 1. Completeness 独立于 FactCorrectness

```
F = 正确断言数 / 总断言数（不含遗漏）
C = 已断言槽位数 / 合同总槽位数（含遗漏惩罚）
错误断言率 = 错误断言数 / 总断言数（独立安全指标，并列报告）
```

### 2. 错误断言惩罚

- 错误断言率作为**独立安全指标**报告，不进入 Q_terminal 加权
- 预注册安全上限：错误断言率 ≤ 基线 +5pp
- 少回答不奖励（C 降低）也不惩罚（F 不受影响）——完整性维度自然约束

### 3. 证据支持语义

- E = 引用正确的断言数 / 总断言数
- "引用正确" = doc_id 指向正确文档 AND quote 在该文档中逐字命中 AND 引文与断言的 fact_id 对应
- 不做语义蕴含判断（避免引入新的 judge 校准问题）
- 语义蕴含不足的案例在讨论中定性分析
