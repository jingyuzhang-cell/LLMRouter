## 0. 研究框架（不随工具漂移）

研究对象不是 DAG 执行器本身，而是：**异构大模型的能力差异、任务依赖结构与运行反馈，如何共同决定复杂任务的最优协作方案**（Z 结构重构、R 节点重执行、π 模型重分配），以及由此产生的终端质量、成本、时延与按期完成率的联合收益。

必须始终区分：

| 机制成功 | 不等于 | 科学假设成立 |
|---|---|---|
| Z 恢复字段 | ≠ | Z 提升终端质量 |
| π 更换模型 | ≠ | π 提升终端质量 |
| Joint 完成联合调度 | ≠ | Joint 优于单策略 |

下一轮的可证伪命题：**在存在真实、不可替代的信息依赖时，Z/R/π 能否产生可重复的终端质量收益，且该收益是否值得其额外成本与时延。**

## 1. 四项裁定（含新增约束）

### 1.1 Relevance 人工裁决 — 批准
- 每任务 2 名独立评审，双盲（不知臂、模型、执行结果），0–1 分，一次性写入 `RELEVANCE_REGISTRY.json`。
- 0 = 任务与材料不相关或不可回答；1 = 充分相关且可回答。
- 分歧大时必须仲裁并保留理由。
- **作用域区分**：评价"题目与材料相关性"可按任务复用；评价"模型答案是否回应题目"必须按每份输出单独评价。两者不得混用。
- 找不到两名独立评审时：**HOLD**，不得用未经校准的 LLM Judge 冒充。

### 1.2 规范化规则 — 批准为候选
- 先冻结规则，再做独立任务盲测；六臂同一规则。
- 同时检查误接受与误拒绝；误接受即回滚该条。
- 不得按实验臂调整规则。
- **V2 的 36 份输出只用于规则开发，不得再充当独立验证集。**

### 1.3 连续逐字证据引用 — 批准
- 每个关键事实有对应证据；引文必须是原始文书中的连续文本；禁止省略号拼接。
- 保留标准文书 ID、页码、跨度；引文必须真正支持事实，而非仅出现在同一文书。
- UNKNOWN 可正确拒答，不得为满足引用要求编造证据。
- **六臂完全相同的证据输出合同**，不得只约束 Z 或 Joint。

### 1.4 Critical Gate 全有全无 — 批准
- 全部关键事实满足正确性、来源定位、证据支持才通过。
- 但必须同时记录：关键事实值正确率、证据定位成功率、证据支持率、Critical Gate 通过率、Q_partial。
- Gate 衡量"可信终端交付"；其余指标解释失败机制；二者不可互相替代。

## 2. 三条研究约束

1. **T1 保留为负对照。** T1 的 positions 消融未降低 A1/A2 材料正确率，不具备非可替代信息依赖。不进入新任务集的效果估计，但保留用于检验 S0/S1/S2 判定是否会错误触发。
2. **任务独立性优先于重复次数。** 独立任务是主要统计单元；同任务两次重复不构成两个独立样本；按任务配对与聚类分析。**V2 的 TP 测量有系统性缺陷，其 SD=0.75–1.27 不能作为新终点的方差依据**；正式样本量必须由新评分体系下的先导数据重新估计。
3. **机制成功与科学假设成立必须分开记录。** 见 §0 表。
