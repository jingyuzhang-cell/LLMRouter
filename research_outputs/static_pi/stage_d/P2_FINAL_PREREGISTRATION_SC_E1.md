## 三、三臂定义

| 臂 | 策略语义 | 动作权限 | 诊断 |
|---|---|---|---|
| **Static** | 静态异构分配 | 零动作（异常→失败） | 无 |
| **Fixed-Recovery** | 固定恢复 | 任何异常→结构修复+重试（不换模） | 无 |
| **Joint-Dynamic** | 诊断驱动联合 | 按异常类型选择 Z/R/π | 有 |

### 异常注入（预定义·公平·可复现）

| 异常类型 | 注入方式 | 可观察表现 | Static 响应 | Fixed 响应 | Joint 响应 |
|---|---|---|---|---|---|
| 执行实例异常 | J1 输出替换为空文本 | 契约守卫触发（empty_text） | 失败 | 结构修复+重试 | 诊断=模型异常→换模 |
| 信息质量异常 | E_决定部署时遗漏关键 prompt 附录 | 下游合同不满足 | 失败 | 结构修复 | 诊断=结构异常→Z |
| 对照（无异常） | 不注入 | 无异常 | 正常执行 | 正常执行 | 正常执行 |

三臂面对**完全相同**的异常（同 seed 同时刻同类型）。异常注入单独标注为"机制验证"。

## 四、评分合同（P0 冻结版）

$$Q_{\text{terminal}} = 0.5 \times F + 0.3 \times E + 0.2 \times C$$

- **F** = 正确断言数 / 总断言数
- **E** = 引用正确断言数 / 总断言数（doc_id 正确 AND quote 逐字命中）
- **C** = 已断言槽位数 / 20（含遗漏惩罚）
- **错误断言率**：独立安全指标 ≤ 基线+5pp

## 五、统计

| 项 | 定义 |
|---|---|
| **主终点** | ΔQ = Q_Joint − Q_Fixed-Recovery |
| 次要 | Joint vs Static / Fixed vs Static / ΔC / ΔL / 恢复率 / 错误断言率 |
| 配对单位 | 同 rep 内三臂共享 E + 同异常 seed |
| 检验 | 配对精确符号翻转（exact permutation） |
| 最小有意义效应 | ΔQ ≥ 0.05 |
| 重复 | 4 rep × 3 条件（正常/执行异常/信息异常）= 12 执行/臂 |
| 总执行 | 3 臂 × 12 = **36 执行** |
| 总调用 | 36 × ~5 = **~180 调用**（需另申请预算） |
| 安全门禁 | 错误断言≤+5pp / 保护倒退≥2 停 / INCOMPLETE≥1/3 停 |

### 预注册预测

| 条件 | 预测 | 证伪条件 |
|---|---|---|
| 正常条件 | 三臂质量相近（无差异） | 任一臂显著优于其他 |
| 执行异常 | Joint > Fixed > Static（换模恢复） | Joint ≤ Fixed |
| 信息异常 | Joint > Fixed ≈ Static（结构修复 vs 不修复） | Joint ≤ Static |
