# DAMJS_V0.3_PILOT 预注册草案（小规模真实对照：R2 vs V0.3）

**状态**：**草案，待操作员批准**。批准前不冻结、不实施、不产生任何 API 调用。批准后：冻结本文 → 最小工程接线（子进程增加 V0.3 开关，见 §6）→ 零调用快速验收 → 单独 GO → 执行。
**依据**：操作员 2026-11-07 五步计划第 4 步；V0.3 机制与零调用验证见 `DAMJS_V0_3.md`（a173154d）与 `damjs_r2/v03/V03_VALIDATION_REPORT.md`（7/7）。

## 1. 科学问题

在真实服务条件下：非破坏性结果提交（H-ND）能否消除结构恢复的负收益（2026-11-06 冒烟实测：S3 严格 −11），同时保留 Z_format 的正收益（宽松 +5，可离线证明）？失败概率门禁（H-EV）在慢服务条件下是否正确拦截且在正常服务下无误拦？

## 2. 设计（建议方案 A；备选 B 见 §7）

| 要素 | 取值 |
|---|---|
| 臂（4，2×2 机制分解） | **R2**（nd=off, ev=off）；**ND-only**；**EV-only**；**V0.3**（both on） |
| 场景 | S3（结构故障，负收益场景）、S4（格式故障，正收益场景） |
| 截止期 | 240 s（冒烟中损伤发生且修复可行的档位；130/150 的截止期机制另批） |
| 重复 | 每格 2 次 → **4 臂 × 2 场景 × 2 重复 = 16 次执行** |
| 随机化 | 与 R2 批次相同：块内四臂洗牌、相邻执行（种子新设，登记于冻结版） |
| 对照基准 | R2 冒烟的 6 次记录作为先验证据引用，**不与本次数据合并**（服务状态不可比） |

**四臂而非两臂的理由**：零调用验证预测 ND 承担主要修复作用、EV 在首次故障前不约束（先验 5.3% < 阈值 10.5%）——2×2 直接检验这一机制分解；若只跑 R2 vs V0.3，两机制的贡献无法区分。

## 3. 预测（预登记，供证伪）

- P1：S3 中，凡修复调用返回不可解析输出且 v1 有效的执行，ND/V0.3 臂触发回滚且该执行严格 TP 显著高于无回滚的同类执行（R2/EV-only 臂）。
- P2：S4 各臂保留格式修复收益（宽松 TP ≥ 12）；ND/V0.3 不产生新损失。
- P3：EV 门禁仅在锁存后触发（事件可审计）；正常服务下零误拦（p<10.5% 时无 EV_gate 排除）。
- P4：V0.3 相对 R2 的增量成本 ≤ 每次回滚修复 1 调用 + ¥0.024 + ~130 s。
- **诚实声明**：H-ND 的现场触发依赖服务出现撞限（基线率 5.3% 时 16 次 S3 执行约含 32 次 J1-GLM 调用，P(≥1 次撞限)≈58%；慢服务夜更高）。若本批未发生撞限，H-ND 现场验证记为"未触发"，机制结论仍以零调用重放为准，不得视为失败或成功。

## 4. 指标与判据（双口径，操作员 2026-11-07 采纳）

- 每次执行自动产出：宽松 TP / 严格证据 TP / UNSUPPORTED 单列、调用/Token/¥（核算与现金）、墙钟与截止期、J1 撞限标记、回滚事件、EV 排除事件、身份块（12 组件 SHA）。
- 成功判据（方向性，探索性证据，n=2 不做显著性宣称）：
  - C1（H-ND）：无一次执行出现"v1 有效但因破坏性覆盖导致严格 TP=0"（R2 的实测失败模式在 ND/V0.3 臂消失）；
  - C2（H-ND）：S4 收益保留（ND/V0.3 臂 S4 宽松 TP ≥ 12）；
  - C3（H-EV）：EV_gate 排除全部伴随慢服务锁存事件，正常服务下为 0；
  - C4：ND/V0.3 臂成本/时延增量满足 P4 界。

## 5. 预算与停止规则

**估算**（冒烟实测均值 ×1.15 裕量）：16 次 ≈ **113 调用 / ~40 万 token / 核算 ¥0.75**。
**建议本批硬上限**：**140 调用 / 450,000 token / ¥0.95**（在 36 次批次账本内滚动执行；批余量 305 调用 / 1.10M token / ¥2.02，充足）。
停止规则沿用 R2 批次五条（SHA 失配 / 路由偏航 / AttributeError / 编号重复 / 账本异常触顶），另加两条：
- 任一执行出现 V0.3 代码路径异常（CommitDict/估计器抛错）→ 停批归因；
- 现场触发回滚 ≥1 次且 C1 被违反 → 停批（机制失败即停，不继续消耗预算）。

## 7. 备选方案（若需更省）

- **方案 B**：两臂（R2 vs V0.3）× 2 场景 × 3 重复 = 12 次（≈85 调用 / ¥0.56）：便宜 25%，但 ND/EV 的独立贡献不可分离（P3 只能靠事件日志侧面检验）。
