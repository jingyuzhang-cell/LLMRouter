## 2. 改进交付机制（v1.1 修订）

### 2.1 D1：比例 token 预算（计数口径冻结）

交付关键节点（kind ∈ {reason, verification, report, merge}）：`max_tokens = 2000 + 150 × n_upstream_facts`，上限 6000；抽取节点维持 2000。

**n_upstream_facts 口径（v1.1 冻结）**：**实际序列化进当前节点输入提示的、按 fid 去重后的有效事实条数**（即 `reference_upstream` 各父节点输出合并后、提示词中真实出现的 fid 唯一计数）。不统计祖父节点未传递的事实，不按引用次数重复计数。**每个节点实际计算出的 max_tokens 逐节点落盘**（记录于执行 JSON 的 node 记录），供审计与复算。

依据（V2 实测）：GLM report 成功样本 ≤1716 token 完成、失败样本全部在 2000 截断；上游事实 10–20 条 → 预算 3500–5000。

### 2.2 D2：证据保真的结构化输出合同（v1.1 重写，替换 v1.0 的 60 字/fid 方案）

v1.0 的"quote 填上游 fid"与"quote 必须逐字"存在字段逻辑冲突，且 V-1 已发现元引用危害。v1.1 合同逐字冻结如下（交付关键节点系统提示追加）：

> 输出契约（交付关键节点）：
> 1. facts 数组每条对象字段：fid（本条事实标识）、value（事实值，一条事实只陈述一个可验证结论，禁止拼贴多条）、doc（证据文档 id）、quote（支持该事实的原文证据跨度）、parent_fid（若本条承接自上游节点输出，填上游事实的 fid；否则省略）、summary（可选，不超过 20 字的展示摘要）。
> 2. quote 必须是 doc 所示文档中连续的原文片段，逐字复制，不得截断、改写、翻译或使用任何标识符、节点名、自述文字代替。
> 3. 选取**能完整支持 value 的最小连续原文跨度**；没有字数上限。若任何单一连续跨度无法完整支持 value：要么把 value 拆分为多条事实（各自带独立 quote），要么把该条移入 unknown。**禁止为迁就长度而压缩或改写证据。**
> 4. 上游已给出的事实默认不重复列出。如确需保留：逐字复制上游的 value/doc/quote（保持完全一致以便去重），并填 parent_fid 指向上游 fid；**不得为上游事实伪造新的或改写的 quote。**
> 5. 无法确认的项列入 unknown 数组。

要点：事实来源标识（parent_fid）与证据引用（quote）**分字段**；原始事实值不被压缩；上游引用通过独立字段建立，不重造证据。此合同同时保持去重核验的四元组可比性（逐字复制使上游重复事实自然命中去重）。

### 2.3 D1+D2 作为整体机制（v1.1 声明）

本实验同时改变 token 预算（D1）与输出合同（D2）。**H1/H2 的任何成立结论只指向"D1+D2 改进交付组合机制"，不得拆归 D1 或 D2 单独起效**。若未来需要拆分两者独立贡献，须另行设计（如 D2-only 臂），不在本批内。

## 4. 统计计划与敏感性（v1.1 重写表述）

1. **本批次是探索性机制实验，不具备确证性统计功效。** n=4 任务下，任务级精确符号置换检验的双侧最小可达 p = 2/16 = **0.125**，任何方向完全一致的结果都无法达到 α=0.05；若未来要使该检验**有可能**达到 0.05，至少需要 **6 个独立任务**（这只是必要条件，不是样本量充分的证明）。
2. **34.5pp 是正态近似下的效应检测敏感性参考，不是该精确检验的"80% 功效"**：推导为任务级交互项每任务 sd ≈ √2×17.4 ≈ 24.6pp（取自 V2 实测任务级对比 sd），n=4、α=0.05 双侧、80% 功效的 MDE ≈ 2.80×24.6/√4。v1.0 中将其表述为"80% 功效 MDE"不够严谨，特此更正。
3. **报告粒度**：必须报告**四个任务各自的交互效应**（Δint 的逐任务分量）与总体均值，不得只报均值。
4. **任务聚类 bootstrap 95% CI 为探索性区间**，不替代确证性检验，不得写成显著性结论。
5. 门通过率恢复（次要终点，n=12/单元）：0.667→0.917 的单侧精确二项检验功效约 63%，如实报告功效不足。
6. 重复内方差来源（V2 实测）：门双峰性（B E05 rep sd 0.366、C E08 0.377、C E06 0.275）；若 D1+D2 稳定门，任务均值精度随之提高，属 H1 内在部分。
7. 无 H0 纯零世界：基线单元为未处理对照；E07 子组作内部稳健性；因果解释受 §5 时间混杂约束。

### 5.3 时间混杂的诚实限制（必须写入结果报告）

- Δint 的解释上限是"**改进交付条件下的关联效应，可能含跨批模型漂移成分**"，**不得写成严格的随机化因果验证**；
- 若 V3 响应 model id 与请求不一致或批内变化，该限制升级为主要限制；
- 缓解措施（同别名同请求结构、交错执行、响应元数据记录）降低但不消除该混杂。操作者如要求更强因果性，替代方案是四单元全部在同批重跑（约 +600 次调用，本申请不含）。
