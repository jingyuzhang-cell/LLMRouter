# RQ1 V1.8.2-R3 失败审计与归因（零调用，只读）

依据：`RQ1_V1_8_2_R3_CALIBRATION.{log,json}`（12,500 次）、`RQ1_V1_8_2_R3_DIAGNOSIS.{log,json}`（1,100 次拆解，本轮新增，低计算量）、`rq1_v1_8_2_r3_mechanism.py` / `_calibrate.py` 逐行审读。
所有数字 SYNTHETIC；不修改原始文件；不调整阈值。

## 0. 数据流核实（先于归因）

任务输入(task,U,sign,eff,feat) → run_task 按 DAG 执行[e0,e1→t,m→r; m,t→v; r,v→p] → 下游 q=被消费父事实 TP 率 → 逐事实 TP/FP/FN/UNK + loc/sup → 终端答案=(v0,v1,p0 三槽 TP∧loc∧sup) → G_Q/G_F/G_R 同样本联合。
**核实结论：主流程与声明一致**，但有 6 处偏差（见 §5）。

## 1. GQ 失败归因（GQ≤0.033 全情景）

**根因 A（实现/校准设计错误，首要）：R3 校准的"H1"实为方向混合世界。**
`task_sign`（hash 奇偶 ±1）乘在所有 adv 上 → 每个任务一半概率 GLM 占优、一半翻转 → 类型级优势按构造抵消。诊断证据（H1 .15）：NT 与 TRUE 的逐节点一致率仅 **0.538**；verification 被训练选为 DS 的比例 **99%**（TRUE 应选 GLM）。"类型一致 H1"在 R3 校准中从未存在。GQ 低首先是**没有可匹配的类型级信号**，而非传播稀释本身。

**根因 B（训练信号混淆，算法设计缺陷）**：NT/BU 的类型均值来自 all-GLM/all-DS 全图运行；上游质量差异污染类型估计——all-DS 运行中 verification 输入 q 高、all-GLM 输入 q 低，本地优势被掩盖。δ=0.20 时混淆更强：report 也被 66% 误选 DS，NT 终端 0.436 **低于** BU 0.455（dQ=−0.020，主动有害）。

**根因 C（机制稀释+尺度不可通约）**：传播与 loc/sup 使 local→term 缩水约 0.10–0.13（TRUE：local .617→term .488）；且 **MVS=6.25% 锚定在 16 槽任务尺度，而本机制终端 Q 是 3 槽均值**（+1 TP=33%）——两个尺度不可通约。即使 TRUE Oracle（.035/.059）也达不到 6.25%，说明该阈值在当前合成机制下**任何策略都不可达**；这是校准设计的尺度错配，不是策略失败。

## 2. GF 失败归因（GF≤0.003）

- 直接原因：NT≈BU（根因 A/B）→ 20 任务 × 3 关键事实的净值仅 ±0.5，精确检验正确地不拒绝。**GF 失败主要是"真实差异不存在"，检验本身无失效证据**（H0 下 GF=0.000，保守）。
- 实现缺口：GF 只用 `ctp−cfp`；FN/UNKNOWN/loc/sup 已记录但**未进入验收**；ctp 不要求 loc/sup，与 G_Q 的 TP 定义不一致（同一"TP"两种口径）。

## 3. GR 失败归因（H1 下 0.024–0.33 vs H0 0.738）

诊断拆解（H1 .15）：cost 通过率 **0.137**、Makespan **0.137**、parseNI **1.000**、contractNI **1.000**。
- **GR 失败 100% 来自成本+时延，与可靠性无关**。
- 机制：传播使 all-DS 端到端更好 → **P(BU=GLM)=0.013**（基线 98.7% 是便宜的 DeepSeek）；NT 在 3 个节点掺 GLM → 成本 +28.2%、关键路径 Makespan +21.2%，超 10% 约束。
- 结构性：GLM（贵 1.0/慢 1.0）恰好被 TRUE 选在 merge/verification/report——全在关键路径上。
- H0 的 GR=0.738 也被污染（见 §5-D）：H0 两模型 parse/contract 不同 → 非纯零假设。

## 6. 失败原因排序（六分类）

1. **实现/校准设计错误**（A,B,C,E）：主导 GQ 失败与 H0 解释。
2. **算法设计缺陷**（训练信号混淆）：主导 NT 劣化为负收益。
3. **可识别性不足**（方向 50/50，特征独立于方向）：主导 Oracle 差距；合成世界结构性无法识别。
4. **资源约束**（成本/Makespan 10% vs 贵模型在关键路径）：GR 唯一瓶颈，真实权衡而非 bug。
5. **统计功效不足**：次要（差异本身≈0 时检验正确拒绝）。
6. **模型能力不足**：合成世界无法判定——TRUE Oracle 显示**若方向可知池有 +.035~+.059 潜力**；真实模型池是否如此 **只能由真实实验回答（BLOCKED）**。
