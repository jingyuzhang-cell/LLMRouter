## 三、关键警告：J 必须与 QP6 有本质区别

**QP6 已证明**：联合支持标注（在证据文本中添加关联标签）**不产生终端质量收益**（+0.0145, p=0.75）。原因是 SINK 已能从平铺证据表自行建立跨来源关联。

**J 节点必须是独立推理步骤，不是附加文本标注**：

| QP6（已证伪） | J 节点（拟验证） |
|---|---|
| 在证据文本中添加关联标签 | E 与 SINK 之间的**独立配对节点** |
| 模型仍一次性处理全部信息 | 先做主体-数值配对，再传给下游 |
| 不改变信息流结构 | 改变了 SINK 的输入（从原始 E 输出变为 J 配对结果） |

**如果 J 只是"更好的提示词"而非结构化推理步骤，将重复 QP6 的零效应。**

## 四、GO 裁定与最小实验设计

### 裁定：**有条件 GO**

条件：
1. J 必须是独立节点（不修改 E/SINK 提示词）
2. J 的输出必须是结构化配对（subject-value-evidence 三元组）
3. 对照组不含 J（Baseline: E→V→SINK）

### 最小对照设计

| 臂 | 路径 | 差异 |
|---|---|---|
| Baseline | E → V → SINK | 无 J |
| Treatment | E → **J** → V → SINK | J 做主体-数值配对 |

固定条件：相同 E 输出（共享）、相同 Gold、相同评分器、Gold 不进运行时提示词。

### 预算估算

| 项 | 数量 |
|---|---|
| E 共享（每 rep 一次） | 3-4 调用/rep |
| J 节点（仅 Treatment） | 1 调用/rep |
| V + SINK（两臂各一次） | 2×2 调用/rep |
| **每 rep 小计** | ~7-8 调用 |
| **3 rep × 2 臂** | **~45-50 调用**（余量 ~75 内） |

### 主要终点

- 终端质量（独立测试集宏平均）
- 主体-数值配对准确率（J 特有）
- 证据定位率
- 成本与时延增量

### 预注册预测（可证伪）

| 预测 | 证伪条件 |
|---|---|
| Treatment 终端质量 > Baseline | ΔQ ≤ 0 |
| 主体配对准确率提高 | 配对错误率不变 |
| 成本增加 ≤ 1 调用/执行 | J 需多次调用 |
| 不引入新错误断言 | 错误断言增加 >2 |
