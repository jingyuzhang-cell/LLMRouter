## 第一部分：三任务证据对应表

### 证据分级定义
- **强证据**：≥2 任务同方向且有效应量
- **方向性证据**：1 任务有信号或方向一致但效应量小
- **链路证据**：执行链路数据（COMPLETE 率/时延/成本）有效但质量评分未完成
- **未验证**：无实验数据

## 第二部分：论文科学贡献框架

### 核心科学命题

> 异构模型能力差异决定复杂 DAG 的执行可行性；诊断机制决定异常发生后是否值得采取恢复动作；动作与异常的匹配以及恢复靶向性决定恢复效果；而任务难度和资源约束最终决定恢复能否转化为终端质量收益。

### 1. 核心科学问题

在具有真实依赖、分支和汇合的复杂任务 DAG 中，能否利用异构模型的节点级能力差异，通过执行反馈识别异常类型并联合决定是否换模、是否重执行、恢复多大范围，在保证终端质量的同时降低成本与时延？

### 2. 研究假设与验证状态

| 假设 | 状态 | 关键证据 |
|---|---|---|
| H1 异构能力利用 | **部分验证**（能力差实锤，质量转化有边界） | GLM 3/3 截断 + DS 7/7；换模恢复 +14 TP 但 MVR2 反例 |
| H2 诊断驱动动作匹配 | **部分验证**（格式强/结构弱） | +6 TP 格式匹配；B-4 诊断>盲换 |
| H3 恢复范围选择 | **初步方向** | +0.5 TP Upstream 方向性 |

### 3. 方法创新

| 创新 | 内容 | 区别于现有工作 |
|---|---|---|
| 节点级契约守卫 | 按节点输出契约判定失败（空/传输/JSON/Schema） | 比端到端重试更精准 |
| 证据驱动异构路由 | 基于实测能力矩阵的合法切换空间（非法方向拒绝） | 比"全部试一遍"更省 |
| 诊断-动作匹配 | 异常类型→对应修复动作（格式/结构/换模） | 比盲目重试有方向 |
| 失败感知降级 | 修复路径失败→自动降级换模 | 比固定策略鲁棒 |
| 三层评价 | Q（质量）/ R（可靠性）/ C-L（效率）分报告 | 比单一指标更完整 |

### 4. 实验发现（论文 Results 章）

**发现 1：能力异构是可行性前提**
- GLM-5.3-Flash thinking 模式在多主体矩阵推理合同上呈预算填充截断（reasoning 耗尽全部 max_tokens，0 文本输出），3 个独立任务族 3/3 复现
- DeepSeek thinking-disabled 在同类合同上 7/7 节点级通过（2-7 秒/节点）
- 含义：异构分配不是优化选项——单模型在特定节点上无法完成执行合同

**发现 2：诊断驱动换模有真实恢复价值**
- J1 异常后：A2 诊断换 TP=14 vs A0 不换 TP=0（+14 TP）
- 跨任务链路复现：MVR2 Proposed 4/4 COMPLETE vs Best-Single 2/4
- 含义：异构恢复能力来自"有合法替代 + 知道何时切换"

**发现 3：诊断优于盲换**
- 健康条件：A2 诊断换 15.0 TP/3.0 调用 vs A1 盲换 14.0 TP/4.0 调用
- 含义：调度器的价值在于"判断什么时候不该动作"

**发现 4：动作-异常匹配有条件收益**
- 格式修复对格式异常：+6 TP（强）
- 结构修复对结构异常：+1 TP（弱）
- 含义：动作匹配收益因异常类型而异，不能推广为普遍收益

**发现 5：恢复 ≠ 正确（重要边界）**
- MVR2 Proposed 链路 4/4 COMPLETE 但编码归一 TP=2.50 < Static 5.75
- 逐槽分析：53% 错误在 SINK 值-槽映射（正确值存在但填错）
- 含义：恢复动作作用于故障节点，但质量瓶颈可能在不同节点——**恢复靶向性**

**发现 6：单模型分配是恢复天花板**
- P11 全 DS 路由 J1 故障后 A2_diag 0/2 COMPLETE——无合法替代即无恢复
- 含义：异构性不仅决定质量，更决定系统的可恢复性

### 5. 适用边界（论文 Discussion 章）

1. 任务难度：多主体×多阶段矩阵任务（MVR2）的终端映射瓶颈（SINK 53%）是当前恢复动作无法触及的
2. 异常类型：格式修复强、结构修复弱——动作匹配效果非均匀
3. 模型异构性：单模型节点故障后无恢复选项
4. 恢复靶向性：换模修复故障节点≠修复质量瓶颈
5. 跨任务推广：3 任务族有证据但均为资本市场舆情域，推广到其他领域需验证

### 6. 尚未解决的问题（论文 Future Work 章）

1. H3 恢复范围的普遍性（当前仅 +0.5 方向性）
2. 终端映射瓶颈的突破（SINK 53% 错误——更优 SINK 提示词/结构化输出约束？）
3. 多任务集扩展（当前 3 任务族各 1 任务，需 ≥2 任务/族）
4. ΔU 决策框架（何时值得恢复 vs 接受损失——需更多边界条件数据）
5. P11 质量评分（state_scorer 适配）
