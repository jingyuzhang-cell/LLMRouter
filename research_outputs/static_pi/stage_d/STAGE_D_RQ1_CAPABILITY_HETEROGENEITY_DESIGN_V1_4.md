## 二、四项科学性加强（V1.4）

### 1. 节点类型可比较性

不只按 node_type 汇总，同时记录四个特征：

| 特征 | 定义 | 用途 |
|---|---|---|
| node_type | extract / timeline / reason / verification / report | 跨任务的主比较单位 |
| information_complexity | 文档数、原文长度、关键事实数 | 解释难度差异 |
| evidence_dispersion | 事实涉及的不同文档数/跨度数 | 解释证据分散 |
| output_complexity | 节点输出字段数/事实数 | 解释输出负担 |
| dependency_depth | 节点在 DAG 中的层级 | 解释上游依赖 |

不能把所有 extract 视为同质：E04 财务数字抽取与 E07 监管事实抽取的难度/证据结构不同。分析中以 node_type 为主，四特征为解释性协变量（探索性，不单独做显著性宣称）。

### 2. LOTO 任务数量平衡

- 先算**每个任务内部各节点类型的均值**，再对训练任务**等权汇总**；不把所有节点混合平均，避免 E04（6 节点）权重过大。
- 每折检查训练任务是否包含留出任务的节点类型：
  - extract / report：5 任务全有 → 可估计；
  - timeline：仅 E04 → **留出 E04 时训练集无 timeline，标记不可估计**，不强行给模型选择；
  - verification：E04/E07 → 留出其中一个时另一个在训练集，可估计；两者同时留出不可能（单折一任务）。
- 报告每折哪些类型可估计/不可估计，不把不可估计类型计入 LOTO 收益。

### 3. 节点级 Gold 独立于被测模型

- 每个节点材料包含：原始 doc_id、输入合同、必要事实、正确值/允许表达、原文证据跨度、UNKNOWN 条件、输出格式、参考上游及来源。
- 评分四项分离：值正确、证据定位、证据支持、合同遵循；**不能因数值正确就认定证据核验正确**。
- E06/E08 的投资者沟通风险因素、E07 的审计最终意见/立案精确日期，原文不可判定 → UNKNOWN；报告若断言具体值即扣分（unknown_asserted）。
- Gold 生成过程不使用 GLM/DeepSeek；E04 的 M8-P2 事实为历史冻结材料。

### 4. 第二层真实终端收益

- 主比较固定：`ΔQ = Q_LOTO − Q_Best_Unified`。
- **Best Unified 只由训练任务决定**：每折在训练任务的 terminal Q 上比较统一 GLM/DS，选更优者作为留出任务的对照；不得用留出任务结果选对照。
- 同时报告 `ΔC`（token/调用/费用）、`ΔL`（makespan）、`ΔR`（合法执行率/节点完成率）。
- 回答问题：局部优势是否传递到终端？上游错误是否抵消？异构分配是否增加成本？是否质量升、时延降/升？
- Materiality（预登记）：Q ≥ +1 TP（≈+4.3%）且 CI 下限>0、关键事实不减少；C/L ≤ +10%；可靠性非劣；UNKNOWN 门禁。5 任务定位探索性/机制验证。
