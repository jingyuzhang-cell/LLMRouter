## 一、表述强度规则（写作纪律）

| 等级 | 允许的表述 | 禁止的表述 |
|---|---|---|
| **强证据** | "实验表明/证实" | — |
| **方向性证据** | "观察到/初步支持/方向性一致" | "证明/显著/普遍" |
| **链路证据** | "执行链路数据显示" | "终端质量提升" |

| **边界发现** | "在X条件下不成立/存在边界" | 将边界隐去 |

### 结论 5：恢复 ≠ 正确（恢复靶向性）
| | |
|---|---|
| **证据等级** | 强证据（MVR2 因果）+ 回顾性机制证据（逐槽分析） |
| **来源** | MVR2 Proposed 4/4 链路完备但编码归一 TP=2.50 < Static 5.75；逐槽分析 53% 错误在 SINK 值-槽映射（正确值存在但填错） |
| **可写** | "MVR2 受控对照中，Proposed 恢复了执行链完备性（4/4 vs Static 4/4）但终端 TP 反而低于 Static（2.50 vs 5.75）；逐槽回顾性分析发现 53% 的首次错误形成于 SINK 层的值-槽映射而非 J1 层——恢复动作作用于故障节点（J1），但质量瓶颈可能位于不同节点（SINK）" |
| **术语** | "恢复靶向性"（recovery targeting）：恢复动作的目标节点与终端质量瓶颈节点可能不一致 |
| **不可写** | "恢复靶向性已获因果验证"（目前为单任务回顾性机制证据） |

### 结论 6：单模型分配缺乏异构恢复空间
| | |
|---|---|
| **证据等级** | 链路+质量双证（P11） |
| **来源** | P11 A2_diag j1anom 0/17（无合法替代→诊断换模无法执行）；A1_blind j1anom 8/17（同模型重执行恢复执行，非跨模型换模） |
| **可写** | "P11 全 DS 路由下，J1 故障时诊断换模策略因缺乏异构替代模型而无法恢复（0/17）；同模型盲换臂通过重执行恢复至 8/17，但这不是跨模型换模——**单模型分配缺乏异构替代所提供的恢复空间**" |
| **不可写** | "单模型完全没有恢复能力"（A1 的 DS 重执行确实恢复了执行）；"0/17 = 模型生成了 17 个错误答案"（0 是执行失败的条件零分，非答案错误） |

## 三、P11 两个表述修正（操作者指示）

1. **A2_diag 0/17**：诊断换模策略因无合法替代模型而无法执行恢复→**执行失败的条件零分**，不是模型生成 17 个错误答案。论文中应写"未能恢复（执行失败）"而非"质量为 0"。
2. **A1_blind 8/17**：DS 重执行恢复了链路——但这不是跨模型换模（J1 本来就是 DS），是**同模型重执行**。论文中应区分"异构换模恢复"（PHASE2B/MVR2）与"同模型重执行恢复"（P11）。

## 四、MVR2 逐槽术语修正（操作者指示）

将"首次信息丢失位置"改为三分：
- **信息未传递**（E→J1 层）：上游有正确信息，下游文本中不再包含（24%）
- **语义映射错误**（SINK 层）：正确信息存在于下游文本中，但绑定到了错误槽位（53%）
- **终端生成错误**（SINK 层）：上游信息正确，终端表达仍错误（可归入语义映射大类）
- J2 层丢失（2%）：信息在 J2 核验/汇总中被丢弃
