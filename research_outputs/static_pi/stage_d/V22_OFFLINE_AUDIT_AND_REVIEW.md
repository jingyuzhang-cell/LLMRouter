## 3. G1 / G2 / G3 独立审计

### G1 DAG 版本一致性 — **PASS**

拆分后：`E2.deleted=True`；`E2_merge.downs=['J1']`（继承出边）；`E2_pos/E2_rest.ups=[]`（继承入边）；
`J1.ups=['E1','E2_merge']`；无悬挂边；无环；`dag_version=1` 且 `edits[{op:'split',added:[...]}]` 可追溯；
旧节点不再出现在 `active_models()`。

### G2 π 作用域与依赖失效 — **PASS**（逐节点表见 `G2_NODE_AUDIT.md`）

S1、Joint 臂实测：

```
U（R₀ 与 Z 之后重算）= ['E2_pos','E2_rest','E3','E4','J1','J2','SINK']
pi_scope              = 同上（逐节点一致）
排除项：E1（异常前已完成）、E2（被 Z 删除）、E2_merge（代码节点）
```

**dependency invalidation 单独验证**（测试 05）：构造 J1/J2/SINK 均已 Completed 的状态，
R₀(E2) 正确把三者置回 Ready，并在随后重算的 U 中被纳入。

**Running 后代的处理 —— 标为 BLOCKED（语义未定义，不擅自发明）**：
- 在本实验的 S1/S1b/S4′ 中，detect 发生在节点调用返回之后（同步），
  而异常节点的后代受依赖门控**尚未派发**（J1 需 E1、E2 均 Completed），故**不存在 Running 后代**；
- 引擎对 Running 节点一律不进入 U（测试 07），其请求按原模型结算；
- **但如果**运行时真的出现"后代 Running 且其上游版本已变"，该请求会带着**过期依赖**完成，
  本方案**未定义**过期结果的处理（丢弃？重跑？标记 stale？）。
  **这是在真实执行前必须裁定的语义空白**，不得由实现自行决定。

## 7. 现有实验能支持与不能支持的结论

**能支持（若真实执行后）**
- 在"抽取合同过度负荷导致字段持续性缺失"条件下，任务重新分解相对固定闭包重执行的**增量收益**；
- 整体模型重配置在此类异常下的**独立增量**（预期接近零，因缺陷是合同级而非模型级）；
- Z×π 是否互补（**描述性**，Pilot 不足以推断）。

**不能支持**
- 完整三维联合优化 `a=(Z,R,π)`（R 本期固定）；
- 节点级异构分配价值（Phase P 未达标）；
- 任何确认性推断（单任务、6 个 Z 有效单元、N=6 双侧最小 p=0.03125 > Holm 0.025）；
- 对"语义错误"类异常的结论（S4′ 仅限合同违规）。
