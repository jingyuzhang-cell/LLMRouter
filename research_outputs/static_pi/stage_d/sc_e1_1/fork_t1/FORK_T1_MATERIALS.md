## 四、终点与配对统计

**终点（预先固定）**：
- **机制主终点**：被压制槽的终端恢复数 R ∈ {0,…,5}，即 F8、F9、F10、F11、F20 中终端为 TP 的个数，每次重复各计一个值。
- **质量主终点**：Q_all（v1.1 合同，冻结评分器）。
- **安全终点**：错误断言率（无断言为空值）、错误断言负担、覆盖率、拒答率、静默遗漏率。安全门为错误断言率 ≤ A0 + 5pp，“无法判定”不算通过。
- **解释用的辅助量**：J2 重跑后的压制再发生率，即 A1、A2 的新 J2 输出中这 5 槽仍被 V2 判为明确压制的比例；A3 的误删数，即被删条目对应槽在 A3 中变为错误断言的个数。
- **成本时延**：调用数、token、记账与边际费用、墙钟时间。时延只在同节点之间比较，因为 J1 有缓存命中。

**比较方式**：同一检查点、等 k 的臂间比较，上游状态完全相同。

| 对比 | 回答的问题 |
|---|---|
| A2 − A1 | 等调用数下，检测器反馈相对盲重跑的增量 |
| A3 − A0 | 只动 SINK 的结构绕过增量 |
| A2 − A3 | 回到 J2 与只动 SINK 的代价收益比 |

**统计（描述性，不作确认推断）**：
- 每臂报告 3 个 R 和 3 个 Q_all 的逐值、均值与极差，以及逐槽结果。
- 3 对 3 的精确置换检验共 20 种排列，单侧最小 p 为 0.05，只报告、不判显著。
- **预注册判读规则**：
  - 只有当 X 的 3 个 R 全部 ≥ Y 的最大值，且 Q_all 均值差超过 A0 的极差时，才记为“X 优于 Y”；否则记为“无法区分”。
  - 若 A1 与 A2 无法区分，且 A1 的压制再发生率低，则收益归于“重采样”，不归于“诊断”。
  - 若 A3 不劣于 A2 且成本更低，则记为“最小范围动作占优”。
