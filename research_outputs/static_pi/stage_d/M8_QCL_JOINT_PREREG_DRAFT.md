## 0. 一句话科学问题

在**冻结的 DAG 拓扑、模型池、动作集、任务面板与评分器**下，Q/C/L 三目标的**有限空间全局最优**是什么？现有部署策略（Static / Fixed / Joint / Adaptive）离它多远？最优解是否随目标向量与约束（deadline / budget）改变？

---

## 1. 先定义“全局最优”（本窗口最关键的纪律）

真实系统是随机的、动作空间连续的、模型调用不可穷举，因此**不能声称真实世界的全局最优**。本窗口只声称以下分级中的 L1/L2：

| 级别 | 含义 | 可声称？ |
|---|---|---|
| **L0 Oracle gap** | 逐节点取实测最优模型的不可达上界，只作参照 | ✅ 可报告 |
| **L1 Surrogate-optimal** | 在冻结的有限策略空间内，用校准代理精确枚举得到的最优前沿 | ✅ 可声称（限定词：under frozen surrogate） |
| **L2 Validated surrogate-optimal** | L1 + 留出真实执行验证，预测误差在预注册阈值内 | ✅ 可声称（限定词：validated on held-out tasks） |
| **L3 True global** | 真实随机系统上的全局最优 | ❌ 不可声称 |

**硬约束**：任何论文表述必须带 “under the frozen policy space and calibrated surrogate” 或 “validated on held-out tasks” 限定；禁止裸写 “globally optimal”。

## 2. 冻结的策略空间（必须有限、可枚举）

| 维度 | 定义 | 规模 |
|---|---|---|
| DAG 拓扑 | 固定（VAL 事件 DAG，N≤8 节点） | 1 |
| 节点分配 | 每节点 ∈ {DS, GLM, GLM-Flash, Qwen} | M^N ≤ 4^8 = 65,536 |
| 恢复动作 | {none, retry, swap, split(Z2), verify(Z1), safe-degrade(Z3), stop} | 每故障类型一个动作 |
| 决策规则 | 阈值族：剩余时间桶 × 故障类型 → 动作（阈值从 VAL 校准，冻结后不调） | 有限 |
| 约束 | deadline ∈ {120,150,250}s；budget 第二窗口再加 | 3 |

**明确排除**：连续阈值搜索、在线学习策略、任意提示词工程、跨模型池泛化。这些不属于本窗口。

## 3. 代理模型（零调用构建）

**输入**：
- CAP 380 行（4 模型 × 19 节点 × 5 重复）：node_Q、parse、truncation、tokens、latency；
- VAL 节点级测量（~200 调用，窗口内采集）；
- 三臂执行的逐节点输出（用于校准传播）。

**估计量**（每个 node kind × model × contract）：
- `P(parse ok)`、`node_Q` 的经验分布（含跨重复方差）；
- 输出 token 中位数/分位数、单调用时延中位数/分位数；
- 交付失败率（截断/空文本/传输）。

**传播模型**（需预冻结并在 VAL 上检验）：
- extract → merge：事实覆盖按“上游命中数 × 池覆盖度”建模；
- merge → report：终值/证据分别建模；
- 依赖独立性假设必须做留一检验，不通过则改用联合重采样。

**校准检验**：留一事件/留一任务；预测 vs 实测的 Q/C/L 误差；报告 MAE 与区间。

---

## 4. 枚举与求解（零调用）

1. **分配枚举**：M^N 全枚举（N≤8 时 ≤65,536），逐分配计算 (Q, C, L) 期望。
2. **恢复策略**：对每个故障类型，在冻结动作集上做后向归纳（MDP，状态 = 故障类型 × 节点类型 × 时间桶），得到期望最优动作；不允许跨类型共享未验证动作。
3. **多目标**：对每个分配 × 策略，得到 (Q,C,L)；非支配过滤；冻结参考点（1.1×max）算 HV。
4. **目标向量**：Q only / Q+C / Q+L / Q+C+L 四组，分别报告最优解与前沿变化。
5. **复杂度控制**：N>8 时用分支定界/剪枝，并在报告中标注“非全枚举”。

**产物**：`M8_FRONT.json`（全部分配点）、`M8_PARETO.json`（非支配集）、`M8_GAP.json`（部署策略到前沿的距离）。

## 5. 真实执行验证（窗口内唯一付费部分）

**目的**：验证代理预测，不是重新搜索。

| 项 | 方案 |
|---|---|
| 采样点 | 前沿上 3 点（低 C / 中 / 高 Q）+ 4 个部署策略 |
| 任务 | VAL 2 事件 × 2 变体；TEST 2 事件 × 2 变体（确认用，不看结果调参） |
| 重复 | 2 reps（VAL）+ 3 reps（TEST） |
| 判定 | `|ΔQ| ≤ 0.05`、`|ΔC| ≤ 15%`、`|ΔL| ≤ 20%` 才升 L2；否则降 L1 |
| 预算 | ~500–800 调用 |

**统计**：任务聚类 bootstrap；精确符号翻转；配对；不跨协议池化；失败/UNKNOWN 全保留。

## 6. 对照与主/次终点

**对照**：Static、Fixed-Recovery、Joint-Dynamic、Adaptive、Oracle-assignment、Surrogate-optimal。

**主终点**：
1. 部署策略到代理前沿的最优性 gap（ΔQ、ΔC、ΔL，带 CI）；
2. 目标向量敏感性：最优分配/动作是否随 Q→Q+C→Q+L→Q+C+L 改变（给出翻转点）。

**次终点**：HV、每 +1 TP 的成本价格、约束满足率、恢复成功率。

**判定**：
- 正向：部署策略存在可测 gap，且 Adaptive 在约束下 ≥ 最优固定；前沿至少两个非支配点。
- 零：所有策略落在同一前沿点（天花板/无故障梯度）→ 报告“无可分辨前沿”。
- 负：代理最优在真实执行中不可复现（L2 失败）→ 报告“代理失效”，不调参重跑。

## 7. 停止规则（预注册）

- 预测误差超阈值（|ΔQ|>0.05 或 |ΔC|>15% 或 |ΔL|>20%）→ 停止确认，降级 L1；
- R1 保护集倒退 ≥2 → 停止；
- INCOMPLETE ≥1/3 → 停止；
- 系统性截断（同节点 ≥20%）→ 停止并修合同；
- 预算触顶 → 按执行边界停，不半组启动；
- 任何“试到正结果”的追加 → 禁止。
