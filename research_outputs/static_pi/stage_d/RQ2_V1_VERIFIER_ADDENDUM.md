# RQ2 V-1 核验器测量附录：分层加权复核（应操作者审查意见）

**结论先行：分层抽样确实引入了权重偏差——16 个"核验器拒绝"层被 100% 抽中（权重 1.000），"支持"层欠采样（权重 1.261–2.957）。按纳入概率加权（Horvitz–Thompson）后，总体口径的特异度是 0.386（近似 95% CI [0.316, 0.457]），比未加权报告的 0.529 更低。门槛判定不变：特异度远未过 0.85，Q_full 维持"未验证"。0.386/0.529 均应表述为"AI 共同评审样本中的观测特异度"，不是人工金标准下的核验器真实特异度。**

## 2. 加权结果

| 估计 | 未加权（原报告） | 设计加权（总体 403 口径） |
|---|---:|---:|
| 灵敏度 | 0.988 | **0.994**（近似 CI [0.984, 1.000]） |
| 特异度 | 0.529 | **0.386**（近似 CI [0.316, 0.457]） |

- 设计效应 deff = 1.094，有效样本量 n_eff ≈ 182.8；区间为 n_eff 下的正态近似（Wilson 区间不直接适用于加权估计，如实注明）。
- 加权推算的总体图景：403 对中约 **46.6 对（11.6%）实为"引用不充分支持"**，而核验器只正确拒绝了约 **18.0 对**——总体上核验器放过了约 28.6/46.6 ≈ 61% 的不充分支持对。
- 总体核验器 supported 率 95.0%（403 对）vs 样本 90.0%——同向佐证样本偏"拒绝"。

## 3. 修订后的表述（以此为准）

1. 0.529 是 200 对分层样本内的未加权观测；**总体口径的观测特异度 ≈ 0.386**。两者都远低于 0.85 预注册门，判定不因加权而翻转。
2. 标注者是 GLM-5.3，核验器是 glm53flash（GLM-5.3-Flash），同家族——**上述数字是 AI 共同评审的观测值，不是独立人工金标准测量**；人工复核前不应写入论文正文作为核验器性能。
3. 对 V2 结论的影响不变：Q_main 主结论不受影响；Q_full（B 60.3% / C 41.2%）按总体口径的过度放行率（~61%）应进一步视为**乐观上界**。
4. 对 V3 的约束不变且加强：主指标 Q_main；Q_full 仅作参考并带"未验证"标签。
