**版本**：V0.3 草案 → 冻结（2026-11-07）。**本文在实现之前冻结**；实现与零调用验证（`damjs_r2/v03/`）不得偏离本文语义。
**依据**：操作员 2026-11-07 裁决（30 次暂缓；双口径采纳；两机制批准为预注册假设；不直接实施到真实批次）。

## 假设 H-ND（非破坏性结果提交 / 事务性提交）

**问题**（2026-11-06 冒烟实证）：A‴ 执行器为"末次尝试覆盖"语义——恢复重试产出不可解析输出时，空 v2 无条件覆盖先前可用的 v1，下游质量崩塌（S3 严格 −11）。两案例：修复调用撞 8192 上限（正文空/169 字符碎片）。

**机制定义**：

```
节点 n 因恢复动作被重新派发时（state≠Completed 且 outputs[n] 已存在）：
  v1 = outputs[n]；v1_valid = extract_json(v1) 是 dict
  执行得到 v2：
    v2_valid = extract_json(v2) 是 dict
    v1_valid 且 非 v2_valid → 回滚：outputs[n] = v1（逐字节），记 node_rollback 事件
    其余情况 → 提交 v2（含"可用换可用"的部分改善，如 S3 FMT 的 +2）
  状态机/异常信号/History 观测仍按 v2 记录（回滚不篡改审计）；
  下游失效不回退（成本已沉没；恢复的是内容世界，不是成本世界）。
```

**提交合格判据取"可用性"而非"信号清除"**，理由：部分改善（可用换可用）仍具价值；信号清除标准会把 S3 FMT 的 +2 误回滚。

**预登记的可检验命题**：
- H-ND-1：v2 不可解析且 v1 可用时，回滚后下游消费 v1，终端质量不劣于同内容无修复路径（S3 场景：回到 ≈Static 水平），差异仅剩已沉没的调用成本与时延。
- H-ND-2：v1 本身不可用（如首调即撞限）时无可保护对象，行为与 R2 相同（不制造额外损失）。
- H-ND-3：可用换可用路径不回滚（S4 FMT / S3 FMT 部分改善保留）。
- **边界声明**：S3 的 v1 缺 relay 字段，保留 v1 ≠ 恢复全部质量；H-ND 验证的是"避免额外损失"，不宣称损失归零。

## 假设 H-EV（失败概率期望收益门禁）

**问题**：现有门禁只用 μ（历史均值增益）与 L̂（p95 时延），看不见动作执行失败概率 p_a；EV 翻转阈值实测仅 10.5%（严格）/17.7%（宽松），服务状态漂移即翻转最优决策。

**决策规则**（预注册）：

```
E[ΔQ(a)] = (1 − p_a)·μ_a − p_a·L_a > 0   （在既有 reliable-gain / 成本 / 截止期门禁之外追加）
不满足 → 该候选剔除（excluded: EV_gate），事件记录 p_a、EV
```

- μ_a：沿用冻结 GAIN_TABLE（不改）。
- **L_a（无回滚世界的严格口径实测损失，预登记表）**：Z_structure(J1)=11；R=11（同节点语义，保守）；Z_format 不适用（本地确定性，p_a≡0，永不受此门禁约束）。
  **保守性规则：EV 门禁一律按无回滚世界评估**（M1 是安全网，不是放行许可证）——两机制同开时门禁仍可能在坏服务下拦截动作。
- **p_a 估计（Beta-Binomial，执行内在线估计 + 服务状态锁存）**：
  - 失败事件（每次 LLM 调用）：传输错误/超时、`stop ∈ {max_tokens, length}`（撞限）、或输出不可解析。
  - 先验：正常服务 `Beta(14, 250)`（均值 5.3%，192 次基线 14/264）；**慢服务锁存后** `Beta(33, 67)`（均值 33%，2026-11-06 实测），后验 = 先验 + 执行内该模型计数。
  - 锁存规则（按模型族，执行内一旦触发保持）：本执行内该模型任一调用 撞限 / 失败 / 或墙钟 > 1.5×基线 p95（GLM: 154 s；DS: 10.5 s）。
  - V0.3 条件化维度仅到**模型级（执行内）**；操作员列出的智能体/节点类型/动作类型/跨执行服务状态维度登记为 V0.3+ 路线（跨执行需状态账本，另批）。
- **已知限制（预登记）**：单次执行 ≤14 调用，正常先验下后验无法越过 10.5% 阈值（需 k>15）——即正常→慢的**转移瞬间**门禁来不及拦截，由 H-ND 兜底；门禁的预防价值集中于锁存后的后续决策与（未来）跨执行状态共享。

## 与既有机制的交互（预登记）

| 情形 | H-ND | H-EV | 预期 |
|---|---|---|---|
| 正常服务、修复成功 | 不触发（提交 v2） | 不约束（p≈5.3%, EV>0） | 与 R2 同 |
| 正常→慢转移、修复撞限 | **回滚保 v1** | 事后锁存 | 损失从 −11 → ≈0（+沉没成本） |
| 锁存后的后续修复决策 | 保险网 | **EV<0 剔除** | 不再投入负期望动作 |
