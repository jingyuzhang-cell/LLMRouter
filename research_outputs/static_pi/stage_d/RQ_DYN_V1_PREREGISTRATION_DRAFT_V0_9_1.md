## 3. 动态策略（冻结，触发条件全部为确定性代码判据）

### 3.0 故障处理优先级阶梯（单一执行序，防双重修复/计费）

每个决策点按以下顺序求值，**一个故障只走一条修复路径，成功即终止该故障的处理**：

1. **Z3 前置判定**：若"上游全灭"（全部 extract 节点 base+reroll 解析失败且 chosen 为空）成立 → **直接降级交付，跳过其余一切修复动作**；
2. **R（同模型恢复）**：节点信号触发 → 同模型重掷 1 次；成功 → 结束；
3. **π（异构兜底）**：R 失败且符合 §3-π 的交付可靠性条件 → qwen 重掷 1 次；成功 → 结束（**并取消该节点已排队/可选的 Z2**）；
4. **Z2（结构拆分）**：仅当 merge 节点的 base、同模型重掷、qwen 兜底**三次尝试全部 parse_ok=False** 才触发拆分（更新定义：原"base 与 reroll 均失败"由三连败取代）；
5. Z1（冲突核验插入）独立于故障阶梯：由 merge 成功输出中的结构化冲突判据触发，不与 R/π/Z2 竞争。
全部尝试（含失败尝试）照常计费入账；同一故障在任一环成功后不得再次触发后续环节。

**信号**：解析失败 / 截断（stop∈{max_tokens,length}）/ 生产缺失 / 引用缺失 / 下游输入退化（上游有效事实数 < 序列化输入的 50%）——均为代码可判。

- **R**：信号→同模型重掷 1 次；仍败→交 π。
- **π**（依据=可靠性与时延证据；**不引用节点质量画像**——CAP/RQ3 教训已证画像不直接适用于实时分配）：
  - 交付类节点（merge/report/verification）重掷失败 → **qwen**（依据：CAP 实测 qwen 0% 截断、100% 解析——纯交付可靠性依据，非质量主张）；
  - **extract 类**：仅当失败原因为**解析失败/截断等交付可靠性问题**且同模型重掷仍败 → qwen 兜底（**明确声明：这不表示 qwen 抽取质量更优——CAP 实测 qwen extract .649 < deepseek .759**；选它只因零截断的交付兜底）；
  - 关键路径节点（至 report 最长剩余链上的节点）首次重掷优先 deepseek（时延：中位 2.8s vs 27.5s）；二次失败才 qwen；
  - verification 节点初始分配仍 deepseek（CAP n=1 不构成初始异构依据）。
- **Z**（触发判据逐条客观化）：
  - **Z1 插入核验节点**：触发=merge 输出中存在 **fid 相同而规范化日期/数值集合不同**的事实对（对 merge 输出 facts 的确定性两两比较：normalize 后按 fid 分组、组内解析全部日期与数字、比较集合；无任何模型判断）。触发后插入 verification 节点，仅针对该 fid 组，重算 D1 预算。
  - **Z2 拆分 merge**：触发=该 merge 节点 base、同模型重掷、qwen 兜底**三连败**（见 §3.0 第 4 条）。**无逻辑死角澄清（v1.0 冻结项）**：merge 节点在运行时**不存在非交付可靠性类失败**——四类信号（解析失败/截断/生产缺失/引用缺失）对 merge 全部属于交付可靠性失败，π 兜底因此对 merge 恒可达，三连败定义无死路；若 qwen 兜底调用本身发生传输级错误（非解析），该次同样计入失败（否则三连败不可达）。拆分合法性：按上游分支拆为 k 个单支 merge + 1 个 join（join 依赖全部支路、report 依赖 join），依赖图无环、其余边不变；每支路按 D1 公式重算预算。
  - **Z3 降级报告**：触发=该任务 DAG 中**全部 extract 节点均 base 与 reroll parse_ok=False 且 chosen facts 为空**（"上游全灭"的代码定义）。动作=跳过 merge/report 的一切重掷，report 以空上游 + 显式 UNKNOWN 清单执行；记录为部分交付。
- 全部动作计入成本/时延；未动作者如实记"未触发"。

## 4. 归因条款（联合收益 vs 单项动作收益，操作者裁定）

- **主结论**：Joint(Z,R,π) 整体 vs HomDS+D1D2 的终端 Q_main 差——**仅此一项为"收益"结论**。
- **机制分析**：动作日志（触发条件、改变节点、槽位前后变化、资源消耗）用于解释收益来源，**不得据此声称 Z/R/π 各自的因果贡献量**。
- **未触发动作**：明确标记"未验证"；不为分离三动作增加消融批次。
- 统计边界：n=2 事件——探索性机制验证；**逐事件结果必报**，不只报合并均值。
