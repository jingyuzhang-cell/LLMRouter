# STAGE_D V2.0 Profiling + Pilot 设计（零调用，待批准）

**状态**：设计候选；**不构成真实调用授权**。D1=Pilot 优先、D2=S5 方向性、D3=预算候选待核算、D4=先 Profiling。V1.3.2 继续历史冻结；192 HOLD。

## 一、目标（不要变成"GLM 思考效果"研究）

研究问题不变：**异构模型的能力差异，能否被 DAG 节点级分配与反馈驱动的联合调度利用，转化为可重复的 Q/C/L 收益？**  
V2.0 只重新测量模型版本/推理模式变化影响的参数，不改变研究主线、六臂对照、R1、精确检验框架与独立终端评分。

## 二、Phase P：新模型 Profiling（先于 Pilot）

| 维度 | 测量 |
|---|---|
| 模型 | GLM-5.3-Flash（thinking=low）、DeepSeek（现状配置） |
| 节点类型 | E1/E2/E3/E4 抽取、J1 合并/relay、J2 口径消歧、SINK 终端（FMT 确定性，不计模型能力） |
| Q | 节点输出合同正确率、证据锚定、终端得分（独立评分） |
| C | 输入/输出 token、实际费用（GLM 套餐 / DS 账单） |
| L | 首 token、节点完成时间、失败/超时 |
| 可靠性 | 超时、失败、解析失败、合同违约、迟到 |
| 推理模式 | thinking=low 实际配置与响应形态 |
| 异构性 | 同一节点类型上 GLM vs DS 的能力差；差异是否足以支持异构分配 |

**任务隔离**：Profiling 使用独立任务（D2/Stage C 任务或 E04/E07），**不使用确认性任务的终端事实**；pilot 也独立。  
**样本（候选）**：3 个独立任务 × 5 类节点 × 2 模型 × 2 重复 ≈ 60 calls；输出能力表与异构性结论。  
**输出**：新模型能力画像；静态 π 分配是否需调整；Pilot 的预期解析率/时延/调用数。

## 三、Phase Pi：小规模 Pilot（独立任务）

- 目的：在 thinking=low 下验证真实执行、解析率、调用消耗、截止期、终端质量；**不估计主实验显著性或最终功效**。
- 设计：6 臂 × S3/S4 各 3 重复 = 36 个执行块（可加 S0/S5 少量）；每执行沿用 V2.0 候选预算（20 调用 / 300s）；记录 Q/C/L、竞速、迟到、异常。
- 数据隔离：Pilot 任务独立，**不进入确认性样本**；Pilot 记录仅用于参数估计。
- 输出：真实配对差分布、方差、零差比例；解析率、调用/token/时延；S5 的真实竞速记录（方向性）。

## 四、Phase R：重新计算功效与检验

- 用 Pilot 的配对差分布作为新先验；必要时保留 D2 折半先验作敏感性。
- 用 `exact_perm_dp.py`（精确 DP，统计方法与枚举完全一致）评估 N=16/24/32：
  - 原型验证：m=24 约 1.1ms、m=32 约 2.7ms；D2 反演与 500 例枚举逐例一致；
  - 保守先验投影（nsim=2000）：N=16≈0.515、N=24≈0.729、N=32≈0.849；最终按 20,000×3 重跑。
- 决定主检验 N、矩阵规模、预算；若 Pilot 效应过低，N=32 仍不足则**不启动确认性主检验**，如实报告。
- **`exact_perm.py` 保持冻结**；V2.0 使用新的 `exact_perm_dp.py`，需冻结+独立审计，统计方法不变。

## 五、Phase D：确认性实验决定
