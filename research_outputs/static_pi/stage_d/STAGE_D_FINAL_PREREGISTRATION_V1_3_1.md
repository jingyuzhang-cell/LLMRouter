## 修订 A · 精确符号翻转检验的统计假设（V1.3 缺失项，操作者审查项 1）

### A.1 零假设与交换性

**H0**：对于给定的配对差 D_i = TP_Proposed,i − TP_Simple,i，其分布关于 0 对称（即两臂在期望上等效）。
**在 H0 与对称性下**，给定 |D_i| 的取值，D_i 的正负号独立等概率——这是符号翻转（sign-flip）精确置换有效的**唯一前提**，本文明确列为假设而非自动成立。

**可检验性说明（如实）**：对称性本身不可直接检验（需在 H0 下）；但**违背对称性的可观察信号**是分布右偏/左偏的中位差——因此预登记 **Hodges–Lehmann 配对位置差估计及其 bootstrap 95% CI 作为对称性的旁证报告**（若 CI 严重偏离 0 且方向与结论一致，说明数据本身偏离 H0，不构成对检验的违背；若结论依赖少数极端对，报告对删除极端值的敏感性）。

### A.2 置换单位（操作者审查项：不得把同上下文观测当独立单位）

| 层级 | 单位 | 独立性论证 |
|---|---|---|
| **置换单位** | **一个配对 = (场景, 重复) 的 (Proposed, Simple) 两臂** | 两臂共享同一冻结上游、同一故障时刻表、同一预算/资源条件——配对满足"同条件对照"；**配对内两臂互相匹配**，差异仅来自策略 |
| 配对间独立性（同族内） | 8 个 S3 配对、8 个 S4 配对 | 各重复为独立执行（独立 API 调用、独立模型采样）；**分块随机化**（区组=场景×重复，区组内六臂顺序随机，区组顺序随机）保证不同重复不在同一时刻臂间并发——排除时段共享 |
| 配对间独立性（跨族） | S3 与 S4 合并 16 对 | **S3 与 S4 的重复编号不联动**——S3 r_k 与 S4 r_k 属不同区组、不同时段、不同故障机制；无共享 DAG 执行上下文。**合并假设：两族在"持续性缺陷 + 匹配动作"语义下同质**（这是设计假设，不是统计事实） |
| 已知残余风险 | 同一 API 服务的时段性波动 | 无法完全排除；如实登记为**跨族合并的敏感性来源**，并以逐族结果（S3-only / S4-only）并列报告 |

### A.3 聚类结构（预登记）

- **主分析：合并 16 对精确符号翻转**（scipy 不用于正式分析；用 `exact_perm.exact_paired_perm`）；
- **敏感性 1（逐族）**：S3-only（8 对）与 S4-only（8 对）分别报告精确 p——**若逐族结论与合并矛盾，以逐族为准并如实报告**；
- **敏感性 2（聚类稳健）**：若审稿要求以"族"为聚类单位，则聚类数仅 2，**无统计功效**——预登记承认此局限，不伪造聚类稳健结果；
- **族非伤害门禁**（V1.1 已定）：任一族中位差 < 0 → 主检验判负。

### A.4 正式分析与模拟的一致性（操作者 checklist 项 1）

- **终局分析脚本必须 `from exact_perm import exact_paired_perm`**，禁止使用 scipy.wilcoxon 作正式 p 值；
- **功效模拟 `power_sim.py` 与本检验同程序**（V2.1 用 scipy exact 仅作连续敏感性对照，正式整数化模拟用 `exact_perm` 全枚举路径——见修订 B）；
