## 4. 机制分析

**为什么动态调度没有产生收益？**

1. **反馈信号太粗**：证据完整率、事实保留率、答案完整率三个信号在 DS 节点上的实际值大多高于阈值（平均升级率仅 0.5 次/格），反馈触发的升级太少、太晚。
2. **DS 在这些任务上并不差**：Single-DS 的 Q=0.224 与 Static（m,v=GLM）的 0.252 差距仅 +0.028（不显著）——R5 合成实验中 m+v 的质量优势在真实任务上远小于合成假设。
3. **升级方向不一致**：某些任务上 GLM 反而比 DS 差（MVR1 上 dynamic_pi 升级后 Q 反而低于 single_ds），说明"强模型"并非在所有节点类型上均优于"弱模型"。
4. **Joint 的 Z/R 机制几乎未触发**（Z 平均 0.1 次、R 0 次）——验证节点很少检测到需要结构重构的问题。

## 5. 科学结论

1. **在当前任务族与模型对（GLM-5.3-flash vs DeepSeek-flash）上，执行反馈驱动的动态模型重分配不产生可测量的终端质量、成本或时延收益。**
2. 静态异构分配（m,v=GLM）同样不优于全 DS——R5 合成结论在真实任务上不成立。
3. **根本原因是模型能力差异太小**：GLM 与 DS 在这些节点类型上的实际质量差异不足以产生"升级值得"的场景。这与 V9 早期发现一致（GLM-Flash 在某些任务上更慢且不更便宜）。
4. **动态调度的前提是存在足够大的能力异质性**。当前模型对（同代、同价位段）不满足此前提。

## 6. 对后续研究的指导

1. **使用能力差异更大的模型对**（如 GPT-4 级 vs 7B 开源模型），使"升级"真正意味着质量跃升；
2. **在更复杂的 DAG 上测试**（当前 7 节点过于简单，反馈触发点太少）；
3. **R5 的合成机制参数（δ=0.20 的质量差异）在真实模型对上不成立**——后续合成实验需要用实测能力差异校准；
4. 成本上限触顶说明实际 DS 调用费用高于预估（DS 单次 ¥0.005 vs 估算 ¥0.003），后续预算需上调 DS 单价。
