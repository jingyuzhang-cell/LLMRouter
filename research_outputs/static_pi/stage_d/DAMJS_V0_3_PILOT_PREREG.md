## 1. 科学问题与设计

在真实服务条件下分解两个机制的独立贡献：非破坏性提交（ND）能否消除结构恢复的破坏性失败，失败概率门禁（EV）能否在慢服务下拒绝负期望恢复，且二者是否交互。

| 臂 | ND | EV | 回答 |
|---|---|---|---|
| R2 | 关 | 关 | 原始基线（与 2026-11-06 冒烟同配置） |
| ND-only | 开 | 关 | ND 独立贡献 |
| EV-only | 关 | 开 | EV 独立贡献 |
| V0.3 | 开 | 开 | 联合 + 交互 |

- 16 次执行 = 4 臂 × {S3, S4} × 重复 {1, 2}，截止期 240 s，全部在同一父看门狗与同一账本下。
- **随机化与区组**：每格四臂在块内洗牌后**相邻执行**（种子 20261107:A，顺序冻结于 `DAMJS_V03_PILOT_MANIFEST.json` plans.A.order），使四臂面对相近服务时段；冒烟阶段固定为 S3 r1 四臂（1 块），主体为其余 3 块。
- 每格 2 次重复：**探索性证据，用于机制定位，不得作确认性统计结论**。

## 2. H-ND 语义（按裁决修正为节点级保护）

1. 恢复动作（structure_repair / format_repair / rerun_asis，及未被本批触发的 retry/swap）的输出先作为**候选**写入；
2. 候选通过合同可用性校验（`extract_json` 为 dict，即 V0.2.1 冻结口径）→ **提交为新版本**；
3. 候选不可用 → **该节点回滚**到恢复前已提交的有效版本（逐字节），记 `node_rollback`；审计层（raw.nodes）保留失败候选，不篡改；
4. **保护范围 = 被恢复动作直接指向的节点**。由父修复而失效的下游节点一律**无条件重执行**（沿用 A‴ 失效语义），其旧输出不因"曾经有效"被复用或回滚——不实现依赖指纹，不保护过期 DAG 状态；
5. v1 本身不可用（如首调即撞限）时无可保护对象，行为同 R2（H-ND-2 边界）。

实现：`damjs_r2/v03/damjs_v03.py`（CommitDict + recovered 集合，仅直接目标在派发时武装）。验证：机制套件 N1/N2/N3/N5/N8（8/8）。

## 3. H-EV 语义（估计规则全文冻结）

**决策规则**：对候选动作 a，`E[ΔQ(a)] = (1−p̂)·μ̂ − p̂·L̂ > 0` 方可入选（叠加在既有 reliable-gain/成本/截止期门禁之上）；违反 → 剔除并留痕。**EV 一律按无回滚世界评估**（保守原则：ND 是安全网，不是放行许可证）。Z_format 为本地确定性动作（p̂≡0），永不受此门禁约束。

**失败事件定义（V0.3.1）**：每次 LLM 调用结果为 ok / fail（stop∈{max_tokens,length} 撞限、输出不可解析、非超时的传输错误）/ truncated（超时且墙钟 ≥ 超时设定 − 1 s，按删失处理）。

**p̂ 估计（V0.3.1 冻结，删失一致口径）**：每次 LLM 调用结果分三类——ok / fail（撞限、不可解析、非超时传输错误）/ **truncated**（超时且墙钟 ≥ 超时设定 − 1 s：调度器截止期截断，按删失处理，不进分子分母，墙钟仍参与锁存）。先验与在线更新同口径：

| 先验 | 来源（排除删失后） | 参数 | 均值 | 95% CI | n_eff |
|---|---|---|---|---|---|
| 正常 | 基线 J1-GLM 撞限 14/241 结果调用（剔 23 次 120 s 删失） | Beta(14.5, 227.5) | 6.0% | [3.4%, 9.3%] | 242 |
| 慢服务（锁存后） | 冒烟 3/8 结果调用（剔 1 次截止期删失） | Beta(2.0, 3.0)（幂先验 a0=0.5） | 40.0% | [6.8%, 80.6%] | 5 |

正常先验的含义：**在超时设定足以让调用自然结束的条件下**的每次调用模型失败概率；不是无条件通用服务失败率。慢先验如实反映 8 次结果调用的极小样本（n_eff=5）。

- 锁存规则：本执行内该模型任一 fail、或墙钟 > 1.5×基线 p95（GLM 154 s / DS 10.5 s）→ 锁存至执行结束；truncated 不计数但墙钟参与锁存。
- 后验 = 先验 + 执行内计数；**每次决策对每个被评估候选留痕 (p̂, n_eff, CI95, truncated, μ̂, L̂, EV)**，实验后不得回改。

**μ̂ 与 L̂（V0.3.1 冻结，单一口径=宽松 TP；归一严格口径见下）**：μ̂ = +1.89（成功条件均值，基线 S3 n=7；归一严格 +2.11）；L̂ = 10（观测最大失败损失；归一严格观测 8.75/9/10）。阈值点估计 **15.9%**（归一严格 17.4%），为**探索性点估计**：自助抽样（20,000 次）阈值分位——宽松 [12.0%, 22.9%, 36.2%]、归一严格 [10.5%, 18.3%, 26.2%]；四状态点决策稳定性见勘误第 2 号第三节，其中"仅慢墙钟锁存"状态在宽松口径下稳定性 88.8%，标为**低稳健状态**，该状态的 EV 决策不单独作为机制证据。

**终端评分三口径（冻结）**：宽松 TP（诊断）/ 严格·原始（冻结评分器原样）/ **严格·归一（主指标）**——分析层按冻结 `DOCMAP {E1:D1,E2:D2,E3:D3,E4:D4}` 规范引用 doc 标签后评分（`caliber_revision.py`）。UNSUPPORTED 继续单列。归一依据：E 节点提示词正文即"文档 Dk 全文"，节点名与文档号指同一文档；原始严格分的随机波动几乎全部来自此命名约定（基线 S3 Static 原始严格 8/8=0，归一后 8–14）。

**诚实限制（冻结声明）**：V0.3 的 p̂ 条件化仅到模型级（执行内）；操作员列出的智能体/节点/动作/跨执行服务状态维度为 V0.3+ 范围。单次执行 ≤14 调用，正常先验下后验无法越过 15.9% 翻转阈值（任一 fail 即锁存）——EV 的现场拦截只在"锁存后的后续决策"发生，首次故障由 ND 兜底；锁存之后必须仍有可决策的结构恢复机会，EV 才可能产生终端质量收益，否则只能证明锁存与拒绝逻辑正确。

（v1 的 μ̂=1.29 与 L̂=11 为跨口径混用，已由上文 V0.3.1 参数取代，见勘误第 1、2 号。EV 仍一律按无回滚世界评估。）

## 4. ND 实际暴露机会与触发概率（修正分母）

ND 被实际检验需同时满足：ND 开启 ∧ 调度器选择恢复 ∧ 恢复调用发出 ∧ 调用失败。S4 无结构修复（J1 首调通过、FMT 本地），故 ND 暴露仅在 S3 的 ND-only（2 次）与 V0.3（2 次）；V0.3 还需首调有效（否则锁存触发 EV 拦截、且 v1 无效无可保护）。

| 单次 J1-GLM 失败率 p（删失一致口径） | ND-only 2 次 | V0.3 2 次 | **ND 任一触发** | EV 任一排除（4 次） |
|---|---|---|---|---|
| 6.0%（正常先验均值） | 11.6% | 11.0% | **21.3%** | 21.9% |
| 9.3%（正常先验 CI 上界） | 17.7% | 16.2% | **31.0%** | 32.3% |
| 37.5%（冒烟 3/8 点估计） | 60.9% | 41.4% | **77.1%** | 84.7% |

（ND-only 每次执行触发概率 = p；V0.3 = (1−p)·p；EV 现场排除需首调失败先行。）

**未触发的结论措辞（冻结）**：若本批未观察到 ND 触发事件，结论记为"**本批次未观察到 ND 触发事件，无法依据真实执行数据估计其现场收益**"——不记为有效，亦不记为无效；机制结论以零调用验证（N2 等）为准。

## 5. 指标、判据与停止规则

- 每次执行自动记录：宽松 TP / 严格证据 TP（CORRECT_GOLD）/ UNSUPPORTED 单列、调用/Token/¥（核算+现金）、墙钟与截止期、J1 撞限标记、回滚事件、EV 评估记录、身份块（15 组件 SHA）。
- 判据（方向性）：C1 无"v1 有效却因破坏性覆盖致严格 TP=0"（ND 臂）；C2 S4 收益保留（各臂宽松 TP ≥ 12）；C3 EV 排除全部伴随锁存、正常服务零误拦；C4 ND 增量成本 ≤ 每次回滚 1 调用 + ¥0.024 + ~130 s。
- 停止规则：R2 批次五条（SHA 失配/路由偏航/AttributeError/编号重复/账本触顶）+ V03_PATH_EXCEPTION（V0.3 代码路径异常）+ **C1_VIOLATION（ND 臂把无效输出提交到有效输出之上）**——触发即停，不追加预算。
