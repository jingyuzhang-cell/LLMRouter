# DA-JS v3 算法规格冻结（V3-SPEC ~ V3-VALIDATION；零调用；2026-11-07）

**交付物**：`da_js_v3.py`（V3-QCL 预测器 + V3-POLICY 决策器 + V3-FEEDBACK 反馈）、`da_js_v3_validate.py`（19/19 零调用验证通过）。可审计：每次决策输出全部候选的 Q̂/Ĉ/L̂/计划/依据/否决理由。

## 一、状态空间 s_t = (G, H, B, D, M)

| 分量 | 内容 | 来源 |
|---|---|---|
| G | 节点/类型/当前执行者/**该节点可用智能体池**/状态/分支结构 | DAG 运行时 |
| H | 每 (节点,执行者) 的 Beta 后验（仅由 R 探针结果更新）+ 故障信号 | 执行反馈 |
| B | 剩余调用/token/费用 | GlobalBudget |
| D | 剩余截止时间 | 时钟 |
| M | 上游质量信号：分支 n_facts、**修正后 provenance**（quote→文档定位）、跨分支重叠、UNVERIFIABLE 比例 | UB-1 store（代码侧，零调用） |

M 的修正 provenance 采用 quote→全文档定位（E03 doc-id 事故教训：doc 字段不可作为证据）。

## 二、动作空间与联合合同（全部沿用 QCL_TABLE_V3 冻结合同）

NONE / R(节点) / π(节点→池内另一执行者) / Zx(段拆分) / E(定向分支重执行，⊆R 依赖闭包) / E+Zx(联合，未测量)。每个动作的依赖失效规则：Zx/E 失效 store+下游；R/π(verify/report) 保留上游。

## 三、V3-QCL：终端收益预测器

经验表（实测来源+不确定性显式）：NONE（E04 0.364–0.636 / E03 0.389–1.000）；R 瞬态 2/2 完全恢复、持续 2/2 失败；π 4/4 完全恢复（唯一持续故障恢复）；**Zx +15.2pp [+9.1,+27.3]（3/3 同向，仅 E04——按纪律不当作普遍常数）**；E 无已验证正值（保留为门控动作，Q 期望不予赋值）；E+Zx 未测量不赋期望。**时延一律保守估计 = 实测最大值 × 1.2**（样本不足以估分位）。

## 四、V3-POLICY：候选生成 → 过滤 → Pareto 选择

1. 生成：健康态出 NONE+Zx（主动升级轴）；故障态出 R+π；M 门通过时出 E。π 合法性受**智能体池约束**。
2. 过滤：硬预算（调用/token/费用）+ 保守时延 ≤ D_rem + 依赖合法性；否决留痕。
3. 选择：质量优先 + 容忍度（ΔQ≤0.05 内取更省，ΔC≤1 内取更快）——无固定权重公式。

**实测表推导的结构性结论（写死进策略语义，非权重调节）**：UB-1 上 R-恢复=π-恢复=基线且等成本 → **池内有替代执行者时 R 被 π 支配**（v2 时代 R 探针有价值是因为当时 R 恢复质量>π；契约化管线消除了这一差距）；R 的角色=池受限时的唯一恢复路径。后验仍保留（跨执行学习+池受限域）。

## 五、V3-FEEDBACK：两个保护机制

1. **E 双门**：触发门=修正信号（n<10 或修正 prov<0.8；doc-id 异常不作证据）；采纳门=空/显著更差的重执行不得覆盖原分支（E03 事故 −50pp 的直接对策）。
2. **故障隐状态**：Beta 后验仅由 R 结果更新；无单次签名分类器（原理上不可行，既往证明）。

## 六、V3-VALIDATION：19/19 通过（零调用）

覆盖：主动升级选择、截止期/预算边界否决（含 Zx 326s 保守时延 vs D=300 的正确淘汰）、预算耗尽保护、故障恢复选择与实测表支配关系、池受限→R、后验更新、E 双门（含 doc-id 伪影不触发）、审计完整性（候选/依据/否决理由/计划全留痕）。

## 七、设计纪律（操作者三条，已内嵌）

1. 小样本均值不作普遍规律（Zx 带 n=3 与区间标注，仅 E04）；
2. 未验证联合收益不进确定性预期（E/E+Zx Q 期望不予赋值）；
3. 算法正确选动作 ≠ 已取得正向收益（结论留待 V3-EXPERIMENT）。
