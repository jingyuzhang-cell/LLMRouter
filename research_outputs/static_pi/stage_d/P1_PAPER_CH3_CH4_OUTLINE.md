# 第三章 方法设计（Methodology）

## 3.1 问题定义与 DAG 任务建模

**内容**：
- 复杂任务形式化：$G=(V, E)$，$V$ 为节点集（抽取/推理/汇总），$E$ 为数据依赖边
- 节点输出契约：每个节点 $v_i$ 有明确的 JSON Schema 契约 $\mathcal{C}_i$
- 分支与汇合：$\exists v_j$ 使得 $|\text{pred}(v_j)| \geq 2$（多分支汇合）
- 执行约束：截止时间 $D$、调用预算 $B$、Token 预算 $T$
- 优化目标：$\max Q_{\text{terminal}}$ s.t. $C \leq B, L \leq D$

**对应实验**：三任务 DAG 结构审计（§4.1）证明任务集满足分支/依赖/汇合标准

## 3.2 异构模型节点级能力画像

**内容**：
- 能力矩阵 $\mathbf{A}[m][v] = (Q_{m,v}, C_{m,v}, L_{m,v}, R_{m,v})$：模型 $m$ 在节点 $v$ 上的质量/成本/时延/可靠性
- 证据驱动构建：通过真实调用日志验证，非假设
- 合法分配空间：$\mathcal{S} = \{(m,v) : R_{m,v} \geq \theta\}$——仅纳入有完成证据的配对
- 非法方向显式排除：无证据或负证据的 (m,v) 对从动作空间中移除并记录拒绝原因

**设计贡献 vs 现有工作**：
- vs LLM Router：Router 是查询级路由（一个请求→一个模型），本文是节点级路由（DAG 中每个节点→最优模型），且路由空间由实测能力矩阵约束
- vs 静态模型分配：静态分配一次性确定，本文允许执行中动态调整

**对应实验**：§4.2 能力矩阵实测（GLM 3/3 截断 vs DS 7/7）

## 3.3 执行反馈与异常诊断

**内容**：
- 节点输出契约守卫（B-1）：五类失败判定（空文本/传输异常/JSON 不可解析/Schema 不合法/自然语言违约）
- 检测信号族：$\Sigma = \{D_1(\text{模型}), D_2(\text{结构}), D_3(\text{格式}), D_6(\text{口径})\}$
- 诊断函数 $\delta: \text{output} \rightarrow \sigma \subseteq \Sigma$
- 空输出传播阻断：契约违反→节点 Failed（非 Completed 空传播）→下游阻塞

**设计贡献 vs 现有工作**：
- vs 简单重试：简单重试不区分异常类型，本文按信号族分类
- vs 端到端质量评估：本文在节点级判定，粒度更细、触发更及时

**对应实验**：§4.3 守卫触发与恢复率（B-4 + Stage C）

## 3.4 反馈驱动的动态恢复策略

**内容**：
- 恢复动作集 $\mathcal{A} = \{a_{\emptyset}, a_{\text{retry}}, a_{\text{swap}}, a_{\text{fmt}}, a_{\text{struct}}\}$
- 诊断-动作匹配函数 $\mu: \sigma \rightarrow a$
  - $D_3$ (格式) → $a_{\text{fmt}}$（格式修复）
  - $D_2$ (结构) → $a_{\text{struct}}$（结构修复）
  - $D_1$ (模型) → $a_{\text{swap}}$（异构换模）
  - 无信号 → $a_{\emptyset}$（不动作——**诊断的价值在于"何时不该动"**）
- 失败感知降级：修复路径再次失败→自动降级至换模（如有合法替代）
- 非法方向拦截：不满足能力矩阵的换模请求被拒绝并记录

**设计贡献 vs 现有工作**：
- vs 固定策略（始终重试/始终换模）：本文按异常类型选择动作
- vs 盲换：健康条件不触发换模→节省调用

**对应实验**：§4.4 诊断 vs 盲换对照；§4.5 动作匹配

## 3.5 恢复范围与联合决策

**内容**：
- 恢复范围选择：$R \in \{\text{terminal-only}, \text{upstream}, \text{full}\}$
- 恢复靶向性问题：首次错误形成位置 $\neq$ 故障节点位置——恢复动作应瞄准质量瓶颈而非故障节点
- 决策框架：$\Delta U(a, R) = \lambda_Q \Delta Q - \lambda_C \Delta C - \lambda_L \Delta L$（辅助排序）
- 硬约束：$\min Q$（最低质量）、$D$（截止时间）、$B$（预算）
- 何时不应恢复：$\Delta U < 0$ 或剩余预算不足

**设计贡献**：
- 提出"恢复靶向性"概念（recovery targeting）——恢复的目标节点与终端质量瓶颈可能不一致
- 证据来自 MVR2 逐槽分析（§4.6）：53% 错误在 SINK 语义映射而非故障节点 J1

**对应实验**：§4.6 恢复范围与靶向性分析

## 3.6 Q/C/L 联合评价机制

**内容**：
- 三维分报告：
  - $Q$：终端事实正确性（Gold TP / V3 TP / Full-correct 三口径并列）
  - $R$：恢复可靠性（守卫触发→恢复率 / 保护槽倒退 / 失败传播）
  - $C/L$：调用成本（核算+实付）/ Makespan / 按期率
- 评分管线语义对齐：离线重评管线与执行器 FMT 状态逐字段一致
- Pareto 分析：质量-成本-时延三维前沿

**设计贡献**：三层分报告避免单一指标掩盖权衡

**对应实验**：§4.7 全部任务的 Q/C/L 汇总

# 第四章 实验设计与结果分析（Experiments）

## 4.1 实验环境、任务集与 DAG 结构审计

**内容**：
- 任务集：三任务族各一任务（MVR2 元道处罚关联 27 槽 / P11 卓然状态演化 17 项×3 阶段 / PHASE2B 俞发祥实体归一 23 槽）
- DAG 结构审计四标准：真实分支 / 明确依赖 / 多分支汇合 / 结构调整改变信息流
- 冻结协议：A‴ 路由（E/J2/SINK=DS@4000, J1=GLM-low@8192）；P11 全 DS
- 评分：三口径并列（旧合同 / V3 / A1 辅助）；Stage A 对齐管线
- 预算硬顶与停止规则

**数据**：Stage C 108 执行 / 334 调用 + Stage D 192 执行 + Stage B B-4 48 执行

## 4.2 异构模型节点级能力差异分析

**核心结果**（强证据）：
- GLM-5.3-Flash thinking 在多主体矩阵推理合同上的预算填充截断：
  - PHASE2B J2：0/4（4000/8000/8192 三档全耗尽）
  - MVR2 J1：0/1（8192 全耗，116s）
  - P11 J1：0/1（8192 全耗，116s）
  - **3 任务族 3/3 复现**——非偶发而是系统性现象
- DS thinking-disabled 同类合同：
  - E 节点：3/3 任务 × 各 3-4 文书 = 10/10
  - J2/SINK：3/3 任务 = 6/6
  - J1（状态判定/阶段衔接）：2/2（P11 7.35s / MVR2 68.5s）
  - **合计 7/7 类节点全部通过**，延迟 2-70s
- 截断模式：reasoning tokens 耗尽全部 max_tokens 配额，最终文本输出为 0 字节

**论文表述**：这一发现直接支撑"异构分配不是优化而是可行性前提"的核心论断。

## 4.3 异构模型诊断驱动恢复实验

**核心结果**（强证据——PHASE2B 受控因果 + MVR2 跨任务链路）：

**PHASE2B H1 嵌对**（J1 异常注入 × 4 臂 × 2 rep）：
- A0 不换模：TP=0，0/2 COMPLETE——J1 故障→链断→全零
- A2 诊断换模：TP=14，2/2 COMPLETE——守卫触发→DS 单次重执行→链恢复
- **恢复收益 +14 TP**（配对差 [14,14]，全部同号）

**MVR2 链路复现**（自然 GLM 故障，非注入）：
- Best-Single（无恢复动作）：2/4 COMPLETE——GLM J1 自然失败 2 次→链断
- Proposed（诊断换模）：4/4 COMPLETE——同故障→守卫→DS 重执行→恢复

**P11 边界**：
- A2_diag j1anom 0/2 COMPLETE——全 DS 路由无合法替代→诊断换模无法执行
- **边界条件**：单模型分配缺乏异构替代所提供的恢复空间

## 4.4 盲换与诊断换模对照实验

**核心结果**（方向性证据——PHASE2B 因果，MVR2 链路支持）：

**PHASE2B 健康条件**：
- A1 盲换：TP=14.0，calls=4.0（每次多付一次 DS-J1）
- A2 诊断换：TP=**15.0**，calls=**3.0**
- **配对差 ΔTP=[0,0,0,0]，ΔC=−1.0/执行**——质量不降且省调用

**论文表述**："诊断策略的核心价值在于'何时不该换'——健康条件下避免了不必要的模型切换，节省 25% 调用而质量不受影响。"

**注意**：单任务因果证据（PHASE2B），MVR2 链路方向性支持（Proposed 4/4 vs BS 2/4），不推广为"诊断策略普遍优于盲换"。

## 4.5 动作与异常类型匹配实验

**核心结果**（方向性证据——PHASE2B 强信号 + B-4 回顾性支持）：

**PHASE2B H2 嵌对**：
- 格式旁路异常：Proposed（格式修复）TP=**14.0** vs 不匹配 TP=**8.0**——**匹配收益 +6 TP**
- 结构异常：Proposed（结构修复）TP=14.0 vs 不匹配 TP=13.0——匹配收益 +1 TP
- 不匹配臂成本：+100% 调用（6 vs 3），零质量收益

**B-4 回顾性**（Stage D 192-run）：
- 格式故障 × 格式修复：+4.94 TP（有动作 13.0 vs 无动作 8.06）
- 结构故障 × 结构修复：+0.36 TP（弱）

**论文表述**："格式修复对格式旁路异常存在较强的匹配收益（+6 TP 受控 / +4.94 TP 回顾性），而结构修复对结构异常的匹配收益较弱（+1 TP）——动作匹配效果因异常类型而异，不能推广为普遍收益。"

## 4.6 恢复范围与恢复靶向性分析

**核心结果**（方向性 + 回顾性机制证据）：

**恢复范围**（PHASE2B H3 嵌对）：
- Upstream recovery：TP=13.0，calls=3.0
- Terminal-only：TP=12.5，calls=3.0
- 方向性：Upstream 略优（+0.5 TP），同调用成本

**恢复靶向性**（MVR2 逐槽分析——本文原创概念）：

| 首次错误形成位置 | 槽-run 数 | 占比 | 分类 |
|---|---|---|---|
| SINK 值-槽映射 | 57 | 53% | **语义映射错误** |
| E→J1 信息传递 | 26 | 24% | **信息未传递** |
| J2 核验丢失 | 2 | 2% | 信息传递中丢失 |
| 无错误 | 23 | 21% | — |

**核心论断**："Proposed 的诊断换模恢复了 J1 的执行（链路 4/4），但 53% 的首次错误形成于 SINK 层的值-槽映射——恢复动作作用于故障节点（J1），而终端质量瓶颈位于不同节点（SINK）。**恢复靶向性（recovery targeting）：恢复动作的目标节点与终端质量瓶颈节点可能不一致，恢复的靶向性决定恢复的质量效果。**"

**注意**：恢复靶向性目前为单任务（MVR2）回顾性机制证据，非因果验证。论文中标注为"回顾性分析发现"。

## 4.7 质量、成本、时延及边界条件分析

**Q/C/L 汇总**（三任务 × 三臂）：

| 指标 | PHASE2B | MVR2 | P11 |
|---|---|---|---|
| Static TP | 13.8 | 5.75* | 7.2 |
| Best-Single TP | 13.8 | 0.00 | 6.8 |
| Proposed TP | 13.8 | 2.50 | 7.5 |
| Proposed calls | 3.0 | 3.8 | 3.0 |
| Proposed makespan | 72-87s | 88-100s | 60-80s |
| Proposed COMPLETE | 4/4 | 4/4 | 4/4 |

*MVR2 编码归一后

**边界条件**（论文 Discussion 素材）：
1. 任务难度调节：MVR2 多主体×多阶段矩阵任务的终端映射瓶颈（SINK 53%）是当前恢复动作无法触及的
2. 异常类型调节：格式修复强（+6）/结构修复弱（+1）
3. 模型异构性前提：P11 单模型无恢复路径
4. 恢复靶向性：恢复故障节点≠修复质量瓶颈
5. 跨任务推广：3 任务均为资本市场舆情域
