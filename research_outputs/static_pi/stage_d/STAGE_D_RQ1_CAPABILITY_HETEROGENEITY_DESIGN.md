## 一、五个问题（研究纪律）

1. **科学问题**：不同 DAG 节点是否存在可利用的模型能力差异？差异是否稳定、可解释、足以改变分配？
2. **假设**：H1 = 模型×节点存在条件化质量（或成本/时延）交互，方向稳定且非解析失败伪影；H0 = 无交互/不可 material。
3. **对照**：第一层固定输入下两模型同节点配对；第二层统一 GLM、统一 DS、节点级分配三条件；任务随机；逐任务 leave-one-out；解析失败分层。
4. **新知识**：模型—节点匹配规律；异质性是否 material；局部优势能否传播到终端；无收益的条件。
5. **论文**：RQ1 能力表 + 交互 + 传播实验；RQ2 的分配依据；负结果/边界同样报告。

## 三、任务抽样

- 任务池：D2/Stage C 的独立任务（含不同文档数/异常类型），**不使用确认性任务**；RQ1 数据不入 RQ2/RQ3/确认性样本。
- 推荐 **5 个独立任务**，覆盖：单文档/多文档、结构异常/格式异常/无异常、长/短输出。
- 每任务 2 重复；重复只用于估计执行随机性，**不作为独立任务数**；报告任务数、重复数、总观测数三者。
- 若只能做 3 任务：明确标注"探索性"，交互 CI 与 leave-one-task-out 作为稳定性证据，不作普遍性结论。

## 四、统计模型与 Materiality

### 第一层（能力异质性）

- `quality_ijkt ~ model_i * node_j + (1|task_k) + (1|task_k:rep_t)`；报告交互系数、边际均值、95% CI。
- 成本/时延同构；解析失败/超时分层，报告可靠性。
- 稳定性：逐任务 leave-one-task-out；方向一致性；不把重复当独立任务。

### 第二层（节点匹配与终端传播）

- 节点级分配规则**只能来自第一层预测量**（不能看第二层结果调分配）。
- 三条件配对：`terminal_Q ~ condition + (1|task) + (1|task:rep)`；报告节点级分配 vs 统一 GLM/DS 的配对差与 95% CI。
- 同时记录 C（token/调用/费用）与 L（makespan/截止期），以及可靠性。

### Materiality 阈值（预登记，统计显著≠实际收益）

| 维度 | 阈值（候选，待操作员冻结） |
|---|---|
| 质量 Q | 节点级分配 vs 最佳统一模型：terminal TP 均值 **≥ +1.0 槽（约 +4.3%）**，且配对 95% CI 下限 > 0；关键事实不减少 |
| 成本 C | token/调用 **≤ +10%**（相对最佳统一模型）；若 Q 提升但 C 超 +10%，记为"质量换成本"，不作净收益 |
| 时延 L | makespan **≤ +10%**；若超，记"质量换时延" |
| 可靠性 | 合法执行率/节点完成率不下降 |
| 净收益 | 至少 Q 达标且 C/L 均未超恶化阈值；否则不通过 |

- **第一层交互显著但第二层 terminal 不 material → 不进 RQ2**（局部优势未传播）。
- 所有阈值在 RQ1 执行前冻结；RQ1 结果不得反向改阈值。
