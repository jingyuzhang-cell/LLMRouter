# DAMJS_ND_CONFIRM 预注册草案（ND 独立确认性实验 · 待操作员批准）

**科学问题**：在相同 DAG、相同任务、相同上游输入、相同恢复异常条件下，非破坏性提交（ND）能否显著减少节点恢复失败造成的终端质量损失？
**前置冻结**：口径 v3（严格·归一+规范化）为本实验及此后一切实验的统一报告口径（见 `CALIBER_V3_FREEZE.md`，`caliber_v3.py` SHA 登记后不再调整）。EV、CP_GATE 均**关闭**（CP_GATE 的收益另批单独验证——先确认 ND，一次实验只改一个因素）。

## 1. 设计（沿用 NDC 受控范式，三处按裁决修订）

| 项 | 取值 | 依据 |
|---|---|---|
| 臂 | R2（nd=off） vs ND-only（nd=on），配对 | 操作员表格 |
| 配对 | **每对独立生成夹具**（真实 E1–E4 + J1 首调 = v1），两臂回放同一夹具；**对内臂序随机**（冻结种子） | 纪律 1、2 |
| 注入 | J1 修复调用注入实录撞限响应（119.83 s，两臂逐字节一致，`injected` 类不计入失败统计） | NDC 已验证 |
| 下游 | J2/SINK/FMT 真实执行 | — |
| **截止期** | **300 s**（NDC 用 240 s） | 纪律 3：240 s 下 J1 首调墙钟需 ≤88 s 才可行（实测 P=0.82，r1a 即翻车），慢夹具层会产生 0/0 平局污染主检验；300 s 下全部观测墙钟（max 116.4）+ 注入 119.8 + 下游 ~12 ≈ 248 s < 285 s，**按设计消除平局层，且不挑选夹具**（所有抽取的夹具一律入组分析） |
| 样本量 | **n = 8 对**（16 次臂执行 + 8 次生成运行） | 功效分析（§2） |
| 续跑 | 已有结果跳过；孤儿区组拒绝自动重试（已修复并验收） | 纪律 4 |

## 2. 功效分析与检验（预登记）

**主检验**：配对差 Δ = TP(严格·归一+规范化, ND) − TP(同, R2) 的**双侧精确 Wilcoxon 符号秩检验**（α=0.05）。
**为何不用符号检验做主检验**（定量依据，`nd_confirm_power.py` 可复核）：双侧精确符号检验在本效应区间功效极低——胜率 q=0.95、平局率 5% 时 n=8 功效仅 0.67，且随 n 增大下降（临界全胜数增长更快）；q=0.85 时任何 n 功效 <0.3。符号检验（双侧）列为次级检验。
**功效模拟**（分量模型，取自观测数据：R2 臂空-J1 下游 TP ∈ {3,5,7,8}，ND 臂 v1 下游 TP ∈ {11,12,13,14}）：

| 模型 | n=6 | n=8 | n=10 |
|---|---|---|---|
| 观测分量模型 | 1.00 | 1.00 | 1.00 |
| 保守重叠模型（R2 4–10 / ND 9–14） | 0.67 | **0.95** | 0.99 |

**n=8 的选择**：保守重叠模型下功效 0.95；同时若真实效应落在更悲观的区间（差值大量重叠/近零），n=8 足以给出明确的阴性区间证据而非模糊结论。**不因中期结果增删样本**（纪律 5）；若出现平局（两臂 TP 相同），按 Wilcoxon 的零差剔除规则处理并在报告中单列。
**次要终点**：宽松 TP、逐口径 Δ、成本（真实调用/Token/现金）、时延（makespan、截止期完成率）、回滚与覆盖事件计数（机制层）、引用支持率。
**机制层终点（必须同时成立，否则解释为机制回归）**：ND 臂全部回滚逐字节成功、R2 臂全部破坏性覆盖、C1 违反=0。

## 3. 判读（预登记，接受阴性结果）

- **阳性**：主检验 p<0.05 且 Δ 中位数 > 0 → "在受控异常条件下，ND 显著减少恢复失败造成的终端质量损失"。
- **阴性-边界**：p≥0.05 但点估计为正 → 报告效应量与 CI，界定机制适用条件（如下游随机性淹没保护收益的条件）。
- **阴性-机制**：任何 C1 违反或回滚失败 → 机制缺陷，停止解释质量结果。
- 不追加样本、不换口径、不做事后分层。
