# DAMJS_ND_CONTROLLED 预注册草案（ND 受控异常对照实验 · 优先级最高 · 2026-11-07）

**状态**：草案，待操作员批准后冻结；**需单独授权真实 API 调用**（与本文件批准是两回事）。
**动机**（操作员 2026-11-07 裁决）：自然服务条件下 ND 的暴露概率低（方案 A 全批 19.1% @基线失败率），依赖随机故障证明机制效率太低。受控异常实验直接构造目标事件，验证 ND 的**因果**效果；其结果标记为"受控条件证据"，与自然条件证据互补、不混用。

## 1. 科学问题

在相同 DAG、相同任务、相同异常条件下：恢复调用失败时，ND（候选不合格则保留已提交的有效版本）相对 R2（末次覆盖）能否显著减少有效结果损失，且不引入不可接受的额外成本与时延？

## 2. 设计

**真实链路 + 单点受控注入**。唯一人为干预：J1 的**修复调用**返回预先定义的不可用输出（从 2026-11-06 冒烟实录取得的 8,192 撞限空响应，含真实 token 计数与墙钟 119.8 s）。其余全部真实：

| 节点 | 来源 |
|---|---|
| E1–E4 | 真实 DeepSeek 调用 |
| J1 首调（产生 v1） | 真实 GLM 调用 |
| 异常信号 → 调度决策 | 真实（S3 部署缺陷照常注入，D2=structure） |
| **J1 修复调用** | **受控注入**（记录实录响应；两臂逐字节相同） |
| J2 / SINK / FMT | 真实调用（消费各自实际收到的 J1） |

- **两臂配对**：R2（nd=ev=off）与 ND-only（nd=on, ev=off），同一重复内两臂共享相同的 E 响应与 J1 首调响应（同重复内先跑 R2，实录其 E/J1-v1 响应后供给 ND 臂回放，保证配对分支唯一差异是恢复语义；J2/SINK 两臂各自真实生成）。DAMJS 调度策略两臂相同（ev 关闭以隔离 ND 效果）。
- **重复**：3 个配对重复（6 次执行）。每重复一个新批次块。
- 截止期 240 s；场景 S3；执行器/看门狗/评分/身份与方案 A 完全一致。

**隔离纪律（硬性）**：
1. 每次执行的进度与结果记录 `controlled_injection=true` 及注入点清单；
2. 注入调用的 token/费用**照实入账**（预算照扣），但其**失败不计入任何服务失败率统计**（估计器在注入调用上记录 `outcome="injected"`，不进 p̂、不触发锁存——两臂 EV 均关闭，此条为防御性设计）；
3. 本批数据在任何汇总中单独分层，永不与自然条件批次合并估计失败率或收益。

## 3. 度量与判据

- 主度量：**配对 ΔTP（宽松）与 ΔTP（严格·别名归一）**，ND − R2，按重复配对。
- 次度量：下游 J2/SINK 消费的 J1 内容有效性（事件流判定）、额外调用数、额外核算费用、额外时延、回滚事件与提交版本一致性。
- 预测（预登记）：
  - P1：R2 臂 3/3 出现破坏性覆盖（J1 终值为空/碎片）；ND 臂 3/3 回滚到 v1 逐字节；
  - P2：ΔTP（宽松）每重复 ≥ +4（回放反事实为 +6）；ΔTP（严格·归一）≥ 0 且以引用标注随机性为界（S3 v1 无 relay，SINK 引用标注随机时归一严格分可达 8–14，见别名归一重核）；
  - P3：ND 臂额外成本 = 0 次额外调用（回滚不调用）；额外时延 ≈ 0（回滚本地）；相对 R2 的差异仅来自下游真实生成的随机性；
  - P4（失败判据）：任一 ND 臂出现"无效输出提交到有效输出之上"（C1 违反）→ 机制失败，停批。
- 预算：6 次 ≈ 45 调用 / ~15 万 token / ~¥0.28；上限 **50 调用 / 160,000 token / ¥0.35**，共用 R2 全局账本，触顶即停。

## 4. 与其他实验的关系

- 本实验**先行**于四臂冒烟（操作员顺序：受控实验 → 冒烟 → 视暴露情况定主体）。其正向结果是"受控条件下的因果证据"，不得单独作为自然条件收益声明。
- 若 P1–P3 成立：ND 进入自然条件验证（四臂方案 A），EV 检验聚焦"锁存后的后续决策"。
- 若 P4 发生：ND 机制存在实现缺陷，回退到机制层修复，一切真实批次暂缓。

## 5. 实现说明（批准后，零新工程面）

复用 v03 子进程与看门狗，仅增加一个注入开关：`APILOT_INJECT={"node":"J1","attempt":"repair","response":"smoke_DAMJS_S3_J1v2"}`——到达该调用时由包装层返回实录响应（token 照记、`outcome="injected"`）。R2 臂与 ND 臂同代码、仅开关不同。验收（零调用）：注入点命中、两臂注入字节相同、注入不进估计器、配对分支唯一差异校验。
