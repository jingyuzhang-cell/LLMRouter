# DAMJS_ND_CONFIRM 预注册（正式版 · 待操作员终批后冻结执行）

**科学问题**：相同 DAG、相同任务、相同上游输入、相同恢复异常条件下，非破坏性提交（ND）能否显著减少节点恢复失败造成的终端质量损失？
**范围边界（冻结）**：本实验证明的是**300 s 截止期、J1 特定受控恢复失败**条件下的 ND 质量保护效果；不得外推到自然服务故障、130/150 s 紧截止期或其他节点/异常类型。EV、CP_GATE 关闭（各自另行验证）。

## 1. 设计

| 项 | 取值 |
|---|---|
| 对照 | R2（nd=off） vs ND-only（nd=on），同对配对 |
| 独立配对 | **8 组**，每对独立生成夹具（真实 E1–E4 + J1 首调 v1），对内两臂回放同一夹具 |
| 臂序 | 对内按冻结种子（20261107）随机，实际顺序入记录 |
| 注入 | J1 修复调用注入实录撞限响应（119.83 s，两臂逐字节一致，`injected` 不入失败统计） |
| 下游 | J2/SINK/FMT 真实执行 |
| 截止期 | 300 s（有效窗口 285 s；历史最坏链 248.2 s，有裕量但**非上界**） |
| 主评分 | **严格·归一+规范化（口径 v3，SHA 冻结）**；次评：宽松、严格·原始 |

**数据边界（冻结）**：此前 NDC 的 33 次计入调用（27 真实 + 6 注入）仅含 1 个独立有效质量配对，只作设计依据，**不充当本确认性样本、不与本实验合并**。
**纳入规则（冻结，防选择性剔除）**：8 个夹具**全部入组**；不得因 J1 首调慢剔除；真实发生的截止期截断按实际终端结果记录；零差值保留于总样本与描述统计；预算/基础设施导致配对未完成时**不得自动补跑**——不足 8 组即不得宣称完成本确认性实验。

## 2. 统计（全部冻结，`nd_confirm_stats.py` 为唯一正式分析入口）

**主检验：双侧精确符号翻转 Wilcoxon 检验**，沿用本项目既有精确纪律（复用冻结 `exact_perm.py` 的平均秩与 `exact_perm_dp.py` 的秩×2 整数化，不新建框架）：
1. 零差值按预登记规则剔除，平局数另行报告；
2. 非零差 |D| 取平均秩；
3. 秩 ×2 整数化（杜绝半整数截断）；
4. 完整枚举 2^m 符号组合（m≤16）；
5. 双侧 p = #{W+≤min(W_obs, W_total−W_obs) 或 W+≥max(W_obs, W_total−W_obs)} / 2^m（**方向对称的两侧尾概率**，2026-11-08 操作员终审修正——原 OR 形式在 W+<W_total/2 区域退化为全空间覆盖，已废除）。
自检（冻结，2026-11-08 版）：400 例随机含并列/零差病例上 DP = 暴力枚举（min/max 尾）逐例相等；**方向对称性 p(D)=p(−D) 500/500**；边界 8 正差 = 8 负差 = 2/2^m = 0.0078125；并列 |D| 的双倍整数秩与枚举 200/200 一致；零差剔除、平局单列。**禁止 scipy 作正式 p 值**。

**次级检验**：双侧精确符号检验。
**正式报告**：Hodges–Lehmann 配对位置差 + 精确 95% CI（Walsh 平均）、配对差值全表、胜/平/负计数、非零对数 m。
**H0 对称性条款**（沿用既有预注册）：符号翻转精确性以 H0 下 D 关于 0 对称为前提，对称性不可由数据检验；报告 leave-one-out 敏感性；若数据强烈偏离对称，主检验降级为方向性并如实报告。

## 3. 功效（联合分布模拟，3 固定种子 × 20,000 次，`nd_confirm_power_joint.py` 可复现）

模拟对象为配对差 D 的**联合生成**（共享夹具质量 S + 保护损失 L + 两臂下游噪声，整数 TP，并列与零差自然产生），非独立边际区间：

| 模型 | n=8 功效（3 种子） | E[零差率] |
|---|---|---|
| correlated（L∈5–10，锚定观测） | 1.000 / 1.000 / 1.000 | 0.0 |
| pessimistic（30% 近平局层 L∈0–2） | 0.892 / 0.888 / 0.891 | 5.5% |
| hostile（50% 近平局层） | 0.645 / 0.636 / 0.639 | 9.8% |

**如实声明**：若真实效应接近 hostile 情形，n=8 功效不足（0.64）。本实验不为追求 0.8/0.95 更换效应假设；**不显著不构成"无效果"的证明**——等效性界值未预登记，故任何结果下都不得宣称"效应足够小"。

## 4. 判读（预登记）

- 阳性：主检验 p<0.05 且 HL 位置差 > 0。
- 阴性：p≥0.05 → 报告效应量、CI 与功效背景；结论措辞为"未能在 n=8 下确认"，不写"无效果"。
- 机制失败：任一 ND 臂回滚非逐字节或 C1 违反 → 停止解释质量结果。
- 不中途增删样本、不换口径、不事后分层。

## 5. 预算与停止规则

- 预计 88 次计入（72 真实 + 16 注入）/ ~30 万 token / 核算 ~¥1.32；硬上限 **100 次调用 / 360,000 token / ¥1.60**；共用授权总额（裁定点 377 真实，已用 72，余 305）。任一触顶即停，不自动补跑。
- 停止规则沿用 NDC 批次（SHA 失配 / 路由偏航 / AttributeError / 编号重复 / 账本异常 + V03_PATH_EXCEPTION + C1_VIOLATION + 注入点未命中 + 夹具失配）。
- 凭据：GLM=bigmodel-api-6、DS=deepseek 条目，仅注入子进程环境。
