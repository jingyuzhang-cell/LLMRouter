# P2-0：节点级失败结构与可重建性分析（零调用，仅用已有数据）

**状态：零真实 API；192 HOLD；未修改 R3/R4/R5/JFR 历史文件、评分、Gold、DAG、MVS、任务。**
**数据：R5 stable H1 .20 的 800 个评测任务（同种子确定性重放）+ 冻结机制的解析期望。**

---

## 0. 结论先行（对应 P2-0 的五项任务）

1. **reason 失败档案**：90.5% 的任务 reason 至少有一个坏事实；1,139 个坏事实中 82.9% 是 FN；57.3% 的坏 reason 任务两条事实同时坏（一次重建平均面对 1.57 个坏事实）；坏 reason 的父节点平均 q=0.435。
2. **共同恢复潜力**：一次"最优模型重建"的期望转换（新抽取，解析期望）——merge **0.86**、verification **0.76**、e1 0.81、e0 0.78、t 0.69、**reason 仅 0.46**、report 0.40。**reason 恰恰是重建产出最低的节点之一**：GLM 重建把两条坏事实同时修复的概率只有 19.3%。
3. **能力差异（实测，槽位通过率，不含 gate）**：DS 强在 e0/e1/t（.666/.651/.559 vs GLM .474/.499/.335）；GLM 强在 m/v/p（.499/.489/.492 vs DS .387/.372/.295）；**r 两边都弱**（GLM .346 vs DS .288）。
4. **成本/时延核算**：一次 GLM 节点重建 +0.143（归一化成本）**超过 20% 预算的全部余量 0.12**；一次 DS 重建 +0.086 只容得下 1 个；事后重建使 Makespan +18.4%～+42.1%（r 是 +31.6%/+42.1%），**只有 p 的 DS 重建（+18.4%）勉强落在 matched-20% 内**；投机并行 GLM 重建时延 +6.1–10.5%（全部满足 strict 10%）但成本被卡死。
5. **70% 的真实价格（解析上界）**：对全部坏节点用最优模型重建，期望转换 ≈3.42/任务 ≈ Q 71.5%，但需要约 **2.2× 基线成本**；若验证器灵敏度 0.75，期望转换降到 ≈2.57 ≈ Q 65.0%。**在冻结的 10/15/20% 预算内，节点重建最多带来约 +2.6pp（约 47.9%），不可能到 70%。**

**因此 P2-1 按原设想（冻结预算内用节点重建到 70%）在算术上不可行，pilot 不应启动**；需要操作者对"质量模式预算"或"机制组合"做明确决策（见 §6）。

## 2. M2：一次重建能恢复多少（新抽取的解析期望，避免 CRN 共单调偏差）

对每个坏节点，用最优/指定模型整体重执行的期望新转换（TP∧定位∧支持）：

| 节点 | 坏节点份额 | DS 期望转换/重建 | GLM 期望转换/重建 | GLM 双坏同修概率 | 最优模型 |
|---|---:|---:|---:|---:|---|
| e0 | 55% | **0.778** | 0.567 | 0.418 | DS |
| e1 | 56% | **0.808** | 0.590 | 0.410 | DS |
| t | 67% | **0.686** | 0.500 | 0.322 | DS |
| m | 85% | 0.535 | **0.860** | 0.505 | GLM |
| **r** | **91%** | 0.424 | **0.459** | **0.193** | GLM（弱优势） |
| v | 86% | 0.526 | **0.761** | 0.412 | GLM |
| p | 70% | 0.249 | 0.400 | 0.400 | GLM |

- **多事实共同恢复在 m/v 上成立**（GLM 重建平均转换 0.86/0.76 个事实，双坏同修 ~50%/41%）。
- **reason 重建的产出最低**：GLM 0.459、双坏同修仅 19.3%。原因：r 对两个模型都难（父 q 0.435、base_p 低），且 92% 坏事实是 FN。
- 重建 r 对下游 p0 的一阶影响很小（期望 Δq +0.009，额外 p0 转换 +0.023/任务）；但**若为事后重建，p 的旧输出失效，必须重执行 p**（额外 +0.086/+0.525 时延）。

## 4. M4：一次节点重建的成本/时延核算（含依赖传播）

归一化：成本余量 = cap − 0.60（10%: 0.06 / 15%: 0.09 / 20%: 0.12）；基线 Makespan 2.85。

| 节点 | 关键路径 | DS 重建成本 | GLM 重建成本 | 事后重建 Makespan（DS/GLM） | 投机并行 GLM Makespan |
|---|---|---:|---:|---|---:|
| e0/e1 | 是 | +0.086 | +0.143 | +26.3% / +35.1% | +8.8% |
| t | 否 | +0.086 | +0.143 | +21.1% / +28.1% | +7.0% |
| m | 是 | +0.086 | +0.143 | +23.7% / +31.6% | +7.9% |
| **r** | **是** | +0.086 | +0.143 | **+31.6% / +42.1%** | +10.5% |
| v | 否 | +0.086 | +0.143 | +28.9% / +38.6% | +9.6% |
| p | 是 | +0.086 | +0.143 | **+18.4%** / +24.6% | +6.1% |

**可行性判定：**

- **GLM 重建（质量价值最高的 m/v/p/r）成本 +0.143，超过 20% 预算全部余量 0.12——任何节点、任何预算档都放不下。**
- DS 重建 +0.086：15%/20% 各容得下 **至多 1 个**（两个 = 0.172 > 0.12）。
- 事后（串行）重建的时延只有 p-DS（+18.4%）落在 matched-20 内；t-DS +21.1% 超出；**r 的两种模型事后重建都严重超时延**。
- 投机并行 GLM 重建时延全部满足 strict 10%（+6.1–10.5%），但成本同样被卡（+0.143）。
- 依赖传播：事后重建 r 需追加 p 重执行（+0.086 成本、+0.525 时延）；拓扑内重建（p 未执行前）无追加成本但时延照样加在关键路径上。

## 5. 70% 的真实价格（解析上界，非模拟结果）

贪心按"期望转换/成本"排序，对全部坏节点用最优模型重建：

| 累计重建集 | 期望转换/任务 | 期望 Q | 追加成本 | 总成本倍数 |
|---|---:|---:|---:|---:|
| e1+e0+t（DS） | 1.34 | 55.6% | +0.258 | 1.43× |
| +m（GLM） | 2.07 | 61.2% | +0.401 | 1.67× |
| +v（GLM） | 2.73 | 66.2% | +0.544 | 1.91× |
| +r（GLM） | 3.14 | 69.4% | +0.687 | 2.15× |
| +p（GLM，部分） | **3.21** | **≈70%** | **≈+0.72** | **≈2.2×** |

- **完美检测下**，节点重建路线到 70% 需要 ≈2.2× 基线成本（+120%），且含 r/p 这些低产出重建。
- **验证器 sens=.75 时**：期望转换 ×0.75 ≈ 2.57 → Q ≈ **65.0%**（仍需 2.2× 成本）。要把检测做满要么提升验证器（新机制假设），要么重建所有节点（无检测，成本更高）。
- **冻结预算内（≤20%）**：至多 1 个 DS 重建（最优选择 e1，期望 +0.34 转换×0.75≈+2.6pp）→ Q ≈ **47.9%**。

## 6. 对 P2-1 的判定与冻结

**判定：按原设想（冻结 10/15/20% 预算 + 节点级重建 → Q≥70%）在算术上不可行；不应启动 pilot。** 具体冻结如下（`P2_1_PROTOCOL.md`）：

- 冻结假设、对照（A Static / B JFR-D / C 同模型重建 / D 能力感知重建 / E 重建+共享证据 / H0 / Sham）、验收门（Q≥70 且 CI 下界>70；stable−H0≥5pp；Sham≤0.5pp；资源如实计入；依赖传播重执行）。
- **三个前置阻塞**写入协议，需操作者决策后才能跑：
  1. **预算档**：GLM 重建需要 ≥0.143 余量（约 25% 档），或显式开"质量模式预算"（≈2.2×）；
  2. **检测器**：sens .75 把 70% 压到 65%；需要更好的节点级坏检信号（可观测特征：父 q、执行失败、输出规模），这是 P2-1 真正值得做的机制部分；
  3. **时延模式**：事后重建只有 p-DS 可行；r/m/v 的 GLM 重建必须走投机并行（时延 +6–10.5%，strict 可守）。
- 若操作者维持冻结预算：P2-1 只能检验"1 个 DS 重建 + 信号研究"，预期 Q≈48–50%，**明确预期达不到 70**，价值在于验证重建机制与归因（stable vs H0），而不是冲 70。
- 共享证据（机制 C'）：节点重建天然整节点输出证据链，共享证据的主要作用是**降低多事实重建的边际成本**（把 2.2× 压下来），P2-1 中以成本消融体现，不单独立机制。
