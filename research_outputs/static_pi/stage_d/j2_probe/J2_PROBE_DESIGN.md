## 一、要回答的问题

在**完全相同的冻结 J2 输入**上，DS、GLM、Qwen 能否完成 J2 核验？各自的质量、语义一致性、完整性、稳定性、成本、时延和可靠性如何？

由此得到 π 的候选集合与先验，在确认实验预注册中先写定。

## 二、输入与固定条件

| 项 | 设定 |
|---|---|
| 输入 | Stage A' 三份已付费 J1 输出（Static、Fixed、Joint 臂）加 SC-E1 槽位，构成三份 J2 用户消息，逐字节复用 |
| 系统提示词 | J2_SYS，与冻结版逐字节相同 |
| 输出契约 | 必须含 `verified` 键；空文本、截断、JSON 或 schema 无效都记为可靠性失败 |
| 温度 | 0（GLM 端点若不支持则记录实际值） |

**三个模型的请求条件**：

| 模型 | 端点 | 关键参数 |
|---|---|---|
| DS | deepseek-flash，`response_format=json_object` | thinking 关闭，max_tokens 4000 |
| GLM | GLM-5.3-Flash，订阅端点 | `reasoning_effort=low`，无 thinking 字段，max_tokens **8000** |
| Qwen | qwen-plus，DashScope 兼容端点 | max_tokens 4000 |

- **不对称**：GLM 无法关闭思考，reasoning 会占用输出预算，所以给 8000。这是有意的不对称，会如实报告；截断按可靠性失败计入，不提高档位。
- **Qwen 的前提**：本实验线的凭据文件里没有 `QWEN_API_KEY`。其他实验线（rq_dyn_*）使用过 Qwen，但这条链从未验证过。需要您提供密钥，或决定本轮不含 Qwen。我不会去其他实验线查找或借用凭据。

## 三、设计（操作员 2026-11-06 修订：双模型平衡设计，HOLD，未授权调用）

| 输入 | DS | GLM | 用途 |
|---|---:|---:|---|
| J2 输入 1（Stage A' Static 臂 J1 输出） | 2 次 | 2 次 | 配对比较 + 重复稳定性 |
| J2 输入 2（Fixed 臂 J1 输出） | 2 次 | 2 次 | 输入多样性 |
| J2 输入 3（Joint 臂 J1 输出） | 2 次 | 2 次 | 输入多样性 |
| **合计** | **6** | **6** | **12 次** |

- 2 模型 × 3 输入 × 2 重复 = 12 次，每对（输入 × 模型）可配对比较，每格内可看重复稳定性。
- **Qwen 不纳入本轮**：无本线凭据，不借用其他实验线的凭据。原三模型设计作废，不以删减冒充原结构。
- **GLM 的截断按可靠性失败记录**，不提高档位、不换端点。
- **按模型隔离停止**（操作员已接受）：某模型出现 HTTP 错误、截断或输出异常时，停止该模型剩余请求，其他模型继续；不自动替换模型、不改提示词或输出上限；失败模型的缺失数据不按零分计入。
- 执行顺序：模型串行（DS → GLM），模型内按输入 1→2→3，每输入先 2 次重复。

## 四、指标（全部离线，用 SC-E1 合同 v1.1 与冻结检测器计算）

| 指标 | 定义 |
|---|---|
| 输出质量 | J2 判为 verified 的槽中 final_value 经评分器值规则判对的比例；派生槽 F19 是否等于基础模块值 201 |
| 语义一致性 | V2 M1 明确压制数；M2 派生不一致；另报标签变体（如 not_found）的扣槽数，作为检测器召回的工作项 |
| 完整性 | 20 槽中被 J2 提及（verified 或 derived）的比例 |
| 稳定性 | 同输入 2 次重复的逐槽结论一致率；各指标极差 |
| 成本 | 输入/输出 token（含 GLM reasoning），记账与边际费用 |
| 时延 | 墙钟时间（只作描述，缓存命中不可比） |
| 可靠性 | 截断、HTTP 错误、空文本、JSON/schema 无效次数 |

**本探针不测**：终端 Q_all（不跑 SINK）、动态调度收益。
