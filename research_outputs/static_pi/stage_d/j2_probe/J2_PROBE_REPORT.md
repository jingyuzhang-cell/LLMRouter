## 四、探针暴露的检测器问题与 V5

探针出现了 V4 词表外的标签：DS 的“正确”、GLM 的“核验一致 / 材料未涉及 / not_supported / not_in_material / inferred”。V4 会把“正确”判为未知标签（低估 DS 质量）、把“材料未涉及”漏出压制计数。已按版本化路径建 **detectors_v5**（sha256 `5bfda18d99aaf845…`）：确认类加“正确、核验一致”，压制类加“not_supported、not_in_material、材料未涉及”；inferred 保持未知（语义含糊，宁保守）。回归：九份历史 J2 输出上 V5 与 V4 逐槽一致（3/3，`V5_REGRESSION.json`）；V2–V4 全部保留。上表已按 V5 口径计算；V4 口径的数字并列保存在 `PROBE_RESULTS.json`。
