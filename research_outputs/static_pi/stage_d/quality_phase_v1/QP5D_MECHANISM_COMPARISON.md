# QP5-D 第三/五项研究：机制比较与候选选择（零调用）

**依据**：`QP5D_COUNTERFACTUAL_ANALYSIS.json`（9 种约束配置的确定性反事实 + 转移表投影）+ `QP5D_ERROR_ATTRIBUTION.md`。
**口径申明**：证据层指标为**精确计算**（在既有条目上）；带 `projQ` 的终端数字是**经验转移率投影**（Study-1 转移表），不是实验结果；需要真实模型行为的项标 UNIDENTIFIED。

## 1. 三种预注册约束机制的反事实（在 C2 既有条目上）

| 配置 | 供给率 | 事实级精确率 | 冲突事实 | 误删正确供给 | 条目/格 | projQ |
|---|---:|---:|---:|---:|---:|---:|
| base（E-v2 原样） | 0.912 | 0.898 | 97 | 0 | 50.2 | **0.459** |
| D1 cap=1 | 0.912 | 0.706 | 0 | 34 | 14.8 | 0.404 |
| D1 cap=2 | 0.912 | 0.785 | 81 | 20 | 26.1 | 0.427 |
| D2 冲突即弃 | 0.412 | 0.887 | 97 | **88** | 11.8 | 0.206 |
| D3 高置信门控 | 0.412 | 0.887 | 97 | 88 | 11.8 | 0.206 |
| D1+D2 / D1+D3 / D2+D3 / 全组合 | — | ≤0.706 | 0 | ≥34 | ≤14.8 | ≤0.404 |

**判读**：
1. **三种约束全部投影为终端损失**（base 0.459 最好）。原因不是机制逻辑错误，而是基线状态：事实级"任一语义正确"供给精确率已达 0.898——**证据生产在供给层已不是约束**。
2. **D2 的代价最重**：97 个冲突事实中 88 个（90%）的冲突集合里含正确条目——错误值与正确值共存，"弃"掉的是以正确为主的供给。多数投票也不行（QP5-C 已证错误值可占多数）。
3. **D1 的选择器困境**：金盲选择器选中的单条精确率 0.706 < 任选 0.898，封顶反而降低事实级精确率并误删 34 个正确供给。
4. **D4（代码值交付）同样 NO-GO**：朴素规范化仅 0.392 < 实际 0.438——模型在值转换上优于朴素代码规则。

## 2. 数据指向的真实瓶颈与新候选（D5）

Study-1 转移表：159 个有正确证据的事实的终端转换率仅 **0.535**；70 个失败中 **61 个是纯格式失败**（信息对、呈现错）。这 61 个占全部 194 个事实-格的 **31.5%**——是全系统最大的单一损失桶。

**D5：终端值合规回显 + 一次纠偏**（金盲）：
- 表内槽位的 value 必须与表条目值**等值回显**（text 型逐字含单位；数值型裸数字）；
- 代码校验（单位感知等值，对**表条目**而非 gold）；不合规槽位触发**一次**SINK 纠偏重调。

上限与不确定性：宏上限 0.767（逐任务见归因报告）；回显合规率与纠偏 efficacy **UNIDENTIFIED**，需真实实验。按 50–70% 修复率投影 Q ≈ 0.60–0.66（投影，非承诺）。

## 3. 任务异质性（不强行统一规则）

- **MVR1 / KANGMEI**：格式可修复占比最高（19/33、19/28）——D5 的主要受益者；上游证据已基本就位。
- **E06 / ZEDA**：TP 已高（26/37、23/34），剩余损失分散，D5 增益中等。
- **GUOEN**：实质错误+错证据为主（D5 上限仅 0.423）——其金额描述型 gold 形态复杂，属 QP6 信息组合问题，D5 不适用。
