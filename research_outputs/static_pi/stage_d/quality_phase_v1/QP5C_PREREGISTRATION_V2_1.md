# QP5-C V2.1 最终冻结版（含两项执行口径）

本文件在 V2 三明治设计（`QP5C_CAUSAL_DESIGN_REVIEW.md`）基础上，写入操作员 2026-11-03
最终授权前的两项执行口径与统计解释规则。**原 V1 设计永久废弃。**

---

## 执行口径一：配对落实到执行层（含 purpose 键审计）

1. 12 个（任务，重复）区组；同区组内 C1′/C2/(C0) 使用**相同任务、文书、输入约束与下游模型配置**；
2. 区组内**臂间执行顺序随机**（种子 20261103），臂内按依赖序（t→m→r→p）；
3. 新 purpose 键**只用于避免缓存命中，不得改变模型请求内容**。执行前 SHA 同一性审计：
   - C1′ 的 t/m/r 请求体 SHA256 必须与 QP4-D 对应记录**完全一致**（同输入同提示）；
   - C1′ 的 p 请求体 SHA256 必须与 QP5-A B2 对应记录**完全一致**；
   - 任一不匹配即停止并报告（BLOCKED），不得开跑。

## 执行口径二：证据生产收益与值抽取收益分离报告

最终报告必须包含（缺一不可）：

| 指标 | 研究意义 |
|---|---|
| E 层值正确率（对 gold 严格） | 是否改变事实识别能力 |
| 证据覆盖率（分母=gold 事实） | 是否找到更多证据 |
| 证据精确率（分母=已绑定表条目） | 新增证据是否可靠 |
| 垃圾率（无法绑定 gold 的条目/总条目） | 是否产生无效证据 |
| 终端复合 Q | 是否转化为实际质量收益 |
| 成本与时延 | 是否值得额外资源 |

**最终结论措辞为"上游证据生产包效应"**（证据合同+schema+补抽三成分），不宣称未分离的纯证据机制效应。

## 统计解释规则（操作员原文采纳）

1. **C2 − C1′ 是主要因果效应估计**；
2. **C0 只在 C1′ 的固定上游输入下测量下游重采样噪声**，不能直接代表 C2 路径的全部随机波动（证据路径重复差曾达 0.355）；
3. **信噪比是辅助指标**，不能代替主终点；
4. **不得从 C2 − C1′ 中减去 C0 的噪声均值**。

## 冻结要点（沿用 V2，未改动）

- 主终点：任务级配对 ΔQ 宏平均；判据 **宏 ≥ +0.10 且 ≥4/6 任务非负**；
- 安全性绝对边际：错误引用 +≤2 实例、错误断言 ≤+2 实例、拒答率 ≤+0.10、关键 TP 不降、Gate 不降；
- 安慰剂：结构性槽位（NEEDS_MULTI/DOC_LACKS）ΔQ 应 ≈0，另监测其表条目数变化；
- 功效披露：任务级 Δ SD≈0.138，n=6 的 MDE≈0.15（80% 功效）；δ_min=0.10 对应约 60% 功效；符号判据不依赖幅度；
- C0 细胞（6 个，预注册）：E06 r1、MVR1 r2、KANGMEI r1、GUOEN r2、ZIJING r1、ZEDA r2（跨重复平衡）；
- 运行时金盲：补抽与下游核验仅用 schema/逐字/自接地信息；
- 预算：**计划 144 / 最坏 168 / 硬停 170 次调用、¥1.00**；预扣费守卫 5% 储备；
- 评分：冻结 QP1-final 严格；held-out 未触碰；R5 的 192 次额度继续冻结。
