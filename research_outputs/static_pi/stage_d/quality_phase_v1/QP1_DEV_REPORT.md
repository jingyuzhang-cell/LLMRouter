首轮评分暴露一个测量口径问题：KANGMEI 的答案引文是**真实且支持事实**的

旧 QP1 判为"不支持"。

修订后的 QP1：

- **支持** = 引文逐字出现在所引页面 **且** 该引文包含事实的值（数值/日期/文本核心）。
- **gold 参考跨度命中** = 单独诊断（`reference_span_match_rate`），不进入 Q/Gate。

这是"引文是否真正支持结论"的可操作化，而非"是否命中某一句 gold"。修订发生在 held-out 之前；
下表同时给出旧/新口径，避免口径切换掩盖结果。

## 4. 结论

1. **Baseline 的复合 Q 为 0**：值正确率约 21%，但引文从未绑定到所引页面（定位 0）。这与此前 V2/S2 的归因一致——链路的主要损失不是"完全不知道答案"，而是"答对了却无法给出可信证据"。
2. **证据约束（E1）把宏 Q 从 0 拉到 0.223**，E06 上 0.235、MVR1 上 0.219；这是方向性的真实正向信号。
3. **E2 的确定性核验没有稳定增益**（0.214，MVR1 上反而低于 E1 0.219）。原因已定位：核验只过滤事实，SINK 仍自行重写引文，未复用被核验的那一条。**下一轮必须把核验后的 doc/page/quote 传给 SINK 并强制逐字复用。**
4. **E3 目前最好（0.254）**，但优势主要来自 KANGMEI 的一格；样本不完整，不能定论。
5. **Critical Gate 全部 FAIL**：关键事实要求全部 TP，而派生事实/多部分事实仍是瓶颈。Gate 与 Q 分开报告，未用平均分掩盖。
6. **离 70% 仍有很大距离**：当前瓶颈是值正确率（21–36%，金额类为主）与证据绑定，而不是"缺少动态调度"。
