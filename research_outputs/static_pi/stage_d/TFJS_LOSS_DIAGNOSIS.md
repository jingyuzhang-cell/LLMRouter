## 三、两个测量伪影（不修正会误判优化方向）

## 五、六个诊断问题的回答

1. **Extract**：好抽样下命中 79%（26/33）；差抽样（V2 r1）4/11。真实缺口集中在少数金额槽的偶发遗漏 + 2 个伪影槽；主体问题不是"没提取"而是**不稳定**（8–9/11 波动）。
2. **Merge**：已提取槽位 ~50% 在此丢失（数字细节被压缩为概括性表述）——**最大真实损失节点**。
3. **Z2 vs 单次 Merge（同一 extract 配对）**：Z2 保留 14/26 vs π-merge 12/26；三 rep 中两个完全相同（5/9,5/9）、一个 Z2 +2（5/9 vs 3/9）。**Z2 并不明显多保留事实**——V1 的 0.545 是 extract 有利抽样的产物（此前已判）。Z2 的真实优势=时延（9s vs 38s）与"从不更差"的稳健性，非覆盖。
4. **Verify**：本管线为标注式（不删除），按构造 **0 槽位被错误过滤**；其自身再输出的事实数偏低（再发射保真度低），但下游不依赖它的事实列表。
5. **Report**：到达 Merge 之后的槽位再丢 ~25%（组二 12–14→9–10；组一 B 臂 29→21）；**集中在日期类**。保真报告（B/C）已回收其中约一半。
6. **Evidence**：修正口径下 ES 0.93–0.97、命中槽位 Support 1.0——**引用定位与锚定不构成瓶颈**。

## 六、结论与建议（不启动新实验，供决策）

1. **剩余 70% 损失的构成**（组二口径）：Merge 压缩 ~39% + Extract 波动/伪影 ~11–27% + Report 组织 ~11–16%。**优先级：Merge 契约 > Report 日期保留 > Extract 稳定性**。
2. Merge 的修复方向与 Report 保真同构：**合并节点也应以逐事实传递为契约**（fid/value/quote 原样保留，只做去重与排序），而非自由改写——这是数据支持的下一假设，待操作者裁定是否实验。
3. 评分侧：建议为标题/条件句类槽位增加**改写容忍次级规则**（关键子串命中），与冻结逐字规则并排报告，不改 Gold。
4. Z2 的论文定位应改写为"低时延稳健恢复"，其"信息升级"主张撤回（与勘误一并处理）。
