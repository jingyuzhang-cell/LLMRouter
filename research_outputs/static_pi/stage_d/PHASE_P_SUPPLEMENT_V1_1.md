## 1. 指标可比性（问题 1）

### 1.1 为什么原判据无效

五类节点的 Q 分别是：字段抽取正确率（T1/T2）、上游事实保留率（T3）、计数/口径正确率（T4）、
终端质量 F1（T5）。它们虽都落在 [0,1]，但**测量对象、噪声尺度、区分度都不同**。
把它们的差值放进同一个 `max−min` 与混合 SD 里，会把**尺度差异**误读成**能力异质性**。

### 1.2 修订后的 P-H1（主判据）

> **证据 A（唯一主证据）：符号反转**
> 存在节点类型对 (i, j)，使
> `sign(Δ_i) ≠ sign(Δ_j)`，且 **|Δ_i|、|Δ_j| 均 ≥ 0.05**（该类型自身量纲上的最小实质差），
> 并且该反转在 **≥2/3 任务**中成立。

其中 `Δ_type = mean_rep(Q_GLM) − mean_rep(Q_DS)`，**只在同一类型内部计算**。

**禁止**：跨类型求 `max Δ − min Δ`；跨类型合并 SD；跨类型平均 Δ。

### 1.3 幅度判据（仅在类型内，作为辅助）

对每个类型单独判断信号是否超噪：

```
超噪 = |Δ_type| ≥ 2 × SD_rep(type)          # SD_rep 由该类型两重复的 Q 值估计
```

- 只有**该类型自身**的超噪结论可以进入报告；
- **不得**把不同类型的"超噪倍数"横向比较；
- 因每格仅 2 次重复（SD 只有 1 个自由度），该判据**只作诊断**，不作显著性声明。

## 2. 重复与稳定性（问题 2）

### 2.1 必须报告的形式（禁止只报均值）

每个 (节点类型, 模型, 任务) 都报告：

| 字段 | 含义 |
|---|---|
| `Q_rep1`, `Q_rep2` | 两次重复的原始质量值（**不得只给均值**） |
| `Δ_rep1`, `Δ_rep2` | `Q_GLM_repk − Q_DS_repk` |
| `sign_agree` | `sign(Δ_rep1) == sign(Δ_rep2)` |
| `Δ_range` | `|Δ_rep1 − Δ_rep2|` |
| `C_*`, `L_*` | 每模型每重复的成本/时延（见 §3） |

### 2.2 P-H3 的明确定义

> **P-H3（稳定性诊断）**：对某节点类型，(i) 两次重复的 Δ **同号**，
> 且 (ii) `Δ_range ≤ 0.10`（该类型量纲上的绝对差），
> 且 (iii) 该结论在 **≥2/3 任务**中一致。

- 满足 → 记为"稳定优势/稳定劣势"。
- 不满足 → 记为"**不确定**"，**不得**据此宣称异质性。
- **明确声明**：2 次重复不足以做统计推断；P-H3 是**诊断**，不是检验。

### 2.3 P-H3 进入 GO 公式

原预注册的 GO 公式未含稳定性；补充如下（见 §5），
即：**符号反转必须在重复层面可复现**，否则不进入 Phase Pi。

## 3. P-H2 对称化与成本口径（问题 3）

### 3.1 对称判据（对两模型完全相同）

对每个节点类型，分别计算两个模型的四元组：

```
(Q, cost_accounting, latency, contract_reliability)
```

**"可利用空间"定义（对称）**：
> 若模型 A 在某类型的 Q 显著高于 B（|Δ| ≥ 0.05 且 P-H3 稳定），
> 且 A 在该类型的**成本不高于** B、**时延不高于** B、**合同合规率不低于** B − 10pp，
> 则该类型记为"**A 的单向优势区**"。
>
> 若 A 的 Q 更高但**成本或时延显著更差**，则该类型记为"**质量-成本权衡区**"，
> 不进入"可直接分配"的候选，需在 Phase Pi 里显式比较其净收益。

两个模型用**同一判据**，不预设谁是"强模型"。

### 3.2 成本口径（关键）

| 口径 | 定义 | 用途 |
|---|---|---|
| **`cash_yuan`（实际现金）** | GLM 资源包**预付费**→边际现金 ≈ 0；DS 按 token 账单 | 报告，反映真实支出 |
| **`accounting_yuan`（核算价）** | 两模型统一按**刊例价**（in/out 分列）折算 | **Q/C/L 比较的唯一口径** |

**为什么不用原始 token 比成本**：两模型 tokenizer 不同，原始 token 数不可直接视为经济量。
成本比较一律用 `accounting_yuan`；原始 token 仅作辅助诊断。

**说明预付费的扭曲**：GLM 的现金成本为 0 是**已支付**而非"免费"。
因此任何"GLM 更便宜"的结论都必须用 `accounting_yuan`，并同时报告剩余额度消耗。

## 4. 边界声明与执行顺序（问题 4）

### 4.1 结论边界（必须写入任何结果报告）

> Phase P 测量的是：**在 GLM 参考链生成的固定上游快照条件下**，
> 各模型在 T1–T5 上的**条件化**节点能力。
> T3–T5 的上游来自参考链（GLM），因此结果**不能**外推为
> "任意上游模型组合下"的普遍能力差异，也不能外推为端到端 DAG 质量。

### 4.2 交错执行顺序（消除时延顺序效应）

原设计"先跑完 GLM 再跑 DS"会让系统负载/缓存/服务端状态随时间变化，
使时延比较带上**顺序偏倚**。修订：

- 每个 (任务, 节点类型) 单元内，两次重复按 **GLM→DS / DS→GLM 交替**；
- 三个任务之间轮换起始模型（任务1 从 GLM 起、任务2 从 DS 起、任务3 从 GLM 起）；
- 参考链（GLM）仍在最前，但其**时延不参与模型比较**（只用于生成快照）。

### 4.3 快照纪律

- 每个任务的参考链输出落盘 + SHA256；
- T3–T5 的所有测量必须引用该哈希，**不得重跑快照**；
- 若某任务参考链任一层解析失败，**该任务的 T3–T5 全部作废**（只保留 T1/T2），
  并在结果中标注，不补跑。

## 5. 修订后的判定表（替代原预注册 §5）

| 假设 | 修订后判据 |
|---|---|
| **P-H1 交互效应** | **符号反转**：∃ (i,j)，`sign(Δ_i)≠sign(Δ_j)` 且 `|Δ_i|,|Δ_j|≥0.05`，在 ≥2/3 任务成立 |
| **P-H3 稳定性** | 参与 P-H1 的两类，Δ 双重复同号且 `Δ_range≤0.10`，在 ≥2/3 任务成立 |
| **P-H2 可利用空间** | 至少 1 个"单向优势区"（Q 高且成本、时延、合规均不劣） |
| **P-H4 合同不劣** | 两模型的 JSON 可解析率与必需字段齐全率均 ≥90%，且互差 ≤10pp |

**GO（进入 Phase Pi 的异构臂）** = P-H1 ∧ P-H3 ∧ P-H4 ∧ P-H2

**三种结果的处置**（与操作员指示一致，不临时改判据）：

| 结果 | 判定 | 下一步 |
|---|---|---|
| 符号反转 + 稳定 + 有单向优势区 | **异质性可利用** | Phase Pi 设三臂：Static-GLM / Static-DS / Heterogeneous |
| 某模型全类型统一占优 | **无交互效应** | Phase Pi 用该模型做统一基线，**不设异构臂** |
| 重复波动过大 / 反转不可复现 | **测量不足** | 如实报告不确定性；**不追加重复**去追求显著 |
