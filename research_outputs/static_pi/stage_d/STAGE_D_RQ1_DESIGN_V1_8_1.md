**结论**：

5. **“达 MVS 任务比例”在 H0 下是 0.229**：不能用未校正的点估计作为事实条件；必须对关键事实差异做检验。

## 1. P1：终端 Q 与 MVS 的操作化

### 1.1 终端 Q

- 只计**通过六查的有效 Gold 槽位**；E04 未处置前不进入。
- UNKNOWN 单独计量：答 UNKNOWN=1，断言具体值=0，未答=0；UNKNOWN 正确**不计入**关键 TP。
- 错误断言（critical_errors）单独报告，并从关键 TP 中排除。
- task-equal 主口径；fact-equal 敏感性；+1 TP 绝对定义不变。

### 1.2 三个独立条件（必须同时满足，不得互相抵消）

**统计条件**
- 独立测试任务的 task-equal ΔQ ≥ 6.25%（MVS，中位任务 +1 TP）；
- 配对 95% CI 下限 >0；
- 检验为训练/独立测试切分；LOTO 仅诊断。

**事实条件**
- 关键事实的**净正确增益** ≥1：Σ(策略关键 TP − 最佳统一关键 TP) ≥1；
- 该净增益必须在关键事实层面做精确检验/CI，不能用“达 MVS 任务比例”的点估计；
- 不得以错误断言或 UNKNOWN 猜测换取收益；
- 某任务增益、另一任务损失时，只认净值；净值<1 不通过。

**资源条件**
- 相对 Best Unified：ΔC ≤ +10%；
- ΔMakespan ≤ +10%；
- 可靠性非劣（parse、contract、critical errors）。

三项分别报告；任一项不通过即不支持“净收益”。

## 2. P2：Oracle 三件套

| Oracle | 定义 | 用途 |
|---|---|---|
| True Oracle | 合成实验的真实参数上限 | 理论上限 |
| Cross-fitted Oracle | 训练/验证选每节点模型，独立测试评估 | 可实现的估计上限 |
| Naive Oracle | 测试集事后取最大观测 | 选择偏差对照 |
| H0 分布 | 无互补时的 Naive/CF Oracle 分布 | 校准偏差与 CI |

- 20k 结果：Naive H0 +0.132；CF H0 +0.0001；Naive H1 0.15 +0.1476；CF H1 0.15 +0.0851；True Oracle 0.15 +0.0855、0.20 +0.1140。
- 校正的不确定性必须进 CI；不能简单“减去一个 H0 偏差”。
- Oracle 不参与训练/选择/部署；不进入确认性策略比较。
