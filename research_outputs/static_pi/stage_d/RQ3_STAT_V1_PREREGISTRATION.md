## 2. 测量（对应操作者四问）

1. **质量**：任务等权 Q_main 配对 ΔQ(B−A)；逐任务 ΔQ；**reason 槽分解**（9 个 merge 指派 Gold 槽的 Δ，增益应集中于此）；E07 零任务检验。

## 3. 判据与决策（先定后看）

- **稳定质量提升**：mean ΔQ(B−A) > 0 **且** ≥3/4 任务 B≥A **且** reason 槽 ΔQ > 0（增益来自替换节点而非随机波动）。
- **成本可控**：Δ计账费用 ≤ +10%（A 组均值基准）；**时延可控**：Δ墙钟 ≤ +20%。
- **统计诚实**：n=4 任务，任务级符号置换下限 p=0.125——本批为机制验证批，配对 ΔQ 报点估计 + 任务聚类 bootstrap 探索性 CI，不作确证性宣称；重复级 n=20 对按任务聚类。
- **决策规则**：三条判据全过 → 进入动态联合调度实验；质量判据不过 → 记录为"节点级优势未能转化为终端收益"（并报告失败层分解：槽位未转化/传播损失/重掷扰动）；质量过而成本/时延不过 → 报告为"质量-资源权衡"，由操作者裁决是否值得。
