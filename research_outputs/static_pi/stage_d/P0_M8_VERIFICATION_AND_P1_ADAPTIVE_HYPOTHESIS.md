## P1：Adaptive 截止时间感知策略——科学假设冻结

### 核心科学假设

> 在复杂 DAG 执行过程中，当节点出现异常时，基于剩余时间和恢复动作预期耗时，动态选择"恢复"或"快速完成"，能在不同截止时间条件下取得不低于最优固定策略的 E[TP_D]。

### 可证伪预测

| # | 预测 | 证伪条件 |
|---|---|---|
| H-Ad1 | 截止 ≤120s 时 Adaptive 选择 Static（不恢复），E[TP_D] ≥ Proposed | 任一紧迫条件下 E[TP_D]_Adaptive < E[TP_D]_Proposed |
| H-Ad2 | 截止 ≥150s 时 Adaptive 选择 Proposed（恢复），E[TP_D] ≥ Static | 任一宽松条件下 E[TP_D]_Adaptive < E[TP_D]_Static |
| H-Ad3 | Adaptive 在全部截止条件下的 E[TP_D] ≥ min(max(Static), max(Proposed)) | 存在某个截止条件下 Adaptive 劣于两个固定策略 |
| H-Ad4 | Adaptive 的决策不使用 Gold 或最终答案信息 | 任何使用不可观测信息的实现 |

### Adaptive 决策规则（预冻结）

```
if remaining_time < P90(Proposed_mk) + margin:
    action = SKIP_RECOVERY  # 保留当前结果，快速完成
else:
    action = DO_RECOVERY    # 执行诊断+恢复动作
```

其中：
- `remaining_time = deadline - elapsed_time`（运行时可观测）
- `P90(Proposed_mk)` = 从历史执行数据校准（M8 数据 P90 ≈ 140s）
- `margin` = 安全余量（初始 20s，可从校准数据调整）
- **不使用 Gold、最终答案质量、或任何后验信息**

### 三组对照设计

| 组 | 策略 | 验证 |
|---|---|---|
| A | **Static** | 快速基线（无恢复动作） |
| B | **Proposed** | 质量优先基线（始终恢复） |
| C | **Adaptive** | 截止感知动态选择 |

### 主要终点

$$E[TP_D] = \frac{1}{n}\sum TP_i \cdot \mathbb{I}(L_i \leq D)$$

次要终点：按期率、调用数、Token、实际成本、Makespan。

### 实验设计

| 项 | 值 |
|---|---|
| 任务 | PHASE2B（Stage D 冻结协议） |
| 场景 | S3 结构故障（有恢复动作差异） |
| 截止 | 120s / 150s / 250s（三档） |
| 重复 | 6 rep/条件（功效分析后调整） |
| 执行数 | 3 臂 × 3 截止 × 6 rep = **54 执行** |
| 调用估算 | 54 × ~7.5 = **~405 次**（余量 ~350 内需精确核算） |

### 统计方法

- 主检验：Adaptive vs 最优固定策略的 E[TP_D] 配对差（精确符号翻转）
- 次级：逐截止条件的 Adaptive vs Static / Adaptive vs Proposed
- 报告效应量 + CI + 方向一致性，不追 p 值

### 如果结果为正

→ "截止时间感知的自适应调度能在不同约束条件下取得不低于最优固定策略的终端质量"——**比"Proposed 优于 Static"更有价值的科学结论**

### 如果结果为负

→ 简单的剩余时间阈值不足以做出正确的策略选择——需要更精细的决策特征（如恢复成功率估计、多节点依赖感知）
