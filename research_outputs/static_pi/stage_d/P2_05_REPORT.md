## 0. 结论先行

1. **检测问题被可观测信号解决**：用"执行失败 ∨ 事实生产缺失 ∨ 证据链缺失"做节点坏检，**灵敏度 96.1%、特异度 100%**（合成验证器只有 75%/85%）。4,085 个坏节点中只有 159 个漏检，且**全部是"带有效证据的自信错误事实（FP）"**——这是唯一真正不可观测的失败类（3.9%）。**不再需要 sens=.75 的惩罚，65% 上限被解除。**
2. **成本仍是唯一硬阻塞**：可观测检测 + 全坏节点最优模型重建 = 期望转换 3.43/任务 → **Q 71.9%**，但成本 ≈2.25×；共享折扣 d=0.3 → 1.99×；d=0.5 → 1.82×。**70% 需要约 1.8–2.25× 预算**（取决于共享检索能省多少）。
3. **冻结预算内上限 ≈50–52%**：20% 档（余量 0.12）在 d=0–0.5 下 Q=49.7–52.0%；15% 48.7–50.4%；10% 47.6–48.8%。
4. **时延可以守住**：投机并行重建全部 ≤+10.5%（仅 r-GLM +10.5% 超 strict 10% 0.5pp，matched-20 全部满足）；DS 节点并行重掷时延 +0%。事后串行重建 +21–42% 全部超时延。**父信号门控的投机**：tau=.999 时 sens .765/spec .449（开火率 73%）——父信号单独不足以做精准门控，但可作为投机触发器（时延安全、成本按开火率计）。

## 1. 检测：可观测信号 vs 合成验证器

| 检测器 | 信号 | 灵敏度 | 特异度 | 漏检坏节点 |
|---|---|---:|---:|---:|
| 合成验证器（JFR 沿用） | 概率标记 | 75.0% | 85.0% | 1,021/4,085 |
| **A：可观测**（exec 失败 ∨ out=2 ∨ 证据链缺） | 全可观测 | **96.1%** | **100%** | 159/4,085 |
| B：保守可观测（exec 失败 ∨ out=2） | 全可观测 | 78.8% | 100% | 865/4,085 |

- 漏检的 159 个坏节点**全部**是 out=1 且 loc∧sup 为真（自信 FP + 有效证据）——真正需要模型判断的隐藏类。
- **假设声明**：A 把"事实生产缺失（out=2）"和"证据链缺失（loc/sup=false）"视为可观测。前者=节点输出里没有该事实，后者=事实没有有效证据引用/支持——两者在真实系统里是格式/引用检查可发现的。这个假设必须在 P2-1 审计门里显式冻结。
- B（不含证据链可观测性）退回 78.8%——**证据链可观测性是检测增益的主要来源**（96.1 vs 78.8）。

## 2. 成本：共享折扣 d 的反演（每事实仍独立核验，共享的只是检索/上下文/证据准备）

分组：{e0,e1,t}(DS)、{m,v}(GLM)、{r}(GLM)、{p}(GLM)；组内共享一次证据准备，d=共享省下的成本比例；**每条事实的事实/定位/支持核验独立进行，不因共享而豁免**。

| 共享折扣 d | 70% 所需预算 | 20% 档 Q | 15% 档 Q | 10% 档 Q |
|---:|---:|---:|---:|---:|
| 0（无共享） | ≈2.1–2.25× | 49.7% | 48.7% | 47.6% |
| 0.2 | ≈2.07× | 50.4% | 49.2% | 47.9% |
| **0.3** | **≈1.99×（add 0.571，Q 70.9%，CI[65.3,76.3]）** | 50.8% | 49.5% | 48.2% |
| 0.4 | ≈1.90× | 51.4% | 49.9% | 48.4% |
| 0.5 | ≈1.82×（add 0.455，Q 70.1%，CI[64.3,75.7]） | 52.0% | 50.4% | 48.8% |

- 全坏节点重建（检测 A 触发）期望转换 **3.43/任务 → Q 71.9%**（CI 见 JSON）；成本 add 从 0.748（d=0）降到 0.489（d=0.5）。
- **反演结论**：要在 ≤1.5× 内到 70%，需要 d≈0.75+（省 3/4 成本）——超出"共享检索/上下文"的合理范围；≤1.2×（冻结 20%）需要 d≈0.85+，不现实。
- d 的现实锚点：一次节点执行的 GLM 成本里，检索+上下文构建+证据整理占多少是经验问题；d=0.3–0.5（共享组内省 30–50%）对应"检索/准备占 30–50% 且组内完全共享"的乐观-中位情形。**P2-1 必须把 d 当作待估参数做敏感度，不得直接取乐观值。**
- CI 说明：以上是 800 任务一阶矩期望的 bootstrap 95% CI；真实重执行的抽取方差会加宽 CI；P2-1 需用真实重执行（新 CRN）验证。

## 3. 时延：投机并行 vs 拓扑内串行

| 节点（重建模型） | 投机并行 | 事后/拓扑内串行 | strict 10% | matched 20% |
|---|---:|---:|---|---|
| e0/e1/t（DS） | **+0.0%** | +21.1–26.3% | 投机✓ | 投机✓ |
| m（GLM） | +7.9% | +31.6% | 投机✓ | 投机✓ |
| r（GLM） | **+10.5%** | +42.1% | 投机✗（超 0.5pp） | 投机✓ |
| v（GLM） | +9.6% | +38.6% | 投机✓ | 投机✓ |
| p（GLM） | +6.1% | +24.6% | 投机✓ | 投机✓ |

- **DS 节点的"并行同模型重掷"时延为 0%**（同延迟并行跑第二份，事后用检测 A 选优）——e0/e1/t 的重建可以零时延代价进行。
- GLM 节点必须投机并行（与 DS 原执行同时启动 GLM 副本）；r 超 strict 0.5pp，可只对 r 降级为"matched-20 下运行"或放弃 r 重建（其期望转换本来就最低，0.46）。
- **父信号门控投机**（tau=.999）：sens .765、开火率 72.6%——作为触发器可用（省 27% 投机成本），但不是精准检测；主检测仍靠事后检测 A 选优。

## 4. 综合判定：P2-1 的可行形态

**质量路线图（检测 A + 投机并行 + 组内共享证据）：**

| 预算 | 预期 Q（d=0.3） | 到 70%？ |
|---|---:|---|
| 1.2×（冻结 20%） | ≈50.8% | 否 |
| 1.5× | ≈58.9% | 否 |
| 1.75× | ≈65% | 否 |
| **≈2.0×** | **≈70.9%** | **是（CI 下界 65.3%，需真实重执行验证）** |
| 2.25×（d=0 无共享） | 71.9% | 是 |

**三个组件的边际贡献分解**（相对 P2-0 的 2.2×/65%）：

1. 可观测检测（96.1%/100%）替代 sens .75：**成本不变（触发即坏节点），转换从 2.57 → 3.43**；
2. 共享证据 d=0.3：**成本 2.25× → 1.99×**；
3. 投机并行 + DS 重掷：**时延约束从"仅 p-DS 可行"变为"全部可行（r 降级 matched）"**。

**剩余阻塞只有一个：预算。** 在冻结 10/15/20% 下，任何机制组合的解析上限都在 ≈48–52%。

## 5. 给操作者的决策点（更新 `P2_1_PROTOCOL.md`）

1. **质量模式预算档**：建议按 d∈{0, .3, .5} 三档敏感度申请 ≈1.8–2.25× 中的一个明确档位（例如 2.0×），或明确维持冻结预算并接受 ≈50% 上限（此时 P2-1 的价值仅剩机制验证与归因）。
2. **证据链可观测性假设**：检测 A 依赖"loc/sup 缺失可观测"。批准后冻结进协议；若不批准，检测退回 B（78.8%），70% 所需转换不可达（3.43→~2.9? 需重算，B 下预期更低）。
3. **r 节点处理**：r-GLM 投机超 strict 0.5pp。选项：放弃 r 重建（转换 3.43−0.42×0.91≈3.05 → Q≈68.7%，不够 70）／r 只在 matched-20 跑／r 用 DS 重掷（0.42 转换，时延 0）补差。**若 strict 必须守住，r 用 DS 并行重掷是唯一时延安全选项。**
4. **d 的估计来源**：真实系统中检索/上下文占节点调用成本的比例——这需要小规模真实测量（未来），P2-1 内只能做敏感度。
