## 0. 结论先行

1. **第一个 strict-10 合规且 Q≥70% 的配置出现了**：P2 计划（DS 基座；e/t/r/v/p DS 并行重掷 + m GLM 投机）+ signal 选择 + 全量语义核验 = **Q 70.78%（×1.87，Makespan 1.079）**。但它的归因差只有 **2.95pp < 5pp**。
2. **归因达标（≥5pp）的配置最高 69.47%**（P5：基座 m=GLM + 其余 DS 重掷 + signal + 核验，×1.79，mk 1.079，dHet 5.99pp）——差 Q 门 0.53pp。
3. **四个门（Q≥70、时延、dHet≥5、sham 干净）同时通过的配置集仍为空**；两侧差距分别为 0.53pp（质量侧）与 2.05pp（归因侧）。
4. **结构性发现：质量来自"投机重掷+语义核验"（模型无关成分高，H0 也大涨），归因来自"基础分配异构"（基座放 GLM 的计划 dHet 6–10.7pp）**。二者当前此消彼长：基座放 GLM 挤占重掷预算。
5. 按纪律**不再继续组合搜索追门**（那会变成 gate-hacking）；以下前沿如实报告，P2-1 的预注册设计以此为基础。

## 3. 语义核验的计价价值（P1，signal 规则）

| 核验范围 | ΔQ | 核验调用/任务 | 成本增量 |
|---|---:|---:|---:|
| m+v+p | +0.74pp | 1.63 | ×1.88→1.92 (c=.05) |
| **e0+e1+t** | **+1.49pp** | 3.30 | ×1.88→1.92 |
| r | +0.31pp | 0.43 | ~0 |
| 全量 | +2.23pp | 4.93 | ×1.88→1.93 |

- **核验价值集中在下游传播大的上游节点（e/t +1.49 > m/v/p +0.74 > r +0.31）**——支持"核验价值取决于 DAG 位置与下游影响"的假设。
- 核验成本极小（每次 c_ver 扫描 0.02–0.10，总增量 ≤×0.11）；**在 capability_c 下核验增益为 0**（选择已饱和，决策不再翻转）。
- **诚实声明**：本模拟假设核验调用能完美判定支持关系（乐观）；P2-1 必须加 sham-verify（随机核验/无信息核验）对照。

## 4. 归因结构（dHet = ΔQ_stable − ΔQ_H0，5pp 门不变）

| 计划类型 | dHet（count/signal） | 解释 |
|---|---:|---|
| DS 基座 + 重掷/核验（P1/P2/P3） | 2.0–3.9pp | 收益主要模型无关（H0 也大涨：60–61%） |
| 基座含 GLM（P4/P5/P7） | **5.3–10.7pp** | 基础分配的异构性是归因主要来源 |
| H0 世界同计划 | Q 50–61% | 无模型差异时重掷/核验仍有效但更弱 |

- **投机+核验的增益大部分是"模型无关纠错"**（P1 signal: stable +23.97pp vs H0 +21.31pp）。
- **要把 dHet 推过 5pp，必须在基础分配里用 GLM**（P5 最优：质量代价 −1.3pp vs P2，换来 dHet +3pp）。
