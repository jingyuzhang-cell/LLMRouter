# 独立处罚案例检索与独立性审计报告

**日期**：2026-11-06
**授权**：操作员授权“检索和下载新的公开处罚文书”，范围与禁止事项见第一节。
**本轮模型 API 调用**：0。只访问了巨潮资讯的公告检索接口与 PDF 静态地址，没有使用任何模型。
**结论**：在冻结标准下找到 **9 家通过独立性审计的案例**。逐字核对后，推荐**千山药机（300216）**为独立确认任务，**索菱股份（002766）**为备选。是否采用、用哪一家，由您决定。Gold 尚未构建。

## 一、授权范围与标准（未放宽）

| 标准 | 实现 |
|---|---|
| 证监会或派出机构的事先告知书与行政处罚决定书 | 决定书公告与同一公司、同一案件的告知书公告配对；告知书当事人与决定书当事人重合度 ≥ 0.5 |
| 至少 8 个责任主体 | 从决定书原文的处罚条款逐条解析 |
| 多档金额与可复算的合计 | 至少 2 档；合计必须能从原文无歧义复算（见第四节皇台案） |
| 两份原始 PDF 可获取 | 均已下载，记录 URL、获取时间、SHA256 |
| 与开发台账零命中 | 股票代码、简称、全称、全部当事人（决定书与告知书）、带发文机关前缀的文号，在工作区、git HEAD 与完整 git 历史中检索 |

禁止事项全部遵守：没有模型调用，没有自动生成 Gold，没有启动实验。

## 二、筛选漏斗

| 阶段 | 剩余 | 说明 |
|---|---:|---|
| 1 候选池 | 566 家 | 巨潮标题检索“行政处罚决定书”，2019–2025，深沪两市；剔除子公司、非本公司事项、更正与进展类 |
| 2 配对 | 439 | 同公司有“事先告知书”公告 |
| 3 批量预检 | 270 | 代码或简称在本地任何位置出现即剔除（169 家） |
| 4 结构 | 66 | 下载双文书，按原文检查主体数、档位、告知书同案 |
| 5 逐词审计 | 16 家已审 | 按“有金额调整 → 告知书重合度 ≥ 0.9 → 主体数”排序后审计前 16 家 |
| 结果 | 9 独立；4 仅人名撞名；3 拒绝 | 见第五节 |

**口径偏严之处（如实披露）**：
- 第 3 阶段对两字简称也做子串匹配（如“应急”“创意”“新元”），会误杀与常用词同形的公司。这只会让标准更严，不会放宽，但可能漏掉合格案例。
- 只审计了排序前 16 家，其余 50 家结构合格的候选未审计，留作备用池。

## 三、推荐案例：千山药机（300216）

**文书**（均为证监会作出）：

| 文书 | 公告标题 | 页数 | SHA256 | 来源 |
|---|---|---:|---|---|
| D1 告知书公告（2019-12-02） | 关于收到中国证监会《行政处罚及市场禁入事先告知书》的公告 | 10 | `69a1a17a1636d04a…` | http://static.cninfo.com.cn/finalpage/2019-12-02/1207130926.PDF |
| D2 决定书公告（2020-08-07） | 关于收到中国证监会《行政处罚决定书》及《市场禁入决定书》的公告 | 16 | `0b7b23b73ee30a55…` | http://static.cninfo.com.cn/finalpage/2020-08-07/1208135217.PDF |

获取时间：2026-11-06 17:01:47 / 17:01:48（+0800）。完整哈希见 `CANDIDATE_MANIFEST.json`；PDF 已设为只读。

**决定书处罚条款（原文，去空白）**：
> 一、对湖南千山制药机械股份有限公司责令改正，给予警告，并处以60万元的罚款；二、对刘祥华、刘华山给予警告，并分别处以30万元的罚款；三、对周大连给予警告，并处以15万元的罚款；四、对姜纯给予警告，并处以10万元的罚款；五、对钟波、刘燕、邓铁山、王国华、郑国胜、彭勋德、黄盛秋给予警告，并分别处以4万元的罚款；六、对付慧龙、金杰给予警告，并分别处以3万元的罚款。

- **14 个受罚主体**（公司 + 13 人），**6 档金额**（60 / 30 / 15 / 10 / 4 / 3 万）。
- 合计可复算：60 + 30×2 + 15 + 10 + 4×7 + 3×2 = **179 万元**。

**两阶段调整**（告知书 → 决定书）：
- 告知书拟罚 25 个主体，合计约 320 万。其中刘祥华拟罚 90 万（作为直接负责的主管人员与实际控制人的合并罚款），决定书改为 30 万。
- 周大连 20→15，姜纯 20→10。
- 原拟罚 5 万的 20 人中：7 人改为 4 万，2 人改为 3 万，**11 人在决定书中不再受罚**。

结构与 SC-E1（獐子岛：9 人移出、多档下调）高度相似，可以直接复用已验证的管线与评分合同结构。

**命名陷阱**：告知书用简称“千山药机”，决定书用全称“湖南千山制药机械股份有限公司”。

**独立性**：
- 逐词审计 20 个词，告知书独有当事人与公司简称另补审 14 个词。
- 范围覆盖工作区、git HEAD 与完整 git 历史，**零命中**。

## 六、边界

- 这里的独立性是相对于**本项目本地语料与 git 历史**而言。两份文书是公开公告，不能排除出现在模型预训练语料中。SC-E1 和任何公开案例都有同样的问题，独立确认实验的预注册需要写明这一点。
- 候选池只来自巨潮标题检索，标题措辞不同的公告可能漏检。
- 处罚条款解析器在“责令…改正”句式上会漏掉公司本身。推荐的两家已逐字核对；其余候选的结构数字未经逐字核对，仅作排序参考。
