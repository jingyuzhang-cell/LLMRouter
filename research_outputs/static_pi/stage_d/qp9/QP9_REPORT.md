## 4. 三个发现

**F1 · 金盲触发信号与质量解耦（核心阴性机制）。**
首过 answer-completeness 与最终 Q 的 Spearman = **−0.29**（24 格）。KANGMEI 完整度最高（0.93–1.00）而 Q=0.000（5–6 条全错、零正确）；ZIJING 完整度最低（0.05，19/20 弃答）而恢复毫无作用。触发器在“自信的错答”处沉默、在“诚实的弃答”处空转——**方向恰好与需要修复的位置相反**。

**F2 · π 无增量：能力互补 ≠ 盲调度可利用。**
Stage A 已用金标筛选证明 54 条非对称事实（23 条严格可修）存在双向互补，但金盲调度器拿不到失败定位，无从知晓何时切换。C−B = −0.015：切换模型在所有触发的格上都不优于同模型重试。能力剖面是必要条件，**正确的失败定位信号才是充分条件**。

**F3 · 表观 B 增益是重采样噪声，不是修复。**
ZEDA r1：B 与 C 同升 +0.177（.294→.471）——任何第二次采样都行；ZEDA r2：B=0.412 恰等于 A 的单次直出；ZEDA C r2 因首过样本“看起来完整”（ac=.71）而未触发，反被坏样本钉死在 0.294。同配置跨重复格间噪声（±0.06–0.12）与任何臂效应同量级，n=2 无法分离。

## 5. 结论与走向

1. **诚实阴性结论**：在金盲完备性触发器下，π（模型切换）相对 R（同模型重试）无质量增量，且时延×2。预注册标准未达成，本线关闭，不追加预算。
2. 阴性结果的科学价值：把 Stage A 的“互补性存在”（金标筛查）与 QP9 的“盲调度不可利用”分离成两条独立命题——动态调度论文需要**正确性感知的反馈信号**（如跨模型一致性/交叉验证）作为 π 的前置条件，这是下一步唯一有依据的假设。
3. 复用资产：QP8R/QP9 干净 E 缓存、parser_v2、QP9_RESULTS_FIXED.json 中的逐格 ac 诊断列。
