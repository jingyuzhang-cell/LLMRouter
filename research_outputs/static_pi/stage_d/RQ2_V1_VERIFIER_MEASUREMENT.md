# RQ2 V-1 核验器真实性能测量（200 对，零 API 调用）

**结论先行：glm53flash 语义核验器灵敏度 0.988（95% CI [0.957, 0.997]，过预注册门 ≥0.70），但特异度仅 0.529（95% CI [0.367, 0.686]，远低于预注册门 ≥0.85）。核验器系统性地放过"引用之上的过度声明"。按预注册规则，V-1 不达标 → Q_full 维持"核验器未验证"标签，主结论继续使用 Q_main；V2 已按此报告，无需改数。**

## 1. 标注来源与独立性披露（必须先读）

- 样本：`RQ2_P2R_V2_V1_SAMPLE.jsonl`，200 对（从 B/C 去重核验的 403 个唯一 (fid,value,doc,quote) 对中按 任务×臂×核验判定 分层抽样）。
- 标注者：**我（助手，GLM-5.3）逐条判读，不是人工标注**。核验器是 glm53flash，与标注者同模型家族——独立性受限，协议预注册写的是"人工标注"，本测量是对该协议的**替代执行**，结果应视为 AI 共同评审，最终仍建议人工抽检复核。
- 机械辅助（完全客观）：①quote 是否在所述文档逐字存在（NFKC+去空白归一化）；②值中的日期/数字/编号元素是否被 quote 覆盖。
- 判读规则（写入 `RQ2_P2R_V1_V1_METRICS.json`）：
  1. 值中断言的所有日期/数字/编号必须出现在 quote 中（ISO 与中文日期格式视为等价）；
  2. 值在 quote 之上追加的结论（审计意见、风险警示状态、规则条文号、枚举清单）→ 不支持；
  3. 元引用（quote 是模型自述而非文档原文）→ 不支持；
  4. 可由引用文档本身消解的指代（"本公告"日期）可接受；法律条文号的归属必须落在 quote 内。
- 标注产物：`RQ2_P2R_V2_V1_LABELED.jsonl`（每行含 `ai_label`、`ai_severity`、`ai_reason`、`span_found`；`human_label` 保留 null 待人工复核）。

## 3. 失败模式（对研究有直接价值）

**16 个 FP（核验器放过的过度声明）：**
- **6 个 major**：值在 quote 之上追加了未落地的结论或枚举——内控否定意见/其他风险警示状态（4 例）、《上市规则》10.3.11 十项情形枚举（2 例，quote 只有"下列情形之一"或被"……"省略）、1 例元引用（quote 为"（文档中未出现'立案'相关表述）"这类模型自述）。
- **10 个 minor**：值引用了 quote 中不存在的公告编号（2026-118、2026-041、2026-044、2026-004 等）或日期、股票代码 300198、条文号归属。

**2 个 FN（核验器错误拒绝）**：V2-019、V2-041——完全落地的治理缺陷表述（quote 覆盖全部元素）被拒；与内容几乎相同的其他对被判 supported，说明核验器判定存在**不一致性**（同质内容一收一拒）。

**机械发现（独立于语义）**：200 条 quote 中 **20 条（10%）在所述文档中不存在逐字原文**（PDF 换行/空格伪影，如"归 属于母公司股东 的净利润"）。评分器（V1.5 Gold 匹配）只检查 value+doc，不检查 quote 真实性——**quote 伪造在当前 Q 口径下不可见**，这是评分体系的已知缺口，冻结不改，记录在案。

## 4. 对 V2 结论的影响

1. **Q_main 不受影响**：V2 主结论（C−B 终态 −21.30pp、B−A +1.44pp）全部基于 Q_main（TP∧定位∧report 门），不含核验判定。
2. **Q_full 是上界**：B 60.27% / C 41.24% 的 Q_full 建立在"95–97% supported"之上；特异度 0.529 意味着其中相当一部分"支持"实为过度声明。**Q_full 只能解读为乐观上界**，且维持"核验器未验证"标签——这正是 V2 报告 §8 的处理，维持不变。
3. **对 2×2 实验的设计约束**：改进交付层若引入"结构化输出压缩"，会让模型少写、少过度声明，恰好也可能改善核验特异度；但 2×2 的主指标必须是 Q_main，Q_full 仅作次要参考，直到有人工标注复核本测量。
