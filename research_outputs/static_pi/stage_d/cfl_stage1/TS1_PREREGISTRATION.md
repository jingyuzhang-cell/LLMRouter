# TS-1 预注册：终端正确选择实验（冻结稿 · 已授权 GO）

**任务**: MVR1（主判据·选择困难）/ E06（保护判据·选择成功）/ ZEDA（边界判据·证据不足）
**预算**: 6 正常 + 2 预留（仅传输/解析失败）= **硬顶 8 次 / 25,000 tokens / ¥0.05**；E 层零调用；基线零调用
**A 臂（现有策略）**: CrossTask B_new 输出冻结复用（`CFL3_CROSSTASK_RESULTS.json`），不重新调用。
**B 臂（选择约束策略）**: 与 A 完全同池、同逐条保真表、同模型、同提示基座（sha 与 CrossTask B_new 行断言一致），**唯一新增**以下冻结选择约束块（逐字追加于提示尾部）：

```
【逐槽选择约束（本次追加）】
1. 每个 fact_id 独立处理，不跨事实借用证据。
2. 优先选择 field 与目标事实相符的证据行。
3. value 必须能够从对应 quote 中得到直接支持。
4. 多条候选冲突时，不允许随意选择。
5. 没有直接支持的事实允许 UNKNOWN（写入 abstentions），不强制生成答案。
6. 最终输出仍遵循原有 JSON Schema。
```

**判定（逐任务、逐重复分别报告；重复不作独立样本）**：
- MVR1 主判据：TP 增加 ∧ 错误断言减少 ∧ Q > B_new 基线（0.250）；不得以增加弃答换取安全性（弃答数不得高于基线 1/0 + 容差 2）。
- E06 保护判据：不明显损失现有 TP（基线均值 9.5）；不引入明显新增错误（基线均值 2）。
- ZEDA 边界判据：不因强制作答增加错误；缺直接证据的槽位允许弃答。
- **关闭规则**：MVR1 两重复均无正确选择收益 → 关闭选择机制实验线，不再更换提示词重试。

**工作假设（修正采纳，未拟合验证）**：终端收益 ~ 可恢复信息损失 × 正确证据覆盖度 × 终端正确选择能力。
**运维**: 429 退避不耗预留（沿 CrossTask 口径）；GLM 用 bigmodel-api-5 文件键，用后即删。
