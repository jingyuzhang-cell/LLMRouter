## 3. 强 Static 与异常起点

强 Static = 探针 E 分配 + J/V 确定性 + SINK=DS，完整执行 DAG 得干净基线 Q/C/L。恢复实验：在强 Static 链上注入传输层异常（截断/超时，共用注入台账）+ 自然异常；**所有动态臂从同一冻结检查点出发**，恢复真实执行；Static 臂=不恢复对照。

## 4. 终点（层次固定）

- **主终点**：质量约束下的**成本 C**——Q_all ≥ 强 Static −单槽分辨率（任务级聚合）；不满足者判不可行、保留并单独报告不可行率；可行者比实际总成本（含探针、失败、重试、全 DAG）。
- **次要终点**：质量约束下**端到端墙钟时延 L**（真实并行：e0∥e1 取 max 非求和）；附恢复成功率与截止期满足率。
- **综合**：真实执行点 Q-C-L Pareto 前沿。C/L 不允许任一显著即宣称联合优化成功。
