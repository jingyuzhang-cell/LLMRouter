# Stage-3 预注册草案：五臂动态联合调度真实对照（待审查与授权）

**核心科学问题**：在相同终端质量保障（统一链、统一 Gold/评分器 v2）下，动态调度（R/π/Z/Joint）能否比 Static 更好地利用异构模型修复真实节点异常，同时降低成本与时延？

## 一、统一实验条件（铁律）

五臂共用：任务输入（冻结 E 缓存 + 契约）、Gold、评分器（v2+sidecar 双分母）、终端执行链（E→J→V→SINK，J 含 E06 空集裁决）、J/V 确定性规则、提示基座。**唯一核心差异 = 调度策略**。所有恢复为**真实调用**（禁用回退图/后果矩阵查表），Q/C/L 逐次实测。

## 二、DAG 拓扑与真实恢复空间（前置事项 2 的回应）

```
e0(文书A半) ∥ e1(文书B半)      ← 并行分支，逐节点模型可分配（DS/GLM）
        ↘  ↙
         J(实体-数值绑定·确定性)  ← 汇合点；绑定失败→UNKNOWN/谓词感知重绑
         ↓
         V(四部件核验·确定性门)   ← 拒绝→不进入证据表
         ↓
         SINK(DS/GLM·统一提示)   ← 组织/弃答/格式异常
```
恢复范围空间（Z）：NONE（诚实降级）/ LOCAL（仅失效节点重执行）/ UPSTREAM（E 级定向重抽，如 CFL-3-MIN 已验证）/ FULL（整链）。动作空间（R/π）：同模型重掷 / 互补模型重分配（按能力画像：SINK KANGMEI/MVR1=DS，E06=DS，E=各任务池源模型）。

## 三、异常来源（全部真实）

1. **自然异常**（已测频率，账本可溯）：解析失败（~1/35）、SINK 全弃答吸引子（3 例观测）、格式彩票（单位装饰）、J 同名误绑（E06 型）、证据覆盖缺口（S2/verify 放行数=0 检测）。
2. **接口级诱导**（沿 RQ_DYN_V2 S1/S3/S4 先例，仅执行层）：传输截断/超时，按自然频率注入（每臂同任务同 rep 同点位，两组共用注入台账）；**不注入语义错误**（自然发生已足够）。

## 四、五臂定义

| 臂 | 异常响应 |
|---|---|
| Static | 不恢复，如实记录（其中 2 历史重复可重放，+1 新执行补足 3 重复） |
| R | 失效节点同模型重执行（≤1 次） |
| π | 失效节点互补模型重分配（≤1 次） |
| Z | 按异常类型选范围（事实缺失→UPSTREAM/降级；绑定错→UNKNOWN/重绑；值表达→V 规范化；组织错→LOCAL），模型不变 |
| Joint | (范围, 动作, 模型) 联合决策，用已验证的异常→动作映射 |

## 七、判定（预注册，不事后放宽）

- 主判据：**Joint vs Static** 的 Q 不劣（ΔQ ≥ −0.02）前提下，C 或 L 显著改善（配对比较，逐任务+宏），且恢复成功率 ≥ R/π/Z 单臂；
- 机制判据：各动态臂在其对应异常类型上的修复率高于 Static（异常分型统计）；
- 安全门：错误断言不升、不可覆盖槽 UNKNOWN 纪律（E06 H3 型错答计违例）；
- 阴性预案：若 Joint 无 C/L 优势但 Q 修复成立 → 结论改述为"质量鲁棒性收益"，Q/C/L 联合优化主张不成立，如实报告。
