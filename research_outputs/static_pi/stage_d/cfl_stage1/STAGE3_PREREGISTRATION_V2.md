# Stage-3 预注册 v2（最终轮 · 按操作员收官裁决修订，取代 v1）

**定位声明**：本轮验证**动态联合恢复**（Z/R/π 在真实异常上的联合决策），不包装为整个系统验证——DAG 自动分解、候选图森林搜索、反馈奖惩机制、多目标 Pareto 搜索**均不在本轮范围**。本轮为最后一轮核心机制验证；其后仅统计验证与论文整理。

## Stage-3A：统一异常配对测试（真实历史异常为共同起点）

**异常语料库**（`STAGE3_ANOMALY_CORPUS.json`，全部账本可溯）：**10 个真实事件**，5 类型 × 5 任务——组织错误×3（弃答崩塌 KANGMEI×2/ZEDA×1）、信息坍缩×1（KANGMEI verify 0/21）、关系绑定×1（E06 H1/H2 同名误绑）、事实缺失×3（E06 违纪错答/ZEDA 抽取缺口/ZIJING 文档级）、执行失败×2（JSON 解析）。**格式彩票事件在终口径下已非错误，不列入**（避免"恢复不存在的问题"）。

**配对设计**：每事件五臂从**同一冻结初始状态**（该事件的历史失效输出/状态）出发；恢复阶段全部**真实新调用**（提示可与历史一致但必须新采样，禁用预计算结果与缓存回放；确定性动作（J 重绑/V 规范化/NONE）零调用如实计）。配对分析单位 = 异常事件（10 对），按任务聚类报告；**本轮结论定位=机制验证，不宣称跨任务泛化**。

## Stage-3B：五臂恢复协议

| 臂 | 每事件动作 | 调用 |
|---|---|---|
| Static | 不恢复，采用冻结失效状态的终局 | **0**（历史已测） |
| R | 失效节点同模型重执行 ≤1 次 | ≤1 |
| π | 失效节点互补模型（按能力画像）≤1 次 | ≤1 |
| Z | 范围选择：组织错→LOCAL；坍缩→UPSTREAM(E 定向重抽)；绑定错→J 重绑或 UNKNOWN；事实缺失→NONE/降级；执行失败→LOCAL | 0–1 |
| Joint | (范围,动作,模型) 联合（含 R/π 选择） | 0–2 |

ZIJING 型事件（文档级缺失）：**正确动作=零调用降级**——任何臂调用即记浪费（这是 Joint 的关键鉴别事件）。

## Stage-3C：联合优化验证

逐事件三元组 (ΔQ, C_recovery, L_recovery) + 任务级聚合；Joint vs Static 的 Q 不劣性与 C/L 改善检验；真实 Pareto 前沿（点=五臂，事件级与任务级两层）。

## Stage-3D：统计与关线（冻结停止规则，不事后放宽）

| 结果 | 最终处理 |
|---|---|
| Q 不劣（ΔQ≥−0.02）∧ C 或 L 显著改善（事件级配对检验） | 支持 Q/C/L 联合优化主张 |
| Q 提升 ∧ C/L 无改善 | 支持质量鲁棒性收益，不宣称联合优化 |
| Joint ≤ max(R,π,Z) 单臂 | 联合决策额外价值未证 |
| 全动态臂无收益 | 关闭实验线，明确适用边界 |

统计：事件级配对（符号检验/Wilcoxon，n=10，如实报告功效限制）+ 任务聚类描述 + 消融（Joint vs 各单臂）。**禁止更换任务/提示/条件追逐正向数字。**
