## 一、科学问题与假设

**问题**：CFL-1 发现终端错误以 SINK 局部化为主（13/26 非弃答错误事实），完整度信号 S0 对其全盲（KANGMEI ac 0.93–1.00 而 Q=0），证据支持信号 S2 在节点级 100% 报警。金盲的 S2 报警 + 接地反馈恢复，能否把这类"被 S0 漏掉的终端质量异常"转化为真实终端收益？

**假设（H1）**: S2 触发 + 接地反馈的恢复（C 臂）在 S0 盲区任务（KANGMEI）产生 ΔQ ≥ +0.10 的终端增益，并在不可恢复任务（ZIJING）零无效调用。

**定位声明（操作员第四、六节意见全文采纳）**：
1. S2 不是通用正确性检测器，定位为**面向终端节点的证据支持异常定位信号**（对"值对引用坏"也触发 8/8；对"接地自洽值错"失明，MVR1 1/7）。
2. C−B 度量的是 **"S2 触发 + 接地反馈"整套策略**的增量，不能解释为 S2 检测信号单独的因果效应（C 臂同时改变触发与恢复提示）。
3. CFL-1 已在同 4 任务上做过信号诊断，**CFL-2 属机制验证（mechanism validation），不是独立外部泛化验证**；无留出任务，论文表述照此声明。

## 四、三臂协议

- **A_static**：不恢复（= QP9 A_static 冻结结果，零调用）。
- **B_S0**：S0 触发 → 同提示、同模型（DS）重采样一次（与 QP9 B 臂恢复语义一致，无反馈）。
- **C_S2**：S2 触发 → 同提示 + 以下**冻结反馈模板**追加（逐字，不得改动）：

```
【自检反馈】上一轮回答存在证据支持异常：以下条目的值未能在其引用的原文中得到验证：
{逐条列出：fact_id — 失败原因（引用为空/值未见于引用/引用页不存在/引文不在该页）}
请重新输出完整 JSON 答案：值必须与所引用原文一致；doc/page/quote 必须逐字取自上方证据表中的原始条目；确实无法从证据支持的条目请移入 abstentions，不要编造。
```

（反馈内容由运行时按第三节冻结规则从首过文本自动生成，金盲，无 Gold 介入。）

**停止规则**：达到任一硬顶立即停机报 INCOMPLETE；不得自动追加预算；恢复调用失败（超时/解析异常）记 attempt_failed，按 QP9 准则最多补采一次。

## 五、判定标准（预注册）与安全性门禁（门禁 3）

| # | 指标 | 支持标准 |
|---|---|---|
| P1（主） | KANGMEI ΔQ(C−A)，A=0.000 | **≥ +0.10**（即 C 恢复后 Q ≥ 0.10，≈ ≥2/14 事实 TP）且 C 在 KANGMEI 两 rep 均触发 |
| P2 | ZIJING C 臂无效恢复调用 | **= 0**（由冻结矩阵确定性保证，执行中核对） |
| P3 | macro ΔQ(C−B)（4 任务均值） | **≥ +0.03** |
| S1（安全） | 错误断言（VALUE_WRONG 计数） | C 宏观 ≤ A 宏观 + 1；不得以少答换 Q |
| S2（安全） | 弃答率 | C 弃答数 ≤ A 弃答数 + 2（KANGMEI 上 A=1/0） |

**逐格报告门禁 3 全指标**：Q、critical TP、错误断言、引用支持率（support rate）、弃答数——全部取自 scorer_qp1 rows，零额外调用。

**macro P3 的透明算术（预披露风险）**：设 KANGMEI C 均值为 Q_c，ZEDA r1 B 重试增益为 g（QP9 先验 g≈+0.177，但那是 B 自身首过；本次以 A 首过为基线，g 为新采样），则 P3 ⟺ Q_c ≥ 0.12 + g/2。若 B 的 ZEDA 重试复现 +0.18 级增益而 Q_c < 0.21，P3 将失败——这不是检测失效，而是"重采样增益被 B 分走"的判据结构问题，报告中将如实分解。

## 六、失败归因分类（操作员第四节）

若不支持，按以下三分法归因（全部零调用可判）：
1. **检测失效**：S2 未在应触发处触发（对照冻结矩阵——本次不可能，矩阵确定；保留为框架项）。
2. **恢复无效**：触发但 Q 不升。细分：值轴不修（B3/B4/B5/B6/C1 仍错）而引用轴修（值对事实的 loc/support 由假变真）→ 结论"S2-反馈分离了引用修复与值修复"；两轴都不修 → 反馈被忽略。
3. **上游不足**：值所需的证据不在 E 表中（对照 CFL-1 E 层标签：KANGMEI E 全对，故本次 KANGMEI 不适用此归因；ZIJING 恒适用）。
