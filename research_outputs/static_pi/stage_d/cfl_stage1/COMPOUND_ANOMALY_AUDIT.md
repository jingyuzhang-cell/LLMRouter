## 二、ZHANGZIDAO 是否适合四臂复合异常实验？

**适合但规模有限**：
- 复合槽 3 个（A1/C1/D6）+ 纯 E 缺失 4 个 = 7 个可恢复槽
- SINK 正确的 9 个槽为不可改善的固定基线
- **理论 Q_max = (9+7)/16 = 100%**（如果全部恢复）

**四臂的动作空间**：
- A/NONE：9/16 = 0.5625
- B/最强单动作：UPSTREAM E 重抽 → 池覆盖增 → SINK → 可得 ~12-13/16 ≈ 0.75-0.81
- C/固定组合（E 重抽→J 补绑→SINK）：同 B 但加 J → 可能再 +1-2 槽 ≈ 0.81-0.88
- D/动态 Joint：根据反馈逐步决定 → 可能在 B/C 基础上选择性升级 SINK 处理复合槽

**关键判据：D vs C 的增量空间 = 3 个复合槽（A1/C1/D6）能否被动态决策额外修复**。如果固定组合 C 已经达到与 D 相同的效果，则联合决策无独立增量。

- 逐臂记录：Q_all、TP、wrong、UNKNOWN、C、L、恢复成功率

## 五、D vs C 差异化的必要条件

Joint 的独立增量仅在以下情况出现：
1. **固定组合 C 未能修复复合槽**（A1/C1/D6），而 D 通过选择性 SINK 升级修复了它们；
2. **固定组合 C 过度恢复**（对已正确的 9 槽造成回退），而 D 通过反馈避免了。

如果 C 一次到位修复了全部可修复槽，则 D 无增量空间——此时结论为"固定组合已充分，联合决策无额外必要"，同样是有效科学结论。
