## 修订 4：干净基线 vs 异常恢复基线分离

- **干净执行基线**：强 Static 完整执行 DAG，正常条件 Q/C/L。
- **异常恢复基线**：8 历史事件作为动态臂共同起点，Static=不恢复。**强 Static 链上的异常**：注入传输层异常（截断/超时）+ 自然异常（采样失败），两组共用注入台账。历史弱 Static 异常**不混称**为强 Static 初始产物。
- 动态臂在强 Static 执行链上注入异常后恢复，强 Static 本身作为不恢复对照。

## 修订 5：统计方法统一

- 事件级：**双侧**精确符号检验（剔除平局），仅作机制分析。
- **任务级配对（主推断）**：事件按任务聚合成任务级 ΔQ/ΔC/ΔL，n=任务数（5），报告效应方向与精确 p。
- 八事件不视为八独立样本；功效不足如实声明，不宣称泛化。
- **停止规则唯一主判据**：任务级配对 ΔC 或 ΔL 中位数改善（Joint vs 强 Static），双侧符号检验 p<0.10（n=5 时的最小可达双侧 p=0.0625，如实标注）。OR 条件删除。

## 修订 6：条件 A 质量门槛精确化

- **非劣效界值 = 单槽分辨率**：KANGMEI 1/14=0.071、MVR1 1/16=0.063、ZHANGZIDAO 1/16=0.063、KDX 1/12=0.083、YJT 1/12=0.083。判定在**任务级聚合 Q_all** 上执行（非逐事件）。
- **两阶段不可筛选偏差**：先判定策略可行性（Q_all ≥ Static_Q − 分辨率）；不可行策略直接判"不可行"不进入 C/L 比较；全部失败/超时/弃答保留原始统计中（不删除、不重跑）。
- 条件 B/C 同理：预算/截止期等价约束下，超限策略判不可行，Q 比较仅含可行策略，但不可行率单独报告。
