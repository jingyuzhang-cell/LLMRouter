# 评价治理包：v1→v2 评审防御文档（零调用 · 全部数字可溯）

## 1. 评分器为何变化、何时发现

**发现时点与触发**：TS-3M 之后的质量门槛审计中，对全部任务做 **gold-vs-gold 自检**（不依赖任何模型输出的独立检验）发现 v1 冻结解析器 `terminal_quality._decimal` 对带单位后缀（元/万元/%）、千分位逗号与前导负号的数值解析失败——金标自身无法匹配自己（KANGMEI B3/B4/B5、ZEDA B2 共 4 槽 unTPable）。该缺陷**双向对称**：金标带单位挂、模型输出带单位也挂，系统性低估双方。

## 2. v1→v2 差异（冻结规则文本见 `scorer_qp1_v2.py`）

| 维度 | v1 | v2 |
|---|---|---|
| 数值解析 | `Decimal(str(v).replace(',','').strip())`——任何非裸数值即失败 | NFKC → 去空格/千分位 → 前导负号 → 尾部单位 → **(数值, 单位) 二元组**比较（'150万元'≠'150元' 尺度保留） |
| 文本 | NFKC+去空格严格相等 | 同 v1 + 冻结前缀连接词（通过/以/采用/使用/利用/借助）双侧修剪 |
| Gold | 原样 | sidecar 补丁（下节） |
