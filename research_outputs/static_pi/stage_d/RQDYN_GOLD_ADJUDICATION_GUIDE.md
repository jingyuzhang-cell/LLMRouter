# RQ_DYN_V1 Gold 人工裁定填写指南（给裁定者与复核者）

**对象**：`RQDYN_GOLD_WORKSHEET_C.csv`（14 槽）、`RQDYN_GOLD_WORKSHEET_B.csv`（10 槽）。
**填写列**：`HUMAN_ADJ`（1=接受为 Gold；0=拒绝；或直接填修订值）、`REVIEWER2`（第二复核者独立填 1/0/修订）、`note`（争议说明）。
**机械核验已完成**：24/24 的 evidence_span 均逐字存在于所指文档（span_check=1），裁定者无需重做机械检查，只需核对**语义与口径**。

## 逐槽裁定要点

### C 事件（视觉中国，14 槽）
| 槽 | 类型 | 裁定要点 |
|---|---|---|
| C-01~C-07, C-10, C-12 | 官方事实 | 值/时间/主体与 quote 是否严格一致；日期格式容许（ISO vs 中文） |
| C-03, C-14 | 市场反应官方事实 | 只确认交易所认定口径（异动日、偏离值、认定依据）；**不得加因果解释** |
| C-08 | 时间线综合 | 是否接受"五节点事件链"为综合槽（各环节均有独立官方事实支撑；无因果声明） |
| C-09 | 公司核实陈述 | 性质=公司自述（官方公告内的核实声明），非研究者推断——是否接受为事实槽 |
| C-11 | 一致性核验 | 异动期间控股股东/实控人未买卖股票（公司自查口径） |
| C-13 | UNKNOWN 槽 | 暂停公告视角下恢复时间不可预计（后被 5-12 消解）——是否保留为 unknown 槽 |

### B 事件（豫金刚石，10 槽）
| 槽 | 类型 | 裁定要点 |
|---|---|---|
| B-01~B-06 | 官方事实（升级自 pilot 种子） | 文号/日期/禁入措施/虚增净资产 |
| B-07, B-08 | 跨年审核一致性 | 两年两所均"无法对情况表发表意见"——是否接受为一致性事实对 |
| B-09 | 跨年占用延续 | 22,339 万期初=期末（表格数据，PDF 提取）；是否需要补充第二笔 2,000 万或修订 |
| B-10 | 多监管方关联 | 河南证监局关注函 + 深交所关注函 + 证监会告知书三轨并存 |

## 约定（操作者裁定）
1. 争议槽：修改值或标 UNKNOWN，不删除；
2. 官方事实 / 市场反应解释 / 因果关系三层不得混槽（现候选无后两层；若裁定者想加解释性槽，请直接拒绝并在 note 说明）;
3. 两人不一致 → 以更保守裁定为准或标 UNKNOWN;
4. 回填后交回：我将按裁定结果生成最终 Gold（含 SHA256 冻结）、定稿预注册 v1.0、提交授权申请（200 次 / 600,000 tokens / ¥6）。
