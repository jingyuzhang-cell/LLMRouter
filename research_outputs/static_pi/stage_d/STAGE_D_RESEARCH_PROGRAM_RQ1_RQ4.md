# STAGE_D 研究纲领：四个科学问题（RQ1–RQ4）

**状态**：零调用研究纲领；不构成真实调用授权。工程系统是实验载体，调度机制是研究对象，经对照验证的规律与机制才是科学贡献。

## 一、研究链

```
RQ1 能力异质性（是否存在可利用的模型—节点差异）
  ↓ 只有差异稳定且 material 才继续
RQ2 静态分配（节点级异构分配 vs 统一模型 / 查询级路由）
  ↓ 静态分配有收益才值得研究动态
RQ3 动态反馈（Z/R/π 联合调整 vs 单维度/固定计划）
  ↓ 动态有效后追问条件
RQ4 收益边界（任务复杂度、能力差异、异常类型、资源竞争、截止期、预算）
```

## 四、决策门（不允许跳过）

- **G1（RQ1→RQ2）**：模型×节点交互存在、稳定、且**material**（按节点分配能带来超过噪声的终端 Q 或 C/L 收益）；否则停止 RQ2，转 RQ4 研究"异质性出现的条件"，不强行证明异构调度有效。
- **G2（RQ2→RQ3）**：静态节点级分配确实优于统一模型/查询级路由；否则动态调度的必要性不成立。
- **G3（RQ3→RQ4）**：联合动态在至少一个预登记终点上优于单维/固定；无论正负都进入边界分析，不隐藏无效区。
- **G4（论文）**：每个 RQ 的结论必须能写成"支持/反驳/边界"三态，而不是只报显著结果。

## 五、每个实验必须回答的五个问题（研究纪律）

1. **科学问题**：对应哪个 RQ？
2. **假设**：H1/H0 是什么；什么结果支持、什么结果推翻？
3. **对照**：如何排除模型、任务、解析失败、资源、时间的替代解释？
4. **新知识**：除了证明代码正确，发现什么规律/机制？
5. **论文**：支持哪条科学结论；边界是什么？

**工程功能、日志、哈希清单本身不构成研究优先级。** 只有当它能回答上述问题时才进入当前计划。

## 六、论文结构与贡献

- 第 1 节 RQ1：模型—节点能力异质性（交互、稳定性、materiality）；
- 第 2 节 RQ2：静态节点级分配收益（统一/查询级/节点级）；
- 第 3 节 RQ3：反馈驱动联合调度（Z/R/π）相对单维的机制；
- 第 4 节 RQ4：收益边界（任务、能力差、异常、资源、截止期、预算）；
- 讨论：模型版本变化下的可复现性；负结果/边界同样报告。
