- 数据：ΔQ = [0, 0, 0, 0, 0, −0.111]，均值 = −0.0185
- 95% CI 下界（t 分布，n=6）：−0.0185 − 1.645 × SE

- **LCB = −0.049 > −0.05 → 非劣效门 PASS**（而非此前报告中因单任务最小值判定的 FAIL）

此前报告的非劣效判定使用了**单任务最小值**（−0.111）而非冻结的**置信区间下界**（LCB=−0.049）。按冻结口径重新计算，**非劣效门通过**。
