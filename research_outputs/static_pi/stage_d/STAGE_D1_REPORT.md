## 四、三个先导发现（对 D2 设计有决定性影响）

1. **瞬态故障语义下质量趋同**：一次性故障（篡改/单次提示词偏离/单次超时）任何重跑类策略都能修复——Simple 也拿到 E2=2。**质量差异化只在系统性故障成立（Stage C 已证）；瞬态故障下动态价值 = 效率**（时延/动作数），非质量。
2. **当日 API 计数方差底噪**：无故障 S0 出现自发 E2=4（π-only/Fixed 臂的 J2 全新抽样）——单 run 质量比较被噪声支配（TP 范围 12-16 同配置）。
3. **Proposed 的效率优势真实存在**：S2 −31.5% makespan、全场景最少动作、总 makespan 六臂最低（261.3s，除 Static 外）——但 n=3 方向性。

- D2 若按原样重复，主要重测方差噪声——**建议改设计**：加入**系统性故障场景**（如持续性提示词偏离，Stage C 语义，naive 策略不可修复）才能在质量维度复现策略差异；或接受 D1 结论定型："瞬态故障→效率价值（方向性），系统性故障→质量价值（Stage C 实证）"，D2 只做效率维度加重复。
