# P2-1 冻结协议（测试前；含前置阻塞，未获决策不得启动 pilot）

## 研究问题
节点级联合重建（整节点重执行，输出完整事实集+证据链+UNKNOWN 边界）能否在成本/时延约束内
把终端 Q 提到 70%，且 stable 增益显著超过 H0（≥5pp）？

## 机制（全部使用冻结的每模型能力参数，不引入修复概率新参数；P2-0.5 更新）
- 重建 = 对被标记节点用指定模型整体重执行（新抽取）；输出按 DAG 依赖传播：
  拓扑内重建（下游未执行）不重执行下游；事后重建必须重执行受影响下游（计入成本/时延）。
- 模型选择（机制 B，以 M3 实测为准）：e0/e1/t→DS；m/r/v/p→GLM。
- 执行模式：投机并行（GLM 副本与原执行同时启动，事后按检测 A 选优）；DS 节点用并行同模型重掷（时延 0）。
- 检测：可观测信号 A（主，96.1%/100%）+ B（敏感性，78.8%）；不再使用合成验证器概率。

## 验收门
1. Q≥70% 且 24 任务 bootstrap 95% CI 下界>70%（终端绝对质量，非通过率）。
2. stable 增益 − H0 增益 ≥5pp。
3. Sham 与 base 差 ≤0.5pp。
4. 成本≤所选用预算档；Makespan 满足该档截止；重执行与下游传播全部计入。
5. 失败任务、UNKNOWN 如实保留；不改评分/Gold/DAG/MVS/任务。
