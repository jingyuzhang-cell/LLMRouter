## 一、核心命题与假设

**命题**：多智能体能否依据执行状态与语义一致性反馈，联合决定恢复范围 Z、重执行节点 R 与资源分配 π，在终端质量、成本与时延之间取得真实收益，且该收益不能仅由更多调用、更多证据或更强模型解释。

| 假设 | 对比 | 判定规则（预先固定） |
|---|---|---|
| H1 质量 | C 对 A | Q_all 配对差 ΔQ(C−A) > 0：精确单侧符号检验（剔除平局），α = 0.05；且平均 ΔQ ≥ δ_min = 0.10 |
| H2 联合决策价值 | C 对 B | **帕累托判据**，两条同时成立：H2a 质量不劣，每个配对重复都满足 ΔQ(C−B) ≥ −0.05；H2b 成本不高，平均调用数与记账费用 C ≤ B。另报告 C 在质量上严格优于 B 的重复数 |
| H3 安全 | C 对 A、B | 错误断言率 ≤ 对照 + 5pp；无断言时为“无法判定”，不算通过 |
| H4 恢复有效性 | 三臂 | 被 V4 标记槽的终端恢复率（标记槽中变为 TP 的比例） |
| H5 时延 | 三臂 | 恢复关键路径墙钟时间（只在同节点间比较，因有缓存命中） |

“正向结果”需要 H1、H2 与 H3 同时成立；只有 Q_all 提高不算。

## 三、设计：同检查点三臂分叉

每个重复 r（r = 1…8）的执行顺序：
1. **共享上游**：E_D1、E_D2、J1、J2 各运行一次（4 次调用），形成检查点 CP_r；BASE_TOTAL、证据表、V4 检测器在 CP_r 上确定性计算。
2. **三臂都从 CP_r 分叉**，上游完全相同，与 T1 同法，以控制上游噪声。
3. **无任何标记的重复**：三臂按构造完全相同。A 的 SINK 输出直接作为 B、C 的结果（不重复付费），该重复在 C−A 与 C−B 中都计为平局。

| 臂 | 策略（全部确定性、不读 Gold） | 每重复恢复调用上限 |
|---|---|---|
| **A Static** | CP_r → SINK，不做任何恢复；执行异常则该臂记为不完整 | 0 |
| **B Fixed-Recovery** | 执行异常：同模型重试一次。任何 V4 M1 标记（明确压制或未知标签）：固定执行 J2 定向重核（附加块同 T1 A2）+ SINK。固定 Z = {J2, SINK}，R = J2，π 不变。不处理 M3 | 3 |
| **C Joint-Dynamic** | 按反馈逐级选择（见下）| 3 |

**C 的决策规则**（预先写定）：
1. **执行异常**：同模型重试一次；仍失败且探针规则指定了替代模型，则对该节点换模（π）一次；否则该臂记为不完整。
2. **语义异常 M1**：先做最小范围动作，即 SINK 绕过（同 T1 A3：删除被 V4 标记的条目，Z = {SINK}，R = SINK，1 次调用）。
   - 若绕过后被标记槽全部作答，且 V4 M3 判一致，则结束。
   - 否则升级为 J2 定向重核 + SINK（Z = {J2, SINK}，R = J2，π 按探针规则，2 次调用）。
3. **语义异常 M3**（最终 SINK 的答案与其引文不一致）：先确定性地把该答案改写为 unknown（0 次调用，只影响安全指标，不可能增加 TP）。若恢复调用预算尚有余量，可改为 H 反馈重跑 SINK（1 次调用，文本见 `FORK_T1_MATERIALS.md` 第一节）。

**公平性约束**（回应操作员要求，B 与 C 必须对齐）：
- **信息供给**：两臂收到相同的证据表、相同的 V4 输出、相同的附加块生成器。C 不读 Gold，也没有 B 看不到的信息。
- **执行条件**：两臂的调用上限、max_tokens、温度、模型池相同。
- **差异来源**：C 与 B 唯一的差别是决策规则，即何时选择哪个 Z、R、π。
- **成本计入**：C 若比 B 多用调用，按帕累托判据全额计入成本。
- **π 的处理**：若探针结论是 J2 维持 DS，则 C 的 π 维度在语义恢复上不启用（如实声明为退化），H2 只检验 Z 与 R 的联合选择。

## 五、样本量与功效（调用前完成）

**统计单位**：配对重复。主检验为精确单侧符号检验，α = 0.05，平局（无标记或 ΔQ = 0）剔除。

| 有效重复数 n_eff | 拒绝条件 | 单重复为正的概率 0.8 / 0.9 / 0.95 时的功效 |
|---:|---|---|
| 5 | 5/5 | 0.33 / 0.59 / 0.77 |
| 6 | 6/6 | 0.26 / 0.53 / 0.74 |
| 7 | 7/7 | 0.21 / 0.48 / 0.70 |
| 8 | ≥ 7/8 | 0.50 / 0.81 / 0.94 |
| 10 | ≥ 9/10 | 0.38 / 0.74 / 0.91 |

**选择 8 个重复的理由**：
- 有效重复数取决于自然语义异常出现的比例。SC-E1 上的压制源于 J1 输出结构缺少财务字段，而千山药机使用同一 DAG，预计会复现，但这点未经验证。
- 每重复出现异常的概率为 0.9 时，8 个重复得到 n_eff ≥ 6 的概率是 0.96；概率为 0.8 时是 0.80。
- 以每重复出现异常的概率 0.9、出现后为正的概率 0.95 估算，总功效约 0.81。
- 正为正的概率参照 T1：同检查点恢复 3/3 一致。但 T1 是开发集，这只是假设，不是已知值。

**充足性规则**：若 8 个重复后 n_eff < 6，报告“自然异常不足，检验无力”，不得自行加做重复；扩展需新授权。

## 七、终点与报告（全部预先固定）

**每个重复、每个臂报告**：
- 终端质量：Q_all、Q_terminal、E_literal、关键槽 TP；
- 安全：错误断言率、错误断言负担、覆盖率、拒答率、静默遗漏率；

- 成本时延：调用、token、记账与边际费用、关键路径墙钟。

**可解释性分解**：
- C 相对 B 的差异按动作类型分解为三类：只用 SINK 绕过就结束、升级到 J2 重核、M3 处理。

**检测器**：V4 为执行依据；V2、V3 对同一输出的判定离线并列报告，不影响执行。
