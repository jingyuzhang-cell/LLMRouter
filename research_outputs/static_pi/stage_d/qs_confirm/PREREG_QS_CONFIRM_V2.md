## 一、核心命题与假设（同 V1，未改）

验证：多智能体依据执行状态与语义一致性反馈，联合决定恢复范围 Z 与重执行节点 R，能否在终端质量、成本与时延上取得不能由“更多调用、更多证据、更强模型”解释的收益。

| 假设 | 对比 | 判定规则 |
|---|---|---|
| H1 质量 | C − A | Q_all 配对差：精确单侧符号检验（剔平局），α=0.05，且平均 ΔQ ≥ 0.10 |
| H2 联合决策价值 | C − B | 帕累托：每个配对重复 ΔQ(C−B) ≥ −0.05 且 C 的平均调用数与费用 ≤ B；另报严格优于的重复数 |
| H3 安全 | C 对 A、B | 错误断言率 ≤ 对照 + 5pp；无断言 = 无法判定，不算通过 |
| H4 恢复有效性 | 三臂 | V4/V5 标记槽的终端恢复率 |
| H5 时延 | 三臂 | 恢复关键路径墙钟（同节点间比较） |

正向结果 = H1 ∧ H2 ∧ H3 同时成立。

## 三、设计：同检查点三臂分叉（同 V1，未改）

每重复：共享 E_D1、E_D2、J1、J2 各一次（4 次调用）成检查点 CP_r → 三臂分叉。无标记重复：三臂按构造相同，A 的 SINK 输出复用为 B、C 结果（不重复计费），计平局。

## 四、三臂策略（**修改 1、2、3 落于此**）

**A Static**：CP_r → SINK。不做任何恢复。

**B Fixed-Recovery**：执行异常 → 同模型重试一次。V4/V5 M1 任何标记（明确压制或未知标签）→ 固定执行 J2 定向重核（GLM）+ SINK。M3 → 不处理。固定 Z={J2,SINK}，R=J2。

**C Joint-Dynamic**，按标签类别分级（修改 1）：

| 检测状态 | C 的动作 | 依据 |
|---|---|---|
| 确认类（affirmed） | 正常执行 | — |
| **明确压制**（EXPLICIT_SUPPRESSION） | 允许最小范围：SINK 绕过（删除该类条目，Z={SINK}） | T1 A3 证据 |
| **未知标签**（UNKNOWN_LABEL） | **不得删除**；直接进入 J2 定向重核（保守路径） | 操作员修改 1 |
| 混合（两类并存） | 一律 J2 定向重核（不删除任何条目） | 同上 |
| 执行异常 | 同模型重试一次（π 不变） | 修改 3 |

**C 的停止条件（修改 2）**：每次恢复动作后，先检查目标槽是否恢复；**已恢复时再执行 Gold-blind 终端完整性检查**，任一触发则升级一级（SINK 绕过 → J2 重核；J2 重核后仍触发则停止并如实报告）：
- 非目标槽中，恢复前引文在证据表中逐字可查、恢复后不可查（引用完整性退化，如 T1 A3 的 F19）；
- 恢复后新出现的 M3 违例（恢复前该槽一致）；
- 派生槽答案与基础模块不一致（恢复前一致）。

该检查零调用，全部确定性。目标槽未恢复也升级。**升级消耗预算；预算耗尽即按“预算内不完整”如实记录，不超限。**

## 五、异常分级与配对口径（**修改 4**）

**基础设施级（立即停止整批，不恢复、不重试）**：传输层错误（HTTP 4xx/5xx、socket、超时）；输入完整性失败（input token < 0.25×字符数）；服务方模型身份不符；台账完整性失败；预算触顶；**共享上游阶段（E/E/J1/J2 检查点形成之前）的任何节点级故障**——此时无臂拥有恢复权，且检查点无法形成。

**节点级可恢复（进入所在臂的策略，计入该臂预算）**：臂自身调用出现的空文本、截断、JSON 解析失败、schema 缺键、异常 stop。处理：同模型重试一次；仍失败 → **该臂该重复记为不完整**（不停止批次，其他臂继续）。

**A 臂不完整的配对口径（修改 4）**：该重复 A 的 Q_all 记 0（保守下界，进入 C−A 配对差）；同时并列报告“剔除不完整重复”的敏感性口径与不完整计数。A 与 B/C 同时不完整的重复在主分析保留（双零 = 平局），敏感性口径中剔除。

精确单侧符号检验，α=0.05，平局剔除。假设单重复自然异常概率 pa、异常后为正概率 pp=0.95（T1 同检查点恢复 3/3 一致为据，属假设而非已知）：

| pa | P(n_eff ≥ 6) | 条件功效（n_eff≥6 下） | **无条件功效** |
|---|---:|---:|---:|
| 0.9 | 0.962 | 0.813 | **0.808** |
| 0.8 | 0.797 | — | 0.722 |
