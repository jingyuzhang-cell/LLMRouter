## 修订一 · S5 科学定位重命名 + 竞速时延完整核算

### 1.1 定位（操作者措辞采纳）

**S5 = 紧截止期约束下的异构模型时延能力错配与动态重分配实验**——不再称"模型执行故障"。它研究的是：当模型能力与剩余时间预算不匹配时，系统能否主动调整模型分配。9.5s SLO 定位为**预登记的压力测试参数**，不称"生产部署验证的 SLA"。

### 1.2 竞速时延完整核算表（操作者三项补充指标全部覆盖）

**DS 时延口径澄清**：全历史 DS J2 wall = 纯 HTTP 时延（n=9，min 4.7 / p50 5.3 / max 6.3s），**不含队列**。队列不存在：终局分块随机化（臂间无外部并发）+ 同 DAG 内 DS 仅换模 1 次 + K_ds=1 → 无排队。

| 指标 | 数值（实测） |
|---|---|
| SLO 违约时刻 | 9.5s |
| DS 纯 HTTP | ≤6.3s → J2 完成时刻 ≤15.8s |
| 不换模（GLM 29.4s）总 DAG 时延 | E28.9+J1 11.4+J2 29.4+SINK 23.8+OV10 = **103.5s → 超期**（D=90s） |
| 换模后（DS 5.4s） | **79.5s → 按时** |
| 竞速场景（9.5s 触发 + DS 6.3s = 15.8s 替换） | **89.9s → 按时（压线 0.1s——如实标注）** |

**三项补充测量指标（预登记）**：
1. **DAG 实际完成时间**：makespan 从 t0 到 SINK 终端（竞速胜出即算）——逐执行记录；
2. **在途请求完全结束的资源释放时间**：GLM 迟到请求自然返回时刻（≤70s）单列记录——K_glm 释放时间；
3. **竞速额外成本**：每次竞速 = 2 次 J2 调用（GLM+DS 双份 token/费用）+ 双槽占用期（K_glm 至迟到者返回、K_ds 至 DS 返回）——全额入成本表，迟到者不得当作没发生。

### 1.4 S5 终点层级（冻结约束三）

**按时率与 Makespan 为联合主终点**（二者同时通过才算 S5 优效——按时率配对符号检验 N=8 单侧 α=0.05 + makespan 配对 Wilcoxon 单侧 α=0.05），质量门禁（≥Static−1 槽）为通过前提。次级：竞速额外成本报告、资源释放时间报告。

## 修订三 · 五方审计边界最终收紧

**故障注入失败三分法（替代 V1.1 的"一律无效"）**：
| 类型 | 处置 |
|---|---|
| 外部输入文件损坏/独立基础设施故障 | 协议无效，留档 |
| **故障注入代码自身执行失败** | **实验执行系统缺陷——保留并报告**（计入注入方的执行失败） |
| **控制器未成功触发故障** | **系统检测/执行失败——保留在正式统计** |

**动作选择准确率分母修正（操作者审查项）**：分母 = **全部真实故障执行**（含漏检场景）——漏检 FN 计为动作选择失败，不得因未触发检测器而消失。预登记：准确率 = 正确动作执行数 / 全部故障执行数。
