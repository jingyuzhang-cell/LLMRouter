# P2 模型分配方案（零调用）

**依据**：J2 双模型探针（`j2_probe/`）+ QS 全现场实测 + Stage A/A′ 证据。

---

## 一、各节点分配

| 节点 | 模型 | max_tokens | 温度 | 端点 | 依据 |
|---|---|---:|---|---|---|
| E_D1 / E_D2 | DS (deepseek-flash) | 8000 | 0 | DS API | Stage A′：DS 完成所有 E 抽取；唯一截断 1 次（重复 6，8000/8000） |
| J1（跨文书衔接） | DS | 8000 | 0 | DS API | Stage A：GLM 在 8000 全部为思考、文本为 0 → 不可用；DS 完成 |
| J2（共享段） | GLM (GLM-5.3-Flash) | 8000 | — | 订阅端点 | J2 探针规则结论：可靠性 6/6、压制 25≤34、质量 0.683>0.667 |
| J2 重核（G3/G4/G6 触发 a3） | GLM | **12000** | — | 订阅端点 | QS 实测重核输入 ~9K + 思考 ~7K 超 8000；12000 为预防措施 |
| SINK | DS | 4000 | 0 | DS API | Stage A′/T1/QS 全部 DS，稳定 |
| G1 Single | DS | 8000 | 0 | DS API | 文书合计 10–17K 字符 + schema，DS 上下文充裕 |

## 二、J2 重核截断问题（关键风险）

| 数据源 | 共享 J2 | 重核 J2（含附加块） |
|---|---|---|
| J2 探针（6 次/模型） | GLM 6/6 可靠，输出 4.1–6.9K | —（无重核） |
| QS（6 重复 + 3 次停止尝试） | 7 次尝试中 1 次截断（7/8=87.5%） | **19 次中 16 次截断（16/19=84.2%）** |
| P2 V1.1 提高至 12000 | 预期覆盖大多数 | **需试点验证** |

**风险声明**：若试点中 12000 下重核截断率仍 >50%，需操作员批准切换重核模型为 DS。这不影响共享 J2（GLM 保持），只影响恢复路径中的 J2 重执行。

## 三、各臂恢复路径的模型使用

| 臂 | a2'/a2（SINK 重跑） | a3（J2 重核 + SINK） | H 反馈 |
|---|---|---|---|
| G1 Single | — | — | — |
| G2 Static | — | — | — |
| G3 Fixed | DS | GLM(12000) + DS | DS |
| G4 Z-only | DS | GLM(12000) + DS | DS |
| G5 R-only | DS | GLM(12000) + DS | DS |
| G6 Joint | DS | GLM(12000) + DS | DS |

**所有臂共享同一恢复路径模型配置**（消除模型分配差异对臂间比较的混杂）。
