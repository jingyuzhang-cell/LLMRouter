# P2 任务选择与准入标准（零调用）

**任务领域**：资本市场舆情·监管处罚链（事先告知书 → 行政处罚决定书），两份以上原始公告、真实分支（并行抽取）与汇合（跨文书衔接）、跨文书金额调整。P2 第一波在此族内取任务；**族的同质性作为边界如实声明**，跨族扩展留待后续。

## 一、准入标准（每条可机械核验或留痕审计）

| # | 标准 | 核验方式 |
|---|---|---|
| A1 | ≥2 份相互引用的原始公告（告知书与决定书同案，当事人重合 ≥ 0.5） | 解析 + 人工确认 |
| A2 | DAG 具备真实分支与汇合（E_D1 ∥ E_D2 → J1 → J2 → SINK） | 结构固定，逐案满足 |
| A3 | ≥8 个 Gold 槽，含 ≥1 个可复算合计、≥2 个日期、≥2 个文号、≥1 个逐人金额档 | Gold 构建器校验 |
| A4 | 两文书合计 ≤ 40K 字符（G1 单智能体一个上下文可容纳，保证六臂公平） | 字符计数 |
| A5 | 合计可无歧义复算（"分别/合计"表述明确） | 解析 + 人工确认（皇台因此排除） |
| A6 | 独立性：代码/简称/全称/当事人/文号/事件实体在工作区、git HEAD、完整历史零命中 | 冻结审计脚本 |
| A7 | PDF 文本层可逐字锚定（异体字等文本层缺陷须在 Gold 阶段对照原件解决并记录） | 逐字校验 |
| A8 | 自然异常可信度：J1 输出结构缺财务/退市字段 → J2 压制的机制在两族已验证 | 结构性（已在 SC-E1 与 QS 两族复现） |

## 四、任务流（每任务进入实验前必须完成）

1. 文书下载与哈希（URL/时间/SHA256，PDF 只读）；
2. Gold 合同构建（规则读原文）+ 逐槽自检（逐字锚定、无 Gold 泄漏到模型输入）；
3. 操作员逐任务审阅 Gold → 冻结为 v1（GOLD_APPROVED）；
4. 独立性审计留痕；
5. 之后才允许该任务的任何模型调用。
