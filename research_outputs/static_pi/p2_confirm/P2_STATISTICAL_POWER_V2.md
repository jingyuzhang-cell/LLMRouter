## 四、诚实结论与决策选项

**核心事实**：按当前假设，16 个任务只有在乐观情景下才有 80% 功效，Holm 校正后仅 54%。中性需 27 个、保守不可达。

| 选项 | 内容 | 后果 |
|---|---|---|
| **A 缩小假设族** | 仅 H2（G6−G2）作确认性，H1/H3/H4/H5 降为探索性（不校正） | H2 单测 α=0.05：中性 n=20 达 70%、乐观 n=16 达 82%；仍偏低 |
| **B 增大任务数** | 补池至 27+ 个干净候选 | 需大量检索与 Gold 构建工作；预算约 ¥5–8 |
| **C 降低 δ_min** | δ_min 从 0.10 降为 0.15 | n=12 中性达 84%、乐观达 95%；但 0.15 是一个很大的效应量 |
| **D 提高重复数** | k=2→k=3（每任务 3 次重复） | 降低任务内方差，σΔ 可能降至 0.15–0.17；等效于 n 增加 ~20–30%；预算增 50% |
| **E 接受较低功效** | n=14–16，中性功效 55–60%，如实报告 | 最诚实的方案；论文声明功效限制 |
| **F 分阶段决策** | 试点 3 任务出实际 σΔ 后，按上表选 n | 推荐方案：避免现在锁死错误的假设 |

## 五、推荐

**选项 F + E 组合**：先执行试点 3 任务，用实际任务级配对差 SD 做 plug-in 重算功效表，然后由操作员根据实际数字决定终 n 与可接受的功效水平。若 σΔ 实测 ≤ 0.18（乐观情景），n=16 可达 80%+；若 ≥ 0.22，如实报告功效不足。

**交互效应检验在所有情景下功效都极低（<20%）**。这可能意味着：(1) 需要专门设计交互检验的子实验（选取 S1 异常丰富的任务子集）；(2) 或者接受交互效应只能作为探索性结论，不做确认性宣称。

## 六、独立复核代码

```python
from scipy import stats as sps
import math
def paired_t_power(delta, sigma, n, alpha=0.05, sided='one'):
    df = n - 1
    t_crit = sps.t.ppf(1 - alpha if sided == 'one' else 1 - alpha / 2, df)
    ncp = delta / (sigma / math.sqrt(n))
    return sps.nct.sf(t_crit, df, ncp)
```
