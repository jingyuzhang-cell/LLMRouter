# P2 统计方案（零调用）

**统计单位：独立任务。** 任务内重复（技术重复）与节点级事件只作降方差与机制描述，绝不冒充独立样本。

## 一、终点

| 层 | 指标 | 定义 |
|---|---|---|
| 主 | Q（Q_all） | 任务级、臂级，对该任务的 k 次重复取均值 |
| 共同次要 | C | 该臂该任务的全部调用 token 与记账费用（含共享上游按臂独立部署口径分摊；批次总账另报，共享只计一次） |
| | L 端到端 | 共享链 + 本臂全部调用墙钟（串行口径） |
| | L 恢复增量 | 仅本臂恢复动作墙钟（H2c 判定量） |
| | 错误断言率 | 错误断言/总断言；无断言=无法判定，不算通过 |
| | 证据引用准确率 | 引文逐字且支撑该槽的断言占比 |
| | 节点恢复成功率 | 被检测器标记槽中恢复为 TP 的比例 |
| 机制（描述） | 检测器状态分布、动作轨迹、GLM 重核截断率 | 不入假设检验 |

## 二、六臂（2×2 因子嵌于其中）

G1 Single / G2 Static 为外部对照；**G3–G6 构成 Z×R 双因子设计**：

| 臂 | Z（恢复范围） | R（重执行集） | 对应 |
|---|---|---|---|
| G3 Fixed | 固定=上游层（J2+终端） | 固定=触发即全量 {J2,SINK} | 即 QS-B |
| G4 Z-only | **动态**（按检测状态选 终端层/上游层） | 固定=所选层全量执行、不早停 | 新 |
| G5 R-only | 固定=上游层 | **动态**（可确定性编辑+仅重跑 SINK、可跳过、可早停） | 新 |
| G6 Joint | **动态** | **动态** | 即 QS-C（V2.1 §4–5 规则逐字复用） |

**操作定义（防 Z/R 串扰，写死）**：
- **Z=允许修改的状态层**：none / 终端层（SINK 的输入与输出）/ 上游层（J2 的输出—经确定性编辑或重执行—及终端层）。
- **R=层内实际重执行的节点集**：对上游层修改，R ∈ {∅+编辑, {SINK}, {J2,SINK}}；对终端层，R ∈ {∅+编辑, {SINK}}。
- 合法动作全集（六臂共用，冻结）：a0 不动；a1 确定性终端编辑（M3 转未知、派生值注入，0 调用）；a2 SINK 重跑（终端层，1 调用）；a3 J2 定向重核+SINK（上游层，2 调用）。E 层重抽取**不纳入** P2 合法集（QS 两次共享段截断均为 E/J 容量问题，属另一研究问题）。
- **M3 处理归属因子**：a1（转未知）为 G3–G6 共同的安全基础设施；**H 反馈重跑归 R 动态因子**（R 固定臂不含）。G2 零动作（不含 a1）——G6−G2 的差含此确定性安全变换，如实声明。
- 触发条件、Z_dyn 的状态→层映射、终端完整性检查与升级规则：逐字复用 QS V2.1 第四、五节（V5 检测器、明确压制→终端层、未知标签/混合→上游层、带证据遗漏→先查恢复前终端）。

## 三、确认性假设族（Holm 校正，α=0.05，单侧优越）

| # | 对比 | 回答 |
|---|---|---|
| H1 | G2 − G1 | 多智能体静态协同是否有价值 |
| H2 | G6 − G2（δ_min=0.10） | 动态调度是否有价值（主主张） |
| H3 | G6 − G3 | 是否优于固定恢复 |
| H4 | G6 − G4 | R 的增量（Z 之上） |
| H5 | G6 − G5 | Z 的增量（R 之上） |

**交互效应（核心检验，双侧，α=0.05，独立于 H1–H5 报告）**：
任务级对比分 q = Q_G6 − Q_G4 − Q_G5 + Q_G3；H0: 中位数 0。显著为正 → Z 与 R 存在协同；显著为负 → 相互抵消；不显著 → 可加性。**Joint 显著优于 Static 不足以宣称联合优化有效，必须过此检验。**

## 四、检验方法

- 任务级配对：精确符号翻转排列检验（2^n 全枚举或 n>20 时 10^5 次蒙特卡洛），报 p、均值差、任务级 bootstrap 95% CI（按任务重抽样）。
- 多重比较：H1–H5 作为一族 Holm；交互单独预指定。
- 敏感性：① 剔除不完整任务重算；② 仅含自然异常任务子集（描述性）；③ Q_terminal 并列。

## 五、样本量与功效

n = 任务数；k=2 次/任务（技术重复，降任务内方差）。配对检验近似功效（δ=0.10，α=0.05 单侧）：

| 任务级配对差 SD（σΔ） | 80% 功效所需 n | 90% |
|---|---:|---:|
| 0.15 | 10 | 13 |
| 0.20 | 17 | 23 |
| 0.25 | 26 | 35 |

σΔ 的证据来源：QS 六重复的重复级 ΔQ SD≈0.13（同检查点设计）；250 面板任务级 dQ SD≈0.29（无同检查点、效应更弱的设计）。**保守初设 σΔ=0.20 → 目标 n=14–16，分两波（6+8~10）。**

**试点（P2-B，3 任务）的定位**：可行性 + 方差/异常率估计 + 协议检修；**不并入确认样本**。试点后用其任务级散点 + QS 数据做 plug-in，按上表定终 n；若所需 n 超预算上限，如实降低功效目标并声明，或提升 k 至 3（只降任务内方差，不改变 n 的独立性含义）。

## 六、停止与扩样规则（预注册）

1. **不完整任务**：某臂无终端输出→该臂 Q 记 0、安全记无法判定（QS 第七节口径）；两套结果并列。
2. **基础设施停止**：传输错误/输入完整性/模型身份/台账失败/预算触顶/共享段节点故障 → 整批停止，现场保留，不重试（QS 第六节）；恢复方式沿用"最小续跑"修订并逐次登记。
3. **扩样**：仅在**全部预注册任务完成后**发现 n 不足功效时，按预注册的补池规则新增任务（新任务Gold先行、审阅冻结），不得看过结果后选择性加样。
4. **试点期协议调整**：只允许在 P2-C 冻结前完成，逐条登记。
5. **执行顺序随机化**：任务序与重复序由预注册种子随机；臂序受检查点依赖约束（G2 终端先于 G3–G6 分叉；G1 独立随机插入），偏离"全随机"的原因如实记录。
