## 二、任务与模型

- 任务：监管处罚链族（P2_TASK_SELECTION.md），候选 7 个干净案例，补池至 ≥12；试点 3 个（ST索菱、ST华铁、中潜股份）。
- 模型分配（固定，沿用探针规则结论与 QS 证据）：E_D1、E_D2、J1、SINK、G1 = **DS**；J2 及其重核 = **GLM**（max_tokens 8000）。动态换模不在 P2 范围。
- 提示词、检测器（V5）、基础合计、恢复动作文本：逐字节复用（P2_ASSET_REUSE_AUDIT.md）。

## 三、每（任务，重复）的执行结构

```
共享检查点：E_D1 ∥ E_D2（DS）→ J1（DS）→ J2（GLM）→ CP{证据表, 基础合计, V5 状态, 覆盖检查}
G1 Single：独立一次调用，双文书全文 + 20 槽 schema（不经 DAG、不享基础模块）
G2 Static：CP → SINK（其输出即恢复前终端，G3–G6 共用）
G3–G6：从同一 CP 与同一恢复前终端分叉，按各自 (Z, R) 规则执行合法动作 a0–a3
```

- k=2 次重复/任务；无任何标记的重复里 G3–G6 复用 G2 终端（零调用、记平局）。
- 每臂每重复调用上限：G1 2（含 1 重试）、G2 2、G3–G6 各 4（QS 实测最高 5，收紧为 4：a3=2 + a2/H=1 + 重试 1）。
- 共享段节点故障 = 基础设施级整批停止（QS 规则）；续跑沿用最小续跑修订。

## 四、六臂操作定义

见 P2_STATISTICAL_PLAN.md 第二节（Z=状态层、R=重执行集、合法动作 a0–a3、M3 归属、G2 零动作的声明）。G3 ≡ QS-B、G6 ≡ QS-C 的规则逐字复用；G4/G5 为新增臂，规则如下（其余同 G6）：

- **G4（Z 动态、R 固定）**：状态→层映射同 G6（明确压制→终端层 a2；未知/混合→上游层 a3；带证据遗漏→仍必须选一层并全量执行：若恢复前终端已恢复选终端层 a2，否则 a3）。选定后**全量执行、不做终端完整性早停、不跳过**（触发即执行）。
- **G5（Z 固定上游、R 动态）**：触发后允许：恢复前终端检查通过→a0（0 调用）；M3-only→a1；明确压制→**确定性编辑 J2 输出 + 仅重跑 SINK**（R={SINK}，1 调用）；未知标签/升级→a3（R={J2,SINK}）；含 H 反馈重跑。
- 合法动作外的任何行为（人工挑选证据、改提示词、改检测器）禁止。
