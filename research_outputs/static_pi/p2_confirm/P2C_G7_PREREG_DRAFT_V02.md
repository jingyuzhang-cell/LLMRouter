## 3. 实验设计

- **两臂配对**：**G6-M** = P2-C G6 执行管线逐字沿用 + 阶段标签/文书类型元数据进入任务输入（两臂同见），**不执行**任何阶段约束；**G7** = G6-M + 阶段一致性约束与有界重锚定。**G7 − G6-M = 约束机制的纯增量**。
- 论文表述纪律：G6-M 是 G6 的公平对照实现，其输入分布与 P2-C 原始 G6 不同，**不得表述为与原版完全相同**；运行后附 G6-M 与 P2-C G6 的描述性对照（非确证）。
- π 固定路由；L 记录真实端到端时延（含核验与重试时间）；C 双口径（核算/边际，共享调用分摊说明）。
- 区组：n=40（暂定，§7）× k=2 重复；臂序随机化种子 = int(新任务清单SHA[:8], 16)，随任务集冻结预登记。

## 4. 约束规范与重锚定执行合同（冻结版）

**约束规则**：
- R1 阶段标签绑定：恢复附页携带 (fact_id[执行侧中性标识], stage_label, document_id, verbatim_quote)；stage_label 来自任务事实单输入元数据。
- R2 引文—事实阶段一致性：判定对象是**逐字引文所支持的阶段**，非文书类型禁令；决定书中明确记载的拟处罚内容对拟阶段事实**有效**。文书类型仅作先验。
- R3 阶段间禁推断：UNKNOWN 终局不得由拟阶段文书推断补全（沿用 P2-C 语义规则），反之亦然。
- 边界：整条事实丢弃不属于阶段约束作用范围，G7 不含完整性机制，丢弃率独立记录。

**执行主体与流程**（v0.2 新增，全部冻结于提示词与执行合同）：
1. **恢复执行智能体自检**：恢复输出为每个阶段敏感事实声明结构化字段 (fact_stage, quote_stage)。
2. **确定性核验器（零调用）**：仅做三项结构检查——(i) 引文在被引文书原文中**逐字存在**（字符串级）；(ii) 声明的 fact_stage 与事实单元元数据一致；(iii) quote_stage == fact_stage。核验器可见范围 = 输入文书原文 + 事实单元元数据；**不可见**：Gold 答案、允许文书清单、评分器内部信息。
3. 核验失败 → **重锚定尝试**：一次携带失败信息与阶段匹配指引的下游重写调用；**上限 2 次**；只允许换引文/换文书，**不允许改值、不允许删事实**。
4. 仍失败 → **保留原引文 + 记录核验失败标志**（防召回博弈：宁留错锚，不删事实）。
5. 全程记录：原引文、新引文、核验结果、重试次数、额外调用与耗时（计入 C 与 L）。

**实现要求与效果目标分离（D3 裁决）**：上述 1–5 为算法实现要求（可审计、可复现）；"阶段错配消除率 ≥80%"仅为**设计目标与功效模拟的目标效应**，不是执行前提或保证值；实测消除率如实报告，若实际为 50%，对应统计功效即 §7 表中该行，不以设计承诺替代实测。

## 5. 任务集与 Gold 构造

- 独立性、准入（两文书；≥6 必答事实；≥3 阶段敏感事实；逐字锚定测试；裁决规则逐字沿用 P2-C）同 v0.1。
- **基线异质性证据（D1 补充分析，零调用）**：P2-C 池 24 个可评价任务阶段敏感槽 min=4 / 中位 7 / max 16（均值 8.2/重复）——**准入 ≥3 槽对 P2-C 池过滤为零**（24/24 满足），该条件是保底下限而非过滤器；槽级错配率在 sens 分桶间稳定（3–7 槽：0.160；8–10 槽：0.133）→ **低基线风险主要来自池级漂移**（标注风格、文书构成、任务难度），无法由准入条件完全防护，以敏感性分析（§7）与如实报告处理。
- Gold 构造规则（阶段敏感事实 allowed_citation_docs = 逐字阶段一致证据所在文书，通常单文书）封堵"双文书白名单"漂移漏洞。
- 筛选量按 P2-C 产率（26/95≈27%）预留。

## 6. 终点与统计（v0.2 修订）

**事实状态判定表（评分侧，随任务集冻结）**：

| 事实状态 | 判定 | 归类 |
|---|---|---|
| 正确阶段引用（值对+引文阶段一致+逐字支持） | 正确 | 分子外 |
| 错误阶段引用 | **错配** | 主终点分子 |
| 事实缺失（未输出） | 遗漏 | 召回分母扣除，召回率分子外 |
| 值错误 | 数值错误 | 独立报告 |
| 值正确但支持不足 | 证据支持错误 | 独立报告 |

**主终点（唯一主要机制终点）**：
- r_{i,a} = 臂 a 在任务 i 的错配槽数 ÷ 该任务该臂**可评价**阶段敏感槽数；d_i = r_{i,G7} − r_{i,G6-M}。
- 以任务为统计簇（**320 个事实槽绝不作为独立样本**）；单侧精确符号翻转检验，n=40 采用 **meet-in-the-middle 精确计数**（复用 P2-C 已验证实现，不宣称直接枚举 2^40），α=0.05。
- 重复聚合：r_{i,a} 为可评价重复上的均值；单重复可评价则用该重复。

**召回保护（防"少输出换低错配"）**：强制共报阶段敏感槽召回率（值正确且阶段正确的槽 ÷ 可评价槽）的配对簇 bootstrap CI；**主张语言要求三条件同时成立**：错配率下降 + 召回未恶化 + Q 非劣；α 控制仅施加于主终点与 Q 非劣。

**Q_all 非劣性（D2 裁决：−0.05 主界值 + −0.032 强制敏感性）**：
- 方法：d_i^Q = 任务级重复均值差（共享失效重复按 M3 置零计入两臂，保留任务内重复相关结构）；任务簇百分位 bootstrap（10^4）单侧 95% 下界 ≥ −margin。
- **界值论证（从 Q_all 评分含义）**：N̄≈17.6 事实/任务（P2-C 实测 14–21）→ −0.05 ≈ 每任务少答对 **0.88 个事实** ≈ H2 效应（+0.064 ≈ 1.13 事实/任务）的 **78%**。在界值边界上，G7 相对静态管线的净收益接近抹平。因此 **−0.05 的定位是"仍偏好恢复而非不恢复"的无差异边界，不是"无实质质量损害"的声明**；−0.032（≈0.56 事实/任务，保留 H2 效应约一半）作为强制敏感性界值，两个方向结果均如实报告，论文同时呈现。

**次级与描述**：TP→lost 计数（关键次级，任务级配对单侧 0.05）；整条丢弃率（独立完整性指标，探索性）；C/L/可靠性描述性（双口径成本）。

**缺失处理（先于运行冻结）**：两重复均不可评价（共享失效）任务——主终点剔除并计数报告；敏感性 S1：按 d_i=0 插补（稀释方向）；敏感性 S2：最劣插补（G7 插补为 G6-M 池化率）；Q 终点按 M3 置零语义天然保留。运行后不得更改规则。

## 9. 预算（n=40 最劣合理路径，D 裁决后重算）

基础路径（80 区组 × 共享~3.9 + 2 臂下游）≈ 627 次调用；重锚定最劣 +160（80 区组 × ~1 次核验失败/重复 × 2 次重试上限）；核验器本身零调用（确定性字符串检查）。最劣合理合计 ≈ **800 次**。
