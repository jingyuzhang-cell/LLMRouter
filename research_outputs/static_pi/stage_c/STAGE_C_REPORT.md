## 三、科学发现

1. **Proposed-Dynamic 以 12.3% 的成本取得 Fixed-Composite 98.2% 的质量增益**（+87/+102 槽位）——自适应干预选择的价值在同等资源下成立。
2. **无诊断的反馈策略（π-only 与 naive-retry）质量增益为零却花费成本**——换模/重试对系统性故障（结构切断、口径歧义、格式旁路）全部无效。**价值驱动因素是诊断，不是反馈本身**——这是本实验最核心的对照证据。
3. **Proposed 与 Fixed 的全部质量差距（−1.2%）恰好等于不可辨识故障族（A3 口径、AMODEL 计数）**——预登记的可观测性边界被精确复现：反馈驱动调度的质量上界受诊断可观测性约束，其成本优势不受此限。
4. R-only（盲用结构动作）在 A4 上误动作花费无效成本且不修复——单一动作策略在非匹配族上失效。
5. 诊断层零幻觉、零误触发：不可辨识处全部诚实输出 UNKNOWN——保守默认有效。

## 四、边界（如实）

- Tier 1+2 = 离线回放：结论限于冻结后果矩阵上的策略表现；并发/资源竞争/Makespan 需在线验证（Tier 3 抽验 ≤15 调用，待授权）。
- 后果单元格 EXACT/APPROX 标注于代码常量（AMODEL 换模为实测 1/3 分布的期望回放）；组合状态场景（A1/A2）为 APPROX。
- 无 Q/C/L 效用函数——不宣称联合最优；本实验证明的是"同预算下自适应选择的质量-成本优势"。
- 30 场景、6 族——探索-确认混合定性，族为推断单位。

## 五、对研究主线的意义

完整因果链首次闭合：**节点执行反馈 → 确定性异常检测（8 检测器，2 剔除/N-A 如实处理）→ 错误家族诊断（可辨识 9/9，不可辨识保守 15/15）→ 匹配动作选择 → 终端质量 +6.9pp @ 12% 成本**。同时给出该范式的边界定理式结论：不可观测错误的修复需要超越内部一致性的反馈信号（外部验证/主动查询）——这是论文的机制贡献与后续工作方向。
