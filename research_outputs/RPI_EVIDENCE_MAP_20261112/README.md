## 结论一句话

主线问题 Q1（R×π 联合增量）在全项目中**确无干净证据**：现有 Joint 臂要么 π 未触发（DD-V5.1、H1、M7 自然格）、要么内嵌于诊断策略不可分离（Stage D V2）、要么 joint 格未测（QCL_V3）、要么大部 stub（netbenefit）；同时 π 的独立收益只有单任务级正向（RPI/QCL）与单任务级反向（π-smoke），无独立任务复现。若操作员决定追求 Q1，这是唯一缺口；工程前提（真实 π 换载、对称注入、fork-共享态、闭包恢复、P2-C 级统计）在 joint_search + P2-C + H1 三个线的存量资产中已经齐备，无需新建工程。
