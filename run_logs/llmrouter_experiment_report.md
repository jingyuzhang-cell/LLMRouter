## 实验过程

1. **准备实验任务**：加载 38 个任务，覆盖通用问答、代码生成、逻辑推理、摘要、专业问答、内容创作和审计合规场景。（38 个参与本轮评分）
2. **加载候选模型**：当前参与路由的模型为：deepseek-chat, qwen-plus, doubao, gemini-2.5-flash, doubao-seed-2.1-turbo, glm-5.2。（6 个模型）
3. **执行策略对比**：主实验只评估代表性范式：成本/质量基线、随机基线、KNN、RouterDC、GraphRouter、AutoMix、SLA Pareto 和本文级联/金融风险方法；其余同类路由器保留在附录/系统展示中。（10 个策略）
4. **模拟评分**：不消耗外部 API 调用，使用模型画像、任务复杂度、风险等级和多目标权重计算可复现实验分数。（可快速复现）
5. **PSO 粒子群调度**：把整批任务的模型分配看作一个整体方案，通过多轮搜索提升综合效用。 主要选择分布：-。（效用 0.000）
6. **GA 遗传调度**：把任务分配方案看作种群个体，通过选择、交叉和变异逐步筛选更优方案。 主要选择分布：-。（效用 0.000）
7. **PPO 强化学习调度**：把用户问题和模型状态看作状态，把选择模型看作动作，用奖励函数模拟策略更新。 主要选择分布：-。（效用 0.000）
8. **生成典型案例**：保留关键策略在每个任务上的候选模型评分、最终模型、选择理由和单任务指标，便于逐条解释。（380 条案例）
9. **得到本轮结论**：综合质量、成本、延迟和可靠性后，本轮综合效用最高的是：AutoMix。（0.789）
10. **PPO 当前定位**：当前 PPO 是可解释原型调度器；后续如果加入用户评分、人工判分和长期调用日志，可以升级成真正持续训练的强化学习路由器。（原型已接入）
