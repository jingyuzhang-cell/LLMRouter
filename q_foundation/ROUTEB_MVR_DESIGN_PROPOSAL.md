> 实施记录：MVR-1（江苏舜天处罚链）合同冻结（16 事实/5 关键/sha256 `035ba655…`），自检四连通过；**MVR-2（元道通信处罚+退市链）合同冻结（27 事实/5 关键/sha256 `a556d229…`），自检五连通过**——迁移验证：多页锚定、双机关三文号、真实拟≠终差异（750→600 万/禁入 5→4 年）、分项加总与四年合计派生、双单位双源核验全部确定性成立；错误套用"拟=终"模式被 FAIL 识别。**无舜天特有规则**。**实验排期待操作者单独批准，批准前零模型调用；合同自检通过 ≠ Dynamic-π 获得收益。**
> 提交依据：操作者 2026-10-30 路线指示（"权威来源＋确定性核验"为最推荐方案；红线：AI 生成答案＋AI 判对 ≠ Gold）。

## 1. 双路线定位

| | 路线 A：完整终端质量 | 路线 B：客观事实可验证评价（本提案） |
|---|---|---|
| 参考 | 人工 Gold（双人盲审+裁决） | 机器可验证参考 MVR（权威原文+哈希+确定性规则） |
| 覆盖 | 六维 Q_terminal（含语义） | Q1 客观事实 + Q2 证据可靠性；Q3 保持 UNKNOWN |
| 状态 | HOLD（原门槛不变，评审者到位即恢复） | **本提案，待批** |
| 宣称边界 | 完整质量 | **不得冒充六维 Q_terminal；不得外推为复杂任务整体质量收益** |

两线互不替代：B 的产出**不满足** P1–P3 人工 Gold 门槛；A 的门槛与冻结规定不受 B 影响。

## 2. MVR 定义与红线

**定义**：任务事实的参考值全部来自模型之外的权威原始文书（证监会处罚决定书/事先告知书、上市公司公告、交易所记录），每项事实绑定：原始文件 SHA-256、页/位置与证据跨度、数据类型、单位、计算规则、适用时间范围。正确性由确定性核验判定（数值/日期/主体/算术/跨度哈希），**无 LLM Judge 参与 Gold 侧**。

**红线**（违反任一即无效）：① 参考值不得由 Planner/LLM/调度算法生成；② 不得 AI 生成答案+AI 判对充 Gold；③ 评价规则在实验前冻结（sha256 封存），看结果后不得调整；④ UNKNOWN 不当正确、不计入有利指标；⑤ Q1+Q2 结果不冒充完整 Q、不外推。

## 3. 评价层次与 v1.2.3 零改动复用映射

- **Q1 客观事实正确性** ↔ `dimensions.fact_correctness`（类型化主体-谓词-值-单位-日期类型匹配 + 派生算术）+ `critical_gate`（关键事实三态否决）+ `fact_metrics`（precision/recall/F1）。
- **Q2 证据可靠性** ↔ `dimensions.evidence_support`（哈希绑定跨度 + ≥80% 覆盖 + 页哈希复算）。
- **Q3 复杂语义** ↔ 无有效评定 → **Q_final 设计性保持 NULL**：v1.2.3 要求 question_relevance 由人工/已校准 Judge 评定，MVR 模式两者皆无 → 天然阻断正式 Q。这恰好是诚实边界——**B 路线只报告维度观测值与关键门禁，不产生 Q_terminal 数值**。评分器一行不改。
- MVR 事实在合同中用 `gold_provenance = official_structured_record`（v1.2.3 既有的正式凭据类：官方结构化记录+源哈希，无需人工 review 块）——这正是该枚举当初预留的语义。

### 任务 MVR-1（旗舰）：江苏舜天处罚链四文档 DAG

| 文档 | 原始文件（SHA-256 已算） | 角色 |
|---|---|---|
| 《行政处罚事先告知书》公告（〔2023〕37号） | st_advance_notice_2023.html（f67b5eda…） | 分支 A：拟处罚 |
| 《行政处罚决定书》（〔2024〕41号）原文 | csrc_penalty_2024_41.html（5f004919…） | 分支 B：最终处罚+虚增明细 |
| 公司公告 2024_020 | st_announce_2024_020.pdf（65c95120…） | 分支 C：公司侧披露 |
| 公司公告 2024_021 | st_announce_2024_021.pdf（fd028267…） | 分支 C：引用与进展 |

**确定性事实清单（草案，待合同化时逐项锚定跨度+哈希）**：
- 当事人×金额绑定（6 主体）：公司 1,000 万、高松 150 万、桂生春 100 万、王重人/李焱/赵凡各 60 万（万元，主体关系=时任职务，区分公司责任与个人责任）；
- **拟 vs 最终一致性**：告知书拟罚与决定书终罚逐主体相等（跨文档汇合核验，预案-实施差异=0 且可解释）；
- **算术派生（已数值复核）**：当事人合计 1,430 万元；**虚增利润总额 934,451,757.26 元 = 虚增营收 10,333,448,392.98 − 虚增成本 9,398,996,635.72（精确到分，subtract 派生）**；
- 文号区分：〔2023〕37 号（告知书）≠〔2024〕41 号（决定书）——混淆即事实失败；
- 日期类型链：立案（2022，0382022008 号）→ 听证 2023-10-17 → 撤回申辩 2024-03-22 → 决定书 → 公告日（各为不同 date_type，不得互换）；
- UNKNOWN 项（预注册）：如当事人陈述申辩的具体内容细节等证据不足以判定项。

**DAG 真实依赖**：A/B/C 三分支独立抽取 → 汇合节点做三方一致性核验（公告引用的决定书文号/金额 vs 决定书原文；告知书 vs 决定书差异）→ 终端答案。任一分支缺失则汇合失败——上游信息真实依赖。**DAG 由既有 Planner 自动生成**（复用 planner/joint 机制），不人工固定模板。

## 5. Static-π / Dynamic-π 双臂设计（操作者表格原样）

| | Static-π（对照） | Dynamic-π（处理） |
|---|---|---|
| 初始 DAG / 初始分配 / 共同执行前缀 / 异常反馈 / R / Z | 相同 | 相同 |
| 剩余节点分配 | 保持原分配 | **根据反馈重新分配** |
| 终端评价 | MVR 客观事实核验 | 同 |

**观测指标**：① 客观事实正确率（weighted precision/recall）；② 关键事实是否全对（critical_gate）；③ 证据支持率；④ 实际调用成本；⑤ 端到端时延；⑥ 重新规划开销 vs 收益。配对分析（同任务同种子同异常），报告逐任务差值与区间；n 与功效按预注册计算后冻结。

**预冻结判定规则**（实验前 sha256 封存）：关键金额错误 → 该事实失败（critical FAIL → 该任务 Q1 记 0）；日期类型错误 → 不算正确（date_type 强校验）；无有效证据跨度 → 不算来源支持（哈希+覆盖核验）；UNKNOWN 正确拒判加分、错断言计失败。

## 6. 治理门禁（需操作者明确批准的三件事）

1. **批准路线 B 成立**（本提案 §1–§5，含宣称边界与红线）；
2. 批准后构建并冻结 MVR-1/MVR-2 正式合同（构建脚本+sha256 封存+三连自检，流程同 E08 模式，provenance=official_structured_record）；
3. 合同冻结后再批准实验排期（双臂、预冻结规则、样本量），方可调用模型。

**批准前：不建合同、不跑实验、零模型调用（本轮已保持）。**

## 7. 与路线 A 的关系

B 不消费 A 的任何门槛；若两名评审者将来到位，A 原样恢复且优先级更高（人工 Gold 仍是完整 Q_terminal 的唯一基础）。B 的实验结论措辞限定为："在多文档、确定性可验的资本市场任务子集上，反馈驱动的剩余节点重分配对客观事实质量/C/L 的影响"——不外推至全任务分布。
