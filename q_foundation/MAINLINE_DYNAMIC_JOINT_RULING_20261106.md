# 研究主线裁定：动态联合调度正向收益必须做实（操作者 2026-11-06）

> 性质：操作者战略裁定，零调用。本文件固化原文要点与执行框架，不引入新解释；执行注记单独标注。

## 一、主线判定：未偏离，不推倒重来

六环节完整保留：① 异构模型能力学习（Q/C/L/可靠性）→ ② 复杂任务理解与 DAG 自动生成 → ③ DAG 结构优化 → ④ 静态异构调度 → ⑤ **动态联合调度与 DAG 图森林（核心研究创新）** → ⑥ 反馈学习与多目标优化。

层次关系（裁定原文）：
- ①–④ 解决系统如何建立、规划、执行；
- ⑤ 是核心创新，必须证明动态联合决策优于静态与固定策略；
- ⑥ 让系统从历史经验持续改进。
- **约束：反馈奖惩、多目标优化等模块不得反过来取代动态联合调度成为主要贡献。**

普通 Router 回答"任务交给哪个模型"；本研究回答"DAG 出现异常/质量问题时，调整什么结构、恢复哪些节点、切换哪些模型、如何重排后续，才能整体更优"。两者不是一个层次。

## 二、核心研究假设（正式固定）

**H**：在具有可利用结构修复空间、执行异常和模型能力互补性的复杂 DAG 任务中，反馈驱动的动态联合调度能够优于静态调度和最强固定恢复策略，并在成本预算与截止时间约束下改善终端任务质量或资源效率。

收益定义：
| 类型 | 判定 |
|---|---|
| 质量收益 | 相同成本与时延约束下，终端质量 Q 提高 |
| 效率收益 | 质量不劣于对照组前提下，成本 C 或时延 L 降低 |

必要条件：可靠性、完成率、错误断言等安全指标无可接受范围外的恶化。

## 三、对照设计（最低要求）

| 对照 | 目的 |
|---|---|
| Static | 动态是否优于静态分配 |
| Z-only | 结构调整独立贡献 |
| R-only | 执行恢复独立贡献 |
| π-only | 模型重分配独立贡献 |
| 最优固定组合 | 排除简单组合已足够的可能 |
| Dynamic Joint | 反馈驱动联合决策的增量 |

**硬性要求：Dynamic Joint 必须与最强固定组合比较，而非仅与 Static 比较**——否则无法证明联合决策本身的额外价值。

## 四、当前位置（操作者诚实评估，原文要点）

| 实验 | 能证明 | 尚不能证明 |
|---|---|---|
| H1 | 存在结构修复与恢复的正向候选 | 联合收益普遍性及独立增量 |
| R6、DYNPI | 不同异常条件下恢复策略存在差异 | π 的稳定质量收益 |
| M6-4 | 已识别 Z/R/π 的条件化贡献 | Joint 超过最强单项策略 |
| M6-5 | 离线反馈可发现无效重试与修正规则 | 前瞻性真实执行收益 |
| PHASE_PI_V2 | 存在 Joint 材料正确性的探索性信号 | 正式终端 Q 收益 |

两个突出问题：
1. M6-4：历史 Joint 的正向效果主要来自 Z，无充分证据证明存在独立于 Z 的额外增量。
2. PHASE_PI_V2：36 次执行全部完成，但正式 Q_final 全部为 None——后验语义诊断不能替代正式质量收益。

**结论：已有正向机制证据，但动态联合调度的核心增量收益尚未坐实；M6-5 完成不等于动态联合调度成功。**

## 五、四优先级（顺序固定）

1. **P1 做实正向收益（当前重点）**：重新核验 H1 等已有实验的共同起点、输入、评分与成本口径；寻找可直接复用的有效正向证据；只补充尚未回答的问题。
2. **P2 证明联合增量**：公平配对条件下比较 Dynamic Joint 与最强固定组合。
3. **P3 验证条件化收益**：不同 DAG 结构、异常类型、模型能力差距、资源约束下联合决策何时有效/无效。
4. **P4 反馈学习与 Pareto 优化**：用已验证的状态-动作-结果关系更新策略，验证更新后控制器改善后续决策。

纪律不变：先查历史、先复用、不重复实验；发现真实证据缺口后才设计最小必要前瞻验证；无明确授权不启动付费调用。

## 六、负结果处置原则

不因负向收益怀疑研究方向；不为证明方向正确而强行把负结果解释成正结果。真正有研究价值的恰是条件化结构：何时结构重构显著改善、何时重试优于换模型、何时换模型提质、何时联合动作反而增本引错、调度器如何依据执行状态判断何时联合/单独/不动。

## 七、研究目标固定表述（原文）

面向复杂任务的异构大模型协同调度与 Q/C/L 联合优化。通过模型能力画像、DAG 自动生成与结构优化、静态异构分配，以及执行反馈驱动的动态联合决策，实现多模型之间的合理分工与协作；进一步利用动态 DAG 图森林搜索、反馈学习和约束式多目标优化，在保证终端回答质量与执行可靠性的前提下，尽可能降低执行成本和时延。

下一阶段重心：从扩展系统模块转向用真实、严格、可重复的实验，证明动态联合调度究竟能带来多少正向收益、在什么条件下成立。
