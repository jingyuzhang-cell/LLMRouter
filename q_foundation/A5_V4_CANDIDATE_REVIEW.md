## 五、反事实重评分（零调用，仅历史归档）

对 15 个归档 run 的 terminal output 用 V4 重评（旧合同 vs V4）：

| run | 旧 A5 | V4 A5 | ΔFact | ΔEvidence | ΔQ_raw |
|---|---|---|---|---|---|
| X-r1 | WRONG | **CORRECT_BUT_UNSUPPORTED_CITATION** | +0.0435 | 0 | +0.0217 |
| X-r2 | WRONG | **CORRECT_BUT_UNSUPPORTED_CITATION** | +0.0435 | 0 | +0.0217 |
| X-r3 | WRONG | **CORRECT_GOLD** | +0.0435 | +0.0435 | +0.0326 |
| 非 X 12 run | WRONG | WRONG | 0 | 0 | 0 |

**解读：**

1. V4 能把 X 链的 A5 **事实**从不可见变为可见（3/3）；非 X 臂零假阳性。
2. **证据支持只有 1/3 改善**：X-r1/r2 的 citation 是 `D1(E1)/D2(E2)` 或 `E1`（节点名/复合 ID），在冻结评分器下不满足证据锚点；X-r3 的 `D1` + 逐字 quote 满足。
3. 因此正式终端可识别的是 **A5 Fact**；Evidence/Full-correct 取决于**引用卫生**，V4 本身不能保证。
4. 所有 ΔFact 都是 +1/23 = +0.0435，与“A5 是 23 个事实之一”一致；Q_raw 增量更小（+0.02–0.03）。

## 六、边界与不可宣称事项

- V4 的分差是**交付编码修正**，不是模型能力、不是调度能力、不是中继机制本身的效果。
- V4 只影响 A5 的正式值匹配；不影响 J1 中继、SINK 语义或其他事实。
- 白名单是封闭的；A′ 若产生新短语，正式分仍可能为 0。**禁止在 A′ 结果出来后追加白名单**（事后拟合）。
- 引用卫生是独立的瓶颈；不要用 V4 的 Fact 增益冒充 Evidence/终端质量增益。
- V4 与 V3 不可合并宣称；三者（旧/V3/V4）必须并列报告。

---

## 七、结论

**V4 值得作为“并行测量仪器”提出，但只在需要正式 A5 Fact 终点时使用。**
若研究问题只是“中继机制是否传递并被 SINK 使用”，A5 语义规则已足够，V4 不必要；
若研究问题包含“正式终端能否识别改善”，V4 必要，但必须同时报告 Evidence 的引用条件限制。
