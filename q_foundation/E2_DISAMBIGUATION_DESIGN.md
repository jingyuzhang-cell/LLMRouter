# E2 任务口径消歧对照实验设计 V1.1（零调用，已按操作者三处修正冻结，待执行授权）

> 操作者定调（2026-11-01）："到底是模型不会数，还是我们没有把要数的对象定义清楚？"——本设计是唯一有鉴别力地回答该问题的最小实验。**性质：第三族干预（口径消歧），独立于已完成的结构族（R）与模型族（π），不触碰 2×2 的历史对照**。V1.1 修订（操作者 2026-11-01 审查）：①对照组按上游一致性重新划分；②四分支解释收窄；③消歧附录收窄至 announcing_company_count 单字段。

## 一、研究问题与鉴别逻辑

E2（gold=2：就俞发祥同一份告知书实例发布公告的两家公司）四臂终端值 4/4/4 → 4/4/4 → 2/4/4 → 3/2/3。既有解释假设：任务口径歧义（"涉及公告的上市公司数"可读作"本批公告文档的公司数=4"或"该告知书实例的公告主体数=2"）。

**对照设计（V1.1 修正：按上游一致性划分，12 个观测不得混组）**：

消歧实验使用**原始 J1** 上游，因此主对照组必须是同为原始 J1 的观测：

| 模型 | 主对照组（同上游同提示词，直接配对） | 消歧实验组 |
|---|---|---|
| GLM | **Static 3 次（0/3 对，全为 4）** | GLM-J2d 3 次 |
| DeepSeek | **π-only 3 次（1/3 对：2/4/4）** | DS-J2d 3 次 |

R-only 的 GLM 观测（0/3）与 Joint 的 DS 观测（1/3，值 3/2/3）**J2 输入含 dates_relay、上下文已变化**——不进入主对照，作为"relay 上下文下的补充观察"单独报告（其价值：显示 relay 会改变 DS 的错误形态 4→3）。

配对保证四同一异：**同一模型、同一冻结上游（原始 J1+E3+E4）、同一原始提示词、同一 run 配对，唯一变化 = 计数口径澄清**。若口径是主要可干预因素 → 澄清后应修复；若澄清无效 → 根因需在模型聚合能力与提示词理解之间进一步区分（见五）。

## 二、消歧附录（唯一提示词变化，V1.1 收窄至单字段）

J2_SYSTEM 尾部追加：

> 计数口径澄清：announcing_company_count 特指：就上述实体归一所认定的同一份立案告知书实例发布公告的上市公司数量（按公司去重，不按公告文档份数计；就其他告知书实例发布公告的公司不计入）。

**V1.1 修正**：personal_filing_instances **完全沿用原合同定义，不在澄清范围内**——一次实验只改一个字段的口径，保护 C2 副作用判断的纯净性。

**说明**：所需判定信息（D1/D2 为同一告知书实例）已在 J1 冻结输出中（SAME_NOTICE_INSTANCE 3/3 全对）——澄清只定义聚合规则，不给数值、不给公司名。**隔离门禁（机械断言）**：附录文本不得包含 gold 值"2"作为独立计数、不得含任何公司名/编号答案；与原 J2_SYSTEM 的差异仅此附录。

## 六、与主线的衔接

错误三族假说即将完整检验：**结构族**（信息传播，R-only 已证可修复 3/3）、**模型族**（换模修复，π/Joint 证明机制存在但不可靠 1/3）、**口径族**（本实验）。三族的鉴别结果直接构成动态调度"按错误类型选干预"的策略空间实证基础——后续动态策略实验的动作集合将由三族证据定义。
