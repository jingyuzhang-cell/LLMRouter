# Stage A/B 三任务 Static-π 设计统一可比性检查（零调用）

> 检查对象：P0-1 / P0-2（[设计](P0_1_P0_2_STATIC_PI_DESIGN.md)，21 调用）与 P1-1（[设计](P1_1_STATIC_PI_DESIGN.md)，18 调用）。结论先行：**三者共享执行协议与隔离纪律，跨任务比较限定在"同一协议下的逐维准确率与关键门禁"，不声称原始分数等价**；各任务基线首先是自身未来 π/R 实验的参照。

## 一、必须相同的（执行协议层）

| 维度 | 三任务统一规定 |
|---|---|
| 传输 | transport.py `call_model`（同一实现，无第二传输路径） |
| 模型 | GLM-5.3-Flash（订阅端点，thinking disabled） |
| 解码 | temperature = 0；每层 max_tokens 固定并在冻结件中记录 |
| 重复 | 3 次/run 级独立 DAG 实例；上游快照哈希随 run 记录 |
| 成本 | 冻结牌价核算（¥0.8/M in，¥2.8/M out）；usage 逐调用记录 |
| 时延 | 逐调用墙钟；**Gateway 串行化约束如实随报告记录**（Makespan 不可作并行主张） |
| 隔离 | SINK 只见槽位/拒判项 ID；Gold 值不进任何提示词；评分器独立于执行模型；适配器零语义改写 |
| 拓扑 | SINK 只消费 J 层（P0 系：依赖表验证；P1-1：传播审计 5/5 PASS）；E 层无旁路 |
| 产物 | 每调用 4 文件 + MANIFEST；prompt/request/response/artifact 四哈希（沿用 Runner3 六要素口径，工程线未闭环部分如实标注） |

## 二、必然不同的（任务构造层，不构成不可比）

| 维度 | P0-1/P0-2 | P1-1 | 处理 |
|---|---|---|---|
| 任务构念 | 实体归一 / 主体绑定计数 | 三维状态演化 | 构念不同，各报各的，不跨任务直接比总分 |
| 评分器 | terminal_quality v1.2.3（冻结） | state_scorer（冻结） | 两者均含关键门禁+UNKNOWN 拒判+锚点核验，机制同构 |
| 槽位 | 23 事实 / 12 关键 / 1 拒判 | 17 事实 / 5 关键 / 3 拒判 | 准确率归一化后可比机制不可比难度 |
| 节点数 | 7（E×4+J×2+SINK） | 6（E×3+J1+J2+SINK） | 每次重复 21 vs 18 调用 |
| 枚举语义 | verdict 枚举随任务 | 三维枚举+语义规则进 J1 提示词 | P1-1 的隔离决策已单独记录在案（枚举语义=任务定义，非 Gold） |

## 三、可比性结论

1. **执行协议可比**：传输、解码、重复、成本、隔离、拓扑纪律完全一致——三任务结果可放入同一论文表格，脚注标明评分器与槽位差异。
2. **构念不可比、机制可比**：P0 系测"归一/绑定/计数"，P1-1 测"状态演化/超 substitution"；比较单位是"关键门禁通过率 + UNKNOWN 拒判正确率 + 锚点 match 率"三项机制指标，而非原始分。
3. **基线用途**：每个任务的 Static-π 基线是**该任务自身**后续 π-only / R-only / Joint 实验的配对参照（同任务同协议内对照），跨任务只做定性对照。
4. **风险预登记**：3 次重复为描述性统计；GLM-Flash 订阅额度与端点稳定性作为环境约束记录；OS 级网络隔离缺失（BLOCKED_BY_ENVIRONMENT）由四哈希+MANIFEST 补偿，如实标注。
