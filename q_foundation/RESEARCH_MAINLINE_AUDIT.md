## 三、RQ1–RQ7 逐项审查

### RQ1 异构模型是否存在可利用的节点级能力差异 → **C（质量）/ B（时延）**

- Batch-1 全维度对比（抽取、日期、算术、JSON、引文）：**零差异**。
- E04-J1 探测：P1–P5 两模型全对。
- 唯一质量差异：J2 计数（GLM 4/4/4 vs DS 2/4/4，1/3）；**口径澄清后两者均 3/3**——差异随任务定义清晰化而消失。
- 唯一稳定异质：**时延**——GLM-J2 20.9–69.5s（中位 27.7s，n=12）vs DS-J2 4.7–6.3s（n=9）。
- **结论**：质量维度的异构性**未被证明**；时延维度的异构性**稳定存在**。这是全项目最重要的负面证据。

### RQ2 复杂任务能否有效分解为 DAG → **D**

- **不存在 LLM 自动分解**：PHASE2B 的 7 节点拓扑由人工设计（`phase2b_prompts.py` 文件头："Topology (necessary-dependency version, operator review §5)"）；MVR 线的 `build_dag` 为**确定性规则**（E 节点按固定 rotation 轮转、F1–F3 全连、SINK 汇总）。
- 分叉/汇合存在（E→F→SINK），但**是设计出来的**，不是分解出来的。
- 无分解质量损失、无协作收益测量。

### RQ3 DAG 结构优化是否具有实际价值 → **D**

- R-only 干预的是 **J1 输出契约**（新增 `dates_relay`）+ 下游失效重算；**未增删节点、未改边**（本方报告已收窄该边界）。
- 拆分、合并、依赖调整、冗余路径：**零实验**。

### RQ4 静态异构分配是否优于合理固定分配 → **D**

- π-only 为**单节点换模**（J2），非能力画像驱动的静态分配。
- **不存在**静态基线 vs 画像分配的对照实验。

### RQ5 反馈驱动动态调度是否真正有效 → **B（本线最强）**

- **离线（Stage C Tier 1+2，零调用回放）**：六臂 × 30 场景。Proposed 66.9% / Fixed 68.1% / Static 60.0% / R-only 62.2% / π-only 60.0% / Simple 60.0%；Proposed 成本为 Fixed 的 12.3%。**无诊断的反馈臂（π-only、naive-retry）质量增益为 0**。
- **真实（D2，108 执行，全部按时）**：
  - S4 持续格式故障：Proposed `15/12/13/15/15` vs Simple `8/8/8/8/10`，**5/5 全胜，p=0.031**；
  - S3 持续结构故障：Proposed `16/16/14/15/14` vs Simple `14/15/14/13/14`（4 胜 2 平，**p=0.125 方向性**）；π-only 在 S3 **恢复率 0%**；
  - R-only 在 S3 同达 100%——**结构修复非 Proposed 独占**（公平性实证）。
- 边界：故障全部为**人工注入**、任务单一、n=5–8、S5 已降级。

### RQ6 动态调度能否在真实资源约束下改善执行 → **C**

- 机制真实存在：K_glm=2 / K_ds=1、180s 与 90s 截止期、调用与费用双限。
- 但**无证据表明资源竞争实际约束了结果**：D1 全部按时（71–115s）、D2 全部 69–125s；makespan 由 API 时延主导。
- **真实模式时钟缺陷 2026-11-02 才修复**（此前 `--real` 使用 mock scale=1000，截止期被压缩 1000×，从未跑过一次有效真实执行）。

### RQ7 Q/C/L 联合优化 → **D**

- 本主线**无效用函数、无 Pareto 前沿、无截止期-预算扫描**。
- `m7_pareto_analysis.py` 存在但服务于另一语料（cap_eval_bench_v1），不覆盖 Stage A–D。
- 现有仅为"质量 / 增量成本 / makespan"分列报告。

## 五、薄弱环节：逐条回答八问

1. **异构性转化为调度收益？** 未证明。D2 的 S4 收益来自**格式动作**（Proposed 14.0 vs Fixed 13.6），非模型异质；π-only 在所有故障族均无稳定收益。唯一可用异质性是**时延**。
2. **DAG 结构优化有独立贡献？** 未证明。R-only 改的是输出契约，不是拓扑。
3. **人为拆分误当真实复杂 DAG？** 是。两份任务 DAG 均为人工设计，另一条为规则生成——RQ2 的 D 级根源。
4. **动态联合优于固定与简单反馈？** 部分。vs Simple 有 S4 显著；vs Fixed 是"质量略低、成本 1/8"的权衡，**非严格支配**。
5. **模型重分配机制充分验证？** 否。1/3 修复率、无稳定收益，唯一优势是时延。
6. **过度依赖人工故障？** 是。全部故障为注入；自然错误仅 Stage A 那批。
7. **跨实验不可比？** 存在：两任务两评分器（terminal_quality vs state_scorer）、分母不同（69 vs 51）——**跨任务分数不可合并**（现有报告已按此纪律执行）。
8. **质量/可靠性/效率区分？** 是，做得最规范：三层质量 + 独立可靠性；恢复成功率不替代终端质量。

### 方向性收缩诊断（明确）

**已发生收缩。** 最近 7 个实验单元（R / π / Joint / e2-消歧 / e2-终端 / 格式层 / Stage B / C / D）全部围绕**错误检测与修复**；而 M2（自动分解）、M3（拓扑优化）、M4（画像驱动分配）、M8（Q/C/L）在实验层面**基本为空**。

当前成果的准确表述应为：

> **"异构 DAG 上的故障感知修复选择机制"**，
> **不是**"完整异构多智能体 DAG 动态调度与 Q/C/L 联合优化"。

## 七、四项审查修正（v1.1）

### 修正 1 · Stage D 的 S5：端点依赖，不得提前判定失效

- **原订阅端点**（`transport.py` / `/api/anthropic/v1/messages`）：当前 429 code 1310（周/月上限），**2026-11-05 16:36:32 重置**；其过期后的时延分布**尚未复测**。
- **标准 API 端点**（`/api/paas/v4`，资源包）：可调用，但 `thinking` 无法关闭（code 1210），J2 规模时延中位 **5.1s**（n=3）vs 冻结基线 **27.7s**（n=12）——**时延机制不同**。
- **结论**：S5 的状态是 **PENDING（取决于端点）**，**不是"已失效"**。若最终在订阅端点执行，S5 的 SLO=9.5s 前提仍成立，需在 11-05 配额恢复后以受控预检重新测定；若在标准 API 执行，则 S5 需重新推导 SLO 并构成新预注册。
- **纪律**：不得在预检完成前把 S5 写成"失效"，也不得在标准 API 上沿用 SLO=9.5s。

### 修正 2 · E1 的样本量：n=5/格为先导筛查

- E1 的 **n=5/格全部定位为"先导筛查（pilot screening）"**，用于估计效应量与方差。
- **正式样本量必须由配对效应量与功效模拟确定**（方法沿用 Stage D 先例：给定效应分布 → 精确符号翻转检验/分层 bootstrap → 目标功效 ≥0.80）。
- 筛查阶段不得报告 p 值作为确认性结论；只能报告效应量与方向。

### 修正 3 · 取消"整体完成度 30–35%"

- 该数字**不作为正式定量指标**，已在 §六 改为**模块证据成熟度分级（L0–L4）**。
- 理由：模块间可比性不足，单一百分比会产生伪精度并诱导"补全表面覆盖"的错误动机。

### 修正 4 · 动态诊断机制：限定为机制性证据

- "价值来自诊断而非反馈"这一结论，现有证据为：Stage C 的零调用回放对照（π-only / naive-retry 增益为 0）+ D2 的动作族匹配（S3 结构 / S4 格式）。
- **定性必须为准：这是机制性证据（mechanistic evidence），不是因果效应的确认性检验。**
- **缺失的匹配消融**：需要"同动作、不同诊断"（例如：给 Proposed 注入错误诊断标签，看收益是否消失）与"同诊断、不同动作"的双向消融，才能把"诊断因果性"从机制解释提升为受控检验。
- 在该消融完成前，论文表述应为"结果与诊断驱动解释一致"，**不得**写"已证明收益来自诊断"。

## 八、下一阶段研究顺序（固定）

**顺序固定，但依赖关系须精确**：E1 → E2 → E3。

- **E1 是 M4（画像驱动分配）与 E3（时延-质量权衡）的前提**：若质量维度无异质性，M4 的收益来源需改写；若时延异质性消失，E3 的区分力丧失。
- **E2 不依赖 E1 的异构性发现**：即使 E1 显示模型质量完全同质，**结构优化仍可在统一模型下独立检验**（Z 的效应与 π 正交）。E2 的"按画像分配"臂在 E1 失败时退化为"统一分配"臂，但结构主效应仍可估。
- **E3 需要 E1 的时延异质性 + E2 的结构变量**，二者任一不成立则 E3 无区分力，应先停。

### E1 异构模型能力画像与可利用性验证

- **假设 H1.1**：模型能力差异在"跨文档推理 / 规则应用 / 状态演化"类节点上显著（≥15pp），在"抽取/日期/算术"类节点上为零或 <5pp。
- **自变量**：模型（GLM-5.3-Flash / DeepSeek）× 节点类型（抽取 / 归一 / 绑定 / 计数 / 状态判定 / 长文截断外事实）× 任务（PHASE2B 与 P1-1 两类构念）。
- **对照**：同提示词、同输入、同评分器、同预算；每格 n=5（**先导筛查**）。
- **指标**：节点语义准确率、关键事实通过率、时延分布、token。
- **统计**：分层 bootstrap（节点类型 × 任务为层），报告效应量与 95% CI；**不出确认性 p 值**，据此设计正式 N。
- **可支持结论**：若某类节点差异 ≥15pp 且跨任务同向 → 异质分配有据；若全部 <5pp → **主前提被证伪，必须改写论文主张**（这是本项目最重要的失败边界）。
- **失败边界**：任务过易导致天花板效应（以 P1-1 状态演进与 Shuntian 长文作难度锚）。

### E2 任务自动分解及 DAG 结构优化验证

- **假设 H2.1**：同一任务下不同 DAG 结构（链式 / 并行分块 / 合并）在**同 token 预算**下产生显著不同的终端 Q；并行分块对长文漏检有独立收益。
- **自变量**：DAG 结构三档（链式 7 节点 / E×4 并行 / 合并 E×2+J×1）× 分配（统一 GLM / 按 E1 画像）× 分解来源（LLM 自动分解 vs 人工最优上界）。
- **对照**：人工设计的最优结构作上界；同预算同模型。
- **任务**：真实长文——Shuntian 公告 14,465 字符，**当前架构只喂前 3,000 字符（79% 从未被抽取）**，这是现成的真实缺口而非人造复杂度。
- **指标**：终端 Q（三层）、关键事实漏检率、总 token、makespan。
- **统计**：结构 × 分配的双因素设计，配对比较 + 交互项。
- **可支持结论**：结构优化是否具有**独立于模型的**贡献（交互项不显著 → 收益来自结构本身）。
- **失败边界**：若并行无收益 → 说明瓶颈在模型能力或提示词，而非结构。

### E3 资源约束下的 Q/C/L 联合优化

- **假设 H3.1**：在 deadline 收紧时，动态重分配可将按时率提高 ≥20pp，且终端质量损失 ≤5pp。
- **自变量**：deadline 三档（宽松 / 中 / 紧）× 策略（Static / Static+retry / 动态联合）。
- **前置条件**：仅当 E1 证明时延异质性可利用时才有意义（GLM 慢、DS 快已在实测成立）。
- **指标**：按时率、终端 Q、总成本、makespan → 绘制 Q-L 与 Q-C 前沿；定义效用函数需在此前预注册。
- **统计**：每档 deadline 内配对比较；Pareto 支配关系（严格支配 / 权衡 / 支配失败）。
- **可支持结论**：在明确效用函数下是否存在非支配策略；**在此之前不得宣称 Q/C/L 全局最优**。
- **失败边界**：若 deadline 从未成为约束（如 D1/D2 所见），则本实验无区分力，必须先收紧 deadline 直到出现超期。

## 九、四个问题的回答

**第一：真正的科学进展是什么？**

1. 一套**可独立复核的终端质量评价栈**（冻结合同 + 双评分器 + 篡改测试 + Gold 锚点 + MVR 替代人工 Gold 的可行路径）——方法论基础设施，真实且可复用。
2. 一条**质量损失分解规律**：结构族（3/3 确定性可修）/ 格式族（20/28 确定性恢复）/ 口径族（6/6 澄清修复）/ 模型族（1/3 不可靠）。
3. 一个**非平凡机制发现**：SINK 语义采纳率 **99.5%**、上游错误过滤率 **55.3%**——终端不是瓶颈，源头才是。
4. 一个**可观测性边界**：62.5% 的异常对内部检测器不可见（B1–B3 全静默、A3/A-MODEL 签名相同）——范式级限制。
5. 动态策略的**机制性证据**：无诊断臂增益为零，**结果与"诊断驱动"解释一致**（**尚未做匹配消融，故非因果确认**）。

**第二：距离主目标多远？**

见 §六 模块分级：M7 达 L3、M5 达 L3、M1/M6 为 L2、M4 为 L1、**M2/M3/M8 为 L0**。缺的不是实验精度，而是**三个原始模块完全没有实验**，外加 M4 无对照。以"可投稿的完整主线"论，当前证据覆盖的是八模块中的两个半。

**第三：Stage D 之后最值得投入的三个科学问题？**

1. **异构性守门**：节点级可利用能力差异是否真实存在（RQ1）——决定整个异构调度前提。
2. **分解与拓扑**：同任务的链式/并行/合并三档 DAG，同模型同预算下 Q/C/L 如何变化（RQ2/RQ3）。
3. **截止期-预算下的 Q-L 前沿**：静态 vs 动态，多档 deadline，画 Pareto（RQ6/RQ7）。

**第四：若只能再做 2–3 组实验？**

**E1（必做，守门）→ E2（补空白）→ E3（Q/C/L 入口）**，与 §八 一致。
- **E1 不可省**：若模型能力在节点级无差异，后续所有调度研究失去前提；这是唯一能"证伪整条主线"的实验，必须最先做。
- **E2 不可省**：它是 RQ2/RQ3 的唯一入口，且现成的长文截断（Shuntian 79% 未抽取）提供了真实缺口，不需要人造复杂度。
- **E3 可在 E1/E2 之后**：只有当 E1 证明时延异质性可利用、E2 给出结构变量时，Q-L 前沿才有区分力。
