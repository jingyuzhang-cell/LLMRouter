## 二、尚未测过的节点类型（差异潜力排序）

按「(a) 认知复杂度 (b) 现实任务中真实存在 (c) 差异可沿 DAG 传播到终端」三项综合排序：

### ★★★★★ 最高潜力：多步条件推理（规则适用判断）

**描述**：给定退市规则条文 + 公司财务指标，判断该公司触及哪条规则。

**为什么可能有差异**：
- 需要同时处理规则条文（法律语义）+ 数值比较 + 逻辑合取
- 不同于抄录（抽取）或单步计算（简单派生），需要**规则匹配+条件组合**推理
- 两个模型可能对规则边界的理解不同（如"连续20个交易日"的"连续"是否排除停牌日）

**语料支撑**：E04 卓然双退市线（12.3.1 条两款，价格线 + 市值线，先触及先适用）；E05 纳川退市情形矩阵（六情形三勾）。

**DAG 结构**：分支=规则文本抽取 + 分支=财务数据抽取 → 汇合=规则适用判断 → sink。
**修复传播**：如果规则适用判断错误（如判为"不适用"），下游 sink 的退市风险结论必然错误。

### ★★★★☆ 高潜力：多文档时间序列状态追踪（supersession）

**描述**：给定时序排列的多份公告，判断某项信息的"当前有效状态"。

**为什么可能有差异**：
- 需要理解"后续公告修正/覆盖/补充先前信息"的语义
- 不是简单取最新，而是判断哪些信息被修正、哪些仍在有效、哪些是新信息
- 可能涉及"部分修正"（金额改了但日期没改）

**语料支撑**：E05 纳川五份公告序列（第五→六次风险提示 + 立案 + 预重整）；E04 卓然三份进展链（080→097→098）。

**DAG 结构**：分支=各时间点信息抽取 → 汇合=状态演进判断（哪些被覆盖/哪些持续有效）→ sink=当前完整状态。

### ★★★★☆ 高潜力：因果归责推理

**描述**：区分"监管认定的违法事实"vs"公司陈述的理由"vs"外部推断的因果关系"。

**为什么可能有差异**：
- 涉及**证据类型区分**（监管认定/当事人陈述/分析员推断——权威层级不同）
- 需要理解"涉嫌"≠"认定"、"立案"≠"处罚"、"预计"≠"确定"
- 需要正确处理否定和限定词

**语料支撑**：全语料通用——每份公告都混合了监管认定语言和公司陈述语言。

**DAG 结构**：分支=各方陈述抽取（监管/公司/中介） → 汇合=证据类型分类 → sink=按权威层级排序的因果链。

### ★★★☆☆ 中等潜力：跨文档实体关系推理（PHASE2B 已设计）

**描述**：同一自然人/同一文书/同一事件在多份文档中的归一与区分。

**已设计**：PHASE2B（E10+E10b+E07+E05，四变体），合同 v2.1 已冻结，等待解除 HOLD。
**潜力不确定原因**：日期关系四分类两模型已收敛全对——实体归一可能同样收敛。

### ★★★☆☆ 中等潜力：长文档信息压缩与结构化

**描述**：从长文档（>5000字）中提取结构化摘要，保留关键逻辑关系。

**语料支撑**：E06-huanrui sup1（业绩说明会 Q&A 长文）。
**潜力不确定原因**：两模型 JSON 结构化率均 100%，可能在长文本上出现长度/覆盖度差异。

### ★★☆☆☆ 较低潜力（已证收敛）：简单抽取/日期分类/精确算术

已有数据证明零差异，不再投入。

## 三、推荐下一步实验设计（零调用构建，待授权后执行）

### 实验 A：规则适用判断（最高优先级）

**任务**：E04 卓然双退市线——给定 12.3.1 条规则文本 + 股价/市值数据，判断：
1. 该公司当前触及哪条退市规则？（价格线/市值线/两者/均未）
2. 各线的关键触发条件是否满足？（连续N日+低于阈值）
3. "先触及先适用"原则下，哪条线先触发？

**Gold 构建**：规则条文 + 触发数据 + 适用结论，全部从冻结 PDF 锚定。

**DAG**：E_rules(条 文抽取) + E_data(财务数据抽取) → J_rule_match(规则适用判断) → SINK

**预期差异机制**：如果两模型对"连续"的理解不同，或对"首次低于1元"vs"连续20日低于1元"的逻辑关系处理不同，将产生真实的规则适用分歧——且该分歧直接影响终端退市结论。

### 实验 B：E05 状态演进追踪

**任务**：纳川五份公告序列——判断各项退市风险指标的当前状态：
1. 哪些情形已确认适用（√）？
2. 从第五次到第六次提示之间，状态有何变化？
3. 预重整对退市风险的影响方向？

### 实验 C：因果归责分类

**任务**：混合文档——将每条信息分类为：
- 监管认定事实 / 公司陈述 / 推断/预计 / 法条引述

## 五、对操作者核心问题的直接回答

**"如何找到一批真实复杂任务，使 GLM 和 DeepSeek 在关键判断节点上产生真实、稳定、可修复的能力差异？"**

1. **停止在抽取和简单分类上找差异**（已证收敛）
2. **集中火力在规则适用推理和多文档状态追踪**（认知复杂度最高、语料最丰富、传播路径最清晰）
3. **同步验证因果归责分类**（涉及权威层级区分，可能有训练数据差异导致的模型分歧）
4. **用 PHASE2B 已设计的实体归一作为中等难度对照**（如果连这个都收敛，则进一步支持"差异只在更高认知层级"假设）
