# M6-5: 离线回放与策略更新验证（2026-10-31，零调用）

**问题（操作员指令原文）**：验证反馈机制能否真正改善后续调度，而不是仅仅记录历史结果。

**一句话结论**：能——回放证明学习到的策略（V1 = M6-3 四规则 + 从语料学到的持久性表）在历史决策点上会做出可测量更优的决策（避免 27,047 tok 已被记录证明无效的原地重试；8 个可绑定场景全部恢复 COMPLETE）；且回放本身发现并修正了两条规则缺陷（R_1′、PI_2′），证明反馈闭环作用于**策略本身**而非仅记录。以上均带循环性披露与边界声明。

---

## 一、方法：回放协议与三级绑定纪律

**回放器**（[m6_replay_harness.py](m6_replay_harness.py)，零模型调用，只读已记录 JSON）把每个历史 run 的事件流重放到每个**故障决策点**，用 V1 策略只依据**决策前信息**（故障类型、节点、attempt、已分配模型、持久性表）给出动作，与冻结臂的实际行为对比。

**反事实三级绑定纪律**（防伪造）：

| 层级 | 内容 | 可靠性边界 |
|---|---|---|
| Tier 1 | 决策审计（同意/偏离分类） | 处处可靠（纯记录事实） |
| Tier 2 | 浪费规避：节省额 = 记录中已发生且已证明失败的原地重试 token | 处处可靠（不虚构结果：那些重试真实发生、真实失败） |
| Tier 3 | 恢复反事实：仅当同 cell 存在**执行了推荐动作**的配对 run 时，借用其 (status, tokens)，标注 comparison_id 与证据级 A | 仅配对场景可用；无配对→标 UNBOUND（诚实缺口） |

**无后见之明规则**：V1 在第 i 个事件决策时只能看到 events[0..i]。持久性表是显式的"策略更新"产物：`persistence = 1 − P(同配置重试恢复)`——**换模型/拆分后的恢复不计入**（它证明故障是系统性的、可干预的，不否定持久性；与冻结调度器 SYSTEMATIC_FAILURES 语义一致）。

**Tier 3（配对恢复绑定，证据级 A，8 个全绑定成功）**——全部 INCOMPLETE → **COMPLETE**：

## 七、Phase E：回放发现的两条规则修正（反馈闭环作用于策略）

| 发现 | 反例/证据 | 修正 | 语料内效果 |
|---|---|---|---|
| R_1 过严：contract 第 1 败即退会错杀唯一可恢复案例 | R6 n4：第 2 次同模型重试成功（91 tok） | **R_1′**：持久故障允许恰好一次同模型重试，attempts≥2 早退 | 放弃恢复数 1→0；浪费不变（chk 类 Z_1 在第 1 败即拆分，不受影响） |
| PI_2 过宽：任何故障都建议换强模型 | 8 次触发全部在 transport（瞬态）；5/8 同模型重试即恢复→换模型是不必要成本 | **PI_2′**：仅系统签名（contract/parse）且同模型重试已失败一次（attempt≥2）才换 | 触发 8→0；误报 5→0；零恢复损失 |
| （规则缺口）瞬态重试无次数上限 | DYNPI pi-only r2：transport 反复失败至耗尽，V1 无限重试 vs 记录臂有界放弃 | 待设计（重试上限），暂不立规则 | — |

**V1.1 = V1 + {R_1′, PI_2′} 在语料上全面占优：浪费相同（27,047）、π 触发 8→0、放弃恢复 1→0。**
状态：**PRELIMINARY**——修正在同一语料上调出，需前瞻性批次（MVR_V1 级）验证后方可转正；PI_2′ 的敏感度面（差距≥0.15 弱模型系统故障）在语料中经修正后为 0 个事件，其正收益证据仍只有 M6-4 的 DYNPI T1-r2（n=1，且该 run 不在本回放语料内）。

## 八、结论与边界

**已确立（三条）**：
1. **浪费规避（Tier 2，非循环）**：V1 在原决策点上会避免 27,047 tok（28.9%）已被记录证明无效的重试——这是记录事实的重新记账，不依赖任何配对假设。
2. **恢复获取（Tier 3）**：8 个可绑定场景全部 INCOMPLETE→COMPLETE，成本符号双向且可由无 Z 臂行为解释（复现并强化 M6-4 悖论解）。
3. **策略自身被改善（Phase E，本回放独有）**：回放发现 R_1 的结果证伪反例与 PI_2 的 5/8 过度触发，产出 V1.1 占优修正——反馈机制不止记录历史，它改变了下一步会执行的策略。

**循环性披露**：Tier 3 在基线实验上重新推导了 M6-4 的配对比较（规则正是从这些 run 学出的）；非循环成分是 Tier 2 记账、LOEO 特异性（Z_1 基线外 0/41 误报）与 Phase E 修正。
**未确立**：(a) 前瞻性改善——需要新批次按 Schema V1 采集后回放验证（M6-2 已就位）；(b) PI_2′ 正收益——敏感度面为空，需差距≥0.15 弱模型系统故障的专门批次；(c) 瞬态重试上限规则——r2 暴露缺口，待设计。
