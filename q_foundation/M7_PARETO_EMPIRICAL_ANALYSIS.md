# M7-1: 现有语料的多目标 (Q, C, L) Pareto 实证分析（2026-10-31，零调用）

**M7 问题**：在资源约束下提高终端质量、降低成本与时延——多目标结构到底是什么样？

**一句话结论**：对 16 个同 cell 配对组、67 个臂对的多目标分析表明：**权衡（tradeoff）是模态情形（49%）**，且即便出现单臂占优（DYNPI 全部 5 cell），**占优臂在不同 cell 间翻转**（π-only 3 个 / R-only 2 个）——没有任何固定臂在所有条件下最优。恢复有可测价格（R9B 每 cell +3,381~+6,899 tok；H1 中 +930 tok 买 +10 条确认事实）。线性权重恰恰在有权衡的 cell 上不稳定（赢家随权重翻转），实证支持 M6-3 的约束式（词典序）建模。

---

## 一、方法与纪律

- 回放器产出的同 cell 数据（同任务、同故障、同参考）→ cell 内 (Q, C, L) 比较（M6-4 Level A 纪律：**Q 绝不跨实验比较**，每 cell 用本实验自己的评分）。
- **INCOMPLETE 处理（M6-3 规则）**：Q=null（绝不赋 0）；完成度 R 作为独立维度参与支配关系。
- **方向性支配定义**：COMPLETE 臂对 INCOMPLETE 臂在 C、L 双不劣时构成**恢复性支配**；INCOMPLETE 臂永不支配 COMPLETE 臂；双 INCOMPLETE 时为**更廉价失败**；Q 仅在双 COMPLETE 之间比较。
- 前沿成员二分：**质量点**（COMPLETE）与**廉价失败点**（仅在"预算 < 最廉 COMPLETE 成本"的退化区间最优）。
- 分析器：[m7_pareto_analysis.py](m7_pareto_analysis.py) → [M7_PARETO_RESULTS.json](M7_PARETO_RESULTS.json)。

## 五、四个可提取的调度事实

**事实 1（权衡是模态）**：49% 的臂对不可比——固定单目标或固定权重必然在近半数情形留下未获取的价值。

**事实 2（占优臂条件翻转）**：DYNPI 同一实验内，π-only 与 R-only 交替占优（π-only 赢在有真实能力差距的 E2 金额节点；R-only 赢在 π 未激活或切换引致失败的 cell）。**"哪个臂最好"不是臂的属性，是条件的属性**——这是 M5 动态调度与 M7 条件化优化的直接实证依据。

**事实 3（恢复有价格，且价格可预测）**：
- R9B 每 cell：+3,381 / +3,682 / +4,237 / +6,899 tok 买 COMPLETE（快速失败 A 臂 vs 拆分 B 臂）
- H1 SC-E1 预算曲线：B=13,897 → G6（3 事实）；B=14,827 → G5（13 事实）——**+930 tok 买 +10 条确认事实**
- M6-4/M6-5 已证价格符号由无 Z 臂行为决定（浪费重试 → 拆分反而更省：H1 G2→G5 为 −2,083）

**事实 4（线性权重恰在权衡处脆弱）**：权重网格（α,β 以 0.1 步进）下，赢家数 ws=2 恰好出现在两个质量权衡 cell（H1 SC-E1、R6 E1-r1）；凡单臂占优 cell 均 ws=1。即**权重选择的不确定性正好集中在需要它的地方**——支持 M6-3 的约束式 max Q s.t. C≤B, L≤D（操作员以 B、D 表达偏好，而非α、β、γ）。

## 六、对 M7 后续设计的输入

1. **机制条件化策略**（M7-2 候选）：占优机制 → 直接取占优臂；权衡机制 → 约束式选择（B/D 为旋钮）；定价恢复 → 预算允许即买恢复（Q 主序）。机制本身可由 V1.1 规则在线判别（持久性表 + 能力差距）。
2. **B 的语义**：预算不只是资源上限，而是"是否购买恢复"的开关——恢复价格分布在 3.4K~6.9K tok（R9B 类）与 0.9K（H1 类），给 B 的设定提供实测参照。
3. **廉价失败点的正确地位**：Static 类臂的前沿占位（5 cell）全部是廉价失败点——仅在预算低于最廉 COMPLETE 成本的退化区间最优；任何现实 B 下应支付恢复价格。
4. **数据缺口**：H1 SC-E3 无 Z 臂（无质量点 cell）；TGV 无故障（等价 cell）——M7 实证版图缺"多质量点 + 预算压力"的 cell，需前瞻批次（MVR_V1 级，HOLD 状态不变）。
