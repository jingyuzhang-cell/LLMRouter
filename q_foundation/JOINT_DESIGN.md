# Joint 联合干预实验设计（零调用，设计授权 2026-11-01，执行待授权）

> 2×2 配对对照的第四臂。前三臂数据已存在（冻结复用，零重复调用）；Joint 仅新增 6 次调用（DS-J2 ×3 + GLM-SINK ×3）。**边界**：不改 Stage A / R-only / π-only 原始数据；不重建评价体系；不加无关工程；**不修改任何提示词（含 E2 任务口径——消歧即第三种干预，破坏 2×2）**；不预设 Joint 优于单项策略。

**两个干净对照（2×2 的科学收益）**：
- Contrast-1（给定 relay，换模效应）：Joint vs R-only——同 J1'，J2 模型不同；
- Contrast-2（给定 DS-J2，中继效应）：Joint vs π-only——同 J2 模型，J1 是否带 relay。

## 2. Joint 完整节点执行路径（每 run k）

```
E1-E4：冻结复用（Stage A runs/runK/E*.json，零调用）
J1'： 冻结复用（R-only runs_r/runK/J1r.json，dates_relay 已验证，零调用）
J2j： DeepSeek-flash( J2_SYSTEM 原文, j2_user(J1'text, E3text, E4text) )   ← 新调用 ×3
SINK： GLM-5.3-Flash( SINK_SYSTEM 原文, sink_user(J1'text, J2j text) )     ← 新调用 ×3
```

- J2 的 user 构造 = R-only 中 J2r 的同一构造函数、同一 J1' 上游（**字节一致性断言**：Joint 的 j2_user 与 R-only 对应 run 的 J2r user 不一致即中止——上游漂移防护）。
- 提示词零改动：J2_SYSTEM/SINK_SYSTEM 与 Stage A 逐字节相同；DS 侧 thinking:disabled（transport 现行，已实测 reasoning=0）。
- 别名白名单按节点：J2j=deepseek，SINK=glm53flash；端点回显进记录；成本硬顶 ¥1.00（DS 侧）。

## 5. 三种结果分支及科研解释（预登记）

| 分支 | 触发 | 科研解释 |
|---|---|---|
| **A 联合机制证据** | C1 成立 + C3 通过 | 结构干预与模型干预**可叠加**：日期恢复（结构族）与 E2 修复（模型族）同时成立且无新倒退——"按错误类型选干预"的联合调度价值获得探索性证据（n=3，不作统计显著性宣称） |
| **B 干预族独立** | C1a 3/3 但 C1b ≤1/3 | relay 上下文不改变 DS 计数行为；**两干预作用于正交错误族，联合对 E2 无增益**——E2 归入第三族（任务口径消歧），π/R 各司其职即最优组合，Joint 无额外价值 |

## 6. Q/C/L 统计口径（冻结）

- **Q（双口径三层）**：冻结评分器 formal（dims/critical_gate/fact_metrics）+ 确定性分解诊断层；报告分层 = 目标槽 {F1,F2,F4,E2} / 全局保护槽 / 整体；逐 run 配对给出四组对照表。
- **C（增量口径优先）**：Joint 边际成本 = 3×J2j（DS 估算 + 账单实付）+ 3×SINK（GLM 核算价，实际 ¥0）；J1'/E 层复用 = 零边际（如实标注 reused，不摊入）；同时报告全路径名义成本（含 J1' 原 R-only 成本）供参考。与 R-only / π-only 的增量成本并列。
- **L（顺序时延，禁止并行主张）**：逐节点墙钟；Joint 边际路径（J2j+SINK）与全路径名义（含 J1' 原时延）分列；DS-J2 与 GLM-J2 的每节点时延差如实报告，但**不据此宣称 DAG 并行 Makespan 优势**（顺序执行 + 无 Gateway，与既往口径一致）。
- 三重复 = 探索性证据；任何百分比只作描述性陈述。

## 7. 失败/倒退/异常处理规则（冻结）

1. **节点 JSON 解析失败**：记录 json_ok=false，原文透传下游（与 Stage A 同规则），不静默修复；
2. **DS 字段遗漏**（如 notice_binding 整体缺失）：记节点级遗漏（C3-b/C5），不补写；
3. **服务端 usage 异常**（如 R-only run2 的 in=58 类）：按上报值记录 + 异常标注 + 按同臂同类调用均值给出估算区间；成本不确定性保留；
4. **HTTP 失败/凭据失效**：单次重试（15s）后仍败 → 节点失败如实记录，臂继续（下游消费空上游）；凭据中途失效 → 臂 BLOCKED 报告；
5. **任何提示词漂移**（断言失败）：立即中止，报告——不允许运行中改提示词；
6. **结果不美化**：C 判定按预登记阈值执行，混合/失败分支照报。

## 8. 与主线的衔接

Static-π（错误分布）→ R-only（结构族 3/3 + 全局倒退教训）→ π-only（模型族 1/3 + 传播机制实例 + 时延优势）→ **Joint（本设计）**：回答"按错误类型选干预 + 全局质量约束"的联合调度是否成立。执行授权后按本文件冻结执行；结果无论 A/B/C 哪个分支，都是对"错误类型→干预动作→传播→全局约束"框架的直接检验。
