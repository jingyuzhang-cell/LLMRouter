## JC-2 · C2 完整四分传播分类 + SINK 消费证据

节点—终端关系按 2×2 完整分类，每 run 归类，禁止只看终端答案：

| J2j 节点 | SINK 终端 | 分类 | 科学解释 |
|---|---|---|---|
| 正确 | 正确 | **修复传播** | 节点修复成功并传播——唯一可计入"DS 修复"的类别 |
| 正确 | 错误 | **传播失败** | 节点修复成功但终端未采信——机制层缺陷信号 |

**消费证据（机械核验，冻结）**：传播分类仅在 SINK 节点记录的 `upstream_text_sha256["J2"]` == 该 run J2j 输出文本 SHA-256 时生效——证明 SINK 实际消费的是 J2j 输出，而非答案碰巧相同。逐 run 记录核验结果；哈希不匹配 → 该 run 传播分类记 invalid 并如实报告。

## 研究定位分层（操作者提醒，记录在案）

本次 Joint 是**固定联合干预实验**（已知日期传播错误→选中继；已知计数错误→选 DS；组合执行）。它能回答：两种干预能否互补、联合是否有额外收益、如何控制全局倒退。**它不能证明系统能自主识别未知异常并自动选择干预动作**——那是后续动态策略实验的研究对象。论文证据分层：

| 证据 | 可支持的结论 |
|---|---|
| Static-π | 真实错误分布 |
| R-only | 信息中继与失效重算的恢复作用 |
| π-only | 异构模型修复的有效性与局限 |
| Joint | 两类干预的互补性及全局质量约束 |
| 后续动态策略实验 | 反馈驱动的自主动作选择与 Q/C/L 联合优化 |

**Joint 的成功不得写成"动态调度算法已成功"。**
