# M7-3D Extract V1/V2 配对实验协议

**版本**: 1.0 | **日期**: 2026-11-01 | **状态**: 冻结待 GO

## 一、实验目的

验证 Extract 合同 V2（日期角色消歧 + 证据锚定）能否提高关键事实提取准确性和一致性，并最终改善终端报告质量。

## 二、实验设计

### 配对对照

| 组 | Extract 合同 | 其他条件 |
|---|---|---|
| V1 组 | 原合同（泛日期提取） | 保持不变 |
| V2 组 | 新合同（date_role + evidence） | 保持不变 |

两组使用：相同任务（E04）、相同文档、相同模型（flash）、相同下游合同（split V2 + report）、相同评分器。

### 运行矩阵

| 组 | 重复 | 每次调用 | 合计 |
|---|---|---|---|
| V1 | 3 | 4（3 extract + 1 report） | 12 |
| V2 | 3 | 4 | 12 |
| **合计** | | | **24** |

预算：≤40 调用（含余量）。累计 ≤293/300。

### 随机化
V1 和 V2 交替执行（V1-r1, V2-r1, V1-r2, V2-r2, V1-r3, V2-r3）。

## 三、观察指标

| 指标 | 定义 | 期望 |
|---|---|---|
| F1 准确率 | filing_date 包含 2025-12-20 的 run 比例 | V2 > V1 |
| F1 一致性 | 3 次重复中 F1 结果相同的比例 | V2 > V1 |
| F2 准确率 | penalty_date 包含 2026-09-11 的 run 比例 | V2 > 0（V1=0） |
| date_role 区分 | V2 中 extract 是否区分披露/收到日期 | V2 可区分 |
| 终端 Q | COMPLETE 条件下 Q 正确数/总数 | V2 ≥ V1 |
| token 成本 | 每 run 平均 token | V2 可能略高（更长提示词） |

## 四、停止规则
- 预算停=终态
- V2 extract 解析失败 >50% → 停止（合同不可执行）
- 任何意外行为 → 记录不停止
