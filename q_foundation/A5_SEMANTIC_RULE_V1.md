# A5 语义归一规则（独立辅助指标，冻结 v1.0）

> **定位**：仅作为**独立辅助指标**，**不进入**旧合同、V3 候选或评分器的正式评分。用于区分"A5 语义已修复但交付编码未通过"与"A5 语义未修复"。
> **零调用冻结**，不修改任何既有文件。

---

## 一、触发与映射

输入：SINK 的 A5 槽位值 $v$（字符串）。
输出：若满足全部 **5 个条件** → 归一为 `均无职务(仅实际控制人)`；否则**原样保留**（不映射）。

| # | 条件 | 判定方式（确定性字符串/正则） |
|---|---|---|
| **K1 身份** | 值中明确陈述"实际控制人"身份 | `实际控制人 ∈ v` |
| **K2 否定职务** | 值中明确陈述"未…担任任何职务" | `re.search(r'未.{0,12}担任(任何)?职务', v)` |
| **K3 主体一致（同句要求）** | 身份词与否定句必须出现在**同一句**（以 `。！？；` 分句），**不做跨句指代消解**；跨句一律不映射 | 按句切分后逐句检查 K1∧K2 |
| **K4 无矛盾** | 不出现"兼任/担任/出任/董事/监事/高管"等**肯定性职务**表述 | `not re.search(r'(兼任|担任(?!.*任何职务)|出任|董事|监事|总经理|高管)', v)` 且不出现肯定职务短语 |
| **K5 非默认推断** | 必须**显式**出现 K2 的否定句；仅"只提实际控制人、未提职务"**不映射** | 由 K2 保证 |

**K3 的实现边界（明确）**：本规则**不做指代消解**。身份词与否定句必须**同句**（`。！？；` 为界）；跨句（含"实际控制人。其未在公司担任任何职务"）一律不映射。这是保守取舍：宁可漏映射，也不误把他人/他句的否定职务表述归到该主体。

## 二、正例（应映射）

| 输入 | 命中 | 说明 |
|---|---|---|
| `均为实际控制人，未在公司担任任何职务` | ✓ | K1+K2 同句 |
| `实际控制人（除为公司实际控制人外，未在公司担任任何职务）` | ✓ | 括号内同一主体 |
| `实际控制人，且未在公司担任任何职务` | ✓ | 同句 |
| `两家公司均称其为实际控制人，其未在公司担任任何职务` | ✓ | 距离 ≤20 |

## 三、负例（不得映射）

| 输入 | 原因 |
|---|---|
| `实际控制人` | 缺 K2（仅未提及职务）——**正是当前失败模式，不得映射** |
| `实际控制人，兼任公司董事` | 违反 K4（肯定职务） |
| `未在公司担任任何职务` | 缺 K1（无身份） |
| `实际控制人，未在子公司担任职务` | K3 主体/范围不符（子公司≠公司） |
| `实际控制人。公司其他人员未担任职务` | K3 主体不同（他人） |

## 四、歧义例（保守：不映射）

| 输入 | 处理 |
|---|---|
| `实际控制人。其未在公司担任任何职务` | 跨句（句号分隔）→ 不映射（同句要求） |
| `经核查，未发现其担任职务的记载` | 非"未…担任任何职务"原式 → 不映射 |
| `实际控制人，据了解未任职` | 无"任何职务"表述 → 不映射 |

## 五、测试结果（2026-11-02 实测）

- 正例 **4/4** 映射
- 负例 **5/5** 拒绝
- 歧义 **3/3** 拒绝（含"实际控制人。其未在公司担任任何职务"跨句被拒）
- **错误接受 0 / 错误拒绝 0（12/12）**

**规则修订记录**：v1 初版用"距离 ≤20 字符"判主体一致，导致跨句歧义例被误映射；v1.0 改为**同句要求**后 12/12 通过。
