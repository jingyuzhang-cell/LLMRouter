# 动态策略实验预注册 V1（第 ⑤ 步，零调用设计，待审查冻结）

> 研究问题：**面对事先不知道错误类型的复杂 DAG 任务，系统能否仅凭执行反馈自主诊断错误家族并选择正确干预动作，在 Q/C/L 上优于固定策略与简单反馈策略？**（操作者 2026-11-01 定位：验证自主诊断与动作选择，不是验证人工规则表）

## 〇、总设计回答四个审查问题（摘要）

1. **测试集组织**：任务 A（PHASE2B，6 场景族 × 3 run = 18 场景）承载**完整 Q/C/L 后果回放**（全部后果有冻结实测数据）；任务 B（P1-1，4 场景族 × 3 run = 12 场景）承载**诊断层终点**（其修复动作尚无实测后果，只测诊断与动作选择，不测后果——如实分层）。
2. **盲化**：控制器输入 = 仅执行反馈（节点输出 + 零 LLM 确定性检测器输出）；错误标签仅存在于评估侧；机械保证 = 控制器代码的输入结构中无标签字段 + 输入日志审计。
3. **公平比较**：六臂同场景集、同后果矩阵、同信息可见范围（检测器输出对所有策略可见——Static/R/π 可见而不用）、同预算上限（每场景动作消耗按冻结实测成本计账，超顶不可用）。
4. **样本量与终点**：任务 A 18 场景配对比较（精确置换检验，预登记方向性假设，α=0.05 单侧，报告效应量；N 小、定性为探索-确认混合）；任务 B 12 场景仅诊断终点（描述性）。主终点见 §5。

## 一、六臂定义

| 臂 | 反馈使用 | 策略 | 回答的问题 |
|---|---|---|---|
| Static | 不用 | 冻结 X 链计划 | 基准 |
| R-only | 二值触发 | 任一检测器触发→只做结构动作 | 结构干预独立收益 |
| π-only | 二值触发 | 任一触发→只做 J2 换模 | 模型重分配独立收益 |
| **Simple-Dynamic** | 简单规则 | 首个触发信号→固定动作（预注册：任一异常→J2 换模重跑；无触发→不动） | 简单反馈规则的上限（**基线**，非本研究主张） |
| Fixed-Joint | 不用 | 无论信号一律全干预（结构+口径+格式） | 过度干预的代价 |
| **Proposed-Dynamic（主实验组）** | 完整签名 | 错误签名→家族诊断→匹配动作（含预算检查与保守默认） | **自主诊断+动作选择的价值** |

## 二、场景集构造（零新调用——全部由冻结实测数据构成）

**任务 A 场景族（6 × 3 run = 18）**，注入方式 = 从冻结臂回放真实状态：

| 场景族 | 构造 | 后果矩阵依据（冻结实测） |
|---|---|---|
| A0 无异常 | X 链健康状态 | 干预=过度干预代价（Fixed-Joint 在此测误触发） |
| A1 结构-日期切断 | 原始 J1（无 relay）状态 | 修复=R/X 臂实测；不修=Joint 实测（F1/F2/F4 失） |
| A2 结构-职务缺失 | 原始 E（无 positions）状态 | 修复=X 实测；不修=A5 失（Stage A 实测） |
| A3 口径-E2 | 原始 J2 提示词状态 | 修复=消歧实测（节点 6/6、终端 5/6）；不修=4/4/4 |
| A4 格式-编码漂移 | X 链 SINK 原始输出（格式层前） | 修复=格式层实测（+20/28）；不修=47→27 |
| A5 模型-J2 计数错 | Joint 臂 J2J 状态（计 3/2/3） | 修复=换模实测（1/3，不稳定——如实入矩阵） |

**任务 B 场景族（4 × 3 run = 12）**：B0 无异常（P1-1 实测健康态）；B1 口径-程序归属（INV/FD 程序维歧义实测态）；B2 口径-状态持续性（VF_S3 型实测态）；B3 方差-首披边界（VF_S1 型）。**B 任务终点只含诊断/动作选择与误触发**（修复后果无实测，不做回放宣称）。

## 三、反馈信号与诊断（控制器可见的全部信息，零 LLM）

**检测器（确定性，8 个）**：D1 解析有效/stop 位；D2 模式完备（18 候选/relay 字段在位）；D3 枚举纯值（值∈词表）；D4 SINK 完备（槽全答+拒判位）；D5 转写完整（J2 中继哈希等值=CL-1 检查）；D6 计数内部一致（personal≤announcing、d3_subject 与绑定条数一致——只用 DAG 自身输出，不用 Gold）；D7 引文在源（quote 含于 source_pages，CL-3 绑定口径）；D8 跨槽自洽（B1=B2→E1≤1 等派生图一致性，合同 derivation 逻辑非 Gold 值）。

**诊断映射（预登记）**：D2/D5 失→结构族；D3 失→格式族；D6 失→口径族；D1/D7 失→模型族；D4 失→结构族（切断）优先；全过→无动作（保守默认）。多信号并存按签名组合判族（预登记映射表，附于执行文件）。

**动作空间（仅已实证机制）**：结构→E 补充抽取/J 中继修复；口径→对应计数/语义澄清附录；格式→确定性合同编码（R1 系）；模型→J2 换模（后果按实测 1/3 计）；不确定→UNKNOWN/不动。每动作成本=冻结实测（调用数/tokens/时延），入预算账。

## 四、盲化与公平机制

- 控制器（Simple/Proposed）输入数据结构固定为 `{node_outputs, detector_outputs, budget_state}`——**无标签字段**；场景标签只在评估器内存留。
- 所有六臂跑同一场景序列，逐场景配对；后果查表函数对所有臂同一份（动作→冻结实测结局），评估器不区分调用者。
- 预算：每场景上限 = X 链边际成本 × 2（¥核算口径与调用数双限）；超限动作不可选（控制器须在预算内选）。
- 无异常场景（A0/B0）专测误触发：Proposed 必须输出"无动作"。

## 五、终点与统计（预登记）

**主终点**：
- E1（任务 A，后果层）：Proposed-Dynamic 的终端 Slot Success **逐场景配对 ≥ 全部五基线**（精确置换检验，H1: Proposed 优于最强基线，单侧 α=0.05；同时报告 vs 每臂的配对胜负计数与效应量）。
- E2（两任务，诊断层）：家族诊断准确率 ≥ 80%（30 个有错场景）；无异常误触发率 ≤ 1/6（6 个无错场景中至多 1 次误动作）。
- E3（动作选择）：有错场景中正确动作选择率 ≥ 75%（"正确"= 与该家族已实证最优修复一致）。

**次级终点**（分开报告，禁止互相替代）：Q 三层（节点语义/终端事实/合同合规）；C 总量/修复增量；L 顺序 Makespan 与按期率（同预算内）；可靠性=各族错误恢复率；调度能力=诊断准确率/动作准确率/误干预率。**恢复成功率不替代终端事实质量。**

**样本量声明**：任务 A 18 场景（6 族×3），配对设计下置换检验最小可检出一致性 15/18（83%）；N 有限，结论定性为"探索-确认混合"，论文表述不带参数显著性膨胀。

## 六、执行形态与预算

- **Tier 1+2（本预注册范围）：零 API 调用**——场景回放、检测器、控制器决策、后果查表、统计全部确定性计算。
- Tier 3（可选后续，另行授权）：对 Proposed 选择的关键 (场景,动作) 单元做真实在线重执行抽验（预计 ≤ 15 调用），验证回放后果与在线一致。
- 产物目录：`/root/research_outputs/static_pi/stage_c/`（场景构造器 + 后果矩阵 + 控制器 + 评估器 + 报告，一次性最小实现，无新工程模块复用既有 transport/评分器）。

## 七、风险与边界（预登记）

- 后果查表granularity：动作在非精确匹配状态下的后果以最近实测状态近似时**标注 approximation**，不 silently 外推。
- 模型族修复实测不稳定（1/3）——Proposed 若诊断模型族，其期望后果按实测分布计（3 次中 1 次成功）——动态控制器无法超越机制本身的可靠性，这正是诚实对照的一部分。
- 本实验验证**诊断与选择层**；机制层可靠性（如换模 1/3）是独立研究问题。
- B 任务后果层留白为诚实边界，后续单独授权补。
