# Stage D 预注册：真实动态 DAG 调度确认性实验（零调用设计，待审查冻结）

> 研究问题（操作者五问）：多节点并发执行时能否动态调整？模型资源槽竞争时能否重分配？节点异常后能否重算剩余 DAG 计划？预算与截止时间变化时能否选更优恢复方案？最终能否同时改善 Q/C/L？**三条纪律预锁死：①主对照=Proposed vs Simple-Dynamic（不是只赢 Static）；②恢复成功率不替代终端质量（三层质量保留）；③资源竞争必须真实发生（K_m < 并行宽度 + 紧截止期强制约束）。**

## 一、真实执行环境（一次性最小实现，无新工程模块）

- **DAG 状态机**：节点 Ready/Running/Completed/Failed/Invalidated；边依赖触发；**已完成节点不重复执行**（版本感知失效：仅结构变更的下游重算——传播审计机制的真实应用）。
- **并发**：线程池按模型资源槽调度（transport.py 纯函数无锁，前置检查已确认直连路径无串行化——真实并行可行，Makespan 为真实墙钟）。
- **资源槽**：**K_glm=2、K_ds=1**（任务 A 的 E 层 4 节点并行宽度 > K_glm → 排队竞争必然发生；换模决策真实占用 K_ds）。
- **约束**：每执行剩余预算（调用数+¥双限）与截止时间 D（预登记：D=180s/执行，紧至错误恢复路径可致超期）；实时可见于调度器。
- **故障注入**（评估侧持有标签，调度器盲）：按预登记时刻表注入——S1 结构故障（E2 节点输出被剥夺 positions 字段——真实节点完成后确定性篡改）；S2 口径+模型混合（J2 使用原始歧义提示词 + J2 一次真实调用注入超时异常触发重试路径）；S0 无故障对照（测误触发与过度干预代价）。
- **在途诊断**：节点完成即跑 Stage C 检测器（8 个，D5/D7 处置沿袭 V1.1）+ 在途信号（超时/stop_reason/解析失败）。

## 二、六臂（Fixed-Composite 为辅助参考臂）

| 臂 | 异常时行为 |
|---|---|
| Static | 不重规划（按初始计划执行完，含故障后果） |
| R-only | 任何异常 → 结构恢复（补字段+下游失效重算） |
| π-only | 任何异常 → 故障节点换模重跑 |
| Simple-Dynamic | 任何异常 → **同模型重试故障节点**（naive，Stage C 冻结版） |
| **Proposed-Dynamic** | **a_t=(Z_t,R_t,π_t)**：诊断→恢复范围 Z（仅必要子图）→重执行集 R（已完成节点除外）→剩余节点模型重分配 π（考虑 K_m 空闲、剩余预算、截止期、关键路径——预登记决策规则表） |
| Fixed-Composite（辅助） | 异常即全干预（质量上限/成本代价参考，不入主检验） |

**Proposed 决策规则（预登记，确定性可审计）**：结构族→补全+最小下游重算（R=受影响下游）；格式族→零调用编码层；口径族（若 D6 触发）→J2 消歧重跑+SINK；模型嫌疑（D1/在途异常）→若 K_ds 空闲且剩余预算≥2 调用且关键路径余量>预计换模时延→换模，否则同模型重试一次；UNKNOWN→不动。**截止期压力规则**：剩余时间 < 关键路径剩余预计时延 ×1.2 → 放弃非必要恢复（保按时完成）。

## 三、场景与预算（分层执行，操作者可选）

- 场景：S0/S1/S2 × 每 arm。**Tier D1（先导）**：1 run × 3 场景 × 6 臂 ≈ 18 次执行 × ~8 调用 ≈ **150 次调用**（GLM 订阅实际 ¥0 + DS 按账单；核算约 ¥0.6）；预计墙钟 ~35-50 分钟（并发 2-3）。**Tier D2（确认）**：+1 run（同配置）≈ +150 次，仅当 D1 机制无异常后执行。

## 四、终点与统计（预登记）

**共主终点（Tier D2 为确认性，D1 为先导校准）**：
- **P1 质量**：Proposed vs Simple-Dynamic 终端 Slot Success 优效（场景族配对，单侧符号检验；3 族×2 run）；
- **P2 按时率**：截止期内完成率 Proposed ≥ Simple-Dynamic（且 ≥ Static——若动态恢复致超期则如实暴露）；
- **P3 成本**：恢复增量成本 Proposed ≤ Simple-Dynamic。
- 次级（Holm 校正）：vs R-only/π-only/Static；Makespan 中位数对比；三层质量分列；诊断/动作/误干预率；恢复成功率**仅作可靠性指标**。
- 样本量声明：6 执行/臂（D2）为方向性确认，配对符号检验最小可检出 5/6 一致（p=0.031）；不足则如实报探索性。

## 五、风险与边界（预登记）

- 并发下 API 限流/5xx：单次重试（15s）后如实记录节点失败——节点失效率本身入指标；
- Makespan 含网络抖动：D2 双 run 配对缓解，报告逐执行原始值；
- 口径族不可辨识（Stage C 结论）在 S2 的表现预期=Proposed 保守不动而 Fixed 全干预——质量差预期存在，按 V1.1 边界如实呈现；
- **通过标准不降**：P1-P3 全过才称"反馈驱动联合动态调度确认"；任一不过如实报告并归因。
