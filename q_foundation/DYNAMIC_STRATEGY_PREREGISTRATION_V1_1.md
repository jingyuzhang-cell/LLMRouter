## 修正四 · 臂定义统一

- **Static = 固定初始计划、固定模型分配、不根据运行反馈改变执行策略**——即原始冻结计划（原提示词、全 GLM、无中继/消歧），非 X 链（X 链已内嵌修复，作 Static 则不公平）。
- 基线计划（所有臂共用）= X 链计划（含在线格式层这一零成本确定性系统组件）；场景 = 基线计划在故障条件下的执行状态。
- **Fixed-Composite**（改名，区别于历史 Joint=结构+换模）= 无论信号一律 结构+口径+格式 三干预。

## 修正五 · 统计口径

- **推断单位 = 任务 A 的 6 个场景族**（族内 3 run 为重复，报告族配对平均差；18 场景逐 run 描述性另报）。
- **预指定共主终点**：E1a Proposed vs Fixed-Composite 终端 Slot Success **非劣效**（边际 = 不可辨识故障的预期质量差，预登记 4 槽 ≈6% 绝对值）；E1b Proposed vs Fixed-Composite **成本优效**（逐族配对）；E1c Proposed vs Simple-Dynamic 质量**优效**（关键次要，Holm 校正）。其余对照 Holm 校正报告。
- 单侧 α=0.05；精确置换检验（6 族为单位的符号检验）；效应量必报。
- 后果单元格 EXACT 主分析 / 混合敏感性（见修正二）。

## 修正六 · 结论边界

- 本实验验证**反馈驱动的诊断与动作选择**；无预定义 Q/C/L 效用函数 → **不宣称 Q/C/L 联合最优**（只报同预算下的 Q/C/L 分项）。
- budget_state 完整规格：剩余预算（调用数+费用双口径）、剩余截止时间、各模型可用资源槽 K_m、已完成/运行中/待执行节点集、剩余执行计划。
- **Tier 1+2 = 离线回放**：结论限于冻结后果矩阵上的策略表现；Tier 3 抽验（≤15 调用，另授权）部分验证在线一致性，不替代并发/资源竞争/Makespan 的完整在线验证（如实声明）。
- **可观测性边界为第一科学结论**：口径族与模型计数族对内部反馈不可见（B 任务尤甚）——反馈驱动调度的质量优势受诊断可观测性上界约束，此发现本身构成论文贡献（指向更丰富反馈信号的未来工作）。

## 验收结构（六层，独立报告禁止互相替代）

诊断（E2a/b/c）→ 动作（E3）→ 安全（误触发）→ 质量（E1a/c + Q 三层）→ 成本（E1b + 增量）→ 时延（顺序 Makespan 如实比较）。
