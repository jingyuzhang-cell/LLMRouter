#### 4.1.2 模型池与执行协议

模型池：GLM-5.3（订阅）、GLM-5.3-Flash（订阅）、deepseek-flash（按量，分时段计价）、

标定（抽取 2048/2560、中游 2560、核验 4096、报告 2048）；三层契约解析（严格 JSON /
控制字符兼容 / 不修复截断与引号错误，分层记录）；90 秒硬截止期（调用前检查、P90 校准
预检、到期硬停，预测取 max(实测×1.15, P90, 统计×1.6)）；统一持久账本、响应先持久化、
断点不重复计费。

#### 4.1.3 故障场景

- **发现 1（时延异构）**：同类型节点跨模型时延差 2.4–2.8×（实体关系最显著），构成

### 4.3 RQ2：反馈驱动动态恢复的必要性

**表 4-2 F7 故障下无恢复 vs 反馈恢复（质量为 T1 字段级+证据链）**

| 条件 | 康得新（e4-v2, n=1） | 舜天（stv2, n=3） |
|---|---|---|
| 无故障基线 | 4/8 | 3/3 |
| 静态混合 + F7 无恢复 | **1/8**（崩溃） | — |
| S5+Capability + F7 | 1/4（可达上限 3/4） | 2/3 ×3 |
| S6 联合 + F7 | 2/4（=上限） | 2/3 ×3 |

- **发现 3（恢复必要性成立）**：关键节点失效使固定分派质量崩溃（4/8→1/8）；任何
  反馈恢复（查表级即可）把质量追回**场景允许的上限**。
- **发现 4（上限由证据供给决定）**：恢复后两策略质量完全相同（ST 三次重复逐条一致），
  上限受检索可达性与报告长度取舍约束，不由恢复策略决定。ST 的 RF7 丢失机理可逐层
  追溯（精确金额仅存在于公司公告线；恢复后更丰富的年报细节挤占 800 字报告焦点）。

### 4.4 RQ3：联合动作 a=(Z,R,π) 的增量

**表 4-3 S6 vs S5+Capability（同故障、同证据、同 90s、同评分）**

| 维度 | 康得新（n=1） | 舜天（n=3，均值） | 判定 |
|---|---|---|---|
| 质量 | 2/4 vs 1/4 | **2/3 vs 2/3（完全相同）** | 无差异（KDX 单次差可由内容方差解释） |
| 端到端时延 | 64.6s vs 71.7s（−9.8%） | 69.1s vs 73.1s（−5.5%，区间重叠） | 方向性优势，n=1/3 均不显著 |
| Token | −4.5% | −4.9%（区间重叠） | 不显著 |
| 现金 | +¥0.017（+76%） | +29% | **S6 恒更贵**（DS 买时延） |
| Z | LOCAL | LOCAL ×3（决策完全确定） | 可行动时恒 LOCAL |
| R | LOCAL 闭包 | LOCAL 闭包 ×3 | **从未偏离**，动态 R 无实证 |
| π | 改 4 节点 | 改 4 节点 ×3（同解） | 唯一活跃维度 |

- **发现 5（π 的机制可追溯但不显著）**：S6 联合分派的 t4→deepseek（8.5s vs GLM 同节点
  14.5–21.0s）是时延收益主要来源；查表规则（质量并列取列表序）结构上做不出该选择。
  但两事件的收益量级均落在重复方差带内。
- **发现 6（Z 的守门价值）**：截止期不可行时联合调度器选择 NONE（拒绝不可行动作），
  真实触发一次（违约前 4 秒，决策耗时 0.25s）；可行动时 Z 恒为 LOCAL——Z 的价值是
  **硬约束下的可行性守门**，非优化优势。
- **结论**：在本文实验条件下，简单反馈恢复已足够；S6 的增量表述为**条件性收益与
  适用边界**（紧截止期 + 大异构时延差时方向性占优，代价是更高现金）。

### 4.5 协议演化与有效性讨论

#### 4.5.1 协议演化（作为方法贡献与威胁控制写入）

1. 证据层：发现 600 字预算均分导致空检索（120 字/文档 < 450 字块）；修复为全局贪心
   整块填充+非空保证+双预算（回归锁定）；多查询 RRF 重排序为 DEV 负结果（更差），
   窗口大小才是主导杠杆（KDX 10K→20K 达 4/4 锚点可达；事件依赖：ST 10K 即 3/3）。
2. 执行层：输出上限按实测标定（t5 需 4096：GLM 110 tok/条×最坏 35 条）；契约解析分层
   （严格/兼容分开记账，兼容永不冒充严格）；截止期从事后观察改为事前行为控制。
3. 度量层：评分从锚点子串演进为字段级规则（双向纠错：语序变体计入、缺主体不计）；
   全版本并存、跨版本不比较。
4. 工程事故披露：一次并发双进程额度突破（OS 排他锁整改）、一次截断级联（上限重标定），
  均完整留痕并转化为威胁控制。

#### 4.5.2 有效性威胁

小样本（KDX n=1、ST n=3，质量方差带未完全闭合）；两事件均 DEV（检索规则含 DEV 开发的
负结果，独立确认需第三事件）；T1 非完整 Gold；单故障族（绑定级不可用）；DS 分时段计价
（高峰轮现金可比性注明）；评分两版本并存（本文所有结论仅用 v2 口径）。

### 4.6 本章小结

1. **RQ1 成立**：节点级异构时延差 2.4–2.8×，抽取层内容保真亦有模型差异——分派问题
   有真实优化空间。
2. **RQ2 成立（门槛低）**：反馈恢复对故障崩溃的追回真实且可靠，查表级简单恢复即可
   达到场景质量上限。
3. **RQ3 部分否定（如实）**：联合 (Z,R,π) 中 π 有方向性、不显著且更贵的时延收益；
   Z 有守门价值；R 无偏离证据。联合调度的贡献应表述为**截止期硬约束与强异构时延
   场景下的条件性收益**，其边界由本文首次给出受控测量。
