# KDX_JOINT_ACTION_DEGENERACY_AUDIT — 联合动作空间退化审计（零付费）

## 1. 退化根因（三个维度）

### R 维度退化
LOCAL R = {t1,t2,merge,t3,t4,t5,t6}（7 节点）vs FULL R = 全部 8 节点（含 t0）。
差异仅 t0（已完成，缓存有效）→ **LOCAL≈FULL，Z 维度几乎无选择空间**。
根因：t1/t2 是近根节点，故障阻断全部下游→合法重执行集合被迫为全闭包。

### π 维度退化
t1/t2 同为 fact_extraction 类型→同一能力表行→**最优模型相同**→无按分支分配差异。
69,633 个枚举候选中的绝大部分是"同类型节点交换模型"的冗余组合。

### 目标函数退化
NONE 得分 = -1（硬编码），不是 -∞。当 w_q 低时，恢复动作得分 ≈ -w_c×cost（负值），
NONE 的 -1 可能**优于**高成本恢复→**产生错误的放弃激励**。
修复：引入完成奖励 `completion_bonus=10.0`，使任何恢复动作的得分高于 NONE。

## 2. 边界扫描发现的真实分离类型

7/8 场景出现动作分离，但分离来源不同于预期：

| 分离类型 | 场景 | 机制 | 研究价值 |
|---|---|---|---|
| **Z=NONE 识别不可行** | F2a/F2b/F4/F5 | t5(核查)仅 GLM-5.3 有产出(Q>0)；屏蔽后 S6 正确判定任务不可完成并放弃；S4/S5 盲目分配 Q=0 的模型 | **高**——S6 避免了浪费资源的无效恢复 |
| **π 优于固定规则** | F1b/F5/F6 | S4 固定"换 GLM-5.3"但 GLM-5.3 被屏蔽→退到 Flash(次优)；S5/S6 正确选 DeepSeek | **中**——S5 也能做到（查能力表），S6 与 S5 收敛 |
| **无分离** | F1a/F3 | 屏蔽 DeepSeek→GLM-5.3 是明显次优→所有策略收敛 | **诚实边界** |

## 3. 核心洞察

**S6 的真正价值不在于"找到更好的 π"，而在于"识别不可行并诚实放弃"。**

- S4/S5 盲目分配模型即使该模型在此节点类型上 Q=0（如 Flash/Qwen 做跨源核查）
- S6 通过质量约束正确判断"没有模型能完成此节点类型"并选择 NONE
- 这避免了**无效的资源消耗**（执行注定失败的恢复）

**第二价值：当 S4 的固定规则遇到边界情况时，S5/S6 的能力表查询提供更好的选择。**
- S4 固定"换 GLM-5.3"在 GLM-5.3 被屏蔽时失效（退到 Flash）
- S5/S6 正确选择 DeepSeek（能力表最优可用模型）

## 4. 调度开销
S6 决策耗时 727ms（8 节点×4 模型枚举）。必须计入端到端墙钟。
对于 <10s 的短任务，此开销 >7%；对于 >60s 任务，<1.2%。
