# KDX_Q_PROXY_VALIDITY_AUDIT — S6 质量可行性判断有效性审计（零付费）

## 1. S6 当前使用的质量指标

S6 的两阶段决策中，"质量下界"约束使用能力表的 `Q_output_ratio`：
```
feasible ⇒ min(Q_output_ratio(n, π(n)) for n in R) ≥ q_min
```

## 2. Q_output_ratio 的含义与局限

| 维度 | Q_output_ratio 的实际含义 | 不是什么 |
|---|---|---|
| 定义 | 模型平均产出条目数 / 该类型最多产出条目数 | ~~模型正确率~~ |
| Q=1.0 | 该模型在此类型产出最多 | ~~100% 准确~~ |
| Q=0.0 | 该模型产出零条 | ~~0% 准确~~（可能是提示词/证据问题） |
| 数据源 | 80 次真实调用的 JSON 条目计数 | 未经过 Gold 对齐 |
| 样本量 | n=3-6/格 | 不足以估计置信区间 |

## 3. S6 质量约束的可信度判定

**当前 Q_output_ratio 只能作为启发式代理**：
- 它可能区分"完全不产出"与"有产出"的模型（如 Qwen 主体关系 Q=0 vs GLM Q=1.0）
- 但不能区分"产出多但质量差"与"产出少但质量高"
- 对 S6 的影响：质量下界约束过滤掉 Q=0 的模型（合理），但无法在 Q>0 的模型间做可靠的质量排序

**结论**：S6 的质量可行性判断**目前是启发式代理，不是质量保证**。
- 在事实提取上排除 Qwen（Q=0.74 但可能质量不差）或选择 DeepSeek（Q=1.0 但可能质量不高）
  都可能是次优决策
- **Gold 完成后**：Q 应替换为 Gold 对齐的 Precision/Recall/F1——届时 S6 的质量约束才有
  可信基础
- **过渡方案**：将 q_min 设为仅排除 Q=0 的模型（即"有产出"而非"产出多"），避免过度依赖
  不可靠的产出量排序
