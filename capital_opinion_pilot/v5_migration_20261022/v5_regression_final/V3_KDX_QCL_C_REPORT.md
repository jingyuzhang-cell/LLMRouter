## 三、发现

1. **Flash 契约首试 2/2 通过**——与此前 0/8 记录相反。结论修正：**契约失败是提示形态/负载
   依赖的，不是 Flash 的稳定属性**（此前失败集中于长证据注入的 extracts 类提示）。
   对 RQ1 的含义：模型选择须联合考虑节点提示形态，不能只用模型标签。
2. **C 与 B 的 Q 完全一致（提取约束型的再次验证）**：下游无论谁执行，终报 Q 都被提取层
   封顶（3/7）。异构分配没有损失质量，还把引用正确率从 0.33 提到 0.67（单样本）。
3. **成本持平而非下降**：本节点规模下 Flash 与 GLM-5.3 单调用 token 同量级（节省此前来自
   "避免修复"，本轮两者都无需修复）。"便宜模型"的收益在这个粒度上不体现为 token 节省。
4. 时延：Flash 两节点略慢（6.0/10.7s vs 5.5/7.9s）——与本端点两类模型的实测服务时延一致。
