# EXPERIMENT_VALIDITY_AUDIT — 历史实验有效性统一审计（零付费）

## 一、统一有效性判定机制（自本轮起强制）

每个臂/结果必须带以下标签之一，且写入结果 JSON 的 `validity` 字段：

| 标签 | 定义 |
|---|---|
| `VALID` | 全链无截断、无失败节点、同会话计量、协议一致 |
| `VALID_WITH_CAVEATS` | 完整执行但带声明的口径限制（跨会话时延/价格未知/复用摊销） |
| `INVALID_CONFOUNDED` | 输出截断/管道塌陷等混杂未消除，仅可作过程证据 |
| `REPLAY_ONLY` | 离线回放/打捞产物，禁止当作实测质量收益 |

## 二、逐轮审计结论（81 次调用 / 204,490 token 全量复查）

| 轮次 | 截断次数 | 有效性判定 | 复用/成本口径问题 |
|---|---|---|---|
| V1 舜天 | 5/15 | INVALID_CONFOUNDED（规划截断+输出丢失）；证据库/事实层 VALID | 最保守口径超限已披露 |
| V2 自主规划+执行 | 0/23 | 全图 VALID_WITH_CAVEATS（跨会话时延；规划摊销另计） | t0 修复 1 次（含在账） |
| V2.1 三臂 | 2/10 | 单模型臂 INVALID_CONFOUNDED（448 截断）；DAG 臂 VALID_WITH_CAVEATS；异构臂 INVALID_CONFOUNDED（t5 预算拦截+继承终报） | 超限 1,084（崩溃重跑重复付费） |
| V2.2 无截断基线 | 1/1 | VALID_WITH_CAVEATS（768 仍触上限但覆盖已达证据包天花板，Q 为紧下界） | — |
| 康得新规划系列（4 轮 7 次） | 3/7 | 两个合法图 VALID；其余 INVALID（截断/接线）+1 个打捞编译图（REPLAY 属性已标注：编译恢复≠LLM直接生成） | — |
| QCL A+B | 3/8 | 双臂 INVALID_CONFOUNDED（ArmA@896、t1/t2@768 截断） | 守卫两口径首次同时达标 |
| 补全轮 | 1/5 | **B 臂下游 VALID**；ArmA v2 VALID_WITH_CAVEATS（1,536 仍截断，Q 为下界） | 提取层复用=打捞（REPLAY 属性），成本已按真实历史支出计 |
| C 臂 | 0/4 | **VALID**（全链无截断；同会话） | 与 B 同输入同契约（唯一变量=分支模型）✓ |
| D 臂 | 0/8 | **VALID（探索性）**：恢复调用全真实；故障为注入处置（声明）；基线节点输出自历史响应回放（REPLAY 属性仅限未受故障影响的受保护输出） | 每种子单次 |

**主要混杂排序**：① 输出截断（15 次调用受累，波及 4 个臂的判定）＞② 跨会话时延配对（B 臂/舜天 DAG 臂）＞③ 价格不可知（全部，订阅制）＞④ 复用/打捞的 REPLAY 属性区分（已在册）。
