# KDX_CLOSURE_GATE_ABLATION — S5+ClosureGate 消融：S6"独有优势"归因分析（零付费）

## 核心发现：F4/F5 的 S6"独有优势"在加入 S5+ClosureGate 后完全消失

**此前声称**：S6 通过联合闭包分析识别不可行恢复→独有优势（F4/F5 两场景）。
**消融结果**：S5+ClosureGate（固定分配+闭包级质量门禁）也选择 NONE→**Gate 完全解释，S6 无独有增量**。

## 结论：S6 当前无联合优化独有增量

**审稿人指出的问题是正确的**：S6 的"优势"来自闭包级可行性检查，不是联合搜索。
一个设计良好的 S5+ClosureGate（固定分配+闭包级门禁）在全部 8 个场景中与 S6 等效。

### 对论文的影响

**不能声称**：
- "联合选择 Z/R/π 优于固定恢复"——不成立（0/8 独有优势）
- "S6 通过联合搜索发现固定策略遗漏的恢复方案"——不成立

**可以声称**：
- "闭包级可行性门禁避免了在注定失败的任务上浪费资源"——成立，但这是门禁的贡献不是联合搜索的
- "在当前模型池和 DAG 结构下，联合优化与固定恢复的决策差异为零"——诚实的边界发现

### S6 何时才可能有独有增量？

| 条件 | 当前状态 | 需要什么 |
|---|---|---|
| 不同节点类型需要不同模型且某节点被屏蔽 | 部分满足（F4/F5 有异构故障） | 但 S5+CloGate 也能识别不可行 |
| 存在多条合法恢复路径且 S6 选到更好的 | **不存在** | 需要多个"足够好"的模型在不同维度有权衡 |
| Z 维度有真正选择空间 | **不存在** | LOCAL≈FULL（t0 缓存） |
| 质量代理能可靠区分模型能力 | **不存在** | Q 是产出数量比，不是正确率 |
| R 维度可选择性保留部分分支 | **不存在** | 近根故障阻断全部下游 |
