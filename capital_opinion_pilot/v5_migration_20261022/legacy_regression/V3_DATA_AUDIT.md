  adjunctUrl（第一轮曾因猜测 URL 出现 404，已废弃猜测方式并全部改用接口返回值）；每份记录
  SHA256、字节数、公开日期、pdftotext 提取字符数；公开日期全部 ≤ 各事件调查截止日。
- **19/19 种子事实确定性接地通过**（逐字引文在全文命中、答案日期 ≤ 截止日、证据文档存在），
  见 `v3_evidence/*/facts_seed.json`。**状态为 seed**：尚未做跨模型 AI 核验（留待授权阶段，
  流程复用 V1 facts 管线）；明确不是人工 gold。
- 巨潮接口（topSearch + hisAnnouncement/query）可用且稳定；证监会/网信办官网不需要（本轮证据
  全部为公司公告口径，监管文书内容经公告转述并标注文号，可程序复核）。

## 已知限制（如实记录）
1. **C 类关注函回复公告不可达**：视觉中国对深交所关注函的回复在巨潮全文检索中未命中
   （多关键词 0 结果）。C 类主证据因此定为 3 份公司公告；深交所关注函与网信办约谈的细节在
   公告中有官方转述（可引用），媒体源（新华/央视/人民网）仅作背景不入事实。
2. **网信办原始通报页未直接检索到**（cac.gov.cn 站内未返回 2019 年原始通报 URL）；天津网信办
   4-19 行政处罚经恢复公告 2019-017 官方转述（含文号与金额），满足可核验要求。
3. **B 类表格数字提取受限**：资金占用/担保专项报告的表格经 pdftotext -layout 后数字错位，
   种子事实因此避开表内数字，仅采用正文叙述句。V3 正式阶段若需表格数字，应先升级 PDF 表格
   解析（见"框架缺口"）。
4. A 类问询回复体量大（5.7 万/4 万字），注入式检索工具需要分段定位能力（见下）。

## 现有调度框架需要新增的节点契约与工具（交付问题之一）
1. 契约缺口：
   - `multi_year_recon.v1`（reasoning）：多年度财务口径对比（事件 A 的跨年度分支需要）；
   - `entity_graph.v1`（extraction）：多主体关系与担保/占用链抽取（事件 B）；
   - `source_trace.v1`（verification）：消息源溯源与官方转述核对（事件 C）。
   既有 index/extracts/timeline/entity_facts/factcheck*/report 契约可复用。
2. 工具缺口：
   - 分段检索注入：按 doc_id + 关键词窗口截取（A 类长文档无法整篇注入）；
   - PDF 表格解析（B 类专项报告的金额表）；
   - 多文档证据包打包上限与选择策略（当前 evidence_pack 为固定拼接，需参数化）。
3. 计量：Meter v2 已支持分账本/双口径/断点续跑，可直接承载三事件并行目录。
