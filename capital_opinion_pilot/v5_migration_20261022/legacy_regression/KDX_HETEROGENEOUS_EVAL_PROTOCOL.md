# KDX_HETEROGENEOUS_EVAL_PROTOCOL — 异构模型 Q/C/L 实验协议（任务四，零调用冻结）

本协议在**任何后续付费调用之前冻结**。对应研究问题：
RQ1 节点级异构 Q/C/L 差异是否存在且可利用；RQ2 节点实例失效后的动态重分配/局部恢复是否有实际
收益；RQ3 预算/截止时间约束下是否存在优于固定分配的 Pareto 方案。

## 一、四臂对照设计

| 臂 | 构成 | 前置条件 | 现状 |
|---|---|---|---|
| A 单强模型 | GLM-5.3 单次调用 + **同一分段检索工具**（同预算同配额） | 可执行事件 | 舜天✅ 立即可做；康得新❌缺可执行图 |
| B 固定模型 DAG | 合法 DAG 全节点 GLM-5.3 | 合法且资源可行的 DAG | 舜天✅（V2 已有，可加受控重复）；康得新❌ |
| C 静态异构 DAG | 规划图 + 事先固定的节点→模型映射 | B 成立 + RQ1 信号 | 待授权 |
| D 反馈驱动动态调度 | 异常识别→合法局部恢复→模型重分配（复用 recover_failed 语义：仅失败节点可重路由，完成输出受保护） | C 成立 | 后续阶段 |

公平性硬约束（继承 V2.1/V2.2 教训）：四臂共用冻结证据库、同分段检索工具与配额、同评分器与
silver 集、同输出契约；**输出预算配平**（各臂 max_tokens 相同，杜绝 V2.1 截断混杂）；
基线臂享有与 DAG 臂等价的检索访问（不得给 DAG 独有信息）。

## 二、节点级 Q/C/L 测量协议

**Q（三层分离，禁止混报）**
1. 内容质量：silver 覆盖率（full/partial 两级，Q=(full+0.5×partial)/N）+ 引用正确率
   （按事实上下文 doc_id 引用 vs silver 证据文档）+ 未验证日期标志；
2. 契约合法性：首试通过率 / 修复后通过率（parse 与内容分开）；
3. 确定性打捞：可打捞率与打捞后内容质量（零 token 程序成本）。

**C（全成本记账，含 V2.1 教训的"完整成本 vs 增量成本"双口径）**
- 规划摊销（规划调用实际消耗）；
- 检索/注入成本（证据 token，按块出处可追溯）；
- 模型调用（首试+修复分开记；失败调用照记）；
- 程序开销（合并/打捞/验证的毫秒级运行时间；零 token 但入账）；
- 复用标记：跨请求缓存复用记 0 新增，但完整成本口径按历史真实支出计入；
- 价格：真实逐调用计费不可得（订阅制），标记 UNKNOWN，token 为成本基数——**禁止折算虚构美元**。

**L**
- 逐调用服务时延（账本 latency_s）+ 程序时间；端到端墙钟仅同会话内可比，跨会话只作描述性
  比较（V2.1 已确立）；C/D 臂的调度决策时间单独记账。

## 三、重复与稳定性

- 受控重复：同 (node, model, prompt_sha) 的有意重复须用显式 rep 标记（purpose 后缀），
  预算内 k≥2（V2 已示 Flash 行为跨两次重复稳定、GLM-5.3 稳定）；
- 每臂同输入以 prompt_sha256 相等性核验；评分全离线零调用。

## 四、判定规则（事前冻结，防事后择优）

- RQ1"可利用"判据：某模型在某类节点上，在 Q 不显著低于对照的前提下，成本或时延存在
  ≥30% 的可重复优势；或契约失败可由确定性打捞零成本补偿。
- RQ2"恢复收益"判据：注入节点实例失效后，D 臂相对 C 臂的完成率/Q 恢复增益 > 恢复调用成本
  （按 token 记）。
- RQ3"Pareto 改善"判据：在 (Q≥Q_min, C≤B_max, L≤T_max) 约束下，C/D 至少一个分配方案
  非支配且优于全部固定分配基线；hypervolume 口径在正式阶段单独冻结。

## 五、纪律条款

- 不得用模拟输出/占位结果声称任何真实收益（延续 V1 起的零模拟规则）；
- silver 与 gold 严格区分标注；规划器与执行节点永不接触 facts 文件（提示哈希可审计）；
- 全部调用经校准预算守卫；超限哨兵触发即停并汇报；
- 每阶段模型调用须单独预算授权；本协议本身的任何修改须在调用前重新冻结并注明版本。

## 六、当前可执行性判定（衔接任务三）

- **舜天事件：A/B/C 三臂条件齐备**（V2 图合法且证据规模可行；C 臂需新授权）；
