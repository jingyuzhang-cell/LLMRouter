## 一、四臂设计（公平证据访问）

所有臂共用：冻结证据库、**同一检索器与分配策略**（A_idf + 长度比例分配）、同注入预算档、
同 silver 评分器、同输出契约与输出上限（杜绝 V2.1 截断混杂）、同信息截止日 2021-06-30。

| 臂 | 构成 | 检索访问 |
|---|---|---|
| A 单强模型 | GLM-5.3 单次调用 | 两线检索结果合并注入（与 DAG 臂同预算同内容） |
| B 固定强模型 DAG | 冻结分化图全节点 GLM-5.3 | 每 extracts_f 节点=其作用域检索结果 |
| C 静态异构 DAG | extracts_f 线=GLM-5.3-Flash(+确定性打捞)，分析/核查/报告=GLM-5.3 | 同 B |
| D 反馈驱动动态 | C + 节点实例失效注入→合法局部恢复（recover_failed 语义：仅失败节点可重路由、完成输出受保护） | 同 B/C |

## 二、成本记账口径（全成本，逐项）

规划（摊销：2 次调用 3,954 tok）+ 检索注入（按线预算）+ 模型调用（首试/修复分记，失败照记）
+ 程序开销（merge/打捞/评分毫秒级，零 token 但入账）+ 恢复重试（D 臂）。复用记 0 新增但完整
成本口径计历史真实支出；价格 UNKNOWN（订阅制），token 为成本基数。端到端时延仅同会话可比。
