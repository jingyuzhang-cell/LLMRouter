## 2. 最小真实试验设计（单 VAL 事件=元道退；小语料 ~6.7K 字）
臂：A 单强模型 / B 固定 DAG / S5 固定局部恢复（配对故障） / S6 联合调度（配对故障）；
先 clean 后一个预注册故障（t_extract 节点 model_unavailable，种子=sha256(event+node)）。
- A：1 次（证据 ~4.5K tok 入 + 2K 出）≈ **6.5K**
- B：5 节点（index 0.9 + extract 1.6 + branch 1.7 + verify 1.8 + report 1.3 ≈ 7.3K）+ 规划摊销
  （复用冻结图结构模板：0 新增；若现场规划 +3K）≈ **7.3-10.3K**
- S5/S6 故障配对各一次：B + 恢复闭包重跑（≈4-5K）≈ **各 12-15K**
- **合计 ≈ 40-48K token / 15-18 次调用**；上限建议：**20 次调用 / 保证线 60,000**
  （含 P95 与一次修复余量）。
- 产物：四臂 Q/C/L（Silver 评分）+ S6 真实决策日志 + 能力表首批实测点 + 预算 V2 校准数据。
  结果用于协议修复（VAL 用途），不宣称测试集优势。
