## 二、核心发现

1. **复杂事件上 DAG 也未显示质量优势**：0.43 < 0.57（两臂在不同层被截断低估——A 在报告层、
   B 在提取层，方向性结论一致）。叠加舜天（Q 持平、单模型 1/4.5 成本）：**两个事件均未出现
   DAG 质量优势；单模型在两事件上成本均更低**。
2. **DAG 链是"提取约束型"**：终报 Q ≡ 提取层 Q（3/7 完全一致）——链路忠实地保真了提取层，
   但没有从同一材料合成出提取层未捕获的事实（A2 罚款 60 万、A6 十年禁入为单模型直接报告
   捕获而提取节点漏采）。且引用正确率沿链衰减（1.0→0.33，doc 级引用与 seed 证据文档错配）。
3. **正面行为数据**：B 臂对无法确认项纪律良好（第二次立案事由标 UNRESOLVED、两份告知书
   金额不一致被显式标出）；A 臂 chunk 级出处可复核。
4. 方法论：四次同型截断事故的系统性修复（输出预算预检规则）在本次 B 臂下游生效（全链无截断），
   ArmA 在 1,536 仍截断——单模型大证据报告需要 ≥2,048。
