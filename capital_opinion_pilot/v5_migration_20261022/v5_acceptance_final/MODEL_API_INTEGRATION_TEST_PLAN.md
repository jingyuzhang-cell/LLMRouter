## 目的

## 每模型 3 次调用（合计 6 次）
| # | 测试 | 通过标准 |
|---|---|---|
| 1 身份与计量 | 1 次 chat：固定 20 字问题 | 返回 usage（prompt/completion tokens）非零；记录确切模型版本串；时延 |
| 2 JSON 契约 | 1 次：facts 型节点提示（与筛选同模板、输出上限 2,048） | 首试解析为合法 JSON 且端口匹配（失败则记录并测 1 次打捞） |
| 3 长度预检 | 1 次：要求 ~40 条事实的富输出 | 实测输出 token 分布 → 确定 2,048 上限对该契约是否足够（不足则筛选前改契约拆分） |

错误处理验证（零额外调用，构造注入）：401（错 key）、429（限流）、5xx 各一次的
重试/记录行为（不自动补跑，只记录）。
