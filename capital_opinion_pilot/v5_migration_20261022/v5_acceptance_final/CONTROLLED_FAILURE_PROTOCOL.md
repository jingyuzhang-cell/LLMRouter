# CONTROLLED_FAILURE_PROTOCOL — 强基线与失效注入协议（v1.0，冻结）

## 1. 六策略对照（同一事件/证据/故障种子/总预算下配对）
| # | 策略 | 排除的解释 |
|---|---|---|
| S1 | 单强模型 + 单模型回退（同模型重试一次） | 跨模型回退本身 |
| S2 | 静态 DAG（固定分配，无恢复；失效→链路 INCOMPLETE） | DAG 结构本身 |
| S3 | DAG + 固定重试（原模型重执行受影响闭包） | 普通重试 |
| S4 | DAG + 固定模型切换（换模型重执行闭包，= 旧 D 臂） | 简单 Reroute |
| S5 | DAG + 固定局部恢复（Z=LOCAL、最小 R、固定 π） | 局部重执行机制本身 |
| S6 | DAG + 联合动态恢复（a=(Z,R,π) 两阶段决策器） | —（待证增量） |

**RQ2 成立判据（预注册）**：S6 在配对比较中同时优于 S5（决策维度价值）与 S4（联合性价值），
事件级聚类 Bootstrap CI 不含 0；否则如实报告无增量。

## 2. 失效条件（预注册四态）
| 状态 | 注入方式 | 性质 |
|---|---|---|
| clean | 无 | — |
| contract_fail | 强制节点输出契约不合法（注入损坏输出，模型照常计费执行后由注入器替换） | 节点异常 |
| model_unavailable | 传输级：规划模型该节点调用返回 503（零 token） | 执行实例失效 |
| timeout | 节点服务时延注入 > 节点级上限 | 执行实例失效 |
故障种子按 `sha256(event+node+seed)` 绑定节点位置，三种子/事件；**节点异常 vs 实例失效在
日志中分列统计**。故障注入是实验处置（零/低成本），恢复执行与评分全部真实。

## 3. 金盲规则（强制）
运行时（调度器/执行器/恢复决策）只可见：DAG 状态、故障信号、预算/时延、冻结的节点级历史
能力表（RQ1 产物）。**任何运行时组件不得读取 gold/、评分器输出或 silver**；测试断言加载器
白名单。评分仅离线事后。

## 4. 公平性硬约束
同事件同证据包（冻结 SHA）；同输出上限（2,048）；同总预算与截止（每策略 B/T 相同，
含调度器自身开销）；端到端墙钟含调度决策耗时（单独列账）；缓存复用记 0 新增但完整成本
口径计历史真实支出；价格 UNKNOWN_CASH+token 单列（或接入按量端点后用真实价）。
