## 核心算法与选择规则

1. **Z与R**：NONE只在没有必须修复输出、输入指纹/合同失效或待强制核验时允许；LOCAL为所有必需根与确认异常的模型节点依赖闭包。遍历闭包时穿过确定性汇合，修复旧V5在`m`处中断的问题。EXPAND的额外根必须有非满接地检查或明确异常记录，且对额外根再次闭包，不能漏掉受影响下游。FULL保留为所有模型节点方案；闭包外工作缺乏证据时记录拒绝。若FULL与其他动作具有相同R和π，则它们可能只是等价执行方案，不凭标签奖励FULL。
2. **VERIFY**：独立注解，需要明确冲突目标及证据引用；不替代缺失/合同失效输出的修复，不无故失效健康缓存。核验本身有独立模型成本和时延，未知核验收益保持不可识别。输出交由独立反馈接口解释，不自动把模型判断当真值。
3. **π**：逐R枚举调用者提供的模型池，过滤不可用、阻塞和不兼容项。缺Token成本、保守时延或受约束的现金计价时拒绝，不能用默认值冒充已知。现金按币种分别过滤，不相加CNY与USD，也不在本轮虚构汇率。预留剩余待执行节点开销；显式计入调用者提供的规划/切换开销。执行器另实测规划耗时并在调用前复核剩余截止期。
4. **质量**：完整计划交给任务级估计器（保留缓存、失效缓存、重执行、待执行、注解、下游变化）；不再对节点Q取最小值。只有标明`terminal_calibrated`的终端估计才能满足`terminal_q_min`。历史事实代理只写`diagnostic_q_proxy`，正式执行强制禁用代理目标。未知Q为null；没有独立终端估计时只能在明确允许的情况下按成本/时延选择，若设置质量下限则拒绝执行。
5. **联合评价**：先硬过滤，再在可比较的已识别质量/现金维度内做Q/C/L Pareto；不制造已知与未知质量间的支配关系。前沿中按“已识别终端质量、冻结加权效用、较小R、稳定Z和π字典序”选择。默认Token/时延权重仍为`2e-5`、`0.01`，可由状态提供；没有给扩大集合额外质量分。
6. **审计与执行**：所有候选含Z/R/π、预测质量及来源、增量Token、分币种现金、关键路径、拒绝原因、Pareto标记和实际执行槽位。未执行候选的实际值保持null；选定动作保存实际回调结果、输入指纹与计量。合同失败、计量未知或超限立即停止，不让非法输出继续下传。已知失败调用计量仍累计；无法计量的失败总费用与Token为null，并另列已知已结算部分，不能记成零费用。

历史代理目标仅在`allow_proxy_objective=True`的研究兼容单元测试中保留，目的是重现原断言；`V5RecoveryExecutor`会强制关闭。该开关不是终端质量验收或性能收益证据。

## 质量公式核对

实际源码的公式是两个分项之和，不是把一个乘积算成14.47：

```
t1保留缓存：15 × 0.29 = 4.350
t2重新执行：0.964 × 15 × 0.70 = 10.122
总期望接地链事实数：4.350 + 10.122 = 14.472
```

原代码乘法本身正确，旧报告存在漏写保留缓存项的解释问题；已有`S6_V5_DECISION_GATE.md`也记载此更正，本轮不覆盖该报告。新增[机器可读分项核对](v5_migration_20261022/QUALITY_FORMULA_CHECK.json)，日志包含公式、分项、总值、样本数和来源。**14.472是历史代理下的期望事实数，不是[0,1]终端准确率，不是联合优化优势。** 无终端校准时正式候选的终端Q继续null。
