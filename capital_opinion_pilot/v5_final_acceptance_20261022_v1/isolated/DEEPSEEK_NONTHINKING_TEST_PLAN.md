# DEEPSEEK_NONTHINKING_TEST_PLAN — 关闭思考模式的配对验证（设计方案，待授权）

## 条件
- 模型：deepseek-flash
- 输入：与原 T2 **完全相同**（同一证据片段、同一系统提示、同一用户提示——逐字节一致）
- 目标：**30–40 条原子事实**（与 qwen T2 相同工作量，不降低）
- 输出上限：2,048 Token
- 思考模式：**显式关闭**（`extra_body: {"thinking": {"type": "disabled"}}`）
- 对照组：原 T2（思考模式默认开启，out=2,048 全推理，content=空）

## 预算估算（逐调用重算）
- 输入：与 T2 相同 ≈ **252 token**
- 输出：上限 2,048（无推理开销 → 全部用于 JSON 内容）
- 保守总计：**≤2,400 token**
- 费用上界（峰价 $0.30/M 入 + $1.20/M 出）：252×0.30/1e6 + 2048×1.20/1e6 = **$0.00254 ≈ ¥0.018**
  （谷价约减半 ≈ ¥0.009）
- 硬上限：**1 次调用 / 2,500 token / ¥0.025**

## 通过标准与后续动作

| 结果 | 判定 | 后续 |
|---|---|---|
| 完整输出（stop≠length）+ JSON 合法 + ≥20 条 | PASS | 非思考配置纳入筛选协议 |
| 完整输出但事实数 < 20 或质量明显下降 | PARTIAL | 保留双模式数据；不只用成本定结论 |
| 仍截断（stop=length） | FAIL | 评估更大输出上限或分块提取（公平标准不变） |
| JSON 契约失败（content 非空但不可解析） | FAIL | 暂缓 DeepSeek 入正式池，修接口或输出契约 |
